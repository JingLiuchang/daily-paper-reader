## 摘要
基准测试主要根据语言模型智能体是否到达正确的最终状态来评判，而不是根据其如何到达。端点评分无法区分以下情况：一个智能体恰好检索到决策所需的证据，而另一个智能体读取了环境的大部分内容；也无法区分一个从未定位到证据的智能体与一个仅差一个动作就停止的智能体。解决这一问题需要参考成本，而人工编写的解决方案只能证明任务可解，不能证明不存在更短路径。我们提出 DetourBench，它约束环境直至该最小值可计算。每个任务都是一个有限的部分可观测转移系统，其访问具有单位成本，且资源在被发现后可在全局范围内寻址。穷举搜索可得到全信息最小动作数 $L_0$ 及可重放的见证；从图可恢复的终止状态出发，它还可得到精确剩余工作量 $R_T$，从而将仅差一次访问而停止的回合与发生游走的回合区分开，而不可逆的错误承诺会被记录为不存在有限剩余距离，而不是被赋予一个有限剩余距离。成功率、达成度、剩余进展和归一化绕行度分别报告。在 375 个已评分回合中——五个模型端点、25 个集成任务、三次重复——成功率范围为 58.7% 到 96.0%，而条件达成度范围为 0.803 到 0.890，并且对模型的排序不同。在可恢复失败中，剩余工作量可将接近完成的轨迹与代价高昂的未完成以及不可逆承诺区分开。我们在 https://github.com/DatagridsAI/DetourBench 开源了实例、oracle 见证和评估工具。

## Abstract
Benchmarks judge language-model agents mainly by whether they reach the correct final state, not by how they got there. Endpoint scoring cannot separate an agent that retrieved exactly the evidence a decision required from one that read most of the environment, nor an agent that never located the evidence from one that stopped a single action short. Settling this needs a reference cost, and authored solutions establish only that a task is solvable, not that no shorter route exists.   We present DetourBench, which constrains the environment until that minimum is computable. Each task is a finite, partially observable transition system with unit-cost accesses whose resources become globally addressable after discovery. Exhaustive search yields the full-information minimum action count $L_0$ with a replayable witness; from graph-recoverable terminal states it also yields exact residual work $R_T$, which separates an episode that stopped one access short from one that wandered, while an irreversible wrong commitment is recorded as having no finite residual distance rather than assigned one. Success, attainment, residual progress, and normalized detour are reported separately. Across 375 scored episodes --- five model endpoints, 25 integrated tasks, three repeats --- success ranges from 58.7% to 96.0% while conditional attainment ranges from 0.803 to 0.890 and orders the models differently. Among recoverable failures, residual work separates near-complete trajectories from costly incompletion and from irreversible commitment. We open-source the instances, oracle witnesses, and evaluation harness at https://github.com/DatagridsAI/DetourBench.

## 一、核心问题与研究动机

- **端点评分的根本盲区**：现有交互式智能体基准主要以“是否到达正确最终状态”判定成败，无法区分“恰好检索到决策所需证据”与“几乎读遍环境”的成功路径，也无法区分“从未找到证据”与“只差一个动作”的失败路径。
- **缺少可辩护的参考成本**：要衡量路径效率，必须有一个参考最优成本；人工编写的参考解只能证明任务“可解”，不能证明“不存在更短路径”。按工具价格加权的评估又需要额外假设工具的相对成本。
- **论文目标**：提出 **DetourBench**，通过约束环境使精确最小动作数可计算，从而在轨迹层面同时报告成功、相对 oracle 的达成度、剩余进展、归一化绕行度与不可逆失败。
- **整体含义**：把评估从“结果对不对”推进到“路径是否必要、失败离成功多远、是否已不可挽回”，为交互式智能体提供一种可证明、可回放的诊断性测量契约。

## 二、方法论

### 1. 核心思想

- 将每个任务建模为**有限、部分可观察的转移系统**，访问成本统一为单位成本；资源一旦被发现，其标识符即可全局直接寻址，不产生导航或回溯成本。
- 在该受限语义下，对完整转移图做**穷举搜索**，可精确求出全信息最小动作数 \(L_0\)，并生成可重放的最短路径见证。
- 对未完成但仍是“图可恢复”的终态，计算**精确剩余工作量 \(R_T\)**；对吸收性的错误承诺，则明确记为“无有限剩余距离”，而不是强行赋一个数。

### 2. 转移与执行语义

- 状态定义为三元组 \(s_t=(V_t,K_t,z_t)\)：已访问资源集合、已获得凭证集合、结果标志（active / success / wrong）。
- 每个动作有源资源、资源前置条件和凭证前置条件；只有前置条件满足时动作才可用。
- 智能体每轮可发出有序动作批次，环境顺序调度，直到批次结束、预算耗尽或进入终止状态。
- **计费规则**：所有到达环境调度器的访问都计入成本 \(C_\tau\)，包括无效、禁用、重复访问；纯模型响应不计费。成本按“已调度访问数”而非模型轮数计算。
- 任务终止条件包括成功、吸收性错误承诺、访问预算耗尽、模型轮数上限或显式提交。

### 3. 精确 oracle 与残差

- 对成功状态集合 \(G\) 做广度优先搜索，求 \(L_0=\min_{\tau:s_0\to G} C_\tau\)，并由前驱图生成最短成功轨迹 \(\tau_o\)，在与模型回合相同的转移函数下重放验证。
- 对终止于 active 状态的回合，定义 \(R_T=d^*(s_T,G)\)，即从该状态到成功所需的最少后续访问数。
- 由于资源与凭证单调增长，且一次性动作是终止性的，所有 active 终态均图可恢复，因此满足 \(0\le R_T\le L_0\) 且 \(C_\tau+R_T\ge L_0\)。
- 成功回合 \(R_T=0\)；吸收性错误承诺不赋予有限残差。

### 4. 轨迹指标

- **条件达成度**：成功时 \(A_\tau=L_0/C_\tau\)，失败时未定义；衡量成功路径相对全信息最小值的效率。
- **剩余进展**：\(P_\tau=1-R_T/L_0\)，用于成功或可恢复未完成回合。
- **归一化绕行度**：\(NDR_\tau=(C_\tau+R_T-L_0)/L_0\)，表示相对离线最优的额外交互量。
- **冗余访问率**：\(RSR_\tau=(I_\tau+D_\tau)/C_\tau\)，其中 \(I_\tau\) 为无效访问数，\(D_\tau\) 为不改变整体状态的合法重复访问数；失败回合不报告 RSR，以避免早期终止造成虚低。
- 成功、达成度、剩余进展、绕行度、冗余率和不可逆失败分别报告，不压缩为单一分数。

### 5. 预算与验证

- 每个实例声明信息完备见证长度 \(L_i\)，预算 \(B=\lceil m\max(L_0,L_i)\rceil\)，主实验固定 \(m=1.5\)；在发布套件中 \(L_i=L_0\)，实际 \(B=\lceil1.5L_0\rceil\)。
- 构建流程包含：源记录到图与前置条件的生成、移除审计、最短路径见证重放、图/oracle 哈希冻结。
- 四类门禁：机械有效性（schema 与见证重放）、构造有效性（来源溯源、结构移除审计、部分任务内容反事实）、生成有效性（唯一性、答案退化、配对完整性）、制品有效性（图、oracle、提示、指标、评测器、预算冻结且哈希一致）。
- 分析对版本或哈希不匹配、运行时预算变更、模型–任务–重复单元不完整等情况**失败关闭**。

## 六、主要结论与发现

- **端点评分确实掩盖效率差异**：在 8 个所有模型所有重复均成功的任务上，模型间条件达成度差距为 0.074–0.190；任务 3 中最好与最差模型均无重复/无效访问（RSR=0），但达成度相差 0.189，说明“合法但非必要的探索”只能被 oracle 相对指标捕捉。
- **成功率与效率排序不一致**：集成套件成功率 58.7%–96.0%，条件达成度 0.803–0.890；GLM 成功率最低，但条件达成度高于 DeepSeek 和 Qwen；按任务平均或限制到全模型均解任务，GLM 仍居第三。作者对 Qwen 与 DeepSeek 的差异不做排序。
- **受控干预有效且可测**：删除一句提示使“时点视图”使用率下降约 63 个百分点、成功率下降约 41 个百分点，同时超范围阅读增加约 2.9 次/回合；在两臂
