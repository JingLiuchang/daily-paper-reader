## 摘要
基于图的近似最近邻搜索（ANNS）被广泛用于大规模语义搜索。其索引主要基于输入数据集（例如文档或图像）的嵌入之间的几何关系构建，而不是显式地针对语义相关性进行优化。然而，当使用这些索引进行下游查询检索时，性能是根据检索结果与查询的语义相关性来评估的。这在索引的构建方式与其检索结果的评估方式之间造成了一种根本性的“几何-语义”不匹配。尽管现有的基于LLM的重新排序方法可以在查询时部分缓解这种不匹配，但它们并未解决图中这一潜在的结构性问题。因此，我们提出LLM引导图剪枝（LLM-Guided Graph Pruning, LGP），这是一个通用框架，通过利用LLM推理来改进现有ANN图索引本身，从而直接解决这种不匹配。LGP识别节点在结构上“低价值”的邻居，并将其替换为LLM选择的替代邻居，这些替代邻居在提供有用语义信息的同时，保留原图所需的几何结构，包括稀疏性和高效可导航性。在代表性语义检索基准上的实验表明，在DiskANN和HNSW等广泛使用的基于图的ANN索引上，LGP相较于普通贪心图搜索和基于LLM的重新排序，均能持续提升端到端检索性能。

## Abstract
Graph-based approximate nearest neighbor search (ANNS) is widely used for large-scale semantic search. Its indices are constructed primarily based on geometric relationships among embeddings of an input dataset (e.g., documents or images), rather than explicitly optimizing for semantic relevance. However, when using these indices for downstream query retrieval, performance is evaluated based on the semantic relevance of the retrieved results to the query. This creates a fundamental "geometry-semantic" mismatch between how the indices are constructed and how their retrieval results are evaluated. While existing LLM-based reranking methods can partially mitigate this mismatch at query time, they leave this underlying structural problem in the graph unresolved. We therefore propose LLM-Guided Graph Pruning (LGP), a general framework that addresses this mismatch directly by leveraging LLM reasoning to refine an existing ANN graph index itself. LGP identifies structurally "low-value" neighbors of nodes and replaces them with LLM-selected alternatives that provide useful semantic information while retaining desired geometric structures of the original graph, including sparsity and efficient navigability. Experiments on representative semantic retrieval benchmarks show that LGP consistently improves end-to-end retrieval performance over both vanilla greedy graph search and LLM-based reranking across widely used graph-based ANN indices such as DiskANN and HNSW.

## 1. 核心问题与整体含义
- **核心问题**：基于图的近似最近邻搜索（ANNS）索引主要按嵌入空间几何关系构建，例如 DiskANN、HNSW 通过向量距离选择邻居；但下游检索效果按“语义相关性”评估。这形成根本性的“几何—语义错配”。
- **错配后果**：在有限搜索预算下，贪心图搜索可能优先访问几何近但语义弱相关的文档，遗漏真正相关文档；查询时 LLM 重排只能缓解，无法恢复初始候选集中未出现的相关文档。
- **整体含义**：论文主张将 LLM 推理从“查询时重排”前移到“索引构建/离线图精炼”阶段，直接修改 ANN 图结构，使局部邻域同时保持几何可导航性与语义信息量。

## 2. 方法论：LLM-Guided Graph Pruning（LGP）
- **核心思想**：在已有 ANN 图上做离线局部边剪枝与替换。识别结构上“低价值”的邻居，用 LLM 选择的、能补充语义信息且不破坏稀疏性/可导航性的候选邻居替换。
- **局部替换候选构造**：
  - 复用原索引已有候选集 \(U_i\)，并加入有向二跳非邻居：
    \[
    T_i=\left(\bigcup_{v_j\in N(i)}N(j)\right)\setminus\{v_i\},\quad
    U_i=(U_i\cup T_i)\setminus(N(i)\cup\{v_i\})
    \]
  - 候选集控制为局部范围，避免全图 LLM 评估。
- **无 LLM 短名单**：对每个候选 \(v_c\) 计算三类结构信号：
  - 距离 \(\delta_i(c)=D(v_i,v_c)\)；
  - 额外二跳覆盖 \(g_i(c)=|N(c)\setminus T_i|\)；
  - 与当前邻域的最小距离 \(\nu_i(c)=\min_{v_j\in N(i)}D(v_c,v_j)\)，越大越不冗余。
  - 按距离升序、覆盖降序、分离度降序各取约 \(M/3\)，合并成最多 \(M\) 个候选。
- **LLM 语义选择**：
  - 输入 anchor 文档、少量当前邻居上下文 \(K\)（如 \(K=4\)）、短名单候选文档。
  - 要求 LLM 选择最多 \(B\) 个能补充语义、扩展而非重复当前邻域的候选；不基于措辞相似，返回编号或 NONE。
- **局部边替换**：
  - 候选需满足最低额外二跳覆盖阈值 \(g_{\min}\)。
  - 若当前度未满，直接加入；否则删除一个低价值原邻居。
  - 低价值邻居通过“唯一二跳贡献”和“冗余度”字典序最小化确定，即优先删除局部覆盖贡献小且与其余邻居冗余的边。
- **索引实例化**：
  - **DiskANN**：第二遍构建中，在 RobustPrune 后应用 LGP，复用 GreedySearch 候选；新边按 DiskANN 规则做 reciprocal insertion。
  - **HNSW**：对已构建 HNSW 的 base layer 做离线精炼，复用 hierarchical search 候选；上层结构、节点层级、入口点不变，base-layer 度数保持不变。
- **关键性质**：查询时仍使用标准贪心搜索，不增加查询时 LLM 调用；只改变离线图结构，保持稀疏性与可导航性。
