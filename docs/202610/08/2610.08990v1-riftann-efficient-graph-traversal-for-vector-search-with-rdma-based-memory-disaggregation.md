## 摘要
面向十亿规模向量集合的图索引可能超出单台服务器的 DRAM 容量。基于 RDMA 的被动式解聚内存无需内存节点参与计算即可提供可扩展的容量，但传统的最佳优先搜索在此场景下表现不佳。细粒度且不必要的远程读取会增加通信开销，而候选评估与后续扩展之间的依赖关系会使遍历串行化，并导致 CPU 空闲。我们提出 RiftANN，一种面向基于 RDMA 的被动式解聚内存的基于图的近似最近邻搜索（ANNS）系统。RiftANN 在计算节点使用紧凑向量进行导航，并利用根据观测到的近似误差校准的阈值，选择性地验证精确向量。一个有界单边 RDMA 流水线将剩余的远程访问批量处理，并与本地处理重叠。RiftANN 并行评估返回的邻居，并增量地纳入已完成的结果。一个影响门控估计未完成的评估是否会改变候选集：当其预期影响较小时允许遍历继续，同时防止因不完整的搜索状态而进行不安全的推进。一个轻量级反馈控制器在搜索配置和查询负载变化时，协调 RDMA 并发度与后台评估能力。我们在 100M 规模的 SIFT、DEEP 和 SPACEV 以及 SIFT1B 上评估 RiftANN。在相同召回率下，RiftANN 相比 DistVS 实现了 1.6 倍至 4.3 倍的延迟加速和 1.1 倍至 2.2 倍的吞吐量提升，相比基于 SSD 的 DiskANN 和 PipeANN 实现了 1.6 倍至 5.6 倍的延迟加速。这些结果表明，被动式解聚内存可以在内存节点无需查询时计算的情况下支持低延迟的基于图的向量检索。

## Abstract
Graph indexes for billion-scale vector collections can exceed a single server's DRAM capacity. Passive RDMA-based disaggregated memory provides scalable capacity without memory-node computation, but conventional best-first search performs poorly in this setting. Fine-grained and unnecessary remote reads increase communication cost, while dependencies between candidate evaluation and subsequent expansion serialize traversal and leave CPUs idle.   We present RiftANN, a graph-based approximate nearest neighbor search (ANNS) system for passive RDMA-based disaggregated memory. RiftANN navigates using compact vectors at compute nodes and selectively verifies exact vectors using a threshold calibrated from observed approximation errors. A bounded one-sided RDMA pipeline batches and overlaps the remaining remote accesses with local processing. RiftANN evaluates returned neighbors in parallel and incrementally incorporates completed results. An impact gate estimates whether unfinished evaluations may change the candidate set, allowing traversal to continue when their expected influence is small while preventing unsafe advancement from incomplete search state. A lightweight feedback controller coordinates RDMA concurrency with background evaluation capacity as search configurations and query loads change.   We evaluate RiftANN on SIFT, DEEP, and SPACEV at 100M scale and SIFT1B. At matched recall, RiftANN achieves 1.6x to 4.3x latency speedups and 1.1x to 2.2x higher throughput than DistVS, and 1.6x to 5.6x latency speedups over SSD-based DiskANN and PipeANN. These results show that passive disaggregated memory can support low-latency graph-based vector retrieval without query-time computation at memory nodes.

## 2. 方法论：核心思想与关键技术

- **整体架构**
  - 内存节点存储统一图记录：每条记录包含精确向量和邻接表。
  - 计算节点执行查询：主线程驱动闭环搜索，后台 worker 池并行评估邻居，反馈控制器动态调节 RDMA 窗口与 worker 配额。
  - 三大组件：
    - Calibrated One-Sided Search Pipeline
    - Impact-Aware Asynchronous Traversal
    - Feedback-Driven Pipeline Balancing

- **Calibrated One-Sided Search Pipeline**
  - **状态驱动远程操作**：根据候选状态决定读取字段，支持三种模式：
    - Expand-and-verify：同时取精确向量和邻接表。
    - Verify-only：只取精确向量，用于未扩展但可能进入 top-k 的候选。
    - Expand-after-verification：只取邻接表，用于已验证候选后续扩展。
  - **误差校准精确验证**：
    - 用紧凑本地表示估计距离，导航图搜索；仅对可能影响最终 top-k 的未扩展候选读取精确向量。
    - 一旦已有至少 k 个精确距离，设 τ 为当前第 k 小精确距离。
    - 校准因子 α 由离线 held-out 查询得到：
      - α = max(1, Q_{1-δ}( d̂(v,q) / d(v,q) ))
      - 其中 Q_{1-δ} 是近似/精确距离比的经验 (1-δ) 分位数。
    - 运行时验证条件：若 d̂(v,q) ≤ ατ，则触发 Verify-only。
    - 该保证条件依赖于候选被发现；图遍历决定发现哪些候选，校准决定验证哪些候选。
  - **异步单边 RDMA 执行**：
    - 每查询维护有界在途窗口 W_R，批量发出单边 RDMA 读。
    - 支持 doorbell chaining、selective signaling 等优化。
    - 请求发出前重新验证，过期请求丢弃；同一候选的扩展与验证请求可合并为整记录读。

- **Impact-Aware Asynchronous Traversal**
  - 目标：并行评估邻居，同时避免在候选集严重不完整时继续扩展。
  - 共享 worker 池评估返回邻居，主线程增量合并已完成结果。
  - **估计隐藏候选集更新**：
    - 用最近 H 个已完成评估的候选插入比例作为更新概率：
      - ρ_q = (1/H) Σ x_i，x_i=1 表示该评估插入了候选。
    - U_q 为尚未返回的未完成评估数。
    - 估计隐藏更新数：Ψ_q = ρ_q U_q。
  - **影响门控扩展**：
    - 仅当 Ψ_q ≤ ε 且 U_q ≤ U_max 时允许下一次扩展。
    - 默认 H=64，ε=1，U_max=128。
    - 搜索前期更新概率高，门控保守；后期更新概率低，允许更多未完成评估并行。
  - 终止前会排空未完成评估，并重新检查导航与验证条件。

- **Feedback-Driven Pipeline Balancing**
  - 将远程读取视为生产者，候选评估视为消费者。
  - 每查询有两个控制旋钮：
    - RDMA 窗口 W_{R,q}：控制任务生成速率。
    - worker 配额 T_q：控制任务处理速率。
  - 定义 defer ratio：
    - r_q = N_deferred,q / max(N_generated,q, 1)
  - 控制策略：
    - r_q > θ_high：计算压力高，优先增加 worker；若不可用则减少 RDMA 窗口。
    - r_q < θ_low：计算压力低，优先释放 worker；否则增加 RDMA 窗口。
    - θ_low 与 θ_high 之间保持平衡区，提供迟滞。
    - 默认阈值约 0.30 与 0.65，控制间隔约 32 次扩展完成。
