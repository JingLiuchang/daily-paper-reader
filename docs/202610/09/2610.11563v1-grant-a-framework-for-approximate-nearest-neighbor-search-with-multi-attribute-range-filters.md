## 摘要
近年来，学术界和工业界已开始考虑带过滤器的近似最近邻搜索（ANNS）问题。在该设定下，每个对象由一个高维向量和若干属性值组成。给定查询向量、针对属性值的过滤器以及 k，该问题会在通过过滤器的对象集合中检索与查询向量近似最近的 k 个向量。本文考虑范围过滤器，即用户可为每个属性指定一个范围约束。大多数现有工作并未考虑这一设定，它们假设 (i) 仅有一个属性，或 (ii) 匹配过滤器要求相同的属性值或类别。针对这些假设的现有技术不适用于我们的设定，或者显然效率不高。尽管诸如前置过滤（pre-filter）和后置过滤（post-filter）之类的标准解决方案可以处理我们的问题，但它们同样效率低下。有些工作处理与我们相同的问题，但其技术需要历史查询负载，这显著限制了实际应用场景。为消除这些限制，本文提出 Grant，一种新颖的框架，可在接受任意范围过滤器和 ANNS 数据结构的同时高效解决该问题。Grant 能够保证搜索时间相对于对象数量呈亚线性，这是现有技术所不具备的。我们进行了大量实验，结果表明 Grant 优于现有技术。

## Abstract
Recently, academia and industry have considered the problem of approximate nearest neighbor search (ANNS) with filters. In this setting, each object consists of a high-dimensional vector and attribute values. Given a query vector, filters for attribute values, and $k$, this problem retrieves $k$ vectors approximately nearest to the query vector among a set of objects passing the filters. This paper considers range filters, i.e., users can specify a range constraint for each attribute. Most existing works do not consider this setting, and they assume (i) only a single attribute or (ii) matching filters that require the same attribute values or categories. Existing techniques for these assumptions are not available for our setting or are trivially not efficient. Although standard solutions, such as pre-filter and post-filter, can handle our problem, they are also inefficient. Some works tackle the same problem as ours, but their techniques necessitate historical query workloads, which significantly limit practical use cases. To remove these limitations, this work proposes Grant, a novel framework that solves this problem efficiently while accepting arbitrary range filters and ANNS data structures. Grant can guarantee a search time sub-linear to the number of objects, which is not held by existing techniques. We conduct extensive experiments, and their results demonstrate that Grant outperforms existing techniques.

## 1. 核心问题与研究动机

- **问题背景**：现代搜索引擎与 RAG 等应用广泛使用高维向量嵌入。带属性过滤器的近似最近邻搜索（ANNS with filters）在学术界（Filtered-DiskANN、ACORN、CAPS 等）和工业界（Alibaba、Apple、Microsoft）都受到重视。典型场景如电商中"在满足价格/评分/生产日期约束的商品中找最相似商品"，或 RAG 中"检索年龄 40–50 岁、血压≥140 的相关资料"。
- **核心问题**：本文研究**多属性范围过滤器**下的 ANNS——每个对象含高维向量与 m（≥2）个属性值，查询给定向量 q、m 个范围过滤器 F = {[l₁,u₁],…,[lₘ,uₘ]} 与 k，需在满足 F 的对象集合 X(F) 中返回近似最近的 k 个对象（以 recall@k 衡量精度）。
- **现有工作的四大局限**：
  1. **单属性假设**：多数工作假设每个对象仅有一个属性，无法处理多属性。
  2. **仅支持匹配过滤器**：多数方法处理的是等值/类别匹配过滤，扩展到连续范围需无限次迭代，不可行。
  3. **依赖历史查询负载**：HQI、SIEVE 等需用历史查询过滤器构建索引，无历史负载则退化为 Post-filter，严重限制实用性。
  4. **向量数据库通用但低效**：Milvus、NaviX、ADBV 本质上是 Pre-filter 或 Post-filter，未针对该问题优化。
- **整体含义**：本文旨在提出一个**无需历史负载、可处理任意多属性范围过滤器、兼容任意 ANNS 数据结构、且具亚线性时间保证**的高效通用框架。

## 2. 方法论

### 2.1 核心思想
- **Grant = Graph in tree index**：把**基于属性值构建的树索引**与**基于高维向量的图索引**结合。树结构负责按属性范围快速定位，图索引负责在候选对象中做向量近邻导航，从而"只访问既满足 F 又与 q 相似的对象"。
- 关键洞察：单纯用树 = Pre-filter（|X(F)| 大时慢）；单纯用图 = Post-filter（需访问大量不满足 F 的对象）。二者结合可同时避免两类低效。

### 2.2 结构构建（Algorithm 1: Build）
- 采用自顶向下建树，保证平衡；设常数超参 c（叶节点容量上限 n/c）。
- `Make-Node(Y, c)`：若 |Y| ≤ n/c，则该节点为叶节点，对其中的对象用**任意图索引**（如 HNSW）建图；否则按属性值对 Y 等分（`Split`）并递归建立左右子节点。
- 因树高为 O(log c) = O(1)、节点数为 O(c) = O(1)，故叶节点数量为 O(c) = O(1)。
- **复杂度**：构建时间 O(n(1+f(n))) + g(n)；空间 O(1) + S(n)（S(n) 为图索引空间）。

### 2.3 查询处理（Algorithm 2: Query）
- 步骤：① 在 Grant 上对 F 做范围搜索，得到与 F 重叠的叶节点集合 U；② 对每个 u ∈ U 运行图 ANNS，只保留满足 F 的对象，更新结果集 S。
- **理论保证**：
  - Lemma 1：算法时间为 T(n) + Õ(1)，其中 T(n) 为范围搜索时间。
  - **Theorem 1**：若基树结构用 kd-tree，则查询时间为 **O(n^(1−1/m))**，即关于 n **亚线性**——这是现有同问题方法所不具备的。
- 注：理论上主要开销是范围搜索，但**实践中主要开销是叶节点上的图 ANNS**。

### 2.4 启发式优化
- **概率节点验证（PNV，对应 Grant-pnv）**：定义 F 与叶节点 u 的重叠比 r(F,u) = max(V(F∩u)/V(F), V(F∩u)/V(u))，在局部均匀分布假设下估计有效候选数 ∝ (n/c)·r(F,u)。对每个 u，若 r(F,u) 大于 (0,1] 上的随机实数，才在该叶节点执行图 ANNS，从而跳过不太可能含真近邻的叶节点（仅当 |U| > O(k) 时启用）。
- **工作负载感知（WA-Grant，Algorithm 3）**：若有历史查询向量 P，则用图索引 G_P 找与 q 最近的 p_i，结合预处理矩阵 𝓜（记录每个 p 在每个叶节点的 ANNS 距离），只保留 d(p_i, ·) 最小的 O(k) 个叶节点做 ANNS。该优化可选、非必需。预处理时间与空间为 Õ(|P|n)。

## 3. 实验设计

- **数据集**（均为 1000 万规模的高维向量）：
  - Deep（96 维深度特征）、SIFT（128 维）、SPACEV（100 维学习型文档向量）、T2I（200 维 Yandex 视觉搜索向量）。
  - 属性值按**幂律分布**生成以贴近真实场景，默认 m = 2。
- **查询设置**：每数据集 100 个随机查询向量；l_j 随机采样自同分布，u_j = l_j + λ×域大小，λ ∈ [0.2, 0.8]，默认 λ = 0.2、k = 10，默认平均选择率约 0.15。
- **对比方法**：
  - 无需历史负载：BF（暴力精确）、Pre-filter（kd-tree，对应 Milvus）、IVF、Post-filter（HNSW，对应无历史过滤器的 SIEVE / VBase）、ACORN-1、Grant-basic、Grant-pnv。
  - 需历史负载：WA-Grant、SIEVE（在相同内存预算下比较）。
- **评测指标**：QPS vs. recall@10 曲线、索引时间、内存消耗、分解时间（范围搜索 vs. 图 ANNS）。
- **参数调优**：HNSW 网格搜索 M ∈ {8,16,32,64,128}、ef_construction ∈ {32,64,100,200,300}；baseline 取 M=64、ef=200，Grant 取 M=16、ef=64；IVF 用 1000 个聚类；Grant 设 c=150。

## 6. 主要结论与发现

- Grant 在四个数据集上**普遍优于现有最先进方法**，在 recall ≈ 0.9 时可在数毫秒内完成查询。
- **理论贡献**：用 kd-tree 作基树时，查询时间为 O(n^(1−1/m))，是现有同问题方法所不具备的亚线性保证。
- **实践瓶颈与优化**：分解时间表明瓶颈不在范围搜索（亚毫秒级），而在叶节点图 ANNS；Grant-pnv 相比 Grant-basic 提升约 **1.3–1.5×**，且不损失 recall。
- **索引与内存**：1000 万高维向量索引仅需 ≤ 1.5 分钟（60–97 秒），优于 IVF、Post-filter、ACORN；内存 < 约 10GB，低于 Post-filter/ACORN（约 10–13.7GB）。
- **WA-Grant vs. SIEVE**：在相同内存预算下 WA-Grant 的 QPS–recall 权衡更好；相比 Grant-pnv 在 recall@10=0.9 时**快 2 倍以上**，证明历史查询向量可有效加速。
- **ACORN 的失效**：k ≥ 20 或 m ≥ 3 时 ACORN 无法达到 ~0.9 recall，因其图遍历会丢失通往真近邻的路径。
- **参数趋势**：c 存在最优值（过大→重叠叶节点多，过小→单节点无效对象多）；Post-filter 对 m 敏感且随 m 增大性能下降，Pre-filter 随 m 增大反而改善（选择率降低）。

## 7. 优点

- **通用性强**：可接受任意多属性范围过滤器，兼容任意多维树索引（kd-tree、R-tree 等）与任意邻近图（HNSW、NSG、Vamana 等）。
- **无历史负载依赖**：结构可完全离线一次性构建，无需历史查询过滤器，实际可用性显著高于 HQI/SIEVE；历史查询向量仅作为**可选加速**。
- **有理论保证**：给出亚线性时间上界，弥补了现有同问题方法无时间界的空白。
- **构建高效**：树+图的组合结构简单，索引时间短（分钟级）、内存可控（<10GB），便于实际部署与批量重建。
- **结构创新明确**：重叠比驱动的概率跳过启发式是针对 Grant 结构特有的、低开销（O(1)）的有效优化。
- **实验较为扎实**：多数据集、多参数、多基线的系统评测，且给出分解时间以验证优化动机。

## 8. 不足与局限

- **静态数据集假设**：论文明确将动态数据（向量插入/删除）下的高效处理列为开放问题，仅建议通过批量重建应对动态场景。
- **小 m 假设**：方法依赖树结构在低维（属性数 m 小）时高效；若 m 很大，因维度灾难树索引性能会退化。作者认为真实场景（价格、评分、日期）通常 m 较小。
- **实验覆盖的局限**：
  - 查询数量仅 100 个，统计稳定性有限；
  - 属性分布固定为幂律，未覆盖其他分布（如均匀、相关属性）；
  - 默认 m = 2，虽然测试到 m = 4，但更高维属性场景未验证；
  - 未测试动态更新场景。
- **对比公平性风险**：SIEVE 被给予与查询完全一致的历史过滤器（不切实际但对其有利），而 WA-Grant 使用随机采样加高斯噪声的 1000 个历史向量，两者历史信息条件并不对等。
- **实现依赖**：理论 Lemma 1 依赖文献 [31] 的图索引结果，但实践中用 HNSW 作为其近似实例，理论保证与实际实现之间存在一定落差。
- **应用限制**：仅适用于内存型场景，磁盘型方法（SPANN 等）不在讨论范围；c 需调参，且最优 c 依数据集而变。
