## 摘要
大规模信息检索系统（包括检索增强生成（RAG）和推荐引擎）广泛使用多层层次化数据结构，以在高维向量空间中实现超快近似最近邻搜索。然而，确保贪心导航既准确又高效的几何条件仍鲜为人知。本文研究在 d 维环面 T^d 上由 n 个数据点构建的邻近图层次结构上贪心导航的效率。我们给出了一个确定性覆盖条件：在该条件下，对任意查询 q ∈ T^d，贪心搜索返回的点到查询的距离不超过其到最近点距离的 (1+ε) 倍。当数据服从齐次泊松过程、Hermitian 行列式过程或有界密度 Cox 过程时，只要 d = o(log n / log log n)，该覆盖性质即以高概率成立。在相同假设下，对固定查询，贪心跳数的期望为 O(exp(1/2 d log d + O(d)) log n)，从而在固定维度下得到对数级期望跳数。

## Abstract
Large-scale information retrieval systems, including retrieval-augmented generation (RAG) and recommendation engines, widely use multi-layered hierarchical data structures for ultra-fast approximate nearest-neighbor search in high-dimensional vector spaces. However, the geometric conditions that ensure accurate and efficient greedy navigation remain poorly understood. In this work, we study the efficiency of greedy navigation on a hierarchy of proximity graphs constructed from \(n\) data points on the \(d\)-dimensional torus~$\mathbb{T}^d$. We identify a deterministic coverage condition under which, given any query $q\in \mathbb{T}^d$, greedy search returns a point within $(1+\varepsilon)$-factor of the distance to the closest point. This coverage property holds with high probability when the data is distributed as a homogeneous Poisson process, a Hermitian determinantal process, or a bounded-density Cox process, as long as $d = o(\log n/\log \log n)$. Under the same assumptions, the expected number of greedy hops for a fixed query is \(O\!\left(\exp\!\left(\tfrac12 d\log d+O(d)\right)\log n\right)\), yielding logarithmic expected hop count in fixed dimension.

## 1. 核心问题与整体含义（研究动机与背景）

- **应用背景**：大规模信息检索系统（如 RAG、推荐引擎、图像匹配、机器人位置识别）广泛依赖**近似最近邻（ANN）搜索**。其中 HNSW（Hierarchical Navigable Small World）是主流方案：将数据组织为嵌套的邻近图层，从稀疏顶层向稠密底层逐层贪心导航，兼顾远距离跳跃与局部精化。
- **理论缺口**：尽管 HNSW 在实践中表现优异，但**保证贪心导航既准确又高效的几何条件仍不清晰**。已有工作表明：
  - 标准固定宽度束搜索（beam search）对任意查询可能无法给出有限近似保证；
  - 在精心构造的数据集上，实际 HNSW 实现即使二维欧氏空间也可能需检查常数比例的数据点。
- **本文目标**：在 d 维环面 $\mathbb{T}^d$ 上，为基于 HNSW 启发的层次邻近图建立**确定性的可导航性判据**，并刻画贪心搜索的精度保证与查询跳数代价，覆盖独立、排斥、聚类三类点过程输入。

## 2. 方法论

### 2.1 核心思想
- 提出一个**确定性覆盖条件（Coverage Class $\mathcal{C}_n$）**：只要层次结构满足该条件，贪心搜索就能对**任意查询、任意非空层、任意起始顶点**同时给出 $(1+\varepsilon)$ 近似保证。
- 进一步证明该条件对三类随机点过程以高概率成立，并给出跳数的期望上界。

### 2.2 关键技术细节

**（1）层次构造（Algorithm 1）**
- 输入：$X_0 \subset \mathbb{T}^d$，尺寸参数 $n$，保留概率 $\rho\in(0,1)$。
- 每点独立赋予几何高度 $H_x$，$\mathbb{P}(H_x \ge \ell)=\rho^\ell$，形成嵌套层 $X_\ell=\{x: H_x\ge \ell\}$，共 $L$ 层。
- 定义层密度尺度 $n_\ell=n\rho^\ell$，特征距离 $h_\ell=(\log n / n_\ell)^{1/d}$；顶层含对数数量点。

**（2）方向性多样化邻居（Directional Diversification）**
- 将单位球面 $S^{d-1}$ 划分为 $K$ 个角直径 $\le \omega$ 的扇区 $U_1,\dots,U_K$。
- 对每个顶点 $v$，先取最近 $m=\lceil C_{\text{pool}}\log n\rceil$ 个候选池 $P_\ell(v)$，再在每个**被占用的扇区**中选取最近的候选点作为出邻居 $N^+_\ell(v)$。由此保证每个方向都有边，且边长为 $O(h_\ell)$。

**（3）贪心查询（Algorithm 2）**
- 从顶层任一顶点出发，在当前层沿"使到查询距离严格减小"的出邻居移动；到达局部最优点后，将该点作为下一更稠密层的入口；逐层下降，返回第 0 层终点 $W_0$。

**（4）确定性覆盖条件（Definition 3.1）**
对每个 $v\in X_\ell$：
1. $B(v, r_{\text{cov}}h_\ell)$ 内至少有 $m$ 个同层点（保证边不长）；
2. 每个扇区 $C_j(v)$ 与候选池 $P_\ell(v)$ 相交非空（保证每个方向有可用边）。

**（5）主要理论结果**
- **定理 1（确定性 $(1+\varepsilon)$ 精度）**：若 $\omega<\omega_\varepsilon$，则对每个非空层 $\ell$、每个查询 $q$：
$$d(W_\ell,q)\le \min\{Bh_\ell,\ (1+\varepsilon)R_\ell(q)\},$$
其中 $R_\ell(q)$ 为层 $\ell$ 中到 $q$ 的最近距离；若 $q\in X_\ell$ 则可精确命中。证明核心是 **Lemma 6.2（进度引理，余弦定理）** 与 **Lemma 6.3（锥体下降）**：只要存在朝向查询方向的足够短边，贪心必能严格降低距离。
- **定理 2（三类点过程的精度）**：当 $d=o(\log n/\log\log n)$ 时，对**齐次泊松、Hermitian 行列式（DPP）、有界密度 Cox** 过程，覆盖条件以概率 $1-O(n^{-M})$ 成立。参数取 $K=\exp(O(d))$、$C_{\text{pool}}=\exp(O(d))$、$r_{\text{cov}},B=O(\sqrt d)$、$D=\exp(\tfrac12 d\log d+O(d))$。
- **定理 3（跳数）**：对固定或独立随机查询，
$$\mathbb{E}[T_{\text{tot}}]=O\!\left(\exp\!\left(\tfrac12 d\log d+O(d)\right)\log n\right),$$
固定维数下为**对数级期望跳数**。证明思路：每层终点在 $B(q,Bh_\ell)$ 内，跳数被该球内点数控制（命题 7.1 给出指数尾界），并利用 Palm 分布（Definition 6.4）验证三类过程的局部计数性质（Proposition 6.7）。

## 6. 主要结论与发现

- 存在一个**统一的确定性方向性覆盖条件**，它同时保证：
  - 贪心搜索对**所有查询、所有层、所有入口**的 $(1+\varepsilon)$ 近似精度；
  - 若查询恰为数据点，则可精确命中。
- 该条件对**齐次泊松、Hermitian DPP、有界密度 Cox** 三类过程在 $d=o(\log n/\log\log n)$ 下以概率 $1-O(n^{-M})$ 成立，覆盖独立、排斥、聚类三种点分布形态。
- **跳数期望**为 $O(\exp(\tfrac12 d\log d+O(d))\log n)$，固定维数下为对数级，说明"层次导航 + 方向性邻居"能同时获得精度与查询代价的理论保证。
- 实验证实：维度升高会使近似比与召回率变差，增大扇区数 $K$ 可缓解但增加计算开销；贪心路径的 route stretch 通常 $\le 1.5$，但可能显著长于最短路径；有限 $n$ 下覆盖率随 $K$ 快速下降，DPP 最稳、Cox 最差。
