## 摘要
稠密检索服务必须随着延迟、质量和内存预算的变化，在嵌入前缀维度和索引码率之间切换。针对每个码率单独调优量化器可获得最佳质量，但检索层此时需同时保存多个码流和量化器状态。我们提出俄罗斯套娃残差向量量化（Matryoshka Residual Vector Quantization, MRVQ），一种用于冻结嵌入的事后残差量化器。其最高码率编码可通过两种方式截断：丢弃残差阶段可降低码率，丢弃嵌入坐标可降低维度。因此，单一常驻产物即可服务于我们评估的每一对（维度，码率）。在 FiQA 和 NFCorpus、四个嵌入系列以及 {4, 8, 16} 字节编码上，MRVQ 是我们评估的 RAM 占用最低的设计。与三个分别训练的 QINCo2 索引相比，其内存占用少 17.8–22.0 倍；与精简的共享模型钢人方案相比，少 1.89–2.02 倍。这种节省并非没有代价：在 FiQA 上，逐码率的 QINCo2 的 nDCG@10 高 0.026–0.107。但在相同编码大小下，MRVQ 优于 PQ、OPQ 和 AdANNS-OPQ。我们还评估了一种低构建成本的 PCA-标量设计，其质量与 RaBitQ 及其扩展相当，而在中位数上拟合速度快 420 倍。最后，我们报告两个负面结果：QINCo2 在高码率下训练时会崩溃；一个排序界假设未达到其预先设定的接受标准。因此，MRVQ 是弹性检索的一种低内存工作点，而非普适的质量赢家。

## Abstract
Dense-retrieval services must switch among embedding-prefix dimensions and index bit rates as latency, quality, and memory budgets change. Tuning a quantizer separately for each rate gives the best quality, but the retrieval tier then holds several code streams and quantizer states at once. We introduce Matryoshka Residual Vector Quantization (MRVQ), a post-hoc residual quantizer for frozen embeddings. Its maximum-rate code can be truncated two ways: dropping residual stages lowers the rate, and dropping embedding coordinates lowers the dimension. One resident artifact therefore serves every (dimension, rate) pair we evaluate. Across FiQA and NFCorpus, four embedding families, and {4, 8, 16}-byte codes, MRVQ is the lowest-RAM design we evaluate. It uses 17.8-22.0x less memory than three separately trained QINCo2 indices, and 1.89-2.02x less than a lean shared-model steelman. The saving is not free: per-rate QINCo2 is 0.026-0.107 nDCG@10 better on FiQA. But MRVQ beats PQ, OPQ, and AdANNS-OPQ at matched code size. We also evaluate a low-build-cost PCA-scalar design that attains quality comparable to RaBitQ and its extension while fitting 420x faster at the median. Finally, we report two negative results: QINCo2 collapses when trained at high rates, and a ranking-bound hypothesis misses its pre-specified acceptance criteria. MRVQ is therefore a low-memory operating point for elastic retrieval, not a universal quality winner.

# MRVQ 论文总结

## 1. 核心问题与整体含义

- **背景**：稠密检索已成为 RAG 与 agentic 系统的一等组件。大规模语料下，文档嵌入与索引状态（而非查询编码器）往往主导常驻内存——768–1024 维 fp32 向量在索引前就占 3–4 KB。
- **两类弹性需求**：
  - **维度弹性**：利用 Matryoshka 表示的前缀维度，在检索质量与查询计算/带宽之间权衡；
  - **码率弹性**：改变文档码大小，在质量与存储之间权衡。
- **矛盾点**：为每个码率单独调优量化器可获最佳质量，但检索层需同时常驻多套码流与量化器状态，内存开销高。
- **核心问题**：能否用**单一常驻文档码**同时覆盖维度与码率两个轴？
- **定位**：MRVQ 是面向冻结嵌入的事后（post-hoc）残差量化器，目标是把「多个码率专用常驻产物」转化为「一个可双轴截断的码」。作者明确强调这是**系统层面的权衡贡献，而非普适质量最优**，并与 AdANNS（维度自适应搜索）、MatQuant（嵌套模型权重精度）区分开。

## 2. 方法论

- **核心思想**：L 阶段残差向量量化，每阶段 K=256 码字（每阶段索引占 1 字节）。解码前 b 个阶段即得 b 字节码，从而**阶段前缀 ⇒ 码率**；同时以嵌入坐标前缀 ⇒ **维度**。同一份码无需重新编码即可服务所有 (m, b) 组合。
- **维度弹性拟合**：码本在加权前缀重建误差下训练：
  - \(L_{prefix} = \sum_i \sum_{m\in M} w_m \| x_i^{[:m]} - \hat{x}_i^{(L)[:m]} \|_2^2\)，\(w_m \ge 0\)，\(\sum_m w_m = 1\)。
  - 即在不同前缀维度上共同优化重建误差，使前缀截断仍然有效。
- **服务方式**：(m, b) 直接选择 \(\hat{x}_i^{(b)[:m]}\)，无额外文档码；查询保持 fp32，采用非对称评分（与 PQ/OPQ、RaBitQ 一致）。
- **常驻内存模型**：
  - MRVQ：\(R_{MRVQ} = 4LKD + 16n\) 字节（fp32 码本 + 每向量 16 字节码）；
  - 逐率独立：\(R_{sep} = \sum_{b\in B}(P_b + nb)\)；
  - 共享模型钢人方案：\(R_{shared} = P_{16} + 16n\)。
  - 文档码项由 28n 降至 16n（渐近 1.75×），而在评测语料规模下，共享固定量化器状态带来更大的实测比值。
- **另一独立设计（PCA-scalar）**：PCA 旋转 → 按坐标方差分配标量比特 → 各坐标独立量化。仅需特征分解、无需迭代学习码本，不计入 MRVQ 内存核算。
- **关键超参**：L=16 阶段、K=256 码字/阶段、fp32 码本、50 次迭代、50,000 采样向量、seed 0、前缀权重均匀、16 个残差阶段等权。

## 3. 实验设计

- **前缀菜单 M**：MPNet/BGE {128,256,384,512,768}；Mxbai {128,256,512,768,1024}；Nomic {128,256,512,768}。
- **码率菜单**：B = {4, 8, 16} B/vector（相对 fp32 小 192–1024×）。
- **指标**：nDCG@10；配对逐查询 bootstrap（5000 重采样，RaBitQ 研究 10000）。
- **对比方法**：

- **拟合与计时**：学习类基线使用匹配拟合预算；PCA-scalar 计时在 ArguAna/Quora/SciDocs 上，3 seeds × 3 比特预算 × {MPNet, Mxbai} = 18 单元，固定 8 线程 CPU、顺序计时。

## 6. 主要结论与发现

- **单产物即最低 RAM 角点**：MRVQ 常驻 12.06–16.88 MiB，在两个数据集、四个家族上均为最低 RAM 配置；相对三套独立 QINCo2 省 **17.8–22.0×**，相对最精简共享模型方案省 **1.89–2.02×**。
- **质量呈双角 Pareto**：FiQA 上逐率 QINCo2 在每个家族–码率单元均优于 MRVQ **0.026–0.107 nDCG@10**；但共享模型 QINCo2 钢人方案仍耗约 1.9× MRVQ 内存。因此是「低内存角」与「高质量角」两种可用工作点，而非单一赢家。
- **优于标准 ANN 量化器**：匹配字节下，MRVQ 对 per-prefix OPQ 约 +0.06–0.07、对 PQ 约 +0.10–0.12，并在所有评测单元中优于 AdANNS-OPQ。
- **优势随语料规模衰减**：相对逐率方案，比值从评测规模约 18× 衰减至 28/16 = 1.75× 渐近；相对共享模型方案，在 n≈7.3M 处仍 >1.1×，超过约 10M 后差距 <8%。
- **PCA-scalar 替代点**：质量与 RaBitQ 相当（所有绝对效应 <0.008，1-bit 小网格均值超出预设 ±0.005 等效带），训练中位快 **420×**、均值 **686×**（0.17–6.95 s vs 72–416 s），适合就地重建。
- **负结果 1**：NFCorpus 16 阶段下逐率 QINCo2 出现检索崩溃（BGE 3/3 种子，最好仅 0.035；Nomic 1/3），尽管验证 MSE 已收敛；最佳 Nomic 种子在码率上非单调（16 阶段 0.294 vs 8 阶段 0.320）。
- **负结果 2**：基于残差能量的无参预测器 \(\epsilon(r)=\sqrt{D(r)}\) 方向有用但未达标——pooled Spearman 0.825（要求 0.85），仅 72% 单元给出非空界（要求 90%）。
- **总判断**：MRVQ 是弹性检索的低内存工作点，当常驻内存而非峰值质量是约束瓶颈时的部署选项。
