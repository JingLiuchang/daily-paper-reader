## 摘要
高效的向量检索既需要语料库几何结构能够支持通过向量相似度检索到正确文档，也需要一个查询编码器能够将查询嵌入到嵌入空间中其目标文档附近。近期工作从实现 n 篇文档所有 top-k 答案集所需的最小嵌入维度这一角度研究了几何容量。我们研究一种不同的几何容量概念——针对冻结文档索引所能达到的最大召回率——并探讨学习得到的查询编码器能否达到这一上限。在多个真实世界检索基准上，我们表明单向量查询编码器的检索质量往往远低于文档索引所能支持的水平。受此观察启发，我们从理论上给出证据表明学习查询编码器可能在计算上是困难的。特别地，我们构造了一个检索任务：(1) 它允许一个具有完美召回率的查询编码器，且该编码器可由小型单隐层 ReLU 网络表示；但 (2) 任何统计查询学习器（一类通过聚合统计量访问训练数据的学习器）可证明需要指数级数量的统计查询，才能相对于随机基线 k/n 获得非平凡的召回率优势。综上，我们的结果表明检索基准中存在大量尚未实现的几何容量，并确立了查询编码器可学习性可能是基于嵌入的检索中的一个障碍。

## Abstract
Efficient vector retrieval requires both a corpus geometry that supports retrieving the right documents through vector similarity, and a query encoder that can embed queries near their desired documents in the embedding space. Recent work has studied geometric capacity through the lens of the minimum embedding dimension needed to realize all top-$k$ answer sets of $n$ documents. We study a different notion of geometric capacity--the maximum recall achievable for a frozen document index--and explore whether learned query encoders can reach this ceiling. On several real-world retrieval benchmarks, we show that retrieval quality of single-vector query encoders often lies far below what the document indices can support.   Motivated by this observation, we give theoretical evidence that learning query encoders can be computationally hard. In particular, we construct a retrieval task that (1) admits a query encoder with perfect recall which is representable by a small one-hidden-layer ReLU network, but (2) any statistical-query learner (a class capturing learners that access training data through aggregate statistics) provably requires exponentially many statistical queries to achieve non-trivial recall advantage over the random baseline $k/n$. Taken together, our results suggest substantial unrealized geometric capacity in retrieval benchmarks and establish query encoder learnability as a possible barrier in embedding-based retrieval.
