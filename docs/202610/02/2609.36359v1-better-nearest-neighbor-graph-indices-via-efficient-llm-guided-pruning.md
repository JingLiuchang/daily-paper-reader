## 摘要
基于图的近似最近邻搜索（ANNS）广泛用于大规模语义搜索。其索引主要基于输入数据集（例如文档或图像）的嵌入之间的几何关系构建，而非显式地面向语义相关性进行优化。然而，当使用这些索引进行下游查询检索时，性能是根据检索结果与查询的语义相关性来评估的。这在索引的构建方式与其检索结果的评估方式之间造成了一种根本性的“几何-语义”失配。尽管现有的基于LLM的重排序方法可以在查询时部分缓解这种失配，但它们并未解决图中这一潜在的结构性问题。因此，我们提出LLM引导图剪枝（LGP），这是一个通用框架，通过利用LLM推理来改进现有ANN图索引本身，从而直接解决这种失配。LGP识别节点中结构上“低价值”的邻居，并将其替换为LLM选择的替代项，这些替代项提供有用的语义信息，同时保留原图所需的几何结构，包括稀疏性和高效可导航性。在代表性语义检索基准上的实验表明，在DiskANN和HNSW等广泛使用的基于图的ANN索引上，LGP相较于原始贪心图搜索和基于LLM的重排序，均能持续提升端到端检索性能。

## Abstract
Graph-based approximate nearest neighbor search (ANNS) is widely used for large-scale semantic search. Its indices are constructed primarily based on geometric relationships among embeddings of an input dataset (e.g., documents or images), rather than explicitly optimizing for semantic relevance. However, when using these indices for downstream query retrieval, performance is evaluated based on the semantic relevance of the retrieved results to the query. This creates a fundamental "geometry-semantic" mismatch between how the indices are constructed and how their retrieval results are evaluated. While existing LLM-based reranking methods can partially mitigate this mismatch at query time, they leave this underlying structural problem in the graph unresolved. We therefore propose LLM-Guided Graph Pruning (LGP), a general framework that addresses this mismatch directly by leveraging LLM reasoning to refine an existing ANN graph index itself. LGP identifies structurally "low-value" neighbors of nodes and replaces them with LLM-selected alternatives that provide useful semantic information while retaining desired geometric structures of the original graph, including sparsity and efficient navigability. Experiments on representative semantic retrieval benchmarks show that LGP consistently improves end-to-end retrieval performance over both vanilla greedy graph search and LLM-based reranking across widely used graph-based ANN indices such as DiskANN and HNSW.

## 1. 核心问题与研究动机

- **几何-语义错配（Geometry–Semantic Mismatch）**：基于图的近似最近邻搜索（ANNS）索引（如 DiskANN、HNSW）在构建时仅依赖嵌入向量之间的几何邻近关系，而下游检索效果却按"语义相关性"评估。二者之间的根本性错位是本文的核心问题。
- **现有方案的局限**：
  - LLM 重排序等"事后"方法只在查询时缓解问题，无法修复图索引本身的结构性缺陷；若相关文档在初始候选集中未被召回，再强的重排序器也无法补救（"候选瓶颈"）。
  - 增大搜索预算可缓解瓶颈，但带来不可接受的查询时开销。
  - 直接按语义关系构图成本高昂，且可能破坏与贪心搜索兼容的几何可导航性。
- **整体含义**：作者主张在**索引构建阶段**（离线）直接修正图结构，使局部邻域同时兼顾几何可导航性与语义信息量，从而在有限搜索预算下提升端到端检索质量。

## 2. 方法论：LLM-Guided Graph Pruning (LGP)

### 核心思想
在已有几何 ANN 图索引之上做**局部边替换**：识别结构上"低价值"的邻居（对二跳可达性贡献小、冗余度高），用 LLM 选出的语义互补候选节点替换之，同时保持稀疏性与可导航性，且**不改变查询时的贪心搜索流程**。

### 算法流程（三步）
1. **局部替换候选集构建**
   - 复用索引自身产生的候选集 $U_i$，并扩充有向二跳非邻居：
     $$T_i := \left(\bigcup_{v_j \in N(i)} N(j)\right) \setminus \{v_i\}, \quad U_i := (U_i \cup T_i) \setminus (N(i) \cup \{v_i\})$$
2. **无 LLM 的结构化初筛（shortlist）**
   - 对每个候选 $v_c$ 计算三个信号：
     - 邻近度 $\delta_i(c) = D(v_i, v_c)$
     - 额外二跳覆盖 $g_i(c) = |N(c) \setminus T_i|$
     - 与当前邻域的最小距离 $\nu_i(c) = \min_{v_j \in N(i)} D(v_c, v_j)$
   - 分别按 $\delta$ 升序、$g$ 降序、$\nu$ 降序排序，各取约 $\lfloor M/3 \rfloor$ 个组成至多 $M$ 个候选（默认 $M=24$ 文本 / $M=12$ 多模态）。
3. **LLM 语义选择**
   - 输入锚点文档 $v_i$、最近的 $K$ 个邻居上下文、初筛候选，LLM 选出至多 $B$ 个"补充而非重复"当前邻域语义的候选（默认 $B=2$）。
4. **局部边替换**
   - 结构过滤：仅保留额外二跳覆盖 $g_i(c) \ge g_{\min}$ 的候选（默认 $g_{\min}=12$）。
   - 若度数未满则直接加入；否则替换"最低价值"原邻居 $v_w$，通过词典序最小化其唯一二跳贡献 $\ell_i(j)$ 与冗余度 $\nu^{-j}_i(j)$ 来确定：
     $$\ell_i(j) := N(j) \setminus \left(\left(\bigcup_{v_k \in N'(i)\setminus\{v_j\}} N(k)\right) \setminus \{v_i\}\right), \quad \nu^{-j}_i(j) := \min_{v_k \in N'(i)\setminus\{v_j\}} D(v_j, v_k)$$

### 实例化
- **DiskANN**：在第二次构建遍历的 RobustPrune 之后应用，复用 GreedySearch 的访问节点作为 $U_i$；新引入的互惠边在当次剪枝中被保护。
- **HNSW**：在构建完成的第 0 层上离线精炼，复用层次搜索的候选，保持原度数不变，上层结构完全冻结。

## 6. 主要结论与发现

- **受控单边替换分析**（图 1）：仅替换一条边即可显著提升 ground-truth recall（Oracle 远高于 Vanilla），而随机替换（Uniform）几乎无提升——证明几何构图留下了可观的语义提升空间，且需要"有选择地"替换。
- **LGP 持续优于 Vanilla**：
  - BRIGHT：贪心搜索 NDCG@10 平均 **+24.4%**，重排序后 **+26.0%**；Recall@10 分别 **+25.2% / +27.4%**。
  - M-BEIR：贪心搜索 NDCG@10 **+11.7%**，重排序后 **+13.2%**；Recall@10 **+11.8%**。
- **窄搜索宽度下增益最大**：BRIGHT 在宽度 10 时贪心 NDCG@10 提升 32.3%，随宽度增大而递减，但始终保持优势。
- **效率提升**：在同等检索质量下最多减少 **50% 的距离计算**（如 Economics 上 800 vs 1600 次）。
- **通用性**：在 HNSW 与不同嵌入模型上同样有效。
- **结构保持**：LGP 改变约 88–89% 的邻域，但平均出度基本不变（<16），说明增益来自**连接重构**
