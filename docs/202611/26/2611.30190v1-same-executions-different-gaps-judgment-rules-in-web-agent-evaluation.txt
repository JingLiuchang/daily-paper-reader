# Same Executions, Different Gaps: Judgment Rules in Web-Agent Evaluation

University of California San Diego La Jolla, USA zew013@ucsd.edu

Abstract 

Success-rate gains guide the development of web agents. Yet know-ing which agent ranks first does not tell us how much confidence to place in its reported advantage. We study the comparison itself: how success is defined, what evidence supports the judgments, and how the difference between agents is estimated. On fixed web-agent executions, changing a judge from predicting likely comple-tion to requiring recorded support can remove most of a reported lead without changing the ranking. This effect persists when un-resolved completion is distinguished from supported failure. Con-trolled source additions explain how missing relations between task requirements, objects and observations can conceal a difference or create an apparent advantage. We also find that making both agents’ score estimates more accurate can make their difference less accurate, because their original errors partly canceled. To estimate a chosen outcome difference, we combine judge predictions with reference labels for sampled task pairs. Across four released execu-tion systems, regression fitted on the same 50 labeled pairs reduces estimation error relative to direct paired sampling. The results give agent researchers a practical basis for assessing claimed improve-ments: make the comparison target explicit, retain the evidence needed to check it, and use paired labels to estimate the difference directly.

1 Introduction 

A new web agent is usually evaluated through its improvement over a baseline. The size of that improvement helps researchers decide whether a change in planning, perception or tool use is worth pursuing. Model judges make these comparisons easier to scale: they inspect saved executions, assign success labels, and turn those labels into scores. But a plausible judgment of each execution is only part of the evidence needed to support a claim that one agent is better by a particular amount. The difference between two scores can behave differently from ei-ther score alone. If an evaluation rule lowers both scores unequally, the ranking may stay the same while the reported improvement largely disappears. More accurate scores can even yield a worse difference when their original errors partly canceled. The claimed advantage therefore needs its own check. Agreement on a winner, or better accuracy for each agent separately, leaves its magnitude unresolved. We study this problem on fixed executions from AgentReward-Bench [11]. A judge can be asked two useful questions: did the task likely succeed, or does the supplied record support comple-tion? Holding executions and records fixed, switching between these questions reduces Claude’s lead over Qwen from 8.33 to 1.33 percentage points in one setting. The point-estimate ranking is unchanged. A new comparison that explicitly allows an unresolved verdict retains the reduction. Additional judges and execution sys-tems show a range of responses, making the meaning of an im-provement claim part of its evaluation. Checking that meaning also requires checking the evidence. A product title alone may not establish that an agent clicked the re-quested grid position; a purchase confirmation may omit which configuration was selected. Our source interventions recover re-lations needed to assess such conditions. They reveal a missed distinction in one comparison and remove an apparent advantage in another. These opposite outcomes illustrate a common objective: make the judgment traceable to the task and its recorded result. For an outcome comparison, we then ask how to estimate the dif-ference using a limited labeling budget. A calibration counterexam-ple shows why correcting the two scores separately is insufficient. We estimate the difference directly, using both agents’ reference labels on sampled tasks and judge outputs on the full cohort. Re-gression fitted on the same 50 labeled pairs improves precision over direct paired sampling across the studied execution systems. Figure 1 connects the empirical problem, the evidence needed to inspect a comparison, and this practical estimation response.

Outcomes and evidence. Judging agents can gather verification ev-idence by inspecting environments [12]. In procedural-trace evaluation, linking evidence to the option it describes reduces false rejection [5]. Conversational-score calibration aligns different judges to a shared human-derived scale [14]. Prediction-powered inference uses predictions and labeled residuals; PPI++ learns a weight for the predictions [1, 2]. We examine how score correction affects the difference between agents, then assess direct estimation of that difference at a fixed paired-label budget.

3.2 Two questions about success 

Prediction asks the judge to predict the execution’s actual outcome. When the record does not settle completion, it must choose the more likely outcome. Certification asks if the supplied record sup-ports completion. Both use the same task-success criteria, evidence and binary response format; the changed instruction governs the decision under uncertainty. A certification zero means success not endorsed , covering both observed failure and insufficient confirma-tion. We use “endorsement rate” when discussing these outputs. Each execution receives two fresh calls per rule and view, whose endorsements are averaged. We report Claude’s lead as its rate minus Qwen’s rate, and the rule effect as the prediction lead minus the certification lead. A positive rule effect therefore means Claude’s lead shrinks. The 95% intervals use bootstrap resampling of task pairs within benchmarks, keeping each task’s agents, rules and repetitions together. Full prompts, sampling settings and missing-verdict sensitivities are in the supplement.

4 The Rule Changes the Reported Advantage 4.1 The ranking can stay the same while the lead changes 

Table 1 shows why score changes must be interpreted jointly. In Astra/final, certification lowers Claude’s endorsement rate more than Qwen’s, reducing the lead from 8.33 to 1.33 points. The exe-cutions have not changed, and Claude still ranks first by the point estimates. What changes is the amount of improvement a reader would attribute to choosing Claude. The same observation has a different practical meaning from a uniform downward adjustment to both scores. The effect varies across judge and view. All five point-estimate leads shrink, with the largest reduction in Astra/final; Sonnet/final and Kimi leave more uncertainty about the change. The ranking alone misses this variation. A fresh wording control also retains the Astra/final reduction under a rewrite of the instructions, supporting its interpretation as a consequence of the judgment question rather than a peculiarity of one phrasing. Complete wording and missing-output checks are provided in the supplement.

5 What Evidence Makes a Comparison Checkable? 5.1 Recover relations needed by the task 

When a task requires a specific item, configuration or field, the evidence must connect that requirement to what the agent actually did. An observation can be relevant without making this connection: a product page may identify the purchased item but omit where it appeared in the requested grid. For a disputed comparison, the source question is which relation supports or challenges the task condition. We examined archived records for every execution contributing to the original Astra/final change. Two human annotators checked the source-recovery annotations; a third resolved disagreements. Relevant relations could be located for 52 of the 59 executions, including records contributing in both directions. These include observations that support completion and ones that challenge it, identifying where a comparison can be checked against additional archived evidence. Supplement T contains the source census. Both intervention studies below use Astra with the original final-view inputs and two repetitions per condition. We append archived observations while preserving the goal, action and reasoning trace, errors and original media. Re-presentation and partial-source con-trols test whether the relevant relation changes the judgment be-yond repeating existing information. The complete intervention designs and results are in the supplement.

5.2 A missed distinction in a positional task 

In VisualWebArena task 756 (Figure 1(b), Case 1), the goal is to select a product in the second row and second column. Qwen clicks the second item in the first row; Claude clicks the requested position and reaches the corresponding product page. The original inputs fail to preserve the relation between grid position, product and destination. Prediction endorses both executions, while certification endorses neither. Both rules therefore report a zero gap despite the different actions. Adding the relations among positions, products and destination pages makes both rules distinguish the executions (Table 3). Re-presenting existing observations does not produce this change. The earlier screenshots alone also leave the requested off-screen position unclear; saved layout information supplies the relevant relation. The useful addition is the connection needed to check the instruction, rather than simply another view of the final product page. 

5.3 An apparent advantage in a purchase task 

A laptop purchase gives the reverse example (Figure 1(b), Case 2). The task requests a Development Laptop (PC), while the confirma-tion names a Dell XPS 13. With the recorded click target mapped to the Order Now button, prediction interprets Qwen’s execution as a wrong purchase and endorses only Claude. The archived product page connects these two names; supplying that relation resolves the mistaken identity and removes the lead. Configuration evidence alone does not resolve the identity question; certification endorses both executions only when both identity and configuration are supplied. The two rules can thus retain the same zero gap while changing their judgments of both agents. Together, these cases show what a source intervention should accomplish: make the task condition checkable against the relevant object and observation. Its value is not determined by whether the lead grows or shrinks. Supplying the relation also does not ensure that every judge will use it correctly. Supplementary query and form experiments retain examples of both improved use and persistent object/time confusion. For practice, the immediate recommendation is to preserve the links needed to inspect a disputed judgment, rather than treat a longer record as sufficient evidence by itself. 

6 Estimating the Intended Agent Difference 6.1 Better scores can give a worse difference 

An outcome comparison needs an explicit reference. The human reference uses AgentRewardBench’s released expert assessments of task completion; the functional reference uses its saved benchmark rewards converted to binary outcomes. They imply substantially different Claude–Qwen leads: 10.67 points for the human reference and 0.67 for the functional reference. Each fixes what the estimator should recover before any calibration is fitted. A researcher must therefore choose the completion criterion that matches the intended claim, alongside deciding what evidence the judge receives. Separate score calibration does not necessarily improve that target difference. A judged gap’s error is the difference between the two agents’ signed rate errors. If both rates are underestimated by similar amounts, those errors largely cancel. Reducing each absolute error can disrupt that cancellation, leaving a worse difference. This is why a close judged gap can be misleading evidence that the individual scores are well calibrated, and why individual calibration improvements do not settle the comparison. We observe this failure using binary error correction fitted sep-arately for each agent on development labels [10]. Table 4 shows the Astra/final certification example against the functional refer-ence. Initially, both scores underestimate their targets by similar amounts. After calibration, Qwen is slightly below its target and Claude is above it. Each score is closer, but their errors now pull the estimated lead in opposite directions. Other settings include joint improvements; the practical lesson is to check whether cali-bration improves the claimed difference. Supplement F.10 provides the complete calibration results.

6.2 Use paired labels to estimate the gap directly 

Existing judgments can still help estimate the chosen difference even when their raw gap is inaccurate. Suppose we can label both agents’ executions for a random sample of tasks. That sample gives a direct estimate of the reference gap. Labeling both executions for each sampled task keeps the two sides of the comparison aligned. The sample may nevertheless overrepresent tasks on which one agent tends to do well. Comparing the sample’s judge gap with the full cohort’s judge gap provides information about this sampling imbalance. A correction uses that information to reduce estimation error, as illustrated in Figure 1(c). Let 𝑌 𝑖 denote the agents’ reference outcome difference on task 𝑖 ,and 𝑍 𝑖 the corresponding difference in judge endorsements. The second adjusts it using the difference between full-cohort and sampled judgments. The fitted weight ˆ𝛽 controls how much of this discrepancy to use. The baselines use fixed weights: 𝛽 = 0 for direct paired sampling and

We learn the auxiliary weight from the labeled pairs [2], regress-ing the paired reference differences on the paired judge differences within the same 50 labeled task pairs. This reuses the labels needed for the comparison instead of requiring a separate development set. All baselines use the same paired labels, so the comparison isolates the benefit of auxiliary judgments. The supplement retains fixed-weight, development-fit and label-splitting controls. The judge’s useful contribution is information about variation across tasks. This explains why neither a small raw gap error nor a large response to the judgment rule is required for an auxiliary judge to help. 6.3 More precise comparisons with the same labels 

We evaluate the full procedure by repeatedly sampling 50 task pairs without replacement from the fixed cohort. Every regression is fitted only on the sampled labels; the known full-cohort reference is used to measure its error. The methods share the same samples, and mean squared error (MSE) counts both variance and squared bias. Fifty task pairs require labels for 100 executions. Complete sampling and interval methods appear in Supplements F.11 and U. Against the human reference, regression reduces MSE by 16.9– 36.9% relative to direct paired sampling across all ten settings (Fig-ure 3). Equal weighting slightly outperforms regression in the two Astra certification settings. Learning how much to trust a judge is useful in many settings, while retaining the fixed-weight control reveals where the additional fit does little. The precision gain also helps answer a practical comparison question. Using the same approximate 95% interval procedure, re-gression identifies the human-reference leader in about 48–62% of samples, compared with 41% for direct sampling. Its measured coverage is 94.2–94.7%, close to direct sampling’s 94.6%. Thus the intervals more often resolve the ordering at the same label budget, with coverage slightly below the nominal level. Exact decision fre-quencies, wrong-direction declarations and coverage are reported together in Supplement V. Kimi illustrates the distinction between rule sensitivity and esti-mation value. Its rule contrast is comparatively small and uncertain, yet its judgments improve regression precision over both direct sampling and equal weighting. The study of additional execution systems extends the precision result to every included pair under both the human and functional references. Regression improves on direct paired sampling throughout; equal weighting remains com-petitive in a few human-reference settings. Supplement S reports all settings and the exceptions. 

7 Implications for Agent Evaluation 7.1 What should an improvement claim report? 

The first decision is what the claim means. A likely-outcome esti-mate and an evidence-supported success rate serve different pur-poses. Naming that target makes comparisons easier to interpret, and reporting both agents’ rates alongside the gap shows whether a rule affects them equally. For an evidence-support target, separat-ing supported failure from unresolved completion makes the result more informative than a binary non-success rate. The next decision concerns a disputed judgment. Preserve the source relation needed to check the task: which item occupied the requested position, which configuration was submitted, or which query produced a count. Our source examples show why this can change the comparison in either direction. They also provide a concrete question to ask of a record, beyond whether it contains enough screenshots or a confident completion claim. When the objective is an outcome difference, paired reference labels provide a direct way to estimate it. With full-cohort judg-ments available, randomly sample tasks, label both agents on each, and use the auxiliary differences to improve precision. Only the sampled executions need reference labels; the remaining tasks con-tribute judge predictions. Same-label regression makes this feasible without purchasing a separate development set. The benefit con-cerns reference-label use; acquiring the full set of judge outputs is a separate cost. Researchers should assess both estimation error and interval coverage for the intended use. 

7.2 Scope 

The study uses fixed released executions, and the source interven-tions establish local effects of particular evidence relations. The es-timation results measure sampling risk within the declared cohorts and references. New tasks, execution interfaces or judge versions may change these results. The complete supplement preserves the comparison matrices, source controls and alternative estimators needed to assess that scope. 

8 Conclusion 

The size of an agent’s reported advantage deserves its own evalu-ation. A stable ranking can conceal a substantially changed lead, and more accurate individual scores can still produce a less accu-rate difference. Our experiments connect these problems to the success target and its evidence, then show how paired regression can improve estimation with limited reference labels. This gives researchers a practical way to support claims about how much an agent has improved.
