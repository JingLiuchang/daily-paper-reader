Abstract 

Vision Language Models (VLMs) have shown remarkable capabilities in qualitative spatial reasoning, but remain limited in quantitative spatial reasoning. Current work leverages the VLM agent to invoke external vision tools to perform computation. However, these methods usually bind each functional requirement to a single predefined vision specialist, implicitly re-sulting in fixed and rigid tool pipelines. In prac-tice, addressing diverse spatial scenarios and tasks demands a broader diversity in pipeline orchestration and vision specialist selection to achieve robust spatial reasoning. However, such diversity leads to a combinatorial execu-tion space, making it challenging for the agent to orchestrate the optimal pipelines and special-ists for different scenarios. In this work, we propose SpatialMem , a mem-ory framework that enables a VLM agent to accumulate tool-use experience and leverage that memory to orchestrate vision specialists to solve the spatial reasoning problem. Spa-tialMem builds a two-level memory structure, with task memory capturing tool orchestration and scene memory capturing tool selection. It further introduces a dual-state trajectory opti-mization process to preserve successful tool experiences and refine suboptimal ones. More-over, existing spatial reasoning benchmarks suffer from quality issues and limited cover-age of scene types and tasks. To address these gap, we propose MetricBench , a benchmark covering both indoor and outdoor scenes and three quantitative spatial reasoning tasks. Our method achieves state-of-the-art results on Met-ricBench , Q-Spatial, and SpatilRGPT-Bench, outperforming best VLM baselines by 32% on 

MetricBench . Additionally, the memory de-sign yields a 9.1% absolute gain over a memory-free agent on MetricBench . Codes are avail-able at https://github.com/compasszzn/ SpatialMem .

1 Introduction 

Recent advances in Vision-Language Models (VLMs) (Zhou et al., 2026b; Zheng et al., 2026a; Chen et al., 2024b; Zheng et al., 2026b; Zhao et al., 2026) have demonstrated remarkable capabilities across a wide range of visual understanding and rea-soning tasks. However, spatial reasoning remains a fundamental capability for VLMs, requiring them to understand object relationships and their sur-rounding environments. It is critical for embodied systems (Li et al., 2025), robot navigation, and spa-tial question answering (Ma et al., 2024b). Recent work (Chen et al., 2024a, 2026; Cheng et al., 2024) achieves strong performance on qualitative tasks (e.g., relative position, distance, and size compari-son) but struggles with quantitative reasoning (e.g., exact metric sizes or object distances estimation). These methods rely on large-scale image-text QA datasets, which often encourage models to exploit statistical biases and linguistic shortcuts rather than develop genuine geometric understanding. To ad-dress this, recent studies (Han et al., 2025; Chen et al., 2025; Marsili et al., 2025) instead treat VLMs as reasoning agents that perform multi-step reason-ing, invoke external tools, and generate executable code for more precise spatial reasoning. Despite this progress, existing methods operate within a highly constrained paradigm. As shown in Figure 1, they typically bind each functional re-quirement to a fixed vision specialist, implicitly forming a static tool pipeline. In practice, each functional requirement can be supported by mul-tiple vision specialists, and the effectiveness of different pipelines and components varies substan-tially across geometric conditions, scene types, and task categories. This variability implies that relying on a single specialist severely limits adaptability and robustness. To address this gap, we introduce SpatialMem ,a novel hierarchical memory framework that em-powers Vision-Language Model (VLM) agents with autonomous experience accumulation and so-phisticated tool orchestration for spatial reason-ing. First, SpatialMem structures experience into a two-level Hierarchical Memory Tree: the macro-level scene memory abstracts environment-wide tool preferences, while the micro-level task mem-ory meticulously schedules specialist selection and execution sequencing for fine-grained spatial tasks. This architecture mitigates blind trial-and-error by enabling context-aware memory retrieval. Sec-ond, SpatialMem implements a dynamic dual-state memory mechanism: a construction state that in-dexes successful trajectories alongside empirical performance statistics, and an evolution state that diagnostically untangles failed executions. By an-alyzing reasoning traces and intermediate visual outputs, it proactively rectifies sub-optimal behav-iors to synthesize superior specialist combinations. Besides, existing spatial reasoning benchmarks suffer from quality issues (e.g., ambiguous refer-ences, truncated instances, and blurry objects) and provide limited coverage of scene and task types. To address this gap, we introduce MetricBench , a benchmark for quantitative spatial reasoning cover-ing object–object distance, object–camera distance, and object size across indoor and outdoor scenes, with rule-based filtering and manual verification to ensure data quality. We conduct extensive experiments on multiple quantitative spatial reasoning benchmarks, includ-ing MetricBench , SpatialRGPT (Cheng et al., 2024), and QSpatial-Bench (Liao et al., 2024), and qualitative spatial reasoning benchmarks CV-Bench (Tong et al., 2024). Our method consistently outperforms existing spatial specialist models as well as proprietary large-scale models, including GPT-5.4 and Gemini-3.1-Pro Preview. The hierar-chical memory system improves performance over the memory-free variant, achieving an average gain of 9.1%. These results demonstrate that our frame-work enhances agents’ ability to select and utilize tools in different scenarios. In summary, our contributions are as follows: • We propose SpatialMem , a hierarchical mem-ory framework that integrates scene-level and task-level memory, while continuously optimiz-ing suboptimal tool trajectories, enabling agents to select better external vision tools across di-verse scenes and tasks. • We release MetricBench , a well-curated bench-mark for quantitative spatial reasoning, covering object-object distance estimation, object-camera distance estimation, and object size estimation in both indoor and outdoor environments. • Extensive experiments demonstrate that hierar-chical memory design and the proposed trajec-tory optimization mechanism substantially im-prove agent performance across diverse spatial reasoning benchmarks. 

2 Related Work 

VLMs Spatial Reasoning. Recent advances in VLMs have spurred increasing research into their spatial reasoning capabilities. Existing works typi-cally frame spatial reasoning as a visual question answering task on image-text pairs. To address this task, current approaches follow two main techni-cal routes. The first synthesizes training data from 3D datasets or simulated environments, as exem-plified by SpatialRGPT (Cheng et al., 2024) and SpatialVLM (Chen et al., 2024a), which generate templated spatial queries via data pipelines. The second incorporates geometric specialist modules into VLMs, such as VLM-3R (Fan et al., 2025) with CUT3R for 3D information injection and Ro-boRefer (Zhou et al., 2026a) with a depth encoder for depth feature extraction. However, both routes require either large-scale training data or architec-tural modifications, which limit interpretability and increase system complexity. Rather than integrating spatial reasoning capa-bilities into the model itself, we enable VLMs to invoke external vision specialist models as tools for solving spatial reasoning tasks. 

Tool-augmented Reasoning. Tool-augmented reasoning enables LLMs and VLMs to invoke ex-ternal tools. In spatial reasoning, recent studies leverage vision specialist models to enhance under-standing. One line of work trains VLMs to interact with external tools, such as SpaceTool (Chen et al., 2025) and TIGeR (Han et al., 2025), using super-vised fine-tuning or reinforcement learning to im-prove tool-use capability. However, these methods demand large-scale training data and substantial computation. Another line comprises training-free approaches: VADAR (Marsili et al., 2025) gener-ates a Pythonic API with task-specific functions, while SpatialPIN (Ma et al., 2024a) relies on a pre-defined tool pipeline for question answering. Yet, these training-free methods typically depend on a single vision specialist per task, with no exploration of selecting a suitable specialist from a candidate pool. 

Memory-enhanced Reasoning. Memory has been widely adopted in agents to accumulate expe-rience and improve generalization. Existing mecha-nisms fall into two paradigms: parametric memory, which stores knowledge in model parameters (Chen et al., 2023; Yin et al., 2024), and non-parametric memory, which leverages external databases or ser-vices for persistent context (Packer et al., 2023; Qian et al., 2025). However, their general frame-work is not tailored to spatial reasoning tasks, and their ability to select appropriate vision specialists under varying conditions remains underexplored. Our work falls within the non-parametric paradigm, extending memory-based agents to spatial reason-ing by enabling adaptive specialist selection based on historical experience. 

3 Problem Formulation 

We organize the heterogeneous tool space T into P

functional groups G = {G1, G 2, . . . , G P }. Each group Gp aggregates multiple vision specialists that share identical functional objectives but ex-hibit complementary performance characteristics under varying scene dynamics. For example, the depth estimation group is formalized as Gdepth =

{UniDepth , DepthPro , MoGe-2 }. The complete tool space is defined as the union of all functional clusters T = SPp=1 Gp, spanning vital vision ca-pabilities such as segmentation, keypoint pointing, 2D/3D bounding box detection, and point cloud estimation (see Appendix E for full details). We formulate quantitative spatial reasoning as a multi-turn, tool-augmented question answering task. Formally, given an image I and a spatial query Q, the VLM agent iteratively reasons and orchestrates vision specialists from T across mul-tiple execution turns to yield the final quantitative textual answer A.

4 Method 

4.1 SpatialMem 

Our framework is illustrated in Figure 2. Spa-tialMem is an orchestration framework designed to supercharge Vision-Language Model (VLM) agents with long-term memory for quantitative spa-tial reasoning. The framework consists of three components: (1) A structured two-level mem-ory tree that maps agent experiences into a joint environment-task space, ensuring structural isola-tion and preventing memory retrieval from cross-domain interference. (2) A continuous optimiza-tion loop consisting of a Construction State to in-dex empirical successes, and an Evolution State 

that diagnoses failed trajectories to iteratively re-fine tool pipelines from execution feedback. (3) An accuracy-driven ranking strategy that identifies elite tool execution chains and instantiates them as robust reasoning priors to guide adaptive tool orchestration.

4.2 Data Construction 

To address quality issues in existing spatial reason-ing benchmarks, including blurry objects, ambigu-ous references, and limited diversity, we introduce 

MetricBench , a curated quantitative benchmark consisting of 658 questions covering object size estimation, object-object distance estimation, and object-camera distance estimation. The dataset is built from Omni3D (Brazil et al., 2023), including SUNRGBD indoor scenes and KITTI/nuScenes outdoor scenes, spanning 81 object categories with physical scales from 20 cm to 50 m. Following previous work (Fan et al., 2025; Yang et al., 2025a), we retain only object instances whose category appears exactly once in each im-age to avoid reference ambiguity. For object-object distance estimation, we also include same-category pairs (e.g., distance between two chairs). For visual quality, we apply a visibility threshold of 0.9 and discard truncated instances with bounding boxes intersecting image boundaries. We construct raw spatial QA pairs from the filtered Omni3D anno-tations. These raw data exhibit two systematic biases: category imbalance (frequent categories dominate) and value-range skew (short distances over-represented). We mitigate these via strati-fied sampling over the ground-truth value range grouped by category, ensuring balanced and di-verse coverage. After automatic filtering, issues such as blurry objects and ambiguous references persist. We therefore instruct human annotators to manually refine the dataset, ensuring high annota-tion quality and spatial clarity. 

5 Experiment 

Setup We evaluate SpatialMem on multiple quantitative spatial reasoning benchmarks, includ-ing Metric-Bench, SpatialRGPT (Cheng et al., 2024), QSpatial-ScanNet (Liao et al., 2024), out of domain test setQSpatial++ (Liao et al., 2024) and multi-image benchmark MMSI-Bench (Yang et al., 2025b), as well as the qualitative benchmark CV-Bench (Tong et al., 2024). Our agent execu-tor, perceiver, and summarizer are built upon GPT-5.4-Nano. For each memory-based method, we evaluate two self-evolving settings: online and of-fline . In the online setting, the agent dynamically updates the memory tree using execution feedback. We consider Online w/ Oracle Feedback , which uses ground-truth verification, and Online w/ VLM Feedback , which relies on a VLM judge without ground-truth labels. In the offline setting, the mem-ory system first accumulates experience from a training set, which is constructed from the Omni3D training split following the same pipeline as Met-ricBench , and is then evaluated on MetricBench .The details of all benchmarks and the training set are shown in Appendix A. 

Baselines We compare our approach against four categories of baselines: (1) proprietary models, in-cluding GLM-4.6V (Team et al., 2025), GPT-5.4, and Gemini-3.1-Pro-Preview; (2) general-purpose open-source models, including Qwen-3-VL (Bai et al., 2025) and InternVL3.5 (Wang et al., 2025); and (3) specialist spatial reasoning models, includ-ing SpatialRGPT (Cheng et al., 2024), RoboRe-fer (Zhou et al., 2026a), SD-VLM (Chen et al., 2026), and MM-Spatial (Daxberger et al., 2025); (4) agentic reasoning methods, including variants without memory as well as memory-integrated ap-proaches such as ReasoningBank (Ouyang et al., 2025) and ReMe (Cao et al., 2025). 

Evaluation We follow SpatialRGPT (Cheng et al., 2024) and adopt a success criterion where pre-dictions within 0.80 × to 1.25 × of the ground-truth value are considered correct across all quantitative benchmarks. For qualitative benchmarks, we use multiple-choice evaluation and report classification accuracy. The details of the implementations and evaluation are in Appendix B.

5.2 Ablation Study 

We evaluate the contribution of each core com-ponent in SpatialMem (offline)on MetricBench .Table 3 reports the results under four ablated config-urations: (1) w/o Memory : remove the entire mem-ory framework; (2) w/o Domain-Specific Structure ;(3) w/o Scene-Level Memory : eliminate scene-level memory; (4) w/o Task-Level Memory : disable task-level memory; (5) w/o Trajectory Optimization :deactivate trajectory refinement. 

Impact of Hierarchical Memory Removing the domain-specific structure reduces success rates from 61.8% to 51.7% on indoor scenes and from 75.5% to 65.5% on outdoor scenes, demonstrating the importance of domain-aware memory organi-zation. Scene-level memory provides moderate im-provements, with removal decreasing performance to 58.2% indoors and 72.3% outdoors, as different environments require different specialists. Task-level memory is more critical, where its removal reduces performance to 51.6% indoors and 65.5% outdoors due to increased cross-task interference. 

Impact of Trajectory Optimization We further evaluate the memory evolution module by disabling trajectory optimization. In this setting, the frame-work stores historical trajectories without failure analysis or optimized trials. This causes a clear performance drop: average success rate falls to 49.0% (indoor) and 67.9% (outdoor). Notably, in-door object-object distance estimation decreases from 57.8% to 33.3%. These results confirm that merely accumulating trajectories is insufficient; op-timization and trial-based validation are essential for continuous memory evolution and correcting suboptimal selections. Further results are shown in the Appendix C.2.

5.4 Robustness Analysis 

We further analyze model robustness across phys-ical distance ranges. For object-camera distance estimation, samples are evenly divided into Near, Mid, and Far groups using thresholds of 1.2 m and 

6.7 m. For object-object distance estimation, we uses thresholds of 3.3 m and 20 .7 m. Figure 4 shows that existing spatial reasoning models degrade significantly as physical scale in-creases. In object-camera estimation, RoboRefer-8B performs competitively in near-range but drops sharply from 84.5% to 12.0% in far-range, indicat-ing limited robustness under large depth variations. SpatialRGPT-8B collapses to nearly 0% beyond near-range. This degradation stems from training data dominated by near-range samples. In contrast, 

SpatialMem maintains strong performance across all scales, achieving over 75% success rate even in far-range estimation. A similar trend holds for object-object distance estimation. Most baselines struggle as object dis-tance increases, especially in far-range scenarios re-quiring precise grounding and geometric reasoning. By contrast, SpatialMem exhibits steadily improv-ing performance from near to far ranges, achieving the best robustness. These results demonstrate that memory-driven specialist selection enables robust reasoning across diverse geometric conditions and large-scale physical variations.

In this work, we proposed SpatialMem , a hier-archical memory framework that enables agentic VLMs to accumulate experience for quantitative spatial reasoning. Its hierarchical memory tree selects better vision specialists for different sce-narios and tasks, while a self-evolving strategy continuously refines the memory. We also intro-duced MetricBench , a curated quantitative spa-tial reasoning benchmark. Experiments show that 

SpatialMem achieves state-of-the-art performance across multiple benchmarks and exhibits strong ro-bustness across physical scales, demonstrating the effectiveness of memory-driven VLM agents for accurate quantitative reasoning.

Limitations 

Our framework is designed specifically for quantita-tive spatial reasoning and primarily focuses on spa-tial question answering tasks. As a result, the cur-rent memory hierarchy relies on predefined scene and task categories, which restricts its immedi-ate generalizability to non-spatial or purely textual long-horizon challenges, such as code generation or multi-step logic programming. In addition, the effectiveness of memory evolution depends on suf-ficient interaction experience and reliable evalua-tion feedback, which serve as key factors for stable memory updates.

QSpatial++. We further evaluate our method on QSpatial++, an out-of-domain benchmark with respect to MetricBench .
