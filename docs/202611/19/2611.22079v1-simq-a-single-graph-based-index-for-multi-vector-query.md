## 摘要
多向量检索模型（如 ColBERT）通过将文档表示为词元级向量集合并经 MaxSim 评分，取得了最先进的效果，但其高计算成本限制了其向大规模语料库的可扩展性。现有近似方法面临根本性瓶颈：质心交互矩阵方法需要在每次查询时计算完整矩阵，并依赖 GPU 加速聚类；而与数据无关的压缩方法召回率不稳定，需要反复补偿。我们提出 SIMQ（Single graph Index for Multi-vector Query，多向量查询的单图索引），一个通过数据感知的采样聚类和逐词元图导航，将单向量图索引与多向量检索桥接起来的框架，同时绕过上述所有瓶颈。SIMQ 通过数据感知采样将所有词元向量组织为细粒度簇，独立于 PLAID 的残差表示在簇质心上构建单一图索引，并通过逐词元图搜索近似 MaxSim 分数，无需物化任何交互矩阵，也不依赖 GPU 加速。我们提供理论分析表明，在流形假设和单元检索成功的前提下，数据感知划分比数据无关划分具有更小的期望近似误差。在此基础上，SIMQ+ 进一步引入基于计数的评分和动态候选集，以提高在不同查询条件下的鲁棒性。在五个基准上的实验比较了召回率、吞吐量和构建时间与多个基线的表现，主要在 CPU 上进行；大规模 PLAID k-means 质心在单独的 GPU 机器上构建。SIMQ 已集成到蚂蚁集团开源向量搜索库 VSAG 中。

## Abstract
Multi-vector retrieval models such as ColBERT achieve state-of-the-art effectiveness by representing documents as sets of token-level vectors and scoring via MaxSim, but their high computational cost limits scalability to large corpora. Existing approximate methods face fundamental bottlenecks: centroid interaction matrix approaches require computing a full matrix at every query and rely on GPU-accelerated clustering, while data-oblivious compression methods yield unstable recall that requires repeated compensation. We propose SIMQ (Single graph Index for Multi-vector Query), a framework that bridges single-vector graph indices and multi-vector retrieval through data-aware sampling-based clustering and per-token graph navigation, simultaneously bypassing all aforementioned bottlenecks. SIMQ organizes all token vectors into fine-grained clusters via data-aware sampling, builds a single graph index over cluster centroids independently of PLAID's residual representation, and approximates the MaxSim score through per-token graph search without materializing any interaction matrix or relying on GPU acceleration. We provide theoretical analysis showing that, under a manifold assumption and successful cell retrieval, data-aware partitioning has a smaller expected approximation error than a data-oblivious partition. Building on this foundation, SIMQ+ further introduces count-based scoring and a dynamic candidate set to improve robustness across varying query conditions. Experiments on five benchmarks compare recall, throughput, and construction time against several baselines, primarily on CPU; large-scale PLAID k-means centroids are built on a separate GPU machine. SIMQ has been integrated into VSAG, an Ant Group's open-source vector search library.

  - **PLAID 类质心交互矩阵方法**：每次查询需计算 \(K \times m\) 的质心—查询词元交互矩阵；增大 \(K\) 可细化簇但矩阵成本上升，减小 \(K\) 则候选过滤成本上升。同时，大规模 k-means 聚类通常依赖 GPU。

  - **IGP/GEM 等图方法**：或保留 PLAID 的残差压缩与聚类管线，或在文档集合级构图，构建复杂、成本较高。
- **核心问题**：如何在避免质心交互矩阵和 GPU 聚类依赖的前提下，实现细粒度、数据感知、可扩展到大规模语料的多向量近似检索。
- **整体含义**：论文提出 SIMQ，将“单向量图索引”与“多向量 MaxSim 检索”桥接起来：用数据感知采样聚类组织全部词元向量，在簇质心上构建单一图索引，并通过逐词元图导航近似 MaxSim。其意义在于为多向量检索提供一条 CPU 友好、无需交互矩阵、图后端可替换的索引路线，并已集成到蚂蚁集团开源向量搜索库 VSAG。

## 2. 方法论

### 2.1 核心思想

- 不直接对文档集合构图，也不计算完整质心—查询交互矩阵。
- 将所有文档的词元向量组织为细粒度簇；每个簇对应一个质心。
- 在质心上构建**单一图索引**，查询时对每个查询词元执行图搜索，找到最近质心，再由质心映射到候选文档。
- 用检索到的质心内积近似每个查询词元与文档的最佳匹配分数，最后对少量候选做精确 MaxSim 重排。

### 2.2 索引构建流程

1. **采样初始化**：按采样比例 \(\alpha\) 从全部词元向量中均匀采样初始质心，借鉴 PAG 的聚合点思想。
2. **临时图分配**：在采样质心上构建临时图索引，其余词元通过图搜索找到最近质心并分配。
3. **超大簇分裂**：对超过阈值 \(T\) 的簇进行递归 \(k=2\) 局部划分，直到所有簇大小不超过 \(T\)。论文实现采用“延迟递归分裂”，将分配与图变更解耦，便于多线程构建。
4. **质心更新**：每个簇质心更新为成员向量的归一化均值，使其位于单位超球面上，与 ColBERT 的 \(\ell_2\) 归一化词元一致。
5. **最终图构建**：在更新后的质心上构建最终图索引，默认使用 HNSW，也可替换为 NSG、Vamana、DPG 等图后端。
6. **映射维护**：维护词元到文档的映射 \(\phi(v)=d\)，以及质心到其成员来源文档的映射 \(\Psi(c)\)，供查询时快速收集候选文档。

### 2.3 查询处理

- 对每个查询词元 \(q_i\)，在质心图上检索 \(n_c\) 个最近质心 \(C_i\)。
- 由这些质心通过 \(\Psi\) 得到候选文档池 \(U_i\)。
- 对候选文档 \(d\)，计算逐词元近似分数：
  \[
  s_i(d)=\max_{c\in C_i\cap C(d)}\langle q_i,c\rangle
  \]
  即用检索到的、包含该文档词元的质心中与查询词元最相似者作为代理。
- 每个查询词元保留最多 \(n_d\) 个文档，形成 \(D_i\)；候选集为 \(D_{\text{cand}}=\cup_i D_i\)。
- 近似 MaxSim 分数：
  \[
  \tilde M(d,Q)=\sum_{i:d\in D_i}s_i(d)
  \]
- 按近似分数选 top-\(k_r\) 候选，访问原始词元向量并计算精确 MaxSim，返回 top-\(k\)。

### 2.4 SIMQ+ 的改进

- **动机**：细粒度划分下，质心与成员向量很近，检索到的质心内积普遍接近 1，不同文档的近似分数差异变小，可能出现“低估相关文档、高估无关文档”的排序反转。
- **基于计数的评分**：不再用质心内积截断和排序，而是统计每个文档被多少个不同查询词元的候选池覆盖：
  \[
  \text{cnt}(d)=\sum_{i=1}^{m}\mathbf{1}[d\in U_i]
  \]
  同一查询词元即使命中多个簇，对同一文档也只计一次。
- **动态候选集**：按命中计数降序收集候选，选择最大阈值 \(\tau\)，使至少 \(N_{\min}\) 个文档满足 \(\text{cnt}(d)\ge\tau\)，并保留边界处所有并列文档，避免固定 top-\(k_r\) 截断任意拆分同分文档。
- 最后对动态候选集执行精确 MaxSim 重排。

### 2.5 理论分析

- 定义近似向量 \(\tilde v_i\) 为真实最佳匹配向量所在簇的质心，近似误差为：
  \[
  \varepsilon=M(d,Q)-\tilde M(d,Q)=\sum_i\langle q_i,v_i^*-\tilde v_i\rangle
  \]
  并由 Cauchy–Schwarz 上界受 \(\delta(v_i^*,\tilde v_i)\) 控制。
- 在低维流形、语义簇、簇间分离、分区混合、成功单元检索等假设下：
  - SIMQ 的数据感知 Voronoi 划分单元半径 \(r_S\) 较小；
  - MUVERA 的数据无关 LSH 以概率 \(p_{\text{mix}}\) 跨越语义簇边界，期望误差为 \(\Omega(p_{\text{mix}}\delta_{\min})\)；
  - 若 \(p_{\text{mix}}\delta_{\min}\gg r_S\)，则 SIMQ 的期望逐词元近似误差更小，进而总期望近似误差更小。
- 论文还指出：MUVERA 重复 \(R\) 次划分只降低随机方差，收敛到数据无关划分的平均行为，不能消除系统性划分偏差。

## 3. 实验设计

- **数据集**：五个信息检索数据集，来自 BEIR 与 ColBERTv2 评测体系：
  - Quora：约 52.3 万 passage，1 万查询；
  - SciDocs：约 2.57 万 passage，1 千查询；
  - NQ：约 268 万 passage，3.5 千查询；
  - HotpotQA：约 523 万 passage，7.4 千查询；
  - LoTTE-pooled：约 282 万 passage，3.9 千查询，作为域外基准。
- **Benchmark 与指标**：
  - 主要指标为 Recall@\(k\)@\(k\)，主实验报告 \(k\in\{20,50,100\}\)，其余默认 \(k=100\)；
  - 吞吐量 QPS；
  - 索引构建时间。
  - 所有方法使用相同 ColBERTv2 词元嵌入，维度 \(h=64\)，相同 qrels。
- **对比方法**：
  - PLAID：k-means 质心 + 残差量化 + 交互矩阵过滤；
  - MUVERA：LSH 分区 + 固定维编码 FDE + 单向量索引；
  - IGP：在 PLAID 质心上加图导航；
  - GEM：原生多向量图索引，文档集合级构图。
- **主要实验组**：
  - RQ1：五数据集上 QPS–Recall 曲线（20@20、50@50、100@100），以及采样比例敏感性、索引构建时间；
  - RQ2：PAG 采样划分与 k-means、LSH 在近似匹配召回下的 QPS/Recall 对比；
  - RQ3：SIMQ 与 SIMQ+ 随 \(n_c\) 变化的召回对比；
  - RQ4：HNSW、NSG、DPG 三种图后端在 NQ、HotpotQA 上的可替换性验证。
- **关键参数**：SIMQ 默认 \(\alpha=0.1\)、最大簇大小 \(T=160\)、HNSW \(M=32\)、efConstruction=50、\(n_d=1000\)、\(k_r=1000\)；SIMQ+ 使用 \(N_{\min}=1000\)。PLAID 在 SciDocs/Quora 使用较小 \(K\)，其余数据集使用约 26.2 万质心；MUVERA 使用 \(R=20\)、\(b=4\)、\(d_{\text{proj}}=16\)。
