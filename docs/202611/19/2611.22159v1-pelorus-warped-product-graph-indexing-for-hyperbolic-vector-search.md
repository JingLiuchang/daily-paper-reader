## 摘要
双曲嵌入能够捕获层次关系，但百万规模近似最近邻搜索必须兼顾测地保真度与内存效率。平坦内积索引会扭曲径向壳层间的顺序，而原生双曲图则反复访问全精度向量，或以奇异共形尺度量化坐标。我们提出 Pelorus，一种用于双曲向量搜索的扭曲乘积近邻图索引。Pelorus 将未量化的 FP32 径向标量与共形标量同尺度不变的 2 比特球面方向编码分离，并将全向量 FP64 评估推迟到紧凑的重排序尾部。共形畸变分析启发了正交投影去偏、纯度门控切锥残差以及 Conformal Jacobian 门控。QuadriPrune 在测地纤维、同壳环和径向电梯之间分配边，并通过生成树弦交换恢复入口可达性。单页记录布局与进位保存式 AVX2 内核加速遍历。在 AMD EPYC 9654 上的八个真实与合成基准中，Pelorus 在 32 线程上构建 Cohere-1M 索引比全精度极坐标图快 5.44 倍，将热导航内存降至 517.0 MB。在 99% Recall@10 下，它将 Cohere-1M 的吞吐量在单线程上提升 4.30 倍、在 24 线程上提升 6.31 倍，并在 MERU-1M 上达到 53,483 QPS。在聚簇窄壳层上，切锥残差将召回率从 34.22% 提高到 99.385%，而各向同性窄壳层压力测试揭示了仍存在的召回率限制。

## Abstract
Hyperbolic embeddings capture hierarchical relations, but million-scale approximate nearest neighbor search must reconcile geodesic fidelity with memory efficiency. Flat inner-product indices distort order across radial shells, while native hyperbolic graphs repeatedly access full-precision vectors or quantize coordinates with singular conformal scales. We present Pelorus, a warped-product proximity-graph index for hyperbolic vector search. Pelorus separates unquantized FP32 radial and conformal scalars from scale-invariant 2-bit spherical directional codes and defers full-vector FP64 evaluation to a compact reranking tail. A conformal distortion analysis motivates orthogonal-projection debiasing, purity-gated tangent-cone residuals, and Conformal Jacobian gating. QuadriPrune allocates edges across geodesic fibers, same-shell rings, and radial elevators, with spanning-tree chord swaps restoring entry reachability. A single-page record layout and carry-save AVX2 kernel accelerate traversal. Across eight real and synthetic benchmarks on AMD EPYC 9654, Pelorus builds Cohere-1M indices 5.44x faster than full-precision polar graphs on 32 threads, reducing hot navigation memory to 517.0 MB. At 99% Recall@10, it improves Cohere-1M throughput by 4.30x on one thread and 6.31x on 24 threads, and delivers 53,483 QPS on MERU-1M. On clustered narrow shells, tangent-cone residuals raise recall from 34.22% to 99.385%, while isotropic narrow-shell stress tests expose remaining recall limits.

## 1. 核心问题与整体含义

- **研究背景**：双曲嵌入（Poincaré ball / Lorentz hyperboloid）能以更低畸变表达层次、分类与蕴含关系，适用于 RAG、视觉-语言对齐、知识库检索等。但在百万规模上做近似最近邻搜索（ANN）时，双曲几何的“共形因子”和“径向壳层”会使传统平坦空间索引失效。
- **核心矛盾**：测地保真度 vs. 内存/吞吐效率。
  - 平坦内积索引会把径向层次深度与角度邻近混在一起，跨径向壳层产生排序失真。
  - 原生双曲图索引要么每次跳转读取全精度坐标，内存与 DTLB 压力大；要么直接量化环境坐标，未解耦奇异共形尺度。
- **论文指出的三类几何障碍**：
  1. **跨壳共形非抵消与 Lorentz-MIPS 量化爆炸**：双曲代理距离中方向内积被候选相关共形权重 \(W(r_q,r_v)=\frac{2}{c}\sinh\rho_q\sinh\rho_v\) 加权，跨壳时查询量化噪声不能像平坦余弦那样抵消；直接量化 Lorentz 空间坐标会使噪声随 \(\|\tilde z\|_2=\Theta(e^\rho)\) 放大。
  2. **径向遮挡与角锥收缩**：负曲率使测地线向原点弯曲，内部 hub 可在 Vamana 剪枝中“遮挡”整个球面邻域；同壳可存活角锥随深度指数收缩。

- **整体含义**：论文提出 **Pelorus**，将双曲流形视为 warped-product（扭曲乘积）结构，把精确径向/共形标量与尺度不变的球面方向码解耦，并联合设计图拓扑、量化估计器与页对齐执行引擎，以在百万规模双曲 ANN 中同时获得高召回、低内存和高吞吐。

## 2. 方法论

### 2.1 核心思想：Warped-Product Polar Decoupling

- 每个点 \(x\in \mathbb B_c^D\) 分解为：
  - 未量化 FP32 径向标量：欧氏半径 \(r_x\)、边界因子 \(F_x=f_x/2=(1-cr_x^2)^{-1}\)、无量纲测地深度 \(\rho_x=2\operatorname{atanh}(\sqrt c r_x)\)，存入 **32 字节 PolarNodeMeta 头**。
  - 尺度不变的球面方向 \(u_x\in S^{D-1}\)，用 **训练-free 2-bit Sign-Magnitude（SM）bitplanes** 编码。
- 双曲代理距离写成：
  \[
  P_{\mathbb B}(q,v)=R(r_q,r_v)+W(r_q,r_v)(1-\gamma_{qv}),
  \]
  其中 \(R=(r_q-r_v)^2f_qf_v\)，\(W=2r_qr_vf_qf_v\)。该代理与真实测地距离严格序同构，因此可将超越函数计算推迟到最终 FP64 重排。
- Lorentz 嵌入在摄入时通过立体投影精确同构映射到 Poincaré ball，避免直接量化 Lorentz 空间坐标导致的指数误差放大。

### 2.2 共形极坐标估计与去偏

- **查询边界深度不变性**：同壳候选比较时，共形因子 \(f_q,f_x\) 在翻转判据中抵消，同壳方向翻转概率不随查询靠近边界而恶化。
- **跨壳查询噪声非抵消**：推导出跨壳查询误差项 \(d_q(r_q;r_x,r_y)\eta_q(u_x)\)，其方差随深度指数增长；因此需要同壳环边、未量化查询重打分等机制。
- **确定性正交投影估计器（Stage-0.5）**：利用两级 SM 的 Pythagorean 恒等式
  \[
  \langle u_v,\hat u_v\rangle=\|\hat u_v\|_2^2=\sigma_v^2,
  \]
  用 \(\langle u_q,\hat u_v\rangle/\sigma_v^2\) 代替普通余弦归一化，沿候选方向无乘性收缩，且无需随机旋转或分布假设。
- **闭式径向最小化**：沿方向射线，双曲余弦目标 \(g_\gamma(\rho)\) 严格 1-强凸，唯一极小点为
  \[
  \rho^*(\rho_q,\gamma)=\operatorname{atanh}(\tanh\rho_q\cdot\max(\gamma,0)),
  \]
  用于路由和壳层代表选择。
- **纯度门控切锥残差 + CJ-Gate**：
  - 对高纯度边界锥，存储归一化切向残差 \(\tilde r_v=(u_v-\alpha_v\mu_c)/\sqrt{1-\alpha_v^2}\) 的 2-bit SM 码，复用原 bitplane 槽，**0 B/vertex 额外开销**。
  - 通过 Conformal Jacobian 门控（CJ-Gate）按 \(\beta_{q,c}\beta_v\) 调整不确定性与平台扩展，避免离轴查询低估误差。
  - 扩散真实数据自动保持全局 2-bit 路径（0 cones）；聚簇窄壳激活 256 个锥。

### 2.3 图拓扑：Inside-Out + QuadriPrune + 弦交换修复

- **Inside-Out 测地播种**：按测地深度非递减排序，内部顶点先插入，减少边界顶点被内部 hub 遮挡。
- **QuadriPrune 四通道出边分配**：

  2. **径向屏蔽同壳环通道**：累计到约 \(7M_0/8\)，按角度加深度差排序，使 \(W(r_q,r_x)\approx W(r_q,r_y)\)，恢复同壳查询噪声抵消。
  3. **向内径向电梯**。
  4. **向外径向电梯**。
- **生成树弦交换岛修复**：并行插入后仍有少量零入度边界岛；通过替换非树弦边、保留 BFS 生成树边，实现从入口 hub 出发的 **100% 有向 BFS 可达性**，且保持最大出度 \(M_0\)。

### 2.4 页对齐执行引擎

- **4096 B HotSmPage 单页共置**：每个顶点记录包含 64 B 头（32 B PolarNodeMeta + 32 B SymSketch256）与完整 2-bit bitplanes；在 \(D=768\) 时每页 16 个顶点，避免 SoA 布局下元数据与 bitplane 分属不同页导致的二次 DTLB walk。
- **两级 beam 过滤**：
  - Stage-1a：用无损径向下界 \(P_{\text{rad}}=(r_q-r_v)^2f_qf_v\) 直接剪枝。
  - Stage-1b：256-bit 符号 sketch 的 Hamming 距离 + 二项方差稳定表，构造乐观余弦上界，提前跳过完整 bitplane 读取；Cohere-1M 上跳过约 57.6% 的完整 bitplane 加载。
- **3-to-2 进位保存 AVX2 内核**：将五个 popcount 的 SM 内积计算通过 CSA 压缩三元组，减少 33% 的 `vpshufb` shuffle 指令。
- **L1 有界 Stage-0.5 + FP64 重排**：用 i16 定点掩码子集和计算非对称投影；最终 top-k 用 FP64 SIMD 精确测地距离重排，避免边界处 \(1-c\|v\|_2^2\) 的灾难性消去。
