## 摘要
大语言模型智能体在记忆中积累经验，而记忆在交互过程中如何演化，与其存储了什么同样重要。近期方法在线更新记忆，但用于变换记忆的算子以及选择这些算子的规则在设计上仍保持固定。我们提出 EvoDisco，将智能体记忆演化形式化为演化策略发现：智能体必须发现应应用哪个算子、何时应用以及如何实例化，而不是在静态算子调度下重写记忆。一个可学习策略以当前记忆状态和近期任务历史为条件，然后选择并实例化四种语义算子之一——Abstract、Refine、Bridge 与 Reframe——它们分别压缩相关记忆、分解过载条目、连接弱关联经验以及重组检索到的推理链。该策略通过双层适应度进行更新。内层信号使用由记忆复杂度正则化的检索质量提升来为每次变换打分。外层信号在过往决策窗口上评估策略效能，结合历史算子效用遗憾、效用预测误差和选择多样性。在 ALFWorld、WebShop 和 LifelongAgentBench（OS 与 DB）上的一次性在线加冻结迁移协议下，EvoDisco 优于包括 MemP 和 MemRL 在内的强记忆基线。最大增益出现在 ALFWorld（相较 MemP 提升 +8.8 在线 / +12.9 冻结迁移点；相较 MemRL 提升 +16.4 / +17.9）。消融实验将这些增益归因于两个适应度层级以及算子库。

## Abstract
Large language model agents accumulate experience in memory, and how that memory evolves during interaction is as important as what it stores. Recent methods update memory online, yet both the operators that transform memory and the rules that select them remain fixed by design. We propose EvoDisco, which formulates agent memory evolution as evolutionary strategy discovery: the agent must discover which operator to apply, when to apply it, and how to instantiate it, rather than rewriting memory under a static operator schedule. A learnable policy conditions on the current memory state and recent task history, then selects and instantiates one of four semantic operators---Abstract, Refine, Bridge, and Reframe---which respectively compress related memories, decompose overloaded entries, connect weakly linked experiences, and reorganize retrieved reasoning chains. The policy is updated with a bi-level fitness. An inner signal scores each transformation using a retrieval-quality improvement regularized by memory complexity. An outer signal scores strategic efficacy over a window of past decisions, combining historical operator-utility regret, utility-prediction error, and selection diversity. Under a one-pass online plus frozen-transfer protocol on ALFWorld, WebShop, and LifelongAgentBench (OS and DB), EvoDisco improves over strong memory baselines including MemP and MemRL. The largest gains are on ALFWorld ($+8.8$ online / $+12.9$ frozen-transfer points over MemP; $+16.4$ / $+17.9$ over MemRL). Ablations attribute these gains to both fitness levels and the operator library.

# EvoDisco 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：LLM 智能体需要跨会话积累经验，记忆已成为核心模块。近期研究共识是"记忆如何组织"与"记忆存了什么"同等重要，因此涌现出大量图结构记忆系统（AriGraph、Zep、A-MEM、G-Memory 等），在关系建模、多跳推理与可解释访问上优于扁平向量检索。
- **关键缺口**：现有结构化记忆大多是**一次性构建**，之后结构基本静态，缺少随任务分布变化而持续重组的能力。
- **已有演化工作的局限**：HAGE 用 RL 训练边权重、MemEvolve 做元演化、EvolveMem 搜索检索配置、FORGE 用种群协议演化自然语言记忆——但**演化机制本身仍由人固定**：变异/交叉用预设概率、边更新遵循指定 RL 规则、配置搜索局限在人工设定的动作空间内。
- **核心追问**：如果智能体本身能对自身记忆进行推理，为何记忆的演化方式要由人类设计者预先规定？
- **论文主张**：把记忆演化从"按固定算子调度重写记忆"提升为**演化策略发现（evolutionary strategy discovery）**——智能体需自行发现**用哪个算子、何时用、如何实例化**。

## 2. 方法论

### 2.1 记忆表示与状态

- 记忆为**有向多关系图** G=(V,E)：节点存事实/情节摘要/流程/概念，含嵌入、时间戳、置信度 c∈[0,1]、检索计数；边为类型化关系（causes、precedes、analogous-to、is-a、generalizes），带强度与证据新近度。
- 每回合后由 LLM 抽取器写入记忆单元与候选关系；执行期用**以查询为中心的扩散激活**检索子图。
- 演化事件 i 的状态 s_i 拼接四组特征：图统计（节点/边数、平均度、模块度、路径长度）、检索统计（延迟、命中率、检索节点多样性）、近期结果（最近算子选择与效用、近期任务得分 y_j）、结构缺陷摘要（高度节点、连通分量、长路径）。
- 动作 a_i=(o_i, c_i, θ_i)：算子 o、候选图 c、实例化参数 θ；执行 G_i⁺=T_{o_i}(G_i;c_i,θ_i)。事件计数包含"未提交编辑"的尝试。

### 2.2 四类认知算子库（固定，不学习新增类别）

- **Abstract**：把相关记忆压缩为高层概念/可复用流程，用 generalizes 边连接支撑记忆，可选剪枝（p>0 且相似度≥0.70+0.25p 且不满足保留检查时删除）。
- **Refine**：沿时间/因果/类别维度把过载记忆分解为 m∈{2,3,4} 个子节点，父节点保留或替换。
- **Bridge**：为语义相近但弱连接的区域生成类型化关系；相似度低于 0.35+0.3p 时拒绝。
- **Reframe**：不改节点文本、不加节点，仅沿一条既有路径重写 causes/precedes 边；策略选 frame，一次冻结 LLM 调用返回重定向，执行器按规则反转或重标（缺失边以 0.75 权重插入，已有边加权 +0.15×0.75，随后该对边权重 +0.1 并更新新近度）。
- **候选构造**：每算子最多 8 个候选（固定规则：Abstract 按 2 跳邻域规模与检索计数排种子；Refine 按度排 hub；Bridge 按嵌入相似度排距离≥2 的分量对，无则用两均值分裂；Reframe 采样长路径），空集算子被屏蔽；第二个头用候选特征与 s 的线性投影点积选候选。五个类别头（k、p、m、维度、frame）每次尝试都采样。

### 2.3 双层适应度（两个反馈时间尺度，非严格嵌套优化）

- **内层：即时效用** U_i = α·ΔQ_i − β·[C(G_i⁺) − C(G_i)]
  - ΔQ_i 为**图局部代理**：在事件前已观测查询缓存上，用扩散激活 Top-3 分数均值计算检索质量变化，与后续任务得分无关；
  - C(G)=λᵀc(G) 为节点数/边密度/路径长度构成的结构复杂度；
  - 未提交编辑记 U_i=−0.05；**不做基于效用的回滚**，无论效用正负都保留变换后图。
- **外层：策略效能** E_i = −γ·Regret_i − δ·PredErr_i + η·Div_i，在最近 K=20 次尝试窗口上计算：
  - Regret：与各算子最近 h=8 次执行均值之差的**正部**平均（作者明确承认这不是同状态反事实遗憾）；
  - PredErr：执行前效用预测 Û_i=q_ψ(s_i,a_i) 与实现值的绝对误差；
  - Div：算子使用频率的熵（软性多样性偏好，非等频要求）。

### 2.4 策略学习流程

- 策略为两层 MLP（隐层 128），因式分解 π_φ(a|s)=π(o|s)·π(c|s,o)·π(θ|s)；学习用加权对数概率 log π_w = log π(o|s)+log π(c|s,o)+(1/4)Σ_j log π(θ_j|s)。
- 每 N=5 次尝试做一次得分函数（REINFORCE）更新：∇J_i = sg(E_i)·Σ_{ℓ∈B_i}∇log π_w(a_ℓ|s_ℓ)；评分窗口 W_i（近 K 次）与更新批次 B_i（上次更新后的新事件）**角色分离**，旧事件不当作新 on-policy 样本。
- 辅助目标：仅 U_i>0 的 (s,a) 进入回放缓冲 D⁺，最小化 −E[log π_w]，与策略梯度更新分离。
- 在线协议：单次遍历；仅前 ρ=0.8 的回合允许演化（触发条件：距上次演化满 T=10 回合，或近 10 回合移动平均分下降 >ε=0.15）；之后仅保留普通记忆写入；held-out 评估时冻结全部记忆（禁写禁演化）。

### 2.5 关键超参

α=1.0、β=0.3、γ=1.0、δ=1.0、η=0.3、K=20、N=5、T=10、ε=0.15、演化截止 0.8、学习率 1e-3、温度 0.0、嵌入 text-embedding-3-large、随机种子 42。

- **统一设置**：全部方法共享同一冻结骨干 GPT-5-mini、同一 agent 循环、划分文件与步数预算。

## 6. 主要结论与发现

- EvoDisco 在**全部四个基准的在线与冻结迁移 SR 上均为最高**：ALFWorld 77.7/88.6（超 MemP 8.8/12.9 点，超 MemRL 16.4/17.9 点）；OS 74.0/77.3（MemP 71.7/76.0）；WebShop 32.8/35.0（迁移超最强基线 1.0 点）；DB 88.4/87.1。
- **记忆并非普遍有益**：DB 上多个记忆基线低于 No Memory；EvoDisco 仅与 No Memory 持平或略优（晚期 20% 二者同为 86.1%）。
- **消融（ALFWorld 迁移 SR）**：去外层 80.7（−7.9）、去内层 79.3（−9.3）、去认知算子 82.1（−6.5）；最好的固定算子 Abstract 为 85.7（−2.9），Fixed Refine/Bridge/Reframe 分别落后 7.2/7.9/8.6。**两个适应度信号对"冻结迁移"的贡献远大于对在线 SR 的贡献**（在线仅降 2.4/1.7 点）。
- **跨基准策略迁移**：ALFWorld 训练策略直接用于 WebShop/OS/DB 分别落后目标域自训练 4.0/2.0/4.4 点，说明策略有一定可迁移性但非最优。
