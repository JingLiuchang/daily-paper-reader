## 摘要
基于大语言模型（LLM）的智能体在解决复杂、长时程任务时会积累大量交互历史，因此高效的记忆管理对其性能和可扩展性至关重要。现有记忆管理方法主要关注保留或检索哪些信息，却往往忽视了应为每个过去交互分配多少感知细节。我们认为，有效的智能体记忆不仅取决于所保留的信息，还取决于对每个过去交互进行感知的粒度。受此启发，我们提出分辨率即注意力（Resolution as Attention, RAA），一种以视觉分辨率作为跨交互历史注意力分配手段的记忆感知机制。RAA 将过去交互渲染为图像，并在每一步根据其与智能体即将做出的决策的相关性动态调整分辨率，从而为关键交互保留细粒度信息，同时降低较不相关交互的视觉 token 消耗。为了自适应地确定每个交互的感知保真度，我们在教师模型指导下训练一个轻量级相关性估计器，并进一步优化它，以在降低视觉 token 成本的同时保持智能体的决策一致性。跨多个任务和骨干模型的实验表明，RAA 在不损害任务性能的情况下将 token 消耗降低 50% 以上。此外，RAA 可作为插件式感知层与现有记忆管理方法集成，带来进一步的 token 节省，并揭示自适应感知是智能体记忆的一个互补维度。

## Abstract
LLM-based agents accumulate extensive interaction histories when solving complex, long-horizon tasks, making efficient memory management critical to their performance and scalability. While existing memory management methods primarily focus on what to retain or retrieve, they often overlook how much perceptual detail should be allocated to individual past interactions. We posit that effective agent memory depends not only on the information preserved, but also on the granularity at which each past interaction is perceived. Motivated by this insight, we propose Resolution as Attention (RAA), a memory perception mechanism that uses visual resolution as a means of attention allocation across interaction histories. RAA renders past interactions as images and dynamically adjusts their resolution at every step according to their relevance to the agent's upcoming decision, preserving fine-grained information for critical interactions while reducing visual-token consumption for less relevant ones. To adaptively determine the perceptual fidelity of each interaction, we train a lightweight relevance estimator with teacher-model guidance and further optimize it to preserve the agent's decision consistency at a reduced visual-token cost. Experiments across multiple tasks and backbones show that RAA reduces token consumption by over 50% without compromising task performance. Moreover, RAA can be integrated as a plug-in perception layer with existing memory management methods, yielding further token savings and revealing adaptive perception as a complementary dimension of agent memory.

- **现有两条主流路线及其局限**：
  - **检索（Retrieval）**：将历史存于外部记忆，按需召回相关片段；其效果受检索质量上界约束，未被召回的片段对智能体完全不可见。
  - **压缩（Compression）**：通过摘要或剪枝将历史压缩为紧凑表示；但会不可逆地丢弃细粒度信息，而这些信息可能对后续决策至关重要。
  - **光学压缩（Optical Compression）**：将文本渲染为图像以更少视觉 token 读取；但通常采用统一压缩率或固定策略（如按时间新近度降采样），导致无关交互浪费 token、关键交互细节不足。
- **核心洞察**：现有方法关注“保留或检索什么信息”，却忽视了“**每条过去交互应以何种粒度被感知**”。作者主张：有效的智能体记忆不仅取决于保留的信息，还取决于感知的粒度，且该粒度应随交互不同、随任务推进而动态演化。
- **整体含义**：提出“记忆感知（Memory Perception）”作为智能体记忆中与检索、压缩正交的第三个维度，并用视觉分辨率作为注意力分配的手段，实现交互级、决策感知、非破坏性的记忆读取。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- **Resolution as Attention（RAA）**：受人类视觉“注意力通过感知精度分配”的启发，将每条过去交互渲染为规范图像，并根据其与“即将到来的决策”的相关性，动态调整读取分辨率。
- 高相关交互保留高分辨率（细粒度细节），低相关交互降采样（节省视觉 token）；智能体本身保持冻结，无需额外训练即可作为即插即用感知层。

### 2.2 问题形式化
- 任务描述为 \(D\)，第 \(i\) 条交互为 \(h_i=(r_i,a_i,o_i)\)，第 \(t\) 步前历史为 \(H_t=(h_1,\dots,h_{t-1})\)。
- 智能体生成：\((r_t,a_t)\sim\pi(\cdot\mid D,H_t)\)。
- 将每条交互渲染为规范图像 \(I_i=\mathcal{R}(h_i)\)，按尺度 \(s_i\in(0,1]\) 缩放：\(\tilde I_i=\mathrm{Resize}(I_i,s_i)\)。
- 视觉 token 数近似为 \(N_i(s_i)\approx s_i^2 N_i(1)\)，即 token 随尺度**平方级**下降。

### 2.3 框架流程（四步）
1. **相关性估计**：轻量重排器 \(f_\theta\) 以任务描述 \(D\) 与最新交互 \(h_{t-1}\) 构成查询，对每条历史 \(h_i\) 独立打分：
   \[
   p_i^{(t)}=f_\theta(D,h_{t-1},h_i)\in(0,1)
   \]
   实际用“yes/no” token logits 的 sigmoid 概率：\(p_i^{(t)}=\sigma(z_{yes}-z_{no})\)。
2. **分辨率映射**：可学习单调归一化 sigmoid 将相关性映射为尺度：
   \[
   s_i^{(t)}=g_\phi(p_i^{(t)}),\quad g_\phi(p)=\frac{\sigma(k(p-b))-\sigma(-kb)}{\sigma(k(1-b))-\sigma(-kb)}
   \]
   其中 \(k>0\) 控制曲线锐度，\(b\in(0,1)\) 控制中点；归一化保证 \(g_\phi(0)=0,\ g_\phi(1)=1\)，且保持相关性排序。
3. **分辨率控制渲染**：从**规范图像**（而非上次渲染结果）重新缩放，构成记忆 \(M_t=\{\mathrm{Resize}(I_i,s_i^{(t)})\}_{i=1}^{t-1}\)，保证每条交互每步都按当前相关性重新感知，信息不被永久破坏。
4. **智能体操作**：冻结的视觉能力智能体感知 \(M_t\) 并生成下一步动作；最新一轮交互保持文本形式作为查询。

### 2.4 两阶段训练（智能体全程冻结）
- **Stage I：相关性监督**
  - 用教师模型（Qwen-3.8-27B）在高分轨迹上对每条历史交互给出“决策依赖度”评分 \(\hat p_i^{(t)}\in[0,1]\)。
  - 以密度加权 MSE 损失蒸馏到轻量估计器（初始化自 Qwen3-Reranker-0.6B）：
    \[
    \mathcal{L}_{sup}(\theta)=\mathbb{E}_{t,i}\big[w_i^{(t)}(p_i^{(t)}-\hat p_i^{(t)})^2\big]
    \]
  - 目的：让估计器从“语义相似度”转向“决策相关性”。
- **Stage II：分辨率强化学习**
  - 将 \(g_\phi\circ f_\theta\) 视为分辨率尺度上的随机策略，以 logit-normal 分布采样尺度：\(s_{i,j}=\sigma(\mathrm{logit}(s_i^{(t)})+\tau\epsilon_j)\)，\(\tau=0.5\)，每个被选交互采样 \(K=8\) 个候选。
  - 奖励函数：
    \[
    R_j=\underbrace{\bar\ell(a_t\mid D,M_t^{(j)})-\bar\ell(a_t\mid D,H_t)}_{\text{决策保真度}}+\lambda\underbrace{(1-s_{i,j}^2)}_{\text{token 节省}}
    \]
  - 用 GRPO 优化估计器与映射；候选间仅改变单条交互尺度，使优势可精确归因到该交互。
- **无全局 token 预算**：与 softmax 注意力分配固定总权重不同，RAA 按相关性独立缩放每条交互，总视觉 token 随决策需求浮动（作者认为预设预算可能截断关键细节或保留冗余）。
