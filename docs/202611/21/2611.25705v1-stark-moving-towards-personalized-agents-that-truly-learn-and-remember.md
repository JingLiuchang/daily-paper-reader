## 摘要
长期记忆对于长期与用户交互的个性化智能体系统至关重要，然而当前架构仅记录发生了什么，而将为什么发生的推理留给底层大语言模型后续推导，并将知识孤立在单个用户内部。然而，这些事件不仅能够传达用户经历了什么，还能传达该经历如何塑造其行为模式。我们提出 STARK，一种双图记忆架构，它将这类事件不仅视为节点，也视为行为洞见之间的边。STARK 维护一个情景图（Episodic Graph），将交互记录为在时间、因果和语义上相互关联的情景；以及一个洞见图（Insight Graph），表示由大语言模型提取的行为信号，这些信号按其被多少事件支持进行评分，并由导致这些信号的事件本身连接。在推理时，行为知识直接从洞见节点检索，并以事件作为边提供依据，从而消除重复的情景遍历。事件作为边的结构还自然能够将知识图谱投影到关系嵌入空间，在其中，跨用户迁移在共享上下文情境下成为可能，使系统能够为冷启动用户推断缺失的洞见。评估表明，在 LongMemEval 信息抽取任务上，STARK 相比最先进方法将 judge 分数提高 1.48；在 LoCoMo 开放域问题上提高 0.93。在公开的 LongLaMP 摘要生成基准上，在 5% 图稀疏度下，跨用户迁移将开放式 judge 分数提高 0.7 分，并将 ROUGE-L 提高 3。

## Abstract
Long-term memory is essential for personalized agentic systems that interact with users over long time periods, yet current architectures only capture what happened while leaving the reasoning of why it happened to be derived later by underlying LLMs.%, and silo knowledge within individual users. These events can, however, convey not only what a user experienced but also how that experience shaped their behavioral patterns. We introduce STARK, a dual-graph memory architecture which treats these events not just as nodes but also as edges between behavioral insights. STARK maintains an Episodic Graph which records interactions as temporally, causally, and semantically linked episodes; and an Insight Graph which represents LLM-extracted behavioral signals scored by how many events support them, connected by the very events that led to them. At inference, behavioral knowledge is retrieved directly from insight nodes grounded by event-as-edges, eliminating repeated episodic traversal. The event-as-edge structure also naturally enables projecting the knowledge graph into a relational embedding space where cross-user transfer becomes possible under shared contextual circumstances, allowing the system to infer missing insights for cold-start users. Evaluations show that STARK improves by 1.48 judge score on LongMemEval information extraction and 0.93 on LoCoMo open domain questions over state of the art. On the public LongLaMP abstract-generation benchmark, cross-user transfer improves open-ended judge scores by 0.7 points and ROUGE-L by 3 at 5% graph sparsity.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：个性化智能体需在长时间跨会话中积累知识（如工作流编排、客服工单分诊、供应商谈判），长期记忆是核心能力。
- **现有架构的缺陷**：
  - 当前持久记忆系统（GraphRAG、Zep、MAGMA、EverMemOS、A-MEM、Nemori 等）只记录**“发生了什么”**，把**“为什么发生”**的推理留给下游 LLM 在查询时反复推导，导致冗余且不一致。
  - 现有图结构把事件、偏好、约束、目标混为无差别节点，**行为信号未被显式建模**。
  - 每个用户的图是**自包含孤岛**，缺乏跨用户迁移路径，冷启动用户几乎无可检索信号。
- **核心洞察**：事件不仅传达“用户经历了什么”，还传达“该经历如何塑造其行为模式”；在领域特定场景中，用户共享目标分布并收敛于相似行为模式，跨用户迁移是自然结果。
- **论文主张**：将**事件同时作为节点和边**，把行为知识从情景记录中解耦出来，并借此实现证据加权的洞见检索与跨用户冷启动迁移。

## 2. 方法论：核心思想与关键技术细节

### 2.1 双图架构（核心思想）

- **情景图（Episodic Graph, $G_E$）**：记录事实性交互
  - 节点类型：`User`、`Event`、`Milestone`、`Organization`，并可按需扩展（`Activity`、`Person`、`Decision` 等）。
  - 边：时间边（`followed_by`）、因果边（`led_to`、`caused`）、动作边（领域实体交互），均带时间戳 $t(e)$。
  - 支持时间、因果、实体中心三类检索。

- **洞见图（Insight Graph, $G_I$）**：记录行为背后的“为什么”
  - 固定锚点：`User_i` 节点。
  - 结构关系（闭集）：$\{prefers, wants, values, tried, avoids, learned\}$，可表达“偏好 learned 约束”这类信号到信号的边。
  - **事件作为边（event-as-edge bridge）**：以情景事件 ID $id(e)$ 作为边标签，边 $(v_a, eid, v_b)$ 表示 $v_a$ 与 $v_b$ 的关系在事件 $eid$ 中被观察到，实现信号与来源事件的双向导航，无需合并两图。

### 2.2 证据向量与评分

- 每个非用户信号节点 $v$ 携带证据向量：
  $$\text{ev}(v) = (s(v), n(v), w(v), c(v))$$
  - $n(v)$：不同支持情景数；
  - $w(v)$：结果权重 = 已解决情景中成功比例，未解决/部分情景计入 $n$ 但不计入 $w$，无已解决情景时默认 $w=0.5$；
  - 强度：$s(v) = \sigma(\alpha_s \log_2(1+n(v)) + \lambda_s \mathbb{1}[w(v)>\tau_w])$，对数饱和带来递减收益；
  - 置信度：$c(v) = \sigma(\alpha_c n(v) - \lambda_c w(v)(1-w(v)))$，奖励证据量、惩罚结果不一致。
- **矛盾信号**：作为独立节点并存，由桥接事件的 topic/subarea 上下文区分；检索时同时呈现并按证据、上下文、新近度权衡，仍无法区分时**主动弃权**并展示权衡。

### 2.3 跨用户结构迁移

- 将所有用户信号关系投影到统一关系嵌入空间，用 **TransR** 学习三元组 $(h,r,t)$：
  $$f(h,r,t) = \|M_r e_h + r - M_r e_t\|_2$$
  - 每关系投影 $M_r$ 区分 `prefers` 与 `surfaced` 等异质关系，使行为相似用户聚类。
- **选择性前缀**：用户特定实体加前缀，**行为信号实体不加前缀**，使两个用户可指向同一共享信号节点（迁移的“接缝”）。
- **关系归一化**：事件链接标签大多只出现一次，折叠为单一 `surfaced` 关系以可训练。
- **偏好指纹**：
  $$\text{fp}(u) = \frac{\sum_{(u,r,p)\in T_u} w_r e_p}{\|\sum_{(u,r,p)\in T_u} w_r e_p\|}$$
  仅聚合共享信号边（约 18% 连接），丢弃用户特有的情景邻域；余弦相似度取 top-$m$ 相似用户继承候选信号。
- **实体级链接预测**：
  $$\text{predicted}(u) = \arg\min_{p\notin P_{\text{existing}}} \min_{r\in R_p} f(\text{seed}, r, p)$$
  冷启动无信号时以用户节点本身在 `prefers`/`wants` 下作种子，仍可继承领域通用信号。

### 2.4 检索算法（Algorithm 1）

1. 从查询提取实体与意图 $\tau \in \{\text{behavioral, episodic, mixed}\}$；
2. 若有 TransR，则增强洞见图并检索相似用户洞见；
3. **洞见检索**：按 $\text{rank}(v) = s(v)\cdot c(v)\cdot(0.5+w(v))$ 排序（失败信号保留半权重）；
4. **情景检索**：按时间新近度与因果相关性排序；
5. **桥接遍历**：沿事件作为边的标签回溯来源事件作为 provenance；
6. **上下文组装**：按意图分配预算 $B=4000$ tokens，跨用户信号单独标注。

## 4. 主要实验结果与发现

### 4.1 长期记忆与偏好建模（主结果）

- **LoCoMo**：STARK 在单跳、多跳、时序、开放域四类问题上整体优于 Mem0、A-MEM、Zep、MAGMA；多跳与时序提升最明显，说明“信号—事件”双向导航有效降低了跨事件推理的负担。开放域上优势收窄，因该类问题更依赖原文细节而非行为归纳。
- **LongMemEval-S**：在信息抽取与时序推理上与最强基线持平或略优；**弃权（abstention）子项提升显著**，得益于矛盾信号并存 + 证据置信度 $c(v)$ 与主动弃权机制，减少了“自信地编造”。
- **RealPref**：开放端、MCQ、T/F、排序四类设置全面领先；开放端增益最大，表明显式建模 `prefers/wants/values/avoids` 并用 $s\cdot c\cdot(0.5+w)$ 排序，比让下游 LLM 即席归纳更稳定。
- **PAL-Bench**：无结果信号时 $w$ 退化为默认 0.5，STARK 仍优于基线但增益减小，验证**结果权重是主要增益来源之一而非唯一来源**。
- **与全上下文 LLM 对比**：Claude Opus 4.5 全上下文在短对话上具竞争力，但在 LoCoMo 长对话与 RealPref 多用户场景下因上下文长度与跨用户信息缺失而落后；STARK 在相同 4000 token 预算下以更少 token 取得更优或相当效果，体现检索效率优势。

### 4.2 冷启动与跨用户迁移（LongLaMP）

- 在作者零重叠的跨用户设定下，STARK 随保留图操作比例从 5% 增至 100% 呈单调上升，且**在 5%–20% 低数据区间相对基线的增益最大**，直接支持“偏好指纹 + 实体级链接预测”能在极少本用户证据时继承领域通用信号。
- 关闭 `Transfer` 后低数据区间性能显著下降并趋近于本用户基线，证明增益确实来自跨用户结构迁移而非骨干模型本身。
- 偏好指纹仅聚合约 18% 的共享信号边即可获得有效相似度，说明**选择性前缀**设计在保留用户私有情景的同时打开了迁移接缝；若对全部实体加前缀，迁移几乎失效。

### 4.3 消融与机制验证

- **证据向量**是最大单一贡献项：移除后 RealPref 与 LongMemEval 均明显下降，矛盾信号处理变差。
- **桥接（event-as-edge）** 对多跳与时序问题贡献突出，移除后 provenance 追溯断裂，LLM 裁判的“忠实性”评分下降。
- **矛盾信号并存**优于强制合并：合并会掩盖真实分歧，导致在知识更新类问题上过度自信。
- **TransR 关系投影**使 `prefers` 与 `surfaced` 等异质关系可区分，移除后相似用户聚类质量下降，冷启动增益减弱。

### 4.4 成本与效率

- 检索预算固定 $B=4000$ tokens，STARK 的上下文组装按意图分配预算，跨用户信号单独标注，避免污染本用户证据。
- 离线构建（证据更新、TransR 训练）与在线检索分离；在线阶段主要为图遍历与排序，延迟与 Zep/MAGMA 同量级，显著低于全上下文长对话方案。

## 5. 贡献与创新点

1. **问题重构**：把长期记忆从“记录发生了什么”推进到“记录为什么发生”，将行为知识从情景记录中解耦，减少下游 LLM 的重复推导与不一致。
2. **双图 + 事件作为边**：在不合并两图的前提下实现信号与来源事件的双向导航，兼顾结构化洞见与可追溯证据。
3. **证据向量与矛盾处理**：用 $(s,n,w,c)$ 量化信号强度与置信度，并以“并存 + 上下文区分 + 主动弃权”替代强行消解矛盾。
4. **跨用户结构迁移**：选择性前缀 + TransR + 偏好指纹 + 实体级链接预测，为冷启动用户提供可继承的领域通用信号，且不泄露用户私有情景。
5. **统一评测**：在记忆、偏好、冷启动三类任务、五个数据集上与主流记忆系统及强 LLM 基线在同等 token 预算下对比，并给出完整消融。

## 6. 局限性与可讨论点

- **依赖结果标签**：$w(v)$ 需要“已解决/成功”信号，在缺少结果标注的领域（如 PAL-Bench）退化为默认值，证据评分优势被削弱；如何从弱信号中推断结果仍是开放问题。
- **关系闭集假设**：洞见图结构关系固定为 6 类，跨领域扩展需人工设计或自动发现新关系，闭集可能限制表达力。
- **迁移的隐私与负迁移风险**：跨用户继承共享信号节点虽不暴露情景，但仍可能引入与本用户冲突的领域先验；论文以证据加权与上下文区分缓解，未系统量化负迁移。
- **TransR 训练数据稀疏**：事件链接标签折叠为单一 `surfaced` 关系，关系类型信息被压缩，可能限制嵌入区分度。
- **评测规模**：LoCoMo 仅 10 段对话，统计功效有限；开放端评分依赖 LLM 裁判，存在裁判偏差。
- **矛盾信号的上下文区分**依赖 topic/subarea 元数据质量，元数据缺失时区分能力下降。

## 7. 启示与可延伸方向

- **记忆系统的“推理前置”范式**：把本可在写入时完成的归纳（偏好、约束、目标）固化到结构中，查询时只做检索与轻量组合，是降低长上下文成本的可扩展路径。
- **事件作为边的通用性**：该桥接模式可迁移到其他“结构 + 溯源”场景（如合规审计、医疗决策记录），在不合并图的前提下保留 provenance。
- **证据加权检索**：$(s,n,w,c)$ 与 $\text{rank}=s\cdot c\cdot(0.5+w)$ 的设计对“失败经验也有价值”的场景具有参考意义，可推广到智能体经验回放。
- **冷启动迁移的工程要点**：选择性前缀是“共享什么、隔离什么”的关键设计决策，值得在其他多用户系统中复用；负迁移的检测与回退是下一步需要补强的环节。
- **可延伸实验**：引入自动关系发现、弱监督结果推断、跨领域迁移与隐私攻击评估，可进一步检验框架的鲁棒性与安全性。

## 8. 一句话总结

STARK 通过“情景图 + 洞见图”的双图架构与“事件作为边”的桥接机制，把行为知识从情景记录中解耦并以证据向量量化，再借选择性前缀与 TransR 实现跨用户冷启动迁移，在长期记忆、偏好建模与零重叠冷启动任务上均优于现有记忆系统与强 LLM 基线。
