## 摘要
搜索，尤其是 top-k 相似性搜索，在许多应用中起着至关重要的作用，但其性能可能受到内存访问开销的严重限制。存内搜索（IMS）是 CPU/GPU 方法的替代方案，它利用内容可寻址存储器（CAM）阵列内的大规模并行性进行原位搜索，并提供低延迟和高能效。然而，单个 CAM 阵列的容量往往不足以满足现代工作负载，需要将数据分布到多个阵列中。在多个 CAM 阵列上部署可扩展的 top-k 相似性搜索面临一个现有设计未能解决的根本问题：如何准确且高效地将本地二值匹配结果归约为全局 top-k 结果。本文提出 CAIMS，一个与存储技术和应用无关的跨阵列 IMS 框架，能够在保持准确性的同时实现可扩展且高效的 top-k 相似性搜索。为了实现准确的 top-k 结果归约，CAIMS 利用现有的阈值匹配功能，并结合离线与在线参数选择方法，将缺乏全局可比较相似度信息的本地二值匹配结果转换为全局粗粒度相似度分数。为进一步提高效率，CAIMS 采用层次化归约，并借助轻量级本地外设仅传输选择结果和必要的控制信号。CAIMS 在 3D NAND Flash 模型上实现，并利用检索增强生成的检索阶段进行演示；与服务器级 CPU 基线以及先前的 3D NAND Flash 加速器相比，CAIMS 的吞吐量分别最高提升 22.3 倍/10.1 倍，能效分别提升 426.6 倍/23.7 倍，同时保持相当的准确率。

## Abstract
Search, especially top-k similarity search, plays a vital role in many applications, but its performance can be severely limited by memory access overhead. In-memory search (IMS), an alternative to CPU/GPU-based approaches, exploits massive parallelism within a content-addressable memory (CAM) array to perform search in situ and provides both low latency and high energy efficiency. However, the capacity of a single CAM array is often insufficient for modern workloads, requiring data to be distributed across multiple arrays. Deploying scalable top-k similarity search across multiple CAM arrays poses a fundamental problem that existing designs fail to address: how to accurately and efficiently reduce local binary match results to global top-k results. This work introduces CAIMS, a cross-array IMS framework that is agnostic to memory technologies and applications, enabling scalable and efficient top-k similarity search while preserving accuracy. To enable accurate top-k result reduction, CAIMS leverages the existing threshold match functionality with a combined offline and online parameter selection approach to transform local binary match results that lack globally comparable similarity information into global coarse-grained similarity scores. To further improve efficiency, CAIMS conducts hierarchical reduction and transfers only the selection results and necessary control signals with lightweight local peripherals. Implemented on a 3D NAND Flash model and demonstrated using the retrieval phase of retrieval-augmented generation, CAIMS improves throughput by up to $22.3\times/10.1\times$ and energy efficiency by $426.6\times/23.7\times$ compared to the server-class CPU baseline and prior 3D NAND Flash accelerators, respectively, while maintaining comparable accuracy.
