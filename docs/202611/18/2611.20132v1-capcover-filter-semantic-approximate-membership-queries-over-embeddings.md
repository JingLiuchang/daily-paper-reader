## 摘要
在不执行最近邻搜索的情况下，判断一个嵌入是否与向量存储中的任一向量足够相似，可以显著提升向量存储系统的查询吞吐量。我们研究语义近似成员查询（Semantic Approximate Membership Queries, SAMQs），这类查询允许在没有被索引向量满足所请求的相似度阈值时拒绝查询，同时保证无假阴性。我们提出 CapCover Filter，一种利用球冠对一组嵌入进行概括的几何数据结构。其表示与查询阈值无关，使得单个过滤器无需重建即可支持任意阈值。我们评估了不同的构建与量化方法，将 CapCover Filter 与竞争过滤器进行比较，并测量其对查询吞吐量的影响。在五个真实数据集上，当余弦相似度阈值为 0.95 时，CapCover Filter 可消除约 20% 至 100% 的索引访问，同时仅使用原始（FP32）嵌入内存的 2%。将其置于 FAISS Flat 索引之前时，查询吞吐量最高提升 382%，在五个数据集上平均提升约 116%，同时返回相同的范围搜索结果。我们还评估了更低的相似度阈值。结果表明，当相似度阈值较严格、检索开销较高且被索引的嵌入高度聚集时，CapCover Filter 可以显著提升向量存储的吞吐量。我们发布了 CapCover Filter 的优化实现及其评估框架。

## Abstract
Determining whether an embedding is sufficiently similar to any vector in a vector store without performing a nearest-neighbor search can substantially improve query throughput in vector-store systems. We study Semantic Approximate Membership Queries (SAMQs), which allow queries to be rejected when no indexed vector meets the requested similarity threshold, while guaranteeing no false negatives.   We introduce CapCover Filter, a geometric data structure that summarizes a set of embeddings using spherical caps. Its representation is independent of the query threshold, allowing a single filter to support arbitrary thresholds without reconstruction. We evaluate alternative construction and quantization methods, compare CapCover Filter with competing filters, and measure its impact on query throughput.   Across five real-world datasets, at a cosine similarity threshold of 0.95, CapCover Filter eliminates approximately 20--100\% of index accesses while using only 2\% of the raw (FP32) embedding memory. When placed before a FAISS flat index, it improves query throughput by up to 382\% and by approximately 116\% on average across the five datasets, while returning the same range-search result. We also evaluate lower similarity thresholds. Our results show that CapCover Filter can substantially improve vector-store throughput when similarity thresholds are tight, retrieval is expensive, and indexed embeddings are highly clustered. We release an optimized implementation of CapCover Filter and its evaluation framework.

## 1. 核心问题与研究动机

- **背景**：向量数据库、RAG、语义缓存等系统广泛使用嵌入表示非结构化数据，并通过相似度搜索判断语义接近性。但很多应用只需要一个**二值判断**——是否存在足够相似的向量——却仍要执行昂贵的最近邻搜索。
- **问题定义**：论文提出 **语义近似成员查询（SAMQ）**。给定索引集合 \(X\)、查询 \(q\) 和余弦距离阈值 \(\tau\)（对应最小余弦相似度 \(1-\tau\)），SAMQ 需回答：是否存在 \(x\in X\) 使 \(1-\cos(q,x)\le\tau\)。要求**零假阴性**（真匹配必被接受），允许假阳性，类似 Bloom filter 的单边近似成员查询。
- **意义**：若能以极低内存快速拒绝大量“无匹配”查询，可显著减少下游索引访问，提升向量库吞吐。论文聚焦语义缓存未命中拒绝、检索前置筛选等场景。

## 2. 方法论

### 核心思想
- 用**至多 \(k\) 个球冠** \(C(u_i,\theta_i)=\{x:\angle(x,u_i)\le\theta_i\}\) 覆盖全部索引嵌入，查询时若 \(q\) 落入任一“扩展球冠”即接受，否则拒绝。
- 关键性质：**表示与查询阈值 \(\tau\) 无关**。存储的球冠只依赖索引数据与内存预算，\(\tau\) 仅出现在查询时的接受条件中，因此一次构建支持任意阈值，无需重建。

### 关键技术细节
- **查询规则**：令 \(\alpha_\tau=\arccos(1-\tau)\)，若存在 \(i\) 使 \(\angle(q,u_i)\le\theta_i+\alpha_\tau\)，返回 YES；否则 NO。由角度三角不等式保证零假阴性。
- **内存预算模型**：给定字节预算 \(B\) 和编码 \(E\)，每 cap 字节数 \(s_E(d)\)、共享开销 \(h_E\)，cap 预算 \(k_E=\lfloor (B-h_E)/s_E(d)\rfloor\)。内存直接约束几何表示，而非间接约束哈希表。
- **优化目标**：最小化未扩展球冠体积和 \(V(C)=\sum_i\sigma(\theta_i)\)（\(\sigma\) 为归一化球冠测度），作为过滤效果的易处理代理；扩展体积 \(J_\tau(C)=\sum_i\sigma(\theta_i+\alpha_\tau)\) 用于上界假阳性。
- **构建流程（Algorithm 1）**：
  1. **Gonzalez 最远优先**初始化方向（角度度量下 2 倍近似）。
  2. **Minimax 精化**：Lloyd 式分配—更新，用 Bădoiu–Clarkson 式最远点更新，5 轮，保留最大角最小者。
  3. **Soft anneal**：软分配至最近 16 或 \(k\) 个方向，softmax 权重，优化平滑代理 \(\Lambda_T\)；用 Riemannian Adam（300 迭代，温度/学习率/幂次几何调度），每 10 迭代评估硬分配下的 \(V\)，保留最优。
  4. **量化与角度重测**：对方向用 TQ 或 SPQ 编码，解码后在**解码方向**上重新测量球冠角并向外取整，保持覆盖；再做一次最近解码方向重分配，仅当 \(V\) 严格下降时保留。
  5. **自动编码选择**：对候选编码分别构建，选 \(V(C_E)\) 最小者。

### 理论分析
- 证明无假阴性、量化保覆盖、球覆盖经角度解码比欧氏扩展更紧（假阳性更低）。
- 给出最远优先的 \(R(C_G)\le 2R_k^\star(X)\) 保证，并指出体积比可随维度指数恶化。
- 给出基于覆盖“超出角” \(\Delta_C\) 的假阳性壳层界，以及均匀球面查询下的空间下界（约每向量数字节量级）。

- **指标**：FPR、FNR、索引访问节省比例 \(\phi=TN/N\)、端到端吞吐提升。
- **对比方法**：
  - 构建方法：Gonzalez、minimax、soft anneal（分别配 FP32、TQ2、TQ4 方向）。
  - 量化：TQ1–TQ4、SPQ \(16\times12\)/\(12\times12\)/\(6\times8\)、auto。
  - 零假阴性基线：VA+-file、Zero-FN LSH、RaBitQ 量化点集。

## 6. 主要结论与发现

- 在 \(\tau=0.05\)（相似度 0.95）、仅用 2% FP32 内存时，可消除约 **20%–100%** 的索引访问。
- 前置 FAISS Flat 后，吞吐**最高提升 382%，平均约 116%，中位 56%**；CC-News 仅约 5%，ChatGPT-Paraphrases 最高。结果与未过滤时范围搜索一致（零假阴性）。
- 阈值越宽松（\(\tau\) 越大），接受区域膨胀，节省下降；**接近索引集的负查询最难拒绝**。
- 小内存预算下几何摘要优于点式表示（Zero-FN LSH 几乎无效，VA+-file 需更大预算才反超）；预算增大后点式方法更具竞争力。
- 未扩展体积 \(V\) 与 FPR 在跨预算时强相关（Spearman 0.91–0.95），但**固定内存下比较不同编码时关联弱**，\(V\) 只是启发式而非可靠排序。
- 吞吐收益取决于后端成本，break-even 条件为 \(L>L_{\text{filter}}/\phi\)；后端越贵，过滤越有价值。
- soft anneal 质量最好但构建慢；minimax 是运行时与质量的折中。

## 7. 优点

- **表示与阈值解耦**：一次构建支持任意 \(\tau\)，工程上非常实用。
- **零假阴性有几何证明**，量化后通过保守角度重测严格保持覆盖，正确性保证清晰。
- **内存预算直接作用于几何表示**，可显式控制 cap 数量与精度，避免哈希结构的间接开销。
- **理论完整**：覆盖正确性、量化保覆盖、球冠 vs 球覆盖比较、构建近似保证、假阳性界、空间下界。
- **实验较系统**：多数据集、多折、多预算、多阈值、构建/量化消融、与多类基线对比，并区分过滤选择性与查询成本。
- **开源实现与评测框架**，可复现性较好。

## 8. 不足与局限
