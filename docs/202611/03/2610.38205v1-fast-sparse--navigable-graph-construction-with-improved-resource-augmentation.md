## 摘要
基于图的最近邻搜索方法在数据点构成的有向图上运行贪心搜索，近年来越来越受欢迎。一个常见目标是构造具有 $α$-可导航性质的搜索图，该性质保证贪心搜索返回可证明良好的近似最近邻，并在少量迭代内收敛。增大 $α\geq 1$ 可提高精度和收敛速度，但需要更多边，从而增加空间和搜索时间。这种权衡促使人们研究为给定点集构造最稀疏 $α$-可导航图的算法。对于任意点集和任意距离函数，我们展示如何计算一个 $α$-可导航图，其边数至多为最稀疏 $(1+\varepsilon)α$-可导航图的 $O(\log n)$ 倍，时间复杂度为 $O(n^ω\log(Δ)/\varepsilon)$，其中 $ω< 2.372$ 是矩阵乘法指数，$Δ$ 是输入的纵横比。这改进了 Khanna、Padaki 和 Waingarten (SODA 2026) 的工作，他们达到相同运行时间，但只能与最稀疏的 $2(1+\varepsilon)α$-可导航图相竞争。由于稀疏性通常随 $α$ 快速增加（通常 $α\leq 1.1$），他们的界可能显著更弱。此前，能与最稀疏的 $(1+\varepsilon)α$-可导航图竞争的最佳算法需要 $\widetilde{O}(n^{2.5})$ 时间。我们的技术还可扩展到构造稀疏 $τ$-单调图，这是最近邻搜索中的另一个热门目标。最后，我们给出细粒度复杂度分析，表明改进 $O(n^ω)$ 运行时间不太可能，或者需要非常不同的方法。该分析基于与验证图是否可导航相关问题（一个具有独立意义的话题）的硬度结果。

## Abstract
Graph-based nearest neighbor search methods, which run greedy search on a directed graph over the data points, have surged in popularity in recent years. A common goal is to construct a search graph with the $α$-navigability property, which ensures that greedy search returns provably good approximate nearest neighbors and converges in few iterations. Increasing $α\geq 1$ improves accuracy and convergence rate, but requires more edges, which increases both space and search time. This tradeoff has motivated the study of algorithms for constructing a sparsest $α$-navigable graph for a given set of points.   For any point set and any distance function, we show how to compute an $α$-navigable graph with at most $O(\log n)$ times as many edges as the sparsest $(1+\varepsilon)α$-navigable graph, in $O(n^ω\log(Δ)/\varepsilon)$ time, where $ω< 2.372$ is the matrix multiplication exponent and $Δ$ is the aspect ratio of the input. This improves on Khanna, Padaki, and Waingarten (SODA 2026), who achieve the same runtime but are only competitive with the sparsest $2(1+\varepsilon)α$-navigable graph. Since sparsity often increases rapidly with $α$ (typically $α\leq 1.1$), their bound can be significantly weaker. Previously, the best algorithm competing with the sparsest $(1+\varepsilon)α$-navigable graph required $\widetilde{O}(n^{2.5})$ time.   Our techniques also extend to constructing sparse $τ$-monotonic graphs, another popular target in nearest neighbor search. Finally, we give a fine-grained complexity analysis suggesting that improving the $O(n^ω)$ running time is unlikely, or would require a very different approach. It is based on hardness results for problems related to verifying whether a graph is navigable, a topic of independent interest.

## 1. 核心问题与研究动机

- **背景**：基于图的近似最近邻搜索（ANN）在向量检索、RAG、推荐等场景中广泛应用。其核心是构造有向图 \(G=(P,E)\)，查询时从某点出发贪心移动到离查询更近的邻居。
- **α-可导航性**：对任意源点 \(s\) 和目标 \(t\)，图中存在边 \((s,v)\)，使得  
  \[
  d(v,t)<\frac{1}{\alpha}d(s,t)
  \]
  即每步至少将到目标的距离缩小为原来的 \(1/\alpha\)。该性质可保证贪心搜索的近似比约为 \(\frac{\alpha+1}{\alpha-1}\)，并在约 \(\log_\alpha \Delta\) 步内收敛。
- **核心权衡**：\(\alpha\) 越大，精度和收敛越好，但图需要更多边，增加空间和搜索时间。实际系统通常取 \(\alpha\in[1.0,1.2]\)，甚至 \(\alpha\le 1.1\)。
- **研究问题**：给定点集和距离函数，构造尽可能稀疏的 \(\alpha\)-可导航图。该问题 NP-hard，因此研究近似算法。
- **已有工作缺口**：
  - Conway 等（SODA 2026）可在 \(\widetilde{O}(n^{2.5})\) 时间内与最稀疏 \(\alpha\)-图竞争，但较慢。
  - Khanna、Padaki、Waingarten（SODA 2026）达到 \(\widetilde{O}(n^\omega\log(\Delta)/\varepsilon)\) 时间，但只能与最稀疏的 \(2\alpha(1+\varepsilon)\)-可导航图竞争，即资源增强因子为 2。
  - 由于实际 \(\alpha\) 接近 1，而稀疏性随 \(\alpha\) 增长很快，\(OPT_{2\alpha(1+\varepsilon)}\) 可能远大于 \(OPT_\alpha\)，甚至接近完全图。因此，**如何在保持近矩阵乘法运行时间的同时，将资源增强从 \(2\alpha(1+\varepsilon)\) 降到 \(\alpha(1+\varepsilon)\)**，是本文的核心目标。

## 2. 方法论

### 2.1 核心思想：将稀疏图构造分解为 \(n\) 个集合覆盖问题

- 对每个源点 \(s\)，选择其出邻居等价于一个集合覆盖实例：
  - 元素：所有目标 \(t\neq s\)。
  - 集合：每条候选边 \((s,v)\) 对应集合
    \[
    S_{s\to v}=\{t: d(v,t)<d(s,t)/\alpha\}.
    \]
  - 选择最少集合覆盖所有目标，即最小化 \(s\) 的出度。
- 直接显式构造所有集合需 \(\Omega(n^3)\) 时间。论文利用预处理支持三类常数时间查询：`MemberOf`、`FreqOf`、`SetOf`，预处理时间 \(O(n^2\log n)\)、空间 \(O(n^2)\)。

### 2.2 关键组件一：局部投票式部分覆盖 `PartialVoteCover`

- 标准贪心集合覆盖可达到 \(O(\log n)\) 近似，但每加一条边后显式更新未覆盖集合代价高。
- `PartialVoteCover` 只要求覆盖当前未覆盖集合 \(U\) 的至少一半：
  - 从 \(U\) 中独立采样 \(C\cdot opt\ln n\) 个元素，其中 \(opt\) 是对最优覆盖大小的猜测。
  - 每个采样元素给包含它的候选集合投票。
  - 当某集合票数达到 \(c\ln n\) 时，将其加入覆盖，并移除这些投票。
  - 返回的覆盖集合数不超过 \(O(opt)\)，并以高概率覆盖至少 \(|U|/2\) 个元素。
- 该过程避免了对整个 \(U\) 的扫描，只处理采样元素及其关联集合。

### 2.3 关键组件二：批量验证 `VerifyNav`

- 将距离按几何尺度离散化：
  \[
  r_\ell=d_{\min}(1+\varepsilon)^\ell,\quad \ell=0,\dots,\lceil\log_{1+\varepsilon}\Delta\rceil.
  \]
- 对每个距离尺度，构造布尔矩阵 \(B(r)\)，其中 \(B_{j,k}=1\) 当且仅当 \(d(p_j,p_k)<r\)。令 \(A\) 为当前图邻接矩阵，计算 \(C=AB(r)\)。若 \(C_{i,k}>0\)，则存在边 \((p_i,p_j)\) 使 \(d(p_j,p_k)<r\)。
- 每个尺度一次布尔矩阵乘法，总时间
  \[
  O\left(n^\omega\left(1+\log_{1+\varepsilon}\Delta\right)\right)
  =O(n^\omega\log(\Delta)/\varepsilon).
  \]
- 返回的未满足约束集合 \(N(G)\) 满足：
  \[
  U_\alpha(G)\subseteq N(G)\subseteq U_{\alpha(1+\varepsilon)}(G),
  \]
  即不会漏掉真正未满足的 \(\alpha\)-约束，也不会把已满足的 \(\alpha(1+\varepsilon)\)-约束误判为未满足。这是资源增强因子 \((1+\varepsilon)\) 的来源。

### 2.4 整体算法：`BatchedVoteCover`

- 对最优出度猜测 \(opt\) 按 \(1,2,4,\dots\) 倍增。
- 对每个猜测：
  1. 先给每个点随机加入 \(opt\ln n\) 条出边，用于覆盖高频目标，使剩余未覆盖元素在集合系统中的出现频次降到 \(O(n/opt)\)。
  2. 对所有活跃源点并行运行 `PartialVoteCover`，每轮为每个源点添加一批边。
  3. 用一次全局 `VerifyNav` 同时刷新所有源点的未覆盖约束，而不是逐边扫描。
  4. 每轮覆盖常数比例约束，因此约 \(O(\log n)\) 轮后完成。
- 总运行时间由 `VerifyNav` 主导，为
  \[
  \widetilde{O}\left(n^\omega\log(\Delta)/\varepsilon\right).
  \]
- 稀疏性保证：
  - 每个源点 \(s\) 的出度不超过
    \[
    O(\log n)\cdot OPT_{\alpha(1+\varepsilon)}(s),
    \]
  - 全局边数不超过
    \[
    O(\log n)\cdot OPT_{\alpha(1+\varepsilon)}.
    \]
- 算法只要求距离函数对称、非负、自身距离为 0，**不要求满足三角不等式**，因此适用于非度量距离。

### 2.5 扩展到 \(\tau\)-单调图

- \(\tau\)-单调图要求对每对 \(s,t\)，要么有直接边 \((s,t)\)，要么存在边 \((s,v)\) 使
  \[
  d(v,t)<d(s,t)-\tau.
  \]
- 同样可转化为集合覆盖，只是覆盖条件改为加性进展。
- 距离离散化改为加性尺度 \(r_\ell=\ell\epsilon\)，`VerifyNav` 返回
  \[
  U_\tau(G)\subseteq N(G)\subseteq U_{\tau+\epsilon}(G).
  \]
- 运行时间为
  \[
  \widetilde{O}(n^\omega\Delta/\epsilon),
  \]
  每个点出度不超过 \(O(OPT_{\tau+\epsilon}(s)\log n)\)。

### 2.6 硬度分析

- **单尺度 α-可导航性验证**：给定固定距离 \(d_0\)，判断哪些 \((s,t)\) 已被满足。论文证明布尔矩阵乘法可归约到该问题，一次 oracle 调用加 \(O(n^2)\) 时间即可计算布尔矩阵乘积。因此，绕开矩阵乘法瓶颈需要布尔矩阵乘法的突破。
- **精确全距离 α-可导航性验证**：证明其与布尔 min-plus product 在 polylog 因子内等价；结合 APSP 猜想下的已知下界，得到不存在 \(O(n^{2.5-\delta})\) 时间算法（除非 APSP 猜想失效）。
- 这些结果说明：在当前框架内，矩阵乘法瓶颈和资源增强较难避免。
