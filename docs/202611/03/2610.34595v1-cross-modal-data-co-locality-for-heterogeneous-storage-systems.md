## 摘要
分布式向量存储正日益服务于多模态工作负载，这些工作负载的表示会被联合访问，但却被独立分区与放置。因此，跨模态物理局部性在很大程度上仍未得到优化。即使每种模态的 ANN 检索仍然高效，多模态查询也可能产生远程访问和跨层数据移动。我们提出 Coloc，这是一个将跨模态访问局部性作为一等数据布局信号的存储管理层。跨模态访问图结合了语义亲和性、共访问和时序行为。移动感知优化器在容量与拓扑约束下放置频繁共访问的向量。迁移管理器在工作负载变化时调整放置，权衡局部性收益与迁移成本。置信度门控预取器隐藏剩余的慢层延迟。Coloc 运行于现有 ANN 索引之上，不修改嵌入、搜索或检索语义。我们在跨 GPU、NUMA-DRAM、NVMe 和 S3 的多层 AWS 测试平台上部署了 Coloc。Coloc 大幅降低了数据移动和查询延迟，同时保持 ANN 检索不变。在计划的工作负载变化下，其迁移管理器达到了周期性全局重组织的局部性，同时数据移动量少 5.9 倍、完成速度快 3.9 倍。

## Abstract
Distributed vector stores increasingly serve multimodal workloads whose representations are jointly accessed but independently partitioned and placed. As a result, cross-modal physical locality remains largely unoptimized. Multimodal queries can incur remote accesses and cross-tier data movement even when each modality's ANN search remains efficient. We present Coloc, a storage-management layer that makes cross-modal access locality a first-class data-layout signal. A Cross-Modal Access Graph combines semantic affinity, co-access, and temporal behavior. A movement-aware optimizer places frequently co-accessed vectors under capacity and topology constraints. A migration manager adapts placement as workloads shift by weighing locality gains against migration cost. A confidence-gated prefetcher hides remaining slow-tier latency. Coloc operates above existing ANN indexes without modifying embeddings, search, or retrieval semantics. We deploy Coloc on a multi-tier AWS testbed spanning GPU, NUMA-DRAM, NVMe, and S3. Coloc substantially reduces data movement and query latency while leaving ANN retrieval unchanged. Under a scheduled workload shift, its migration manager matches the locality of periodic global reorganization while moving 5.9x less data and completing 3.9x faster.
