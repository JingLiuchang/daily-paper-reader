## 摘要
长上下文模型会反复解决密切相关的检索问题。注意力或全局检索能够保留大型存储，但每次前向传播都会再次搜索重要信息。循环压缩仅通过提前决定要保留哪些信息来避免这种搜索。这两种机制都没有直接利用相邻检索步骤中的有用记忆可能大幅重叠这一事实。我们提出一种替代方案，其中检索是通过地址空间进行的持久局部遍历。我们将记忆的内容与其地址分离。效用由检索内容所揭示的信息定义，而几何结构仅决定以多低的代价到达该信息。这引出一个成本正则化的索引目标，该目标在局部邻域内保留信息价值，同时对每个被设为局部可访问的记忆收取代价。其边际价值形式同时产生吸引压力和排斥压力。因此，当额外价值超过检索成本时，互补记忆应可被共同检索；而冗余记忆不应仅因各自单独有用就占据同一检索集。作为原理验证，我们仅在 MiniGrid Memory 上测试最简单的固定几何实例。在五 token 上下文下，一个持久局部遍历头在 0.59M 训练步后达到 0.95 平均回报，相比之下，高斯绝对寻址需要 0.94M 步，类别绝对寻址需要超过 2M 步。该实验未测试学习得到的几何结构或重复检索。相反，它支持如下假设：有状态检索可能比无状态检索更容易学习。为检验完整的所提方法，还需要进一步实验。

## Abstract
Long-context models repeatedly solve closely related retrieval problems. Attention or global retrieval can retain large stores, but each forward pass again searches for what matters. Recurrent compression avoids this search only by deciding earlier what information to preserve. Neither mechanism directly exploits that useful memories at neighbouring retrieval steps may substantially overlap. We propose an alternative in which retrieval is a persistent local traversal through an address space. We separate a memory's content from its address. Utility is defined by the information revealed by retrieving the content, while geometry determines only how cheaply that information can be reached. This leads to a cost-regularised indexing objective that preserves information value inside local neighbourhoods while charging for every memory made locally accessible. Its marginal-value form gives both attractive and exclusion pressures. Thus, complementary memories should be co-retrievable when the additional value exceeds retrieval cost, whereas redundant memories should not occupy the same retrieval set solely because they are individually useful. As a proof of principle, we test only the simplest fixed-geometry instance on MiniGrid Memory. A persistent local traversal head reaches $0.95$ mean return after $0.59$M training steps with a five-token context, compared with $0.94$M for Gaussian absolute addressing and more than $2$M for categorical absolute addressing. The experiment does not test learned geometry or repeated retrieval. Instead, it motivates the hypothesis that stateful retrieval may be easier to learn than stateless. To test the full proposed method further experimentation is necessary.

## 1. 核心问题与整体含义

- **研究动机**：长上下文模型在相邻推理/检索步骤中往往反复解决高度相关的检索问题。注意力或全局检索保留大量历史，但每次前向传播都要重新搜索；循环压缩虽避免扫描，却在未来信息需求未知前就决定保留什么。
- **被忽视的成本来源**：相邻检索步骤中有用记忆可能大幅重叠，但现有方法通常把每次查询当作独立匹配问题，未利用这种重复性。
- **核心主张**：将检索视为在地址空间中的**持久局部遍历**，把记忆的“内容”与“地址”分离：内容决定信息价值，地址/几何只决定到达该信息的成本。
- **整体含义**：提出一种面向有状态长上下文智能体的价值索引记忆框架，试图用决策价值而非内容相似性组织记忆，并用成本正则化替代固定的 top-k 检索预算。

## 2. 方法论

- **核心思想**：记忆内容 \(M_j\) 与其地址 \(z_j=\Phi(C_j^w)\) 分离；检索某记忆时，将内容 \(m_j\) 放入工作上下文，而不是写入时的上下文。检索头在地址空间中持续局部移动，相邻查询可复用上一检索状态。
- **信息价值定义**：对当前上下文 \(c\) 和记忆集合 \(S\)，定义
  \[
  V(S;c)=\mathbb{E}[U(c\oplus M_S)-U(c)\mid C_t=c]
  \]
  即检索这些内容带来的任务效用增量。几何不影响内容价值，只影响可达成本。
- **成本正则化局部索引目标**：
  \[
  L_\lambda(\Phi)=\mathbb{E}[V(\Omega_t;C_t)-V(N_{C_t}(\Phi);C_t)+\lambda|N_{C_t}(\Phi)|]
  \]
  其中 \(N_{C_t}(\Phi)=B_\varepsilon(\Phi(c))\) 是查询位置 \(\varepsilon\)-邻域内可访问的记忆集合，\(\lambda\) 为每个可访问记忆的检索成本。
- **边际价值与互补/冗余**：定义边际价值 \(\Delta_j(S;c)=V(S\cup\{j\};c)-V(S;c)\)，以及条件交互
  \[
  s_{ij}(S;c)=V(S\cup\{i,j\};c)-V(S\cup\{i\};c)-V(S\cup\{j\};c)+V(S;c)
  \]
  正值为互补，负值为冗余。共同检索 \(i,j\) 优于只检索 \(i\) 的条件是 \(\Delta_j(S\cup\{i\};c)>\lambda\)。
- **吸引与排斥压力**：互补记忆在额外价值超过成本时应被共同局部可达；冗余记忆不应仅因各自单独有用就占据同一检索集。精确替代记忆具有相同边际价值和相同交互轮廓。
- **持久遍历机制**：维护持久检索头位置 \(i_t\)，每步可访问集合为
  \[
  M_t=B_\varepsilon(\Phi(c_t))\cup B_\varepsilon(i_t)
  \]
  工作窗口保留最近 \(H\) 步遍历过的记忆。检索头移动规则被留作模块化设计，可由 RL 学习或由价值估计器扩展。
- **低漂移假设**：定义成本最优检索集 \(S_t^\star\) 及一步新增漂移 \(D_t=|S_t^\star\setminus S_{t-1}^\star|\)。当漂移相对集合规模较小时，持久机制可复用上一状态而非重新全局搜索。

- 在固定几何、五 token 上下文的单次检索任务中，持久相对移动头在 **0.59M 步**达到 0.95 平均回报；高斯绝对寻址为 **0.94M 步**；类别绝对寻址超过 **2.0M 步**仍未确定。

- 结果仅支持初步结论：在该单检索任务中，增量式相对寻址比测试的绝对寻址方案更容易学习，且行为效率接近全上下文参考。
- 实验**没有**验证学习价值索引目标、交互驱动几何或低漂移重复检索；不能声称完整方法已获实验支持。
- 负控制表明短窗口智能体可通过等待时钟或轨迹编码线索，因此当前实验只能作为学习效率和行为效率的证据，而非能力差距证据。

## 7. 优点

- **概念清晰**：将记忆内容与地址分离，把“检索什么”和“以多低成本到达”区分开，避免用内容相似性直接替代决策价值。
- **理论形式简洁**：成本正则目标自然导出边际价值阈值，替代任意 top-k 预算；互补/冗余的交互定义清楚。
- **有决策论视角**：强调冗余应按下游决策价值而非隐表示协方差判断，具有启发性。
- **持久遍历思路合理**：利用相邻检索集重叠，将检索从无状态匹配转为有状态局部遍历。
- **实验可复现**：公开代码，算力需求低，报告种子范围和阈值指标，并诚实设置负控制。
- **自我限定明确**：作者清楚区分理论主张与实验证据，未过度宣称。

## 8. 不足与局限

- **核心方法未验证**：实验使用手工时空几何 \(\Phi_0=(x,y,t)\)，未学习价值索引 \(\Phi\)，也未优化成本正则目标 \(L_\lambda\)。
- **任务覆盖窄**：仅 MiniGrid Memory 单任务、单次信息检索；不测试多记忆顺序访问、重复检索或长上下文语言任务。
- **未测试关键假设**：低漂移假设、互补/冗余几何、\(\lambda\) 与 \(\varepsilon\) 的影响均无实验。
- **移动规则非规范化**：检索头移动规则是模块化的，未与 \(\Phi\) 的构造统一；训练 \(\Phi\) 的细节缺失。
- **几何表达力未知**：固定维度地址空间能否同时表达“某些上下文互补、另一些上下文冗余”的交互结构尚不清楚。
- **实验统计有限**：基线仅 3 个种子，部分绝对寻址运行未在预算内达到阈值；单环境结果外推性弱。
- **负控制削弱结论**：短上下文基线可通过行为编码线索，说明性能提升不一定来自检索机制本身。
- **应用限制**：目前仅适用于有明确环境坐标/时空索引的强化学习场景，向通用长上下文模型迁移仍需大量工作。
