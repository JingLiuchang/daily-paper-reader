## 摘要
近似最近邻（ANN）搜索通过检索与给定查询向量相近的向量，是向量数据库中的一项基础操作。然而，新兴应用（例如为基于照片的动画和视频合成选择源图像）可能需要在匹配内容的同时，允许查询指定的方面对比度（如光照变化）发生变化；单个查询点无法直接表达这一需求。本文研究近似直线最近邻（LANN）搜索，其中一条无限查询直线消除沿指定方向的距离贡献，而数据库记录仍为点。现有方法仅关注 LANN 的 top-1 搜索，并且可能带来较高的构建成本。通过维度提升将 LANN 转换为普通点 ANN 搜索会显著增加索引构建和查询成本，而在为普通点 ANN 搜索构建的近邻图上直接搜索可能遗漏靠近一条直线的不同区域。为解决这些问题，我们提出 LinePG，它通过成对边增强现有近邻图，以促进分离的近线区域之间的导航。为了高效地找到这些成对边，我们首先生成在空间或图上分离且靠近一条直线的区域对。然后，我们对所选区域对之间的边进行评分，以指导点端点的选择。我们进行了广泛的性能研究，并与基线方法比较，确认了 LinePG 的准确性和效率。

## Abstract
Approximate nearest neighbor (ANN) search, which retrieves vectors close to a given query vector, is a fundamental operation in vector databases. However, emerging applications, such as selecting source images for photo-based animation and video synthesis, may require matching content while allowing a query-specified aspect contrast, such as an illumination change, to vary; a single query point does not directly express this requirement. In this paper, we study approximate line nearest neighbor (LANN) search, where an infinite query line removes the distance contribution along a specified direction while database records remain points. Prior approaches focus on top-$1$ search only for LANN and can incur high construction costs. Converting LANN into ordinary point ANN search through dimension lifting substantially increases index construction and query costs, while direct search on a proximity graph built for ordinary point ANN search can miss distinct regions close to a line. To address these issues, we propose LinePG, which enhances an existing proximity graph with pair edges to facilitate navigation between separated near-line regions. To find these pair edges efficiently, we first generate region pairs with spatial or graph separation, and near a line. We then score edges between the selected region pairs to guide the point endpoint selections. We conduct extensive performance studies and confirm the accuracy and efficiency of LinePG in comparison with the baseline approaches.

## 1. 核心问题与研究动机

- **背景**：近似最近邻（ANN）搜索是向量数据库的基础操作，但新兴应用（如 Google Picasa Face Movies、Runway Gen-4 References、基于照片的延时视频合成）要求**在匹配内容的同时，允许查询指定的某个方面（如光照）发生变化**。传统点查询无法表达"沿某方向的距离不计"这一需求。
- **问题定义**：论文研究**近似直线最近邻（LANN）搜索**——查询是一条无限仿射直线 \(L=\{b_0+t(b_1-b_0):t\in\mathbb{R}\}\)，数据库记录仍为点，按点到直线的垂距 \(\delta(p,L)=\min_t\|p-b_0-t(b_1-b_0)\|\) 排序返回 top-\(k\)。
- **研究动机案例**：YaleB 数据集上，用两张不同光照（方位角 −35° 与 +35°）但同主体同姿态的图像嵌入作为直线端点，直线检索 top-5 全部命中同主体同姿态，而任一端点或中点查询只能命中 2/5 或 4/5。
- **现有方法的三大局限**：
  - **TheoryLP**（Andoni 等）：仅支持 top-1，圆柱分解构建复杂度高达 \(O(dN^{7/2})\)，构建开销不可接受。
  - **二次维度提升**：论文证明精确归约所需最低维度为 \(D^\star=d(d+1)/2+d=\Theta(d^2)\)，导致索引存储 \(\Theta(Nd^2)\)，构建与查询成本剧增。
  - **直接在点 ANN 近邻图上搜索**：近线点彼此未必接近，可能分布在沿直线分离的多个区域，束搜索在一个区域找到足够候选后即停止，遗漏其他更优区域。

## 2. 方法论：LinePG

### 2.1 核心思想
复用为点 ANN 构建的近邻图 \(G\)，**增加少量"成对边"（pair edges）连接沿直线分离但都靠近同一直线的区域**，同时保持原始向量维度和总度数上限 \(M\)。局部探索靠原边，跨区域跳转靠 pair edges。

### 2.2 关键技术细节

- **几何直觉**：若 \(p,q\in S_r(L)\) 且 \(\|q-p\|\gg r\)，则割线 \(q-p\) 与查询方向 \(u\) 近似平行（\(\sin\angle(q-p,u)\le 2r/\|q-p\|\)），因此可用此类"近似平行割线"作为跨区域边。

- **层次结构（Hierarchy）构建**：
  - 递归平衡划分，每次在最大方差坐标上做中位数切分。
  - **图平滑**：对分裂信号 \(f^{(0)}_p=p_j-c_{C,j}\)，用行随机矩阵 \(W\)（基于图边距离的高斯权重）迭代 \(f^{(t+1)}=\frac{1}{2}(f^{(t)}+Wf^{(t)})\)，默认 \(t_s=4\) 轮。
  - 定理 5.1 证明平滑保持加权均值且方差单调不增，每轮值落在前一轮极值之间；过度平滑会丢失几何区分度。
  - 叶子容量默认 \(b=32\)。

- **商图（Quotient Graph）构建**：叶子为顶点，原图中跨叶子的边生成弧（去重）。用于识别**不存在短有向路径**（hop 距离 \(>\kappa\)，默认 \(\kappa=3\)）的区域对。

- **候选区域对生成（Algorithm 2）**：
  - 层次侧：从源叶子向根移动，在每个兄弟子树中均匀采样至多 \(s_h\) 个叶子。
  - 商图侧：先均匀采样 \(n_p=\min\{|L|,128n_w\}\) 个目标池 \(D\)，用位并行 BFS 做 \(\kappa\) 步可达性传播，取不可达者作为候选；定理 6.1 证明该"先采样后判可达"策略对每个合格叶子是均匀的。
  - 每叶子至多 \(n_w=s_h\lceil\log_2|L|\rceil\) 个候选，去重后按得分取前 \(r\) 个（默认 \(r=16\)）。

- **区域对打分**：
  - 分离度 \(g(A,B)=\dfrac{d_{AB}^2}{d_{AB}^2+\sigma_A^2+\sigma_B^2}\)（\(d_{AB}\) 为质心距，\(\sigma^2\) 为均方散布）。
  - 支撑度 \(h(A,B)=\frac{1}{|A|+|B|}\sum_{z\in A\cup B}\frac{1}{1+\delta^2(z,\lambda_{AB})/d_{AB}^2}\)（\(\lambda_{AB}\) 为过两质心的代表割线）。
  - 综合得分 \(S(A,B)=g(A,B)\cdot h(A,B)\)，要求"分离"与"割线支撑"同时成立。

- **成对边端点选择（Algorithm 1）**：
  - 目标区域代表库 \(R(B)\)：最近质心的 8 个点 + 最远 4 个点。
  - 支撑分 \(J(p,y;B)=\sum_{z\in B\setminus\{y\}}1/(1+\psi_{p,y}(z))\)，\(\psi\) 为归一化到直线 \(p+R(y-p)\) 的平方距离，选 \(J\) 最大的有效端点。
  - 方向多样性：\(\nu(p,y)=1-\max_{z\in F_p\setminus\{y\}}\chi(p;y,z)\)（与已选 pair 边去冗余），\(\alpha(p,y)=1-\max_{z\in N^+_G(p,y)}\chi(p;y,z)\)（与原图前向邻居去冗余）。
  - 超出 \(M_{pair}=4\) 时按 \(\nu\cdot\alpha\) 最小剔除；总度数超 \(M=32\) 时剔除最长原边。

- **搜索算法（Algorithm 3）**：
  - 束搜索按点到直线距离排序，先展开 \(E_{reg}\) 原边；若当前前沿已有更近的未展开点则跳过 pair 边，否则按 \(J\) 降序考察 pair 端点。
  - **叶门控**：\(\ell(y)\notin Done\) 才允许进入，避免重复进入已探索区域。

- **理论贡献**：定理 3.1 证明精确归约维度下界 \(D\ge D^\star=\Theta(d^2)\) 且构造可达该下界；复杂度分析给出层次+商图构建 \(O(h(Nd+md+t_s(N+m)))\)。

## 6. 主要结论与发现

- 在 Recall ≥ 0.99 时，LinePG 相对 DirectSearch 在 \(k=10\) 取得 **4.23x / 2.00x / 2.14x / 1.55x** QPS 加速（YaleB/CelebA/FFHQ/Multi-PIE），\(k=100\) 取得 1.44–2.44x 加速。
- DirectSearch 在全量 SIFT/GIST 上无法达到 0.99 recall，而 LinePG 最高可达 0.9993/0.9997；SIFT \(k=10\) 上 LinePG 以 613 QPS 达到 0.9958 recall，DirectSearch 最高仅 13.70 QPS / 0.9893 recall（44.76x 吞吐且 recall 更高）。
- 相对 Lift：同 recall=1.0 下 QPS 加速最高 **976.17x**，索引空间约为其 **1.86%**，构建时间约为 **2.15%**。
- 相对 TheoryLP：\(N=512\) 子集上 QPS 加速最高 **1,665.63x**，构建时间快 3 个数量级以上。
- 索引开销：全量数据集上 LinePG 总存储为 DirectSearch 的 **1.000–1.046 倍**，几乎零额外空间。
- 消融表明：加边并剪枝与加边不剪枝各有胜负但均优于原图；层次候选、商图候选、图平滑三者组合最优（0.99 recall 下为各变体的 1.09–2.43x QPS）；叶门控有效；\(M_{pair}=4\)、\(b=32\)、\(t_s=4\)、\(s_h=4\)、\(\kappa=3\)、\(r=16\) 为较优默认值。
- 可扩展性：100M 规模下仍达 394.3 QPS（Recall@10=0.95）与 140.8 QPS（Recall@100=0.95），索引大小近线性增长，增强阶段耗时与 HNSW 构建同量级。

## 7. 优点

- **问题建模新颖**：将"允许某方向变化"的检索需求形式化为无限直线查询，并给出可落地的 LANN 定义与召回度量。
- **避免维度爆炸**：

**避免维度爆炸**：论文证明了精确归约到点 ANN 所需的最低维度为 \(D^\star=\Theta(d^2)\)，但没有沿用“提升维度后建点索引”的路线，而是在原始 \(d\) 维空间中构造图索引。这样既绕开了 \(O(Nd^2)\) 的存储与构建开销，也避免了高维提升后距离集中、索引退化等副作用。

- **索引复用性强、额外开销极低**：LinePG 以现成的 HNSW 近邻图为基础，只增加少量成对边；全量实验中的总存储仅为 DirectSearch 的 1.000–1.046 倍，基本实现“近零额外空间”。这使方法易于嵌入现有向量数据库，而不必重建一套专用索引。
- **局部探索与跨区域跳转分工明确**：原图边负责沿直线方向的局部细化，pair edges 负责连接沿直线分离但都靠近同一直线的区域，二者互补。该设计直接针对 DirectSearch 因束搜索早停而遗漏远端更优区域的失效模式，几何直觉清晰，实现也较简洁。
- **离线选边机制较系统**：层次划分、图平滑、商图可达性、区域对打分、端点支撑度与方向多样性共同构成一套从“找候选区域”到“选具体端点”的流程，而不是随机加边；消融实验也验证了三个离线组件组合后的收益。
- **理论分析有针对性**：除了给出精确归约的维度下界，还分析了层次与商图构建复杂度，并对“先采样后判可达”的候选区域采样策略给出均匀性定理，说明启发式设计背后有可解释的依据。
- **实验对比维度较全**：同时报告 Recall 与 QPS，覆盖人脸、GAN 隐码、传统 SIFT/GIST 以及 10M–100M 规模；与 Lift、TheoryLP、DirectSearch 的对比分别揭示了空间、构建成本和吞吐上的优势，结论有较强说服力。
- **工程可落地性较好**：默认参数统一、单线程查询、C++ 实现，100M 规模下仍保持数百 QPS；构建增强阶段与 HNSW 构建同量级，说明方法不依赖离线超长预处理。

## 8. 局限与可改进之处

- **对底层点图质量存在依赖**：LinePG 的局部探索完全建立在原 HNSW 图上，若原图在特定数据分布下连通性差或召回不足，成对边只能部分弥补跨区域问题，无法从根本上修复底层索引。
- **查询模型仍较理想化**：论文只处理无限仿射直线与欧氏垂距，未讨论有界线段、射线、带权方向惩罚、多个方向同时不变等更复杂查询；实际应用中“允许变化的方向”往往带有范围约束或非线性流形结构。
- **成对边选择属于启发式**：区域对打分 \(S(A,B)=g\cdot h\)、代表库 \(R(B)\)、支撑分 \(J\)、方向多样性 \(\nu\cdot\alpha\) 等均含人工设计成分；虽然消融显示有效，但不同数据尺度、簇结构或噪声水平下的稳健性仍缺少理论保证。
- **参数数量偏多**：\(M_{pair}, b, t_s, s_h, \kappa, r\) 等参数共同影响效果，论文给出了默认值和敏感性分析，但在新数据集上仍可能需要调参；相比“即插即用”的期望，部署成本略高。
- **baseline 覆盖不完整**：TheoryLP 仅在小规模子集评测，Lift 在多个数据集上超时或内存溢出，导致全量对比中部分基线缺失；这虽可归因于基线本身开销大，但也削弱了跨方法结论的完整性。
- **查询构造依赖特定假设**：人脸光照对、GAN 语义方向、随机点对三种构造方式分别对应不同应用场景，论文未系统讨论查询端点噪声、方向估计误差或直线长度变化对召回的影响。
- **未讨论动态更新与删除**：成对边在插入、删除、图重连后的维护策略未展开；若底层图频繁更新，pair edges 是否需要重建、如何增量维护仍是开放问题。
- **理论下界针对精确归约**：\(D^\star=\Theta(d^2)\) 说明精确降维不可行，但并不直接给出 LANN 在近似条件下的信息论下界；LinePG 的理论保证更多是复杂度与构造合理性，而非查询召回的最坏情况界。

## 9. 总结与启发

LinePG 的核心贡献在于：**不把直线查询转化为高维点查询，而是在原始空间的点近邻图上“补少量跨区域边”**。它把问题拆成“离线识别沿直线分离的区域对”和“在线束搜索中按需跳转”两部分，以极低的索引增量换取了相对 DirectSearch 的显著吞吐提升，并在与 Lift、TheoryLP 的对比中展现出空间与构建成本上的数量级优势。

对后续工作的启发包括：其一，查询对象从“点”扩展到“线/子空间”时，复用点索引并只增加结构性边，可能比重新设计专用索引更具工程可行性；其二，跨区域跳转边的选择可以进一步学习化或数据驱动化，以减少手工打分与参数；其三，可将直线模型推广到有界线段、方向区间约束或流形上的“允许变化”查询，并研究动态图下的增量维护与理论召回保证。
