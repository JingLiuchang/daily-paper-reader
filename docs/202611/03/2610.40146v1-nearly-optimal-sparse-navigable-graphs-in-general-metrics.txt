# Nearly Optimal Sparse Navigable Graphs in General Metrics 

Hongyi Chen ∗ Tianyi Zhang †

Abstract 

We study approximation algorithms for constructing sparse navigable graphs in general metrics. Given an n-point metric (P, d) and a parameter α ≥ 1, a directed graph on P is α-navigable if, for every pair of distinct points s, t ∈ P, the source s has an outgoing neighbor p

with d(p, t) < d(s, t)/α. The objective is to minimize the number of edges. Recent independent works of Khanna, Padaki, and Waingarten (2026) and Conway et al. (2026) give O(log n)-approximation algorithms and show that an o(log n) approximation is NP-hard in general. Before our work, the best known running time for such an approximation for general α ≥ 1 was 

eO(min {n OPT α, n2.5 }), where OPT α is the minimum number of edges in an α-navigable graph. In this paper, we give a randomized algorithm that, with high probability, runs in eO(n2) time and achieves an O(log n) approximation for every α ≥ 1. In general, these guarantees are nearly optimal up to constant factors in the approximation and polylogarithmic factors in the running time.

Nearest neighbor search aims to preprocess a dataset so that, given a query point, an exact or approximate nearest neighbor can be found efficiently. Graph-based methods approach this problem by building a graph on the dataset points and answering queries by following edges toward points closer to the query. This approach underlies practical methods such as HNSW [MY20], NSG [FXWC19], and DiskANN [SDK +19]. The graph must provide edges that allow a search to make progress, while keeping neighborhoods small enough to inspect efficiently. Recent work has improved graph construction and search guarantees [DGM +24, LT25, GKSW25, AJDG +25]. Complementary studies examine the efficiency, accuracy, and scalability of graph-based search in practical settings [ZPL +26, AEP25, SSKS21, GKL +25, AM26]. A central theoretical abstraction for this approach is navigability [IX23]. 

Definition 1.1 (α-navigability) . Let (P, d) be an n-point metric and let α ≥ 1. A directed graph (P, E)

with no self-loops is α-navigable if, for every pair of distinct points s, t ∈ P, some edge (s, p) ∈ E

satisfies 

αd(p, t) < d(s, t).

We call s the source, t the target, and p an intermediate point; p may be t itself. For α = 1, the condition guarantees that a greedy search can always move closer to a target in P until it reaches that target. Larger values of α require more progress from each step. The analysis of Indyk and Xu [IX23] implies that, for every 0 < ε ≤ 1, one can choose α = O(1/ ε) so that greedy search on an α-navigable graph finds a (1 + ε)-approximate nearest neighbor (ANN) of any query point in 

O(log (∆/ε)) search steps, where ∆ is the aspect ratio of (P, d), defined as the ratio of the largest pairwise distance to the smallest nonzero pairwise distance. Logarithmic factors in asymptotic bounds are understood to be at least 1.This motivates the following problem: given (P, d) and α ≥ 1, build an α-navigable graph with as few edges as possible. Let OPT α denote the minimum number of edges in such a graph. We seek an efficient algorithm whose output size is within a small multiplicative factor of OPT α for every input metric. 

Previous work. Khanna, Padaki, and Waingarten [KPW26] and, independently, Conway et al. [CDFC +26] initiated the study of approximation algorithms for this problem. Both formu-late the problem as a Set Cover instance for each source. For a fixed source s, each possible outgoing edge (s, p) corresponds to the set of targets t ∈ P \ { s} for which (s, p) satisfies the navigation requirement. Choosing outgoing neighbors for s is therefore equivalent to selecting as few such sets as possible to cover P \ { s}. Applying greedy Set Cover to all n instances yields an O(log n)

approximation in O(n3) time. Both works also show that obtaining an o(log n) approximation is NP-hard in general. Thus the remaining algorithmic question is how quickly we can obtain the logarithmic approximation. For general α ≥ 1, Khanna, Padaki, and Waingarten [KPW26] give an eO(n OPT α)-time algo-rithm, and Conway et al. [CDFC +26] obtain eO(min {n OPT α, n2.5 }) time. Here eO suppresses factors polylogarithmic in n. For α = 1, Conway et al. further obtain an eO(n2)-time construction, assuming that the distances from each point to the other points are pairwise distinct. Their work leaves near-quadratic construction for general α open. Khanna, Padaki, and Waingarten also use matrix multiplication to obtain a bicriteria guarantee: the output is α-navigable, but its size is compared with the optimum under a stronger navigation requirement. These results leave the following question: 1Can we obtain an O(log n) approximation to the sparsest α-navigable graph in near-quadratic time for every α ≥ 1?

1.1 Main Result 

We give an affirmative answer to this question. Even for α = 1, our result removes the distinct-distance assumption in the near-quadratic construction of Conway et al. [CDFC +26]. Our contribu-tion is a simple, unified algorithm to solve the coupled Set Cover instances arising from navigable graph construction in near-quadratic time. 

Theorem 1.2. Let (P, d) be an n-point metric space. For every α ≥ 1, there is a randomized algorithm that constructs an α-navigable graph on (P, d). With high probability, the algorithm runs in O(n2 log 2 n) time and returns a graph with at most O(log n) OPT α edges, where OPT α is the minimum number of edges in an 

α-navigable graph on (P, d).

The O(log n) approximation also holds separately for each source’s outdegree, and is optimal up to constants in general. Moreover, even for α = 1, any randomized algorithm achieving an 

o(n) approximation with constant success probability requires Ω(n2) distance queries [KPW26, Theorem 5]. Thus our running time matches this query lower bound up to polylogarithmic factors. For any 0 < ε ≤ 1, a more careful choice of parameters and standard refinements of the analysis give a (1 + ε)( ln n + 1) approximation in Oε(n2 log 2 n) time with high probability. We present the simpler version for readability and briefly outline this refinement at the end of Section 2. 

1.2 Related Work 

Bicriteria approximation. For β ≥ α, let OPT β denote the minimum number of edges in a β-navigable graph on the same metric. An (α, β)-bicriteria approximation constructs an α-navigable graph and compares its edge count with OPT β. Let ω denote the matrix multiplication exponent. Khanna, Padaki, and Waingarten [KPW26] introduced this bicriteria formulation. For every 

α ≥ 1 and 0 < ε < 1, their algorithm uses matrix multiplication to construct an α-navigable graph with O(log n) OPT 2(1+ε)α edges in eO(nω log ∆/ε) time. In the notation above, this is an 

(α, 2 (1 + ε)α)-bicriteria O(log n) approximation. In a follow-up work, Chen and Zhang [CZ27] reduce the running time to eO(n2 log ∆) for constant α ≥ 1. Their algorithm achieves both an (α, 2 α + O(1)) -bicriteria 5-approximation and an (α, α + O(1)) -bicriteria O(log n) approximation. They also establish logarithmic approximation hardness for the (α, 2 α − η)-bicriteria problem, for every constant η ∈ (0, 1 ), under P̸ = NP .The constant-factor bicriteria guarantee is measured against OPT 2α+O(1), whereas Theorem 1.2 gives an O(log n) approximation relative to OPT α. Since OPT β ≥ OPT α for β > α, a constant-factor bound relative to OPT β does not in general imply a constant-factor approximation relative to OPT α.Our running time is also independent of the aspect ratio ∆. # 2 Technical Overview 

For a fixed source s, choosing outgoing neighbors can be formulated as a Set Cover problem, following previous work [CDFC +26, KPW26]. For each possible intermediate point p̸ = s, define the set of targets for which the edge (s, p) satisfies the navigation requirement: 

Ss(p) = {t ∈ P \ { s} : αd(p, t) < d(s, t)}.

3Choosing outgoing neighbors that satisfy the navigation requirement for s is equivalent to covering 

P \ { s} with the corresponding sets Ss(p). Let ks denote the minimum number of sets needed, equivalently the minimum feasible outdegree of s.We say that p covers t when t ∈ Ss(p). Let U denote the uncovered targets , those not covered by any selected intermediate point. Initially, U = P \ { s}. Adding p to the outgoing neighborhood inserts (s, p) and updates U ← U \ Ss(p).An incidence is a pair (p, t) with t ∈ Ss(p). These incidences define a bipartite incidence graph :each left vertex corresponds to an intermediate point p̸ = s and represents the set Ss(p), while each right vertex corresponds to a target t̸ = s. The two vertices are adjacent exactly when t ∈ Ss(p). The degree of a target is its frequency , the number of sets containing it; the degree of an intermediate point p is the set size |Ss(p)|.The graph has at most n vertices on each side and can contain Θ(n2) edges. Constructing it explicitly and running greedy, which repeatedly selects a set covering the most uncovered tar-gets, takes O(n2) time per source and O(n3) time overall. Our goal is to preserve the O(log n)

approximation while reducing the total running time to near-quadratic.

Let Q be the set of points obtained from O(D log n) independent uniform samples from P;we call these points pivots . Add the edges (s, q) for q ∈ Q \ { s}.We show that after adding the pivot edges, every uncovered target has frequency O(n/D) with high probability. Figure 1 illustrates the argument.

Sampled greedy coverage. In each iteration, we aim to choose at most D additional intermediate points covering at least half of the current uncovered targets U. We sample targets from U and run greedy on the sampled Set Cover instance to choose these points. We then check their coverage on 

U exactly. If they cover at least half of U, we add the corresponding edges (s, p) and remove the covered targets from U. Otherwise, we discard the proposed points and report failure. At the start of each iteration, draw a uniform sample T of O(D log n) targets from U without replacement. If |U| is smaller than the prescribed sample size, take T = U. This defines a sampled Set Cover instance with targets T and sets Ss(p) ∩ T for p̸ = s. Its incidence graph retains all left vertices and only the target vertices in T.Run greedy on the sampled instance for at most D steps, each time choosing a restricted set covering the most remaining sampled targets. Stop earlier if all sampled targets are covered. An optimal neighborhood of s provides at most ks sets covering T. At each step, one of these sets covers at least a 1/ ks fraction of the remaining sampled targets, and greedy covers at least as many. Since 

D ≥ ks, the covered fraction of T is therefore at least 

1 − (1 − 1/ ks)D ≥ 1 − e−1 > 5/8. 

We only need this constant coverage, rather than a cover of the entire sample. We use a standard sampling argument [HPS11, HPIMV16]. Fix any collection of at most D

intermediate points covering less than half of U. Hoeffding’s inequality bounds the probability that it covers at least 5/8 of T by e−| T|/32 . There are at most nD such collections. Thus O(D log n)

sampled targets suffice, by a union bound, to ensure that every collection covering at least 5/8 of T

also covers at least half of U, with high probability. If T = U, this implication holds deterministically. This guarantee holds simultaneously for all such choices on the same sample T. It therefore applies to greedy’s choices, even though they are made after examining T. Consequently, the proposed points cover at least half of U with high probability. For each target t, we sort P by distance to t once and reuse this order for all sources. By the frequency bound, each sampled target has degree O(n/D), so the sampled incidence graph has O(D log n) · O(n/D) = O(n log n) edges. For each t ∈ T, we scan its distance order until 

αd(p, t) ≥ d(s, t) to enumerate its incident edges. We implement greedy using buckets indexed by the number of sampled targets a set still covers, updating the affected sets whenever a sampled target is covered. Each incidence is processed O(1) times, so constructing the sampled incidence graph and running greedy take O(n log n) time in total. Each successful iteration halves |U|, so O(log n) such iterations use O(D log n) neighbors in total. To handle the unknown value of ks, try degree estimates D =

1, 2, 4, . . . , capping the last estimate at n − 1. At each estimate, add edges to the corresponding pivots and remove the targets they cover from U. Repeat the sampled greedy iterations, adding the proposed points as neighbors only if they cover at least half of U. With high probability, every iteration at the first estimate D ≥ ks passes the check, so the source finishes at that estimate or earlier. This estimate is less than 2ks. Each successful iteration therefore adds O(ks) neighbors, and there are only O(log n) successful iterations across all estimates because each halves U. The pivot sets also contribute O(ks log n) neighbors in total, since their sizes grow geometrically with the degree estimates. Summing over sources gives O(log n) OPT α edges. There is at most one failed iteration per estimate, so each source performs O(log n) iterations in total. Each takes O(n log n) time, giving O(n log 2 n) time per source. The shared preprocessing for all O(log n) degree estimates costs O(n2 log 2 n) in expectation and with high probability. Thus the total running time is O(n2 log 2 n).

Relation to prior techniques. Set sampling and element sampling are established techniques in streaming and sublinear Set Cover [DIMV14, HPIMV16, IMR +18]. The former covers high-frequency elements using random sets, as in our construction of Q; the latter selects sets on a sampled universe to cover much of the original universe, as in our sampled greedy coverage. Conway et al.’s VoteCover [CDFC +26] achieves a similar effect through a sampling-based simulation of greedy, using voting ideas with earlier precedents in Rajagopalan and Vazirani [RV98]. Controlling the cost of updating uncovered targets requires additional structure. For α = 1,Conway et al. partition unfinished sources into O(n/D) groups of at most D vertices and make each group C a clique in the output graph. In their setting, the vertex of C closest to an external target t is a valid intermediate point for every other source in C, but need not satisfy the navigation requirement for α > 1. Thus, when α = 1, each clique leaves at most one uncovered source–target pair per external target, giving O(n) such pairs per clique. Across all groups, this leaves O(n2/D)

uncovered source–target pairs. Their eO(D) update cost per pair therefore gives eO(n2) total update time. To control this update cost for general α, we adapt the center-selection construction of Thorup and Zwick [TZ01, Theorem 3.1]. Together with the sampling techniques above, this yields a near-quadratic construction for every α ≥ 1.

Refining the approximation factor. To reduce the leading constant, use O(εD log n) pivots at degree estimate D, for 0 < ε ≤ 1. The two residual degree bounds then become O(n/(εD)) . Use 

O(ε−2 D log n) sampled targets and accept the first greedy prefix leaving at most an e−1 + O(ε)

fraction of U uncovered, updating the exact coverage incrementally. When D ≥ ks, this rule accepts a prefix of at most ks choices with high probability. The smaller pivot sets contribute only O(εks log n)

neighbors in total. Choosing the constants appropriately gives a (1 + ε)( ln n + 1) approximation while preserving exact α-navigability through validation. These refinements take O(ε−3n2 log 2 n) time with high probability. The factor ε−3 combines the 

ε−1 increase in the residual degree bounds with the ε−2 increase in sample size needed to control the coverage error to O(ε). For a fixed source s, an intermediate point p ∈ P \ { s} is a possible outgoing neighbor of s.Define its covered targets by
