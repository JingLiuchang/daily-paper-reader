## 摘要
基于图的最近邻搜索算法（如 HNSW、DiskANN、NSG 等）近年来因其相较于 IVF 数据结构和局部敏感哈希（LSH）等空间划分方法具有出色的经验性能而广受欢迎。然而，与 LSH 及相关方法不同，为基于图的搜索获得强最坏情况理论保证一直颇具挑战。本文证明了一个强下界，有助于解释为何在获得此类保证方面缺乏进展。我们表明，任何标准基于图的方法（即在扁平图或层次图上运行贪心搜索变体的方法）在欧几里得空间中执行近似最近邻搜索时，都无法实现亚线性查询时间，即使近似因子任意大。另一方面，我们证明，如果允许搜索图中存在 Steiner 点，则亚线性查询时间是可能的。我们获得了与 LSH 相当的界，例如表明带有 Steiner 点的基于图的搜索可以在欧几里得空间中以查询时间 $\tilde{O}(n^{1/(c-1)})$ 解决 $c$-近似最近邻搜索。我们通过初步实验补充了这一结果，探索如何将 Steiner 点融入实际的基于图的方法。

## Abstract
Graph-based nearest neighbor search algorithms like HNSW, DiskANN, NSG, and others have surged in popularity in recent years due to their excellent empirical performance in comparison to space-partitioning methods like IVF data structures and Locality Sensitive Hashing (LSH). However, in contrast to LSH and related methods, obtaining strong worst-case theoretical guarantees for graph-based search has proven challenging. In this paper, we prove a strong lower bound that helps explain the lack of progress towards such guarantees. We show that no standard graph-based method (any that runs a variant of greedy search on a flat or hierarchical graph) can achieve sublinear query time for approximate nearest neighbor search in Euclidean space, even for an arbitrarily large approximation factor. On the other hand, we prove that sublinear query time is possible if we allow for Steiner points in the search graph. We obtain bounds comparable to LSH, showing e.g., that graph-based search with Steiner points can solve $c$-approximate nearest neighbor search in Euclidean space with query time $\tilde{O}(n^{1/(c-1)})$. We complement this result with initial experiments exploring how Steiner points can be incorporated into practical graph-based methods.

## 2. 方法论

### 2.1 问题形式化
- 定义**通用贪心搜索模型**（Algorithm 1）：维护按到查询距离排序的最小优先队列，每步弹出最近节点并将其出邻居加入队列，直至终止条件满足；覆盖 beam search、纯贪心等多种终止策略。
- 定义**图基 $c$-近似 ANN**：允许任意图构造算法、任意起点、任意终止条件，甚至允许任意大的预处理时间；下界对所有这些变体成立。
- 扩展：节点集可为 $X \cup S$，其中 $S$ 为不属于数据集的 **Steiner 点**。

### 2.2 核心下界（Theorem 1 / Theorem 4）
- **硬实例构造**：$x_i = a_i v_i$，其中 $\{v_i\}$ 为 $\mathbb{R}^n$ 中任意正交基，$0 \le a_1 < a_2 < \cdots < a_n$。
- **关键性质**：由于正交性，$\|x_i - x_j\|_2^2 = a_i^2 + a_j^2$，故对任意查询 $q \in X$，距离排序与查询无关——$x_1$ 是所有人的最近邻，$x_2$ 是第二近邻……
- **推论**：贪心搜索按固定顺序遍历 $X$ 直至命中 $q$，平均需 $\Omega(n)$ 次距离计算，即 $\Omega(nd)$ 时间。由于 $q \in X$ 时最近邻距离为 0，近似与精确等价，下界对**任意有限近似因子 $c$** 成立。
- **扩展**：可推广至余弦相似度（通过追加坐标归一化）及 HNSW 等层次图方法（距离函数仅用于比较，搜索顺序仍与查询无关）。

### 2.3 低维下界（Theorem 2 / Theorem 7）
- 对 $d = O(\log n)$ 的随机超立方体点集，证明**纯贪心搜索**（一旦无法改进即终止）必须使起点出度达到 $\Omega(n^{1/2-\gamma})$，故查询时间下界为 $\Omega(dn^{1/2-\gamma})$。
- 证明工具：基于 Diwan et al. [2024] 的"可导航图"平均度下界，通过近邻集合 $N(j) = \{i : \langle x_i, x_j\rangle \ge \tau\}$ 的随机集合性质（大小 $\Theta(\sqrt{n})$、交集小）与"首跳覆盖约束"（Lemma 4）推出源点度数下界（Lemma 5）。

### 2.4 上界：Steiner 点模拟 LSH（Theorem 3）
- **核心思想**：将 Datar et al. [2004] 的投影型 LSH 哈希 $h_{a,b}(x) = \lfloor (\langle a,x\rangle + b)/w \rfloor$ 用贪心搜索图模拟。
- **关键构件——Steiner 比较小工具（Lemma 2）**：对任意向量 $a$ 与阈值 $\theta$，构造两个 Steiner 点 $s_L, s_R$（可位于任意大的范数处），使得 $\|q - s_L\|_2 < \|q - s_R\|_2 \iff \langle a, q\rangle < \theta$。其原理是让两点连线的垂直平分面恰为超平面 $\langle a,q\rangle = \theta$。
- **单表模拟（Lemma 1）**：对每个非空哈希桶放置一个终端 Steiner 点，并连向桶内任一点；构建平衡二叉路由树，内部节点用比较小工具实现桶边界比较；通过让深层 Steiner 点范数远大于浅层，保证贪心搜索沿树正确下行、不回溯。规模 $O(kn)$ 个 Steiner 点、$O(k\log n)$ 步、出度 $\le 2$。
- **多表重复（Theorem 6）**：将 $L$ 个单表图的终端/失败节点串联至下一表根节点，通过范数分层保证搜索顺序推进，实现固定半径 $(R,c)$-近邻搜索。
- **归约到 ANN（Theorem 3）**：对几何间隔的半径序列 $R_i = \gamma^i R_0$ 构建多级结构并串联；通过取略小的 $c_0 < c$ 吸收归约损失的 $\gamma$ 因子。最终查询时间 $\tilde{O}(dn^{1/(c-1)})$，Steiner 点数 $\tilde{O}(n^{1+1/(c-1)}\log\Delta\log(1/\delta))$，与 LSH 界相当。

### 2.5 实验方法
- 用 k-means 将数据集聚为 $k \in \{0.05n, 0.15n, 0.25n\}$ 类，将**聚类中心作为 Steiner 点**加入点集，用 ParlayANN 的 Vamana/DiskANN 在其上建图；查询时 Steiner 点参与 beam search 扩展但不计入输出结果。

## 6. 主要结论与发现

1. **理论下界**：任何标准图基方法（扁平或层次图上的贪心搜索变体），在欧氏空间中对任意有限近似因子 $c$，都无法以 $o(nd)$ 时间解决 $c$-ANN；该下界可扩展至余弦相似度与 HNSW。
2. **低维仍受限**：即使 $d = O(\log n)$，纯贪心搜索仍需 $\Omega(n^{1/2-\gamma})$ 时间，说明对 $d$ 的指数依赖在纯贪心设定下是本质的。
3. **Steiner 点突破瓶颈**：允许搜索图包含 Steiner 点后，可用贪心搜索模拟 LSH，达到 $\tilde{O}(dn^{1/(c-1)})$ 查询时间，与经典 LSH 界相当。
4. **实验发现**：简单 k-means Steiner 增强在 GloVe-200、NYTimes 上带来明显收益（如 GloVe 上 Recall@1 相同情况下距离计算减少约 25%）；但在 SIFT、Fashion-MNIST（基线召回已接近饱和）及 YFCC 上出现轻微退化（1–3 个百分点），原因尚不明确。

## 7. 优点

- **理论贡献完整且对称**：下界与上界配对，清晰刻画了"标准图方法不行、加 Steiner 点可行"的边界，直接回答了领域内重要开放问题。

## 8. 不足与局限

- **理论构造不实用**：Theorem 3 需要 $\tilde{O}(n^{1+1/(c-1)})$ 个 Steiner 点，远超数据集规模，仅是存在性证明；从该构造到 k-means 实验之间缺少理论指导的中间方案。
- **低维下界适用范围窄**：仅针对**纯贪心搜索**且要求对所有 $q \in X$
