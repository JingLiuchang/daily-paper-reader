## 摘要
长期记忆使大语言模型（LLMs）能够在扩展对话中保持连贯且个性化的交互。然而，现有记忆系统面临两个关键挑战：（1）信息纠缠，即异构信息混合在粗粒度记忆单元中；（2）组织失配，即主要基于语义相似度的记忆结构可能忽略其他关联。为解决这些挑战，我们提出 ETAMem，一个多视图记忆框架，用于解耦异构对话信息，并使记忆表示与组织方式同其不同特性相对齐。具体而言，异构信息解析提取原子记忆单元并识别情感信息。视图特定记忆结构化随后将这些单元组织为三个互补的层次化视图：事件、情感和时间。ETAMem 通过自适应校准阈值增量维护记忆结构。在检索方面，基于熵的检索在多个视图间分配查询特定的预算，并在每个视图内执行层次化搜索。在 LoCoMo 和 LongMemEval-S 上的实验表明，ETAMem 优于最先进基线，分别取得 12.46% 和 7.96% 的相对准确率提升，同时保持有竞争力的 token 效率。进一步分析证明了不同记忆视图的互补优势。

## Abstract
Long-term memory enables Large Language Models (LLMs) to maintain coherent and personalized interactions across extended conversations. However, existing memory systems face two key challenges: (1) Information Entanglement, where heterogeneous information is mixed within coarse-grained memory units; and (2) Organizational Mismatch, where memory structures based primarily on semantic similarity may overlook other associations. To address these challenges, we propose ETAMem, a multi-view memory framework that decouples heterogeneous conversational information and aligns memory representations and organization with its distinct characteristics. Specifically, heterogeneous information parsing extracts atomic memory units and identifies affective information. View-specific memory structuring then organizes these units into three complementary hierarchical views: Event, Affect, and Time. ETAMem incrementally maintains memory structures with adaptively calibrated thresholds. For retrieval, entropy-based retrieval allocates query-specific budgets across views and performs hierarchical search within each view. Experiments on LoCoMo and LongMemEval-S demonstrate that ETAMem outperforms state-of-the-art baselines, achieving relative accuracy improvements of 12.46% and 7.96%, respectively, while maintaining competitive token efficiency. Further analyses demonstrate the complementary benefits of different memory views.

- **研究背景**：长期记忆是 LLM 驱动的个性化对话智能体在跨会话交互中保持连贯性与个性化的关键能力。现有记忆架构可分为**扁平式**（将对话信息存为独立文本条目，用嵌入相似度检索）与**结构化式**（用层次或图结构组织记忆单元）。
- **两大核心挑战**：
  - **信息纠缠（Information Entanglement）**：现有系统以对话轮或摘要为粗粒度记忆单元，未显式区分事实事件、个人偏好、时间语境等异构信息，导致检索时证据难以隔离、引入噪声。
  - **组织失配（Organizational Mismatch）**：主流记忆结构主要按语义相似度组织，会忽略情感、时间等其他关联维度，使相关证据散落在不同分支，难以被整体检索。
- **核心洞察**：不同信息类型需要不同的表示与组织原则——回答"我喜欢什么活动"需跨情境连接情感信息，回答"这周我做了什么"需按时间关系聚合经历。这与认知神经科学中情景记忆与情绪处理由功能专门化但相互作用的神经系统支撑的发现相呼应。
- **研究问题**：如何对对话信息进行识别、表示与组织，以支持长期记忆检索？
- **整体含义**：论文主张**解耦异构对话信息，并使记忆表示与组织方式同其特性对齐**，提出 Event-Time-Affect 多视图记忆框架 ETAMem。

## 2. 方法论

### 2.1 核心思想
将对话历史解析为原子记忆单元（AMU），按信息类型分流到**事件（Event）、情感（Affect）、时间（Time）** 三个互补层次视图，各视图采用专属表示与组织原则；检索时用熵路由为各视图分配查询特定预算，并在各视图内做层次化 beam search。

### 2.2 关键技术细节

- **异构信息解析**：
  - 用 LLM 将每轮对话 $x_t=(d_t,\tau_t)$ 分解为语义完整的原子记忆单元集合 $\mathcal{A}_t=\{a_{t,1},\dots,a_{t,n_t}\}$。
  - 用现成情感分类器 $f_{sent}$ 为每个 AMU 赋予极性标签 $p_{t,i}\in\{\text{negative},\text{neutral},\text{positive}\}$。

- **视图特定表示**：
  - 中性 AMU 用文本编码器 $\phi_{text}$ 编码；正/负 AMU 用情感编码器 $\phi_{affect}$ 编码，即 $r_{t,i}=\phi_{text}(a_{t,i})$（中性）或 $\phi_{affect}(a_{t,i})$（非中性）。

- **三视图记忆结构** $\mathcal{M}=\{V_{event},V_{affect},V_{time}\}$：
  - **Event 视图**：按文本语义层次聚类中性 AMU，捕捉重复事件、实体与交互。
  - **Affect 视图**：按情感语义层次聚类正/负 AMU，捕捉持续偏好与态度。
  - **Time 视图**：按 Session→Day→Week→Month 预定义时间层次索引全部 AMU，Session 层存 AMU，高层存摘要。
  - 树结构：叶节点存 AMU，内部节点存子树摘要（叶层摘要由 AMU 文本生成，高层摘要由子节点摘要生成）。

- **动态记忆维护**：
  - **Attachment（挂载）**：节点用子树 AMU 表示的质心 $\mu_n$ 表示，相似度 $g(a_{t,i},n)=\cos(r_{t,i},\mu_n)$；从根节点做 beam search 保留 top-$B$ 路径，选最优候选 $n^\star$；依匹配分 $\rho^\star$ 与阈值 $\theta_{attach}$、$\theta_{new}$ 决定执行 **Attach**（挂到现有叶）、**NewLeaf**（在 $n^\star$ 父节点下新建叶）或 **NewRoot**。
  - **Split（分裂）**：当叶节点 AMU 数超 $M_{max}$ 或凝聚度 $\kappa(n)$（叶内 AMU 两两余弦相似度均值）低于 $\theta_{coh}$ 时，用余弦 K-means 分裂为 $k=\max(2,\lceil m/M_{max}\rceil)$ 个新叶。
  - **Merge（合并）**：每会话结束时，对质心相似度 $\cos(\mu_{n_i},\mu_{n_j})\ge\theta_{merge}$ 的节点对合并；叶节点合并后还需满足 $|S_{n_i}\cup S_{n_j}|\le M_{max}$；跨分支合并置于最近公共祖先下。
  - **Summary Update（摘要更新）**：用待处理变更计数器 $u_n$ 实现惰性更新，仅当 $u_n\ge\delta$ 时才重新生成内部节点摘要，降低 LLM 开销。

- **自适应校准**：
  - **结构参数**：按观测到的 AMU 数量中位数 $\tilde{n}_v$ 重算叶容量 $M^{(v)}_{max}=\max(2,\text{round}(\sqrt{\tilde{n}_v}))$、分支因子 $b^{(v)}_{max}$ 与最大深度 $H^{(v)}$，不重建已有树。
  - **维护阈值**：收集插入时的余弦相似度分布，用 **Otsu 方法**划分低/高相似子集；$\theta_{new}$ 取低相似子集 75 分位，$\theta_{attach},\theta_{coh},\theta_{merge}$ 取高相似子集 25/65/85 分位；再用 **EMA**（系数 $\eta=0.5$）平滑跨轮波动。

- **基于熵的检索**：
  - **视图路由**：计算查询与各视图叶摘要的相似度，经温度 $\beta$ 的 softmax 得叶级概率分布 $\alpha_{v,j}$；计算归一化熵 $\bar{H}_v$，以 $1-\bar{H}_v$ 为路由分数并归一化得权重 $w_v$；按 $K_v=\max(1,\text{round}(K w_v))$ 分配各视图叶检索预算。分布越集中（熵越低）的视图获得越大预算。
  - **Beam Search**：每视图内结合语义相似度 $\cos(\phi_{text}(q),\phi_{text}(z_n))$ 与 BM25 词法相关性，按 $\text{score}=(1-\lambda)\tilde{s}_{sem}+\lambda\tilde{s}_{lex}$ 逐层保留 top-$B$ 节点，最终选 top-$K_v$ 叶。
  - **证据融合与回退**：跨视图 AMU 合并去重形成证据集 $\mathcal{E}_q$；若 LLM 判定证据不足返回"no information"，则回退到对应原始对话轮 $\mathcal{D}_q$。

## 3. 实验设计

- **数据集 / Benchmark**：
  - **LoCoMo**：10 个用户组、1,540 个问题，覆盖单跳（841）、时序（321）、开放域（96）、多跳（282）。
  - **LongMemEval-S**：500 个问题，覆盖知识更新（KU, 78）、多会话（MS, 133）、单会话助手/偏好/用户（SSA/SSP/SSU, 56/30/70）、时序推理（TR, 133）。
  - **CloneMem**（补充分析）：由日记、社交媒体、邮件等非对话数字痕迹构建，评估 Experience、Emotion、Opinion 三类个人记忆问题。
- **对比基线**：MemoryBank、A-MEM、Mem0、MemoryOS、MemOS、MAGMA、TiMem、LightMem（共 8 个代表性记忆系统）。
- **实现设置**：
  - 主实验统一用 **gpt-4o-mini** 作 LLM 骨干、**Qwen3-Embedding-0.6B** 作文本嵌入；另用 **Qwen3-30B-A3B-Instruct-2507** 评估 ETAMem（记为 w/ Qwen3-30B）。
  - 检索预算 $K=20$；ETAMem 设 $\lambda=0.25$、beam width $B=10$、$\delta=20$、路由温度 $\beta=0.1$。
  - 情感视图用两个 RoBERTa 模型：Twitter-RoBERTa-Sentiment（分类器）与 RoBERTa-GoEmotions（编码器）。
  - 评估指标为 **LLM-as-a-judge 准确率**；记忆构建成本按每会话 LLM 调用平均 token 数计，推理成本按每查询平均输入 token 数计；结果取 3 次运行的均值 ± 样本标准差。
  - 校准初始化：$M_{max}=25$、$b_{max}=5$、$H=4$，$\theta_{new}=0.4$、$\theta_{attach}=0.5$、$\theta_{coh}=0.6$、$\theta_{merge}=0.7$，百分位 75/25/65/85，$\eta=0.5$。
