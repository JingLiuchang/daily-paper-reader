## 摘要
隐私保护近似最近邻（ANN）搜索允许客户端在不可信服务器上进行搜索而不泄露敏感查询，适用于医学诊断和信用评分等场景。在各种隐私保护原语中，可信执行环境（TEE）的开销远低于重量级密码学方案，但它们会泄露内存访问模式，使对手能够推断查询内容。不经意随机存取存储器（ORAM）可以以 O(log N) 的渐近开销隐藏这些访问模式，但现有高性能 ANN 搜索算法（如 IVF 或 HNSW）表现出复杂且依赖数据的访问模式，对 ORAM 不友好。此外，标准 ORAM 构造通常假设存在少量可信存储，这会削弱安全保证，且并不总是可行。消除此类可信存储的方案（称为双重不经意性）通常会使性能进一步退化至 O(log^2 N)。我们提出 O2N2，一个围绕随机旋转 k-d 树森林中的单路径搜索构建的双重不经意 ANN 框架。基于指针的 Circuit ORAM 存储搜索结构，并为紧凑的内部节点和承载向量的叶节点分别存储。每个被访问的叶节点由不经意选择网络处理，固定调度的去重与选择将局部结果合并为最终 top-k。我们在真实世界数据集上评估 O2N2，并在 1 亿个向量上进一步测试其可扩展性。在指定高召回率目标下的 10-NN 和 100-NN 搜索中，它相比最快的双重不经意基线实现了 9.8--125.9 倍的加速。

## Abstract
Privacy-preserving approximate nearest neighbor (ANN) search allows clients to search from an untrusted server without revealing sensitive queries, and is useful in scenarios like medical diagnostics and credit scoring. Among the various privacy-preserving primitives, trusted execution environments (TEEs) have much lower overhead than heavy cryptographic ones, yet they leak memory access patterns, enabling adversaries to infer query contents.   Oblivious RAM (ORAM) can be used to hide those access patterns at $\mathrm{O}(\log N)$ asymptotic cost, but existing high-performance ANN search algorithms (e.g., IVF or HNSW) exhibit complex, data-dependent access patterns that are unfriendly for ORAM. Furthermore, standard ORAM constructions typically assume there exists a small amount of trusted storage, which weakens the security guarantees and is not always feasible. Solutions that eliminate such trusted storage (known as {\em double obliviousness}) typically degrade performance further to $\mathrm{O}(\log^2 N)$.   We introduce O2N2, a doubly oblivious ANN framework built around single-path search in randomly rotated $k$-d tree forests. A pointer-based Circuit ORAM stores the search structure, with separate storage for compact internal nodes and vector-bearing leaves. Each visited leaf is processed by an oblivious selection network, and fixed-schedule duplicate removal and selection combine the local results into the final top-$k$.   We evaluate O2N2 on real-world datasets and further test its scalability on 100 million vectors. For 10-NN and 100-NN search at the specified high-recall targets, it achieves a $9.8$--$125.9\times$ speedup over the fastest doubly oblivious baselines.
