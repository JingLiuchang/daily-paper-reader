## Abstract 

Geo-filtered approximate nearest-neighbor (GFANN) search re-trieves the objects inside a query-specified geographic disk whose feature vectors are closest to a query vector, a core operation in location-aware Web search. A disk filter on a standard proximity graph invalidates out-of-disk routing vertices; on selective disks, these removals break greedy paths and recall drops sharply. Existing methods scan all in-disk objects, over-fetch unfiltered candidates, or maintain separate sub-indexes across spatial partitions, trading la-tency for index overhead. We propose REACH, a single-graph index based on row-local active-order invariance : if every vertex stores its outgoing neighbors in a fixed-width row sorted by vector distance, any disk filter masks out-of-disk entries while surviving in-disk (active ) neighbors remain vector-sorted. Offline, each vertex merges globally closest vector candidates with a nearest-first geographic stream into one row; online, beam search evaluates vector distances only for the first ℓ active entries of each visited row. Because co-located objects share the same distance to every query center, every disk admits a coordinate group in full or not at all, decomposing ac-tive connectivity into intra-group and inter-coordinate conditions. Under a spatial marked-site model with repeated coordinates, we prove that polylogarithmic out-degree guarantees strong connec-tivity across all disks and constant-factor distance reduction per hop on compact disks, while a cut-rank threshold characterizes the minimum scan budget ℓ. Across four datasets up to 10 7 objects, one REACH index per dataset outperforms SOTA methods, achieving 2.49 × higher geometric-mean QPS than the strongest baseline at 0.95 Recall@10 on selective queries, while building 3 .8×–11 .9×

faster and using 37%–45% less space than a SOTA spatial-graph index.

## 1 Introduction 

Approximate nearest-neighbor (ANN) search in high-dimensional vector spaces is a core operation in Web search, recommendation, and retrieval-augmented generation [20, 27]. Proximity graphs such as HNSW [25], NSG [13], and DiskANN [17] achieve the strongest trade-off between recall and latency [41] by linking each object to proximate vector neighbors and routing queries through best-first beam search. In location-aware Web services, vector similarity is often paired with a spatial range filter: a user may search for geo-tagged photos visually similar to a query image within a kilometer of a landmark, or retrieve points of interest (POIs) matching a text query within walking distance. We call this problem geo-filtered approximate nearest-neighbor (GFANN) search: given a query vector and a query-centered geographic disk, return the 𝑘 in-disk objects closest to the query in vector space. Applying a geographic disk filter to a standard proximity graph breaks its navigation structure. Because semantic similarity is in-dependent of physical location, a vertex’s closest vector neigh-bors are scattered globally; restricting traversal to a disk removes out-of-disk routing vertices, which severs multi-hop paths and disconnects the in-disk subgraph ( filter-induced path erosion , Sec-tion 2). Existing filtered ANN methods struggle as disk selectivity varies [8]. Filter-agnostic strategies fail at one extreme: (1) pre-filtering (Spatial-First [7]) scans all in-disk objects, which is fast on tiny radii but slows by orders of magnitude on neighborhood-or city-scale disks (10 2–10 6 objects); (2) post-filtering (Vector-First ,VBASE [46]) retrieves global vector candidates before spatial fil-tering, wasting most distance evaluations on selective disks; and (3) in-filtering (ACORN [28]) explores two-hop unfiltered neighbor-hoods, which still disconnect under selective disks. Predicate-aware indexes encode filters into the graph for discrete labels [6, 15, 24, 42], workload-tuned sub-indexes [21], weighted attribute–vector met-rics [40, 45], or 1D numeric intervals [12, 23, 43, 47, 48]. However, 1D range graphs rely on a global attribute order under which every interval is contiguous; 2D disks admit no such order even on three objects and induce Ω(𝑛 2) distinct active sets (Section 2), whereas spatial partitions [37, 44] either split queries across cell graphs or duplicate edges across tree levels. In this paper, we show that a single static graph of fixed out-degree can support arbitrary geographic disks through Ranked Active-Graph Recovery . ## 6 Related Work 

Filtered and Hybrid ANN Search. Proximity graphs searched with beam search (HNSW [25], NSG [13], DiskANN [17]) lead unfiltered ANN [2, 3, 27, 41]. For attribute filters [8], Filtered-DiskANN [15], UNG [6], and JAG [42] embed discrete labels into edges; CGIF [24] pairs HNSW with inverted files; SIEVE [21] builds workload-tuned sub-indexes; VBASE [46] uses relaxed monotonic-ity; NHQ [40] and DEG [45] define composite attribute–vector metrics; and ACORN [28] filters two-hop neighborhoods. However, 2D disks cannot be indexed by finite inverted lists and act as hard boundaries ( Δ(𝑠 𝑣 , 𝑔 𝑞 ) ≤ 𝑟 𝑞 ). Range graphs (SeRF [48], uRNG [23], RNSG [47], WinFilter [12], iRangeGraph [43], UNIFY [22], DSG [29], DIGRA [19]) rely on a 1D attribute order absent for 2D disks. 

Spatial–Vector and Fiber-Navigable Retrieval. Spatial [14, 16, 34] and geo-textual indexes [7] prune 2D space before secondary filtering ( Spatial-First , Geo-Partition ); REACH uses a flat grid only for 𝜏 entry seeds. Mesh [37] tunes cell graphs for a known workload and switches between spatial scan and cell-graph search by selectiv-ity, whereas CubeGraph [44] builds graphs across tree levels. Unlike FNS [10], which calls any predicate-induced subgraph a “fiber,” our 

coordinate fibers 𝐹 (𝑧 ) are co-located object classes admitted in full or not at all by any disk (Lemma 3.4), which connects intra-fiber 

𝛼 -pruning with RGG theory [4, 9, 30–32]. 

## 7 Conclusion 

We proposed REACH for GFANN search via Ranked Active-Graph Recovery : (1) filtering a vector-sorted row preserves survivor order, recovering Hℓ (𝑐 ) governed by cut rank ℓSC (𝑐 ); and (2) coordinate fibers pass or fail any disk filter as a unit, yielding polylogarithmic-degree connectivity and 2 .49 × higher selective QPS.
