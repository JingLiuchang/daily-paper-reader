## 摘要
地理过滤近似最近邻（GFANN）搜索检索位于查询指定地理圆盘内、且特征向量最接近查询向量的对象，这是位置感知 Web 搜索中的核心操作。标准邻近图上的圆盘过滤器会使圆盘外的路由顶点失效；对于选择性圆盘，这些移除会破坏贪心路径，导致召回率急剧下降。现有方法要么扫描所有圆盘内对象，要么过度获取未过滤候选，要么跨空间分区维护单独的子索引，以索引开销换取延迟。我们提出 REACH，一种基于行局部活跃序不变性的单图索引：如果每个顶点将其出邻接点存储在按向量距离排序的固定宽度行中，则任意圆盘过滤器会屏蔽圆盘外条目，而存活的圆盘内（活跃）邻居仍保持向量排序。离线阶段，每个顶点将全局最近的向量候选与最近优先的地理流合并为一行；在线阶段，束搜索仅对每个访问行的前 l 个活跃条目计算向量距离。由于同位置对象到每个查询中心的距离相同，每个圆盘要么完整接纳一个坐标组，要么完全不接纳，从而将活跃连通性分解为组内条件和坐标间条件。在具有重复坐标的空间标记点模型下，我们证明多对数出度可保证所有圆盘上的强连通性，并在紧凑圆盘上实现每跳常数因子距离缩减，同时割秩阈值刻画了最小扫描预算 l。在四个对象数高达 10^7 的数据集上，每个数据集仅需一个 REACH 索引即可优于 SOTA 方法，在选择性查询上以 0.95 Recall@10 达到比最强基线高 2.49 倍的几何平均 QPS，同时构建速度快 3.8 倍至 11.9 倍，且比一种 SOTA 空间图索引少用 37%-45% 的空间。

## Abstract
Geo-filtered approximate nearest-neighbor (GFANN) search retrieves the objects inside a query-specified geographic disk whose feature vectors are closest to a query vector, a core operation in location-aware Web search. A disk filter on a standard proximity graph invalidates out-of-disk routing vertices; on selective disks, these removals break greedy paths and recall drops sharply. Existing methods scan all in-disk objects, over-fetch unfiltered candidates, or maintain separate sub-indexes across spatial partitions, trading latency for index overhead. We propose REACH, a single-graph index based on row-local active-order invariance: if every vertex stores its outgoing neighbors in a fixed-width row sorted by vector distance, any disk filter masks out-of-disk entries while surviving in-disk (active) neighbors remain vector-sorted. Offline, each vertex merges globally closest vector candidates with a nearest-first geographic stream into one row; online, beam search evaluates vector distances only for the first l active entries of each visited row. Because co-located objects share the same distance to every query center, every disk admits a coordinate group in full or not at all, decomposing active connectivity into intra-group and inter-coordinate conditions. Under a spatial marked-site model with repeated coordinates, we prove that polylogarithmic out-degree guarantees strong connectivity across all disks and constant-factor distance reduction per hop on compact disks, while a cut-rank threshold characterizes the minimum scan budget l. Across four datasets up to 10^7 objects, one REACH index per dataset outperforms SOTA methods, achieving 2.49x higher geometric-mean QPS than the strongest baseline at 0.95 Recall@10 on selective queries, while building 3.8x-11.9x faster and using 37%-45% less space than a SOTA spatial-graph index.

## 1. 核心问题与整体含义

- **问题定义**：地理过滤近似最近邻（GFANN）搜索——给定查询向量 $x_q$、查询中心 $g$ 与半径 $r$ 构成的球面圆盘 $c=(g,r)$，返回圆盘内（活跃集 $A(c)$）向量距离最近的 $k$ 个对象。这是位置感知 Web 搜索的核心操作（如" landmark 1 公里内视觉相似的照片"、"步行范围内匹配文本的 POI"）。
- **核心痛点：过滤诱导的路径侵蚀（filter-induced path erosion）**。标准邻近图（HNSW/NSG/DiskANN）的邻居按语义相近连接，与地理位置独立；圆盘过滤会删掉盘外路由顶点，期望每条边存活概率仅 $\sigma$，当 $\sigma=10^{-3}$、$B=32$ 时每点仅剩约 0.032 条活跃边，活跃子图 $G[A(c)]$ 断裂，贪心路径失效、召回骤降。
- **现有路线的困境**：
  - 预过滤（Spatial-First）：扫描全部盘内对象，小半径快，城市级圆盘（$10^2$–$10^6$ 对象）慢几个数量级；
  - 后过滤（Vector-First/VBASE）：先取全局向量候选再过滤，选择性高时大量距离计算浪费；
  - 图内过滤（ACORN）：探索两跳未过滤邻域，选择性圆盘下仍不连通；
  - 谓词感知索引（离散标签、工作负载子索引、加权属性-向量度量、1D 区间图）：1D 区间图依赖"每个区间连续"的全局序，而 2D 圆盘不存在这种序；
  - 空间分区（Geo-Partition/Mesh/CubeGraph）：把查询拆到 cell 图或跨树层复制边，以索引开销换延迟。
- **论文的理论起点**：证明 2D 圆盘诱导 $\Omega(n^2)$ 个不同活跃集（VC 维 4 给出 $O(n^4)$ 上界），且三个点即可构造反例说明不存在使所有圆盘活跃集连续的线性序（Prop. 2.3）。
- **整体含义**：提出 REACH，论证**一张固定出度的静态邻近图**即可通过"排序活跃图恢复（Ranked Active-Graph Recovery）"统一服务任意地理圆盘，无需多子索引或边复制。

## 2. 方法论

### 2.1 核心思想：行局部活跃序不变性
- 每个顶点 $u$ 将 $B$ 个出邻居存入固定宽度行 $row(u)$，按向量距离 $d(x_u,\cdot)$ 严格排序（并列按 ID）。
- 任意圆盘 $c$ 过滤后，活跃子序列 $C_u(c)=row(u)\cap A(c)$ **仍保持原有排序**——过滤不改变存活条目的相对次序。
- 定义两级图：
  - **完整活跃投影** $H_\infty(c)=G[A(c)]$：保留全部活跃条目，决定该圆盘的召回上限；
  - **恢复图** $H_\ell(c)$：每点只保留前 $\ell$ 个活跃条目，每步向量评估上限为 $\ell$。
- **割秩阈值** $\ell_{SC}(c)=\max_{\emptyset\neq S\subsetneq A(c)}\min_{u\in S,\,v\in C_u(c)\setminus S} rank_{u,c}(v)$：$H_\ell(c)$ 强连通当且仅当 $\ell\ge \ell_{SC}(c)$（Thm. 3.3），从而把"扫描预算 $\ell$"与连通性精确挂钩，且 $H_\ell\subseteq H_{\ell'}$（$\ell\le\ell'$）、$H_B=H_\infty$。

### 2.2 坐标纤维与两尺度路径分解
- **坐标纤维** $F(z)=\{v:s_v=z\}$：同一坐标的对象到任意查询中心距离相同，故任意圆盘**要么整族接纳、要么整族拒绝**（Lemma 3.4，fiber closure）。
- **Thm. 3.5（两尺度分解）**：$G[A(c)]$ 强连通，当且仅当同时满足 (i) 每个活跃纤维内部强连通；(ii) 把活跃纤维收缩为 site 后的坐标商图强连通。两个条件都不随圆盘数量增长：前者只依赖 $M$ 个静态纤维子图，后者只依赖圆盘内 site 集合。
