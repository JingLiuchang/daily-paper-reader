## 摘要
我们研究在一般度量下构造稀疏可导航图的近似算法。给定一个 n 点度量 (P,d) 和参数 α≥1，α-可导航图是一个有向图 G=(P,E)，使得对于每一对不同的有序点 s,t∈P，顶点 s 都有一条出边 (s,p)，满足 d(p,t)<d(s,t)/α。目标是最小化边数。Khanna、Padaki 和 Waingarten（SODA 2026）以及 Conway 等人（SODA 2026）独立地最近研究了该问题的近似算法。这些工作表明，单准则问题面临集合覆盖障碍：可以达到 O(log n)-近似，而获得 o(log n)-近似是 NP 难的。为了获得更快的算法，Khanna、Padaki 和 Waingarten 引入了双准则近似，其中输出图需要是 α-可导航的，而其规模与某个松弛参数 β≥α 下的最优 β-可导航图的规模进行比较。他们给出了一个快速的基于矩阵乘法的算法，可在时间 Õ(n^ω log Δ/ε) 内计算 (α,2(1+ε)α)-双准则 O(log n)-近似，其中 Δ 表示纵横比，ω 是矩阵乘法指数。我们的主要结果是一个更简单的近二次时间算法，具有更强的双准则保证。对于每个常数 α≥1，我们在时间 Õ(n^2 logΔ) 内计算一个 α-可导航图，它同时是 (α,2α+O(1))-双准则 O(1)-近似和 (α,α+O(1))-双准则 O(log n)-近似。我们用一个硬度结果补充该算法，表明对于每个常数 η∈(0,1)，除非 P=NP，否则没有多项式时间算法能够计算 (α,2α-η)-双准则 o(log n)-近似。

## Abstract
We study approximation algorithms for constructing sparse navigable graphs in general metrics. Given an $n$-point metric $(P,d)$ and a parameter $α\ge 1$, an $α$-navigable graph is a directed graph $G=(P,E)$ such that for every ordered pair of distinct points $s,t\in P$, the vertex $s$ has an outgoing edge $(s,p)$ with $d(p,t)<d(s,t)/α$. The objective is to minimize the number of edges. Approximation algorithms for this problem were recently studied by Khanna, Padaki, and Waingarten (SODA 2026), and independently by Conway et al. (SODA 2026). These works show that the single-criterion problem faces a Set Cover barrier: an $O(\log n)$-approximation is achievable, whereas obtaining an $o(\log n)$-approximation is NP-hard. To obtain faster algorithms, Khanna, Padaki, and Waingarten introduced bicriteria approximation, in which the output graph is required to be $α$-navigable, while its size is compared against that of an optimal $β$-navigable graph for some relaxed parameter $β\ge α$. They gave a fast matrix-multiplication-based algorithm that computes an $(α,2(1+\varepsilon)α)$-bicriteria $O(\log n)$-approximation in time $\widetilde O(n^ω\log Δ/\varepsilon)$, where $Δ$ denotes the aspect ratio and $ω$ is the matrix multiplication exponent. Our main result is a simpler near-quadratic-time algorithm with stronger bicriteria guarantees. For every constant $α\ge 1$, we compute in time $\widetilde O(n^2\logΔ)$ an $α$-navigable graph that is simultaneously an $(α,2α+O(1))$-bicriteria $O(1)$-approximation and an $(α,α+O(1))$-bicriteria $O(\log n)$-approximation. We complement the algorithm with a hardness result showing that for every constant $η\in(0,1)$, no polynomial-time algorithm can compute an $(α,2α-η)$-bicriteria $o(\log n)$-approximation unless $P=NP$.

## 1. 核心问题与研究背景

- **研究对象**：图基近似最近邻搜索（ANN）的理论抽象——**可导航图（navigable graph）**。给定 n 点度量 $(P,d)$ 与参数 $\alpha\ge 1$，若对任意有序点对 $s\ne t$，$s$ 都存在一条出边 $(s,p)$ 满足 $d(p,t) < d(s,t)/\alpha$，则称有向图 $G=(P,E)$ 是 **$\alpha$-可导航**的。
- **优化目标**：在保证 $\alpha$-可导航的前提下**最小化边数**（边数直接决定内存占用与查询时邻居扫描代价）。已有结果表明，$\alpha$-可导航图可支撑 $(\frac{\alpha+1}{\alpha-1}+\epsilon)$-近似 ANN，用 $O(\log_\alpha \Delta/(\alpha-1)\epsilon)$ 步贪心搜索完成，因此大 $\alpha$ 恰是高精度检索的理论相关区间。
- **理论困境（Set Cover 壁垒）**：对固定源点 $s$，覆盖所有目标 $t$ 等价于一个集合覆盖实例（集合 $Z_\alpha(s,u)=\{t: d(u,t)<d(s,t)/\alpha\}$）。因此单准则问题可获 $O(\log n)$-近似，但近期两项独立工作（Khanna–Padaki–Waingarten, SODA 2026；Conway et al., SODA 2026）证明 $o(\log n)$-近似是 NP 难的。
- **破局思路：双准则（bicriteria）近似**。允许输出图仅为 $\alpha$-可导航，但把它的边数与**更宽松的 $\beta$-可导航最优图**（$\beta\ge\alpha$）比较，记为 $(\alpha,\beta)$-双准则 $c$-近似。此前最快算法为 $\tilde O(n^{\omega}\log\Delta/\epsilon)$ 时间的 $(\alpha,2(1+\epsilon)\alpha)$-双准则 $O(\log n)$-近似（$\omega$ 为矩阵乘法指数）。
- **本文回答的开放问题**（Question 1.3）：是否存在**二次时间**的（双准则）$O(\log n)$-近似算法？本文在 polylog 因子内给出肯定回答，并给出匹配下界。

## 2. 方法论

### 2.1 核心思想
- **从“逐源点贪心”到“全局共享代表点”**：不做每个源点独立的集合覆盖，而是**预先在多个距离尺度上计算全局球覆盖**，把覆盖中心作为所有源点共享的候选出邻居，从而把 $O(n^3)$ 的朴素过程加速到近二次时间。

### 2.2 关键技术细节
- **热身：逐源点有序贪心（ordered greedy）**。固定 $s$，按 $d(s,t)$ 非降序处理目标；若当前目标未被已有出边“导航”，则加入边 $(s,t)$。设选中点 $p_1,\dots,p_k$ 按距离递增，则必有
  $$d(p_i,p_j)\ge d(s,p_j)/\alpha \quad (i<j)$$
  这是**“分离/打包（packing）”条件**。对任意 $2\alpha$-可导航图 $H$，为每个 $p_j$ 选取 $H$ 中满足 $d(u_j,p_j)<d(s,p_j)/(2\alpha)$ 的出邻居 $u_j$，用三角不等式可证映射 $p_j\mapsto u_j$ **单射**，故贪心选点数不超过 $H$ 中 $s$ 的出度。**但该方法逐源点运行需 $O(n^3)$ 时间**。

- **尺度体系与环带（annulus）**。设 $\delta=1/\alpha$，$r_i=(1+\delta)^i$，$L=\lceil\log_{1+\delta}\Delta\rceil$，球半径 $\rho_i=r_i/(\alpha+2)$，源点 $s$ 在第 $i$ 层的环带为
  $$A_i(s)=\{v:\ r_i-\rho_i < d(s,v)\le r_{i+1}+\rho_i\}$$
  对每个 $s$ 与每个中心 $p\in A_i(s)$ 加入边 $(s,p)$。

- **两种球覆盖例程**（分别在 $O(n^2)$ 量级实现，用计数器+优先队列惰性更新）：
  - `SeparatedBallCover`：任取未覆盖点为中心，吞掉其半径 $r$ 球内未覆盖点；保证**中心两两距离 $>r$**（对应上述打包条件的尺度版类比）→ 用于**常数因子**保证。
  - `GreedyBallCover`：标准贪心集合覆盖（每步选覆盖最多未覆盖点的球），**中心可以已被覆盖、也可以不属于自己簇**→ 用于**对数因子**保证。

- **正确性关键引理**：若 $d(c,v)<d(c,u)/(\alpha+1)$，则由三角不等式可得 $(u,c)$ 是 $u\to v$ 的 $\alpha$-导航。结合“$t$ 落在某簇 $C\subseteq B(p,\rho_i)$ 且 $p\in A_i(s)$”即可证两算法输出均 $\alpha$-可导航（Lemma 2.2）。

- **常数因子分析（Lemma 2.3）**：对最优 $\beta$-可导航图 $G^\star$，把每个被选中心 $p$ 映射到 $G^\star$ 中导航到 $p$ 的出边 $(s,x)$。利用**同层中心分离性**证明该映射在每层**单射**；再用 $d(s,x)$ 的上下界推出对固定边 $(s,x)$ 只有常数层（比值为 $(1+1/\alpha)^4$，至多 5 层）能命中，得 $|E_s|\le 5|E_s^\star|$，取
  $$\beta=2(1+\delta)(\alpha+2)+2=2\alpha+8+4/\alpha\ (\le 2\alpha+12)$$
  即 $(\alpha,2\alpha+O(1))$-双准则 **5-近似**。

- **对数因子分析（Lemma 2.6）**：用贪心集合覆盖的**对偶权重** $y_v=1/|C_j|$（$v$ 在贪心第 $j$ 步被覆盖），证每个半径 $\rho_i$ 球内权重和 $\le H_n\le \ln n+1$；对每个 $(s,i)$ 定义局部集合覆盖实例 $(U_{i,s},\mathcal F_{i,s})$，得 $|E_i^s|\le(\ln n+1)\mathrm{OPT}_{i,s}$；再用 Claim 2.8 说明 $G^\star$ 中导航边对应的球覆盖该局部实例，且每条边只属于常数层（比值 $(1+1/\alpha)^7$，至多 8 层），最终
  $$\beta'=(1+\delta)(\alpha+2)+2=\alpha+5+2/\alpha\ (\le\alpha+7),\quad \text{近似比 } 8(\ln n+1)$$

- **两构造合并**：同时运行两算法并**返回边数更少者**；两者均 $\alpha$-可导航，故结果同时继承两个双准则界（Theorem 1.4）。总运行时间 $\tilde O(\alpha n^2\log\Delta)$，常数 $\alpha$ 下为 $\tilde O(n^2\log\Delta)$——由于输入含 $\Theta(n^2)$ 个距离，这在显式输入模型下已是对数因子最优。

- **下界（Theorem 1.5）**：由 Set Cover（Dinur–Steurer 的 $\frac12\ln n$ 硬度）归约。构造 $K=\lceil 2(m+n+1)/\eta\rceil$ 个副本，每副本含 hub $c_i$、集合点 $\mathcal F_i$、元素点 $\mathcal U_i$；hub–集合与集合–元素边权 1，跨副本任意两点边权 $2\alpha$，取最短路度量。给出一个含 $O(K^2(m+n+1)(|C^\star|+1))$ 条边的 $(2\alpha-\eta)$-可导航图作为比较基准，再通过**平均化论证**从任一 $(\alpha,2\alpha-\eta)$ 双准则 $c_\eta\ln N$-近似解中抽取规模 $\le \rho(|C^\star|+1+\eta)$ 的集合覆盖，与 $\frac12\ln n$ 硬度矛盾。结论：**低于 $2\alpha$ 的双准则参数下，$o(\log n)$-近似仍是 NP 难的**。

## 6. 主要结论与发现

- 对每个常数 $\alpha\ge1$，可在 $\tilde O(n^2\log\Delta)$ 时间内构造**同时**满足以下两条的 $\alpha$-可导航图（取边数较少者）：
  - $(\alpha,\,2\alpha+8+4/\alpha)$-双准则 **5-近似**；
  - $(\alpha,\,\alpha+5+2/\alpha)$-双准则 $O(\ln n)$-近似（具体 $8(\ln n+1)$）。
- **$2\alpha$ 是“绕过 Set Cover 对数壁垒”的尖锐阈值**：允许约 2 倍（加性常数）的双准则松弛即可获常数因子近似；而任何严格低于 $2\alpha$ 的松弛都无法突破 $\Theta(\log n)$。
- 在 $O(\log n)$-近似一侧，本文的双准则损失 $\alpha+O(1)=(1+o_\alpha(1))\alpha$ **渐近最小**（因必须有 $\beta\ge\alpha$）。
- 运行时间从 $\tilde O(n^\omega\log\Delta/\epsilon)$ 改进到 $\tilde O(n^2\log\Delta)$，且算法更简单（无需矩阵乘法），在显式距离输入下对数因子最优。
- 明确界定适用范围：结论主要针对**大 $\alpha$**（即高精度 ANN 区间）；实践中常见的小 $\alpha$（如 $<2$）不在覆盖范围内。

## 7. 优点

- **理论贡献清晰且“紧”**：上界与下界在 $2\alpha$ 阈值两侧互补，形成完整图景；双准则损失在 $\log$-近似侧渐近最优。
- **算法显著简化**：以“层次球覆盖 + 环带取中心”替代矩阵乘法加速，易于实现（每层覆盖 $O(n^2)$ 量级），且时间近最优。
- **统一框架产出双保证**：同一构造骨架下换用两种覆盖例程（分离覆盖 / 贪心覆盖）分别拿到常数因子与对数因子，再用“取更小者”合并，设计优雅。
- **分析工具扎实**：把有序贪心的“打包条件”提升为尺度化的中心分离性；对数侧用贪心集合覆盖的对偶权重与调和数界，并精细论证“每条最优边只被常数层复用”（层数 5 与 8）。

- **方法论价值**：核心贡献不只是具体数值，而是**"层次球覆盖 + 环带共享中心"这一范式**——把逐源点的集合覆盖贪心替换为跨源点复用的全局覆盖结构，从而把 $O(n^3)$（乃至矩阵乘法加速的 $O(n^\omega)$）压到近二次。该范式可能迁移到其他"每个源点需独立选边"的图构造问题（如稀疏 spanner、hopset、路由表构造）。
- **理论图景的补全**：本文与 KPW、Conway et al. 的工作共同刻画出一条清晰的相变曲线——双准则松弛严格小于 $2\alpha$ 时 $\Theta(\log n)$ 近似不可改进，达到约 $2\alpha$ 时即可常数因子近似。这类"阈值型"结果对理解 Set Cover 壁垒在几何/度量图问题中的边界具有一般意义。
- **对实践的启示（需谨慎）**：结论主要服务于大 $\alpha$（高精度 ANN）区间的理论分析；对实际系统常用的小 $\alpha$ 与有限 $n$，常数 5、$8(\ln n+1)$ 及隐藏 polylog 因子的实际影响仍待实证检验。若要落地，最直接的方向是补齐实现与在真实数据集上的边数/查询召回率对比。
- **可信度**：论文含明确的 AI 使用声明（仅用于文字润色与技术论证核查），且作者主动披露据此修正了 2.5 节早期分析中的一处 bug，透明度良好；但作为纯理论工作，其价值最终取决于证明的正确性，建议读者重点复核 Lemma 2.3、Lemma 2.6 中"每条最优边只属于常数层"的计数论证与 Theorem 1.5 的平均化论证。
