## ABSTRACT 

Many long-term memory systems for LLM agents are built around embedding-based retrieval. Al-though effective for semantic matching, similarity ranking alone does not establish whether re-trieved memories satisfy the conditions implied by a question. In this paper, we introduce KITE (Knowledge-Indexed Temporal Evidence), a vector-free framework that formulates memory re-trieval as an explicit decision procedure. KITE organizes multi-session conversations as structured knowledge indexed by a governed topic vocabulary, which evolves through controlled expansion and consolidation. At query time, questions are compiled into inspectable retrieval plans over the same knowledge index that guides memory construction. The plans are then executed through fixed lookup and ranking operations, while sparse lexical retrieval recovers surface details omitted from the structured representation. Experiments on LoCoMo and LongMemEval-S show that KITE achieves 93.5% and 86.0% accuracy while using only about 1.6k reader-context tokens per ques-tion. These results demonstrate that conversational memory can move beyond similarity ranking by unifying memory construction and query compilation around a governed index, turning retrieval into an inspectable decision procedure for determining which evidence satisfies the question. 

## 1 Introduction 

As large language model (LLM) agents engage in multi-session interactions, they need to carry useful knowledge forward from earlier exchanges. Although larger context windows expose more history, they do not inherently support selective retention (Hsieh et al., 2024). Persistent memory has therefore become a key component of long-term LLM-agent architectures, allowing relevant information to be retained and reused across sessions (Zhong et al., 2024). In practice, many memory systems retrieve past information through nearest-neighbor search over embeddings (Packer et al., 2023; Chhikara et al., 2025). Although effective for semantic matching, single-vector similarity ranking alone does not ensure that the retrieved memories satisfy the conditions of the query (Weller et al., 2026). As Figure 1 illustrates, semantically close memories may outrank evidence that answers the question (Trappolini et al., 2026). In addition, fixed top-k selection returns candidates without explicitly indicating when none satisfies the query (Kim et al., 2025). Beyond retrieval, storing N memories as d-dimensional dense vectors requires O(N d ) space, while encoder changes often require rebuilding the entire embedding index (Monath et al., 2024; Goswami et al., 2025). These limitations of embedding-based retrieval motivate a formulation of memory retrieval as an explicit decision pro-cedure that evaluates query conditions rather than relying on similarity ranking alone (Wang et al., 2026). By exposing matching conditions and intermediate results, this approach makes retrieval decisions inspectable and supports the di-agnosis of retrieval failures (Ru et al., 2024). However, as conversations evolve, the same concepts may be represented by different surface labels or graph nodes, complicating consistent indexing (Zhang & Soh, 2024; Mo et al., 2025). Moreover, questions may refer to stored information through different wording or implicit cues, making relevant ev-idence harder to retrieve (Hu et al., 2026b). To this end, we propose KITE 1 (Knowledge-Indexed Temporal Evidence), a vector-free framework for long-horizon conversational memory that organizes multi-session interactions into structured knowledge indexed by a governed topic vocabulary. Each memory entry is enriched with typed contextual and temporal facets, providing complementary access paths beyond topics. At query time, KITE compiles a natural-language question into an inspectable retrieval plan over the same governed knowledge index, specifying the conditions to apply. The validated plan is then executed through explicit lookup and ranking operations, making evidence selection deterministic. KITE also supplements the primary path with sparse lexical retrieval to recover surface details missed during memory construction. Experiments on LoCoMo (Maharana et al., 2024) and LongMemEval-S (Wu et al., 2025) show that KITE achieves accuracies of 93.5% and 86.0%, respectively, while remaining token-efficient by limiting reader context to a compact evidence set. The key contributions of this paper are as follows: • Retrieval as a deterministic decision procedure. We formulate memory retrieval as a decision procedure that eval-uates explicit query conditions against indexed evidence. Validated plans are then executed through fixed lookup and ranking operations, making evidence selection deterministic per plan and inspectable. These mechanisms establish a practical alternative to similarity-based retrieval while maintaining high accuracy with compact reader contexts. • A governed and evolving knowledge index. We organize memories using a topic vocabulary that evolves across multi-session conversations under controlled expansion and consolidation, with typed facets for finer-grained access to evidence. This design limits topic fragmentation and keeps memories coherently organized as conversations grow. • A shared index for memory construction and query compilation. We align question interpretation with memory organization via a shared knowledge index. Mapping question concepts to existing index keys grounds retrieval plans in stored topics and entities, reducing the semantic gap between natural language and indexed knowledge. 

## 2 Related Work 

2.1 Long-Term Memory for LLM Agents 

Extending the context window of language models is a direct approach to supporting long-horizon interaction (Beltagy et al., 2020; Bulatov et al., 2022). However, longer contexts increase inference costs, while model performance re-mains susceptible to position-dependent degradation (Liu et al., 2024; Hutter et al., 2025). Persistent-memory systems instead preserve information across sessions, beyond the limits of the active context window. For example, MemGPT (Packer et al., 2023) manages information transfer between the model context and the external storage. In addition, MemoryBank (Zhong et al., 2024) incorporates a time-dependent forgetting mechanism, whereas Mem0 (Chhikara et al., 2025) extracts salient facts into an editable memory store and supports add, update, and delete operations. Beyond individual memory operations, several works investigate broader mechanisms for managing information accu-mulated over long interactions. A prominent direction explores system-level memory architectures with hierarchical storage and lifecycle control (Kang et al., 2025; Li et al., 2025). Meanwhile, MEM1 (Zhou et al., 2026) consolidates

2.2 Memory Organization and Index Governance 

Recent studies have explored structured representations for organizing conversational memory. A-MEM (Xu et al., 2025) builds interconnected notes whose attributes and links evolve as new memories arrive. Similarly, Zep (Ras-mussen et al., 2025) organizes conversational knowledge as a temporal knowledge graph that tracks facts along with their validity over time. Alongside these relational approaches, Memanto (Abtahi et al., 2026) structures memories through predefined semantic types, while EverMemOS (Hu et al., 2026a) consolidates episodic MemCells into the-matic MemScenes. In general, these approaches provide richer structures for organizing related memories over time. As these structures grow, a related challenge is maintaining consistent representations of recurring concepts. EDC (Zhang & Soh, 2024) canonicalizes extracted relations into a consolidated schema, including settings without a pre-defined target schema. KGGen (Mo et al., 2025) addresses the same problem from a graph-construction perspective by clustering entities and relations to reduce fragmentation. These works highlight the importance of keeping related concepts aligned and reducing redundant representations, providing a more stable basis for subsequent retrieval. 

2.3 Query Alignment and Executable Retrieval 

Once memories are organized, retrieval must connect each question to the representations in which evidence is stored. Sparse lexical methods such as BM25 (Robertson & Zaragoza, 2009) rank candidates by scoring matches between query terms and stored text. However, questions may express the same information in different words, making relevant memories harder to find through lexical matching alone. QueryLink (Hu et al., 2026b) addresses this mismatch by building semantic representations of questions and memories at different levels of detail for similarity-based retrieval. Complementary work makes memory access explicit through executable operations. ChatDB (Hu et al., 2023) treats databases as symbolic memory, allowing an LLM to generate SQL instructions for memory retrieval and manipula-tion. More generally, Text2Mem (Wang et al., 2026) translates natural-language memory commands into validated operations with a common execution interface. For more structured knowledge, KAG (Liang et al., 2025) combines logical-form planning with hybrid retrieval over knowledge graphs and text, while supporting schema-free knowl-edge extraction. Executable programs can further support reasoning after retrieval, as in TReMu (Ge et al., 2025), which performs temporal calculations over retrieved timeline summaries. Taken together, these approaches establish executable operations as a general-purpose mechanism for explicit access and reasoning over stored evidence. This emphasis on explicit operations also aligns with diagnostic work on intermediate evidence. RAGChecker (Ru et al., 2024) separates retrieval from generation to localize pipeline failures. In long-term memory, MemTrace (Long et al., 2026) distinguishes whether source evidence is reachable from whether it is successfully used. These evaluations highlight the value of making the evidence process inspectable rather than relying on final-answer accuracy alone. 

## 3 Method 

To connect memory organization with evidence selection, KITE formulates long-term conversational memory retrieval as an explicit decision procedure over a governed knowledge index. As illustrated in Figure 2, each session is converted into structured memory entries indexed under a governed topic vocabulary and enriched with contextual and temporal facets. At query time, KITE uses the same knowledge index to compile each question into an inspectable retrieval plan that specifies the conditions for selecting evidence. The validated plan is then executed deterministically through fixed lookup and ranking operations, while sparse lexical retrieval provides complementary evidence. Consider a sequence of dated conversation sessions U = ( u1, . . . , u m) ordered chronologically. Given a later natural-language question q, the retrieval task is to recover evidence from this history that supports an answer. 3.1 Governed Knowledge Index Structured memory entries and provenance. Rather than indexing raw dialogue directly, KITE converts each conversation session into structured memory entries. Each entry can be represented as 

m = ⟨xm, ρ m, T m, A m⟩, (3) where xm is the self-contained memory content and ρm its provenance, including the source session and supporting utterances. The set Tm holds the entry’s governed topics, while Am stores typed contextual and temporal facets, such as entities and events. These fields separate evidence from the structured information used to index and retrieve it. For each session, the extraction model processes the dialogue with the current topic vocabulary as context, produc-ing source-linked entries with facet annotations. Relative time expressions are also resolved against the date of the corresponding session whenever possible, while candidate memory entries without valid provenance are discarded. 

Governed topic vocabulary. Rather than assuming a complete ontology in advance, KITE derives its topic vocab-ulary from the accumulated conversation history. Starting from a small set of canonical roots, the extraction model reuses existing topics when possible and gradually proposes more specific children when new concepts emerge. To ensure consistency, new topics must fit within the existing hierarchy, which helps maintain a stable index over time. 4KITE: Retrieval as a Decision Procedure for Long-Term Conversational Memory PREPRINT 

Vocabulary expansion is further controlled by keeping proposed topics provisional until they recur across multiple sessions and time periods, rather than admitting each new topic as soon as it first appears. As the vocabulary evolves, potentially redundant sibling topics are consolidated, with their memory entries redirected to the selected canonical topic. These controls reduce unnecessary topic fragmentation while preserving stable index keys for retrieval. 

Faceted knowledge indexing. Topics provide broad thematic access to memory, while typed facets offer finer-grained conditions for locating relevant evidence. The index space is defined as 

Σ = Σ topic ∪ Σentity ∪ Σparticipant ∪ Σobject ∪ Σplace ∪ Σevent . (4) A memory entry may therefore be assigned keys from multiple types, providing complementary access paths to the same evidence. For example, consider the LoCoMo question In which state is the shelter from which James adopted the puppy? (Maharana et al., 2024). The dialogue describes James adopting a puppy named Ned from a shelter in Stamford. KITE indexes this entry with James as a participant, Ned as an entity, dog as an object, Stamford as a place, and adoption as an event. Although the question does not explicitly mention Ned , the participant and event keys can provide access to the relevant entry, where the required location information can be recovered. For each key type a, KITE constructs a posting list: 

Pa[s] = {m ∈ M | s ∈ I a(m)} , (5) where s ∈ Σa denotes an index key and Ia(m) gives the keys of type a assigned to memory entry m. Each posting list gives direct access to the memories under a key. Temporal annotations are stored separately in chronological order, enabling time constraints to be evaluated during retrieval. These structures form the governed knowledge index P.

3.2 Index-Grounded Query Compilation Shared-index grounding. Query compilation uses the same knowledge index built during memory construction, so each question is interpreted against the stored vocabulary and entities. Thus, references inferred from the question can be resolved to existing index keys, keeping query interpretation aligned with memory organization. The compiler then maps the question to these keys, while the executor determines which memories satisfy the resulting conditions. 

Typed retrieval plans. Each question is compiled into a typed retrieval plan that makes its evidence requirements explicit before execution. Formally, the plan consists of one or more subqueries 

π = ( π1, . . . , π n), πi = ⟨select , where , pipe ⟩ , i = 1 , . . . , n. (6) Here, select determines the retrieval granularity for each subquery, while where specifies the indexed and temporal conditions on evidence. Finally, pipe applies fixed operations to the results, such as sorting, limiting, or counting. Subqueries can be linked sequentially, allowing results from an earlier step to constrain the search performed in subsequent stages. These dependencies keep multi-hop retrieval explicit in the plan while preserving fixed execution. 

Plan validation. Before execution, each plan is validated against a fixed typed grammar and the knowledge index. Indexed references are resolved to valid keys in the governed representation. Speaker mentions are mapped to par-ticipant constraints, while temporal expressions are normalized into explicit ranges. Plans with unresolved references or unsupported structures are rejected. The validated plan is executed by the retrieval executor without further model intervention, drawing a clear boundary between model-based interpretation and deterministic evidence selection.

The effective conditions remain explicit throughout, and execution stops at the first non-empty result. In practice, exact matches on index keys receive the strongest preference, while broader hierarchical matches or agreement on additional typed facets provide supporting signals. For example, a memory matching both the queried entity and event outscores one linked only through a broader topic. Ranking is applied only after condition checks admit the candidates, so it changes their ordering rather than eligibility. For fixed P, π, and θ, the scores are deterministic, while the basis of each ranking decision remains inspectable. 

Sparse lexical support. Structured memory is designed to capture reusable concepts and retrieval cues, but this abstraction may omit surface-form details preserved in the source text, such as rare names or numerical values. To retain access to such information, KITE augments the indexed path with a deterministic sparse lexical channel. The ranked evidence from both paths is merged under a fixed fusion rule, without dense embeddings or neural reranking. A retrieval attempt may fail to produce a structured match without failing to find anything at all. In that case the result is recorded as a fallback, and the lexical channel may still provide evidence to the reader, marked as such rather than as a match. The reader thus gains additional evidence while the meaning of a match remains unchanged. 

## 4 Experiments 

4.1 Experimental Setup Benchmarks. We evaluate KITE on two long-term conversational memory benchmarks, LoCoMo (Maharana et al., 2024) and LongMemEval-S (Wu et al., 2025). Specifically, the LoCoMo experiments cover 1,540 questions across ten multi-session conversations, while LongMemEval-S comprises 500 questions over longer interaction histories. 

Baselines. We compare KITE against prior memory systems, namely Mem0 (Chhikara et al., 2025), Zep (Ras-mussen et al., 2025), MemOS (Li et al., 2025), and EverMemOS (Hu et al., 2026a). We also consider Naive RAG as a retrieval baseline and full-context inference over the complete conversation history as a non-retrieval reference. 

Evaluation protocol. We evaluate answer quality using LLM-as-a-judge accuracy, reported overall and by question category. Throughout the KITE experiments, gpt-4.1-mini serves as both reader and judge. The reader receives only the question and retrieved evidence, without the full conversation history, and answers strictly from this context. 

Implementation details. Unless otherwise specified, KITE combines plan-guided retrieval over the knowledge index with a sparse lexical channel under a fixed fusion strategy. We use small benchmark-specific seed vocabularies and apply the same governance procedure across both benchmarks. Further implementation details are provided in Appendices B–C, and the source code is available at https://github.com/memoket/memoket-kite .

Overall, these results show that strong long-term memory performance does not require dense similarity retrieval or full-history input to the reader.

4.4 Effectiveness of Vocabulary Governance 

In addition, we examine how governance of the topic vocabulary affects index growth and query compilation on LoCoMo. All variants start from the same canonical topic roots and process conversations in chronological order. 

Fixed Vocabulary keeps the initial topic set unchanged, whereas Immediate Expansion admits valid new topics as soon as they are proposed. Delayed Expansion keeps proposed topics provisional until they recur across multiple sessions and time periods, while KITE further consolidates redundant sibling topics. Each variant uses its resulting topic vocabulary for both memory indexing and query compilation, with all other experimental settings remaining fixed. Table 4 illustrates the value of governing topic evolution rather than simply restricting or expanding the vocabulary. 

Immediate Expansion yields the lowest recall and accuracy, suggesting that related evidence is scattered across too many labels. Conversely, Fixed Vocabulary achieves higher recall, but its longer reader context may include tangential memories that complicate answer generation. With controlled admission and consolidation, KITE achieves the highest accuracy with fewer topics than expansion-only variants and the same average context length as Delayed Expansion .

We conduct ablation studies on LoCoMo to evaluate the main design choices of KITE. As shown in Table 5, each experiment changes one part of the pipeline with the rest fixed. This isolates the contribution of each design choice. 

Typed facets. Removing typed facets while retaining topic indexing reduces overall accuracy from 93.5% to 90.0%. The largest declines occur on open-domain and temporal questions, at 15.6 and 4.3 percentage points, respectively. These cases often hinge on distinctions beyond broad thematic alignment, including contextual attributes and temporal cues. Such facets complement the topic hierarchy with finer-grained constraints for isolating supporting evidence. 

Retrieval channels. We evaluate both retrieval channels separately and in combination to assess their individual con-tributions. Specifically, Indexed Only retains only plan-guided retrieval over the governed knowledge index, whereas

## 5 Conclusion 

We introduced KITE, a vector-free framework that formulates long-term conversational memory retrieval as an ex-plicit decision procedure. To this end, KITE organizes conversations into structured memories within a governed knowledge index keyed by topic. At query time, the same index guides the compilation of each question into a retrieval plan, aligning its interpretation with the structure of stored memories. The plan is then executed determinis-tically to select evidence that satisfies explicit contextual and temporal conditions. In this way, retrieval is driven by whether the available information meets the question’s requirements, rather than by semantic similarity alone. Results on LoCoMo and LongMemEval-S show that KITE combines high accuracy with compact reader contexts. It achieves 93.5% and 86.0% using only 1.5k and 1.6k tokens, respectively, with particular strength in temporal and multi-hop reasoning. With a fixed memory store, plan-guided retrieval excels in answer accuracy and evidence recall, highlighting the role of explicit conditions in recovering supporting information. Vocabulary-governance experiments further suggest that controlled expansion and consolidation improve accuracy by limiting topic fragmentation. Further improvements could focus on interpreting indirect preference expressions more consistently across memory construction and query compilation. These refinements would strengthen the semantic alignment between the two stages while continuing to preserve KITE’s deterministic evidence selection through a shared knowledge index.

B.1 Benchmarks and Evaluation Metrics Benchmarks. Evidence packing and answer generation. After channel fusion, duplicate entries are removed and the remaining items are added in fused rank order until a fixed token budget is reached. A bounded follow-up check then handles responses that are incomplete or weakly supported. If the first reading identifies a specific missing fact, the system may run one additional search over the same index. No external information is introduced, and the final response follows each benchmark’s rules for answering or abstaining.
