## 摘要
视觉丰富文档（VRDs）通过文本、视觉和布局信息传递知识，而以文本为中心的检索增强生成（Text-RAG）难以充分利用这些信息。近期的Vision-RAG方法能够直接从文档图像中进行检索和生成，从而保留这种多模态信息。然而，早期的Vision-RAG方法通常采用粗粒度的检索表示和整页视觉上下文，这可能掩盖局部证据，并带来大量冗余和计算开销。为应对这些挑战，我们提出MV-VisRAG，一个区域级Vision-RAG框架，使用语义完整的区域进行文档表示和视觉增强。具体而言，MV-VisRAG首先通过内容自适应区域化模块构建这些区域。然后，它使用基于视觉语言模型（VLM）的检索器将这些区域编码为局部区域向量和页面级全局向量，该检索器通过多模态重建预训练和检索微调进行训练。借助这种紧凑的多向量表示，MV-VisRAG执行后期交互检索，并根据匹配分数估计区域贡献。这些贡献指导相关区域的选择，随后将其重新排列为紧凑的视觉上下文用于生成。在五个基准上的实验表明，相较于相应基线在检索和生成上均有提升，同时区域级增强显著减少了视觉token和计算成本。我们的代码将在 https://github.com/xandery-geek/MV-VisRAG 公开。

## Abstract
Visually rich documents (VRDs) convey knowledge through textual, visual, and layout information that text-centric Retrieval-Augmented Generation (Text-RAG) struggles to fully exploit. Recent Vision-RAG approaches enable retrieval and generation directly from document images, retaining this multimodal information. However, earlier Vision-RAG methods commonly adopt coarse retrieval representations and full-page visual contexts, which can obscure local evidence and introduce substantial redundancy and computational overhead. To address these challenges, we propose MV-VisRAG, a region-level Vision-RAG framework that uses semantically complete regions for both document representation and visual augmentation. Specifically, MV-VisRAG first constructs these regions through a ContentAdaptive Regionalization module. It then encodes them into local region vectors and a page-level global vector using a VLM-based retriever trained through multimodal reconstruction pretraining and retrieval fine-tuning. With this compact multi-vector representation, MV-VisRAG performs late-interaction retrieval and estimates region contributions from the resulting matching scores. These contributions guide the selection of relevant regions, which are then rearranged into a compact visual context for generation. Experiments across five benchmarks demonstrate retrieval and generation gains over corresponding baselines, while region-level augmentation substantially reduces visual tokens and computational cost. Our code will be made publicly available at https://github.com/xandery-geek/MV-VisRAG.
