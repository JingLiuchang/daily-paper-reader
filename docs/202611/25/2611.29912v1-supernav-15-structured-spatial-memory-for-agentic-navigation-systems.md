## 摘要
本文针对跨会话和连续物体目标的高效导航中的场景级记忆设计挑战。近期方法通常使用场景图或图像—文本记录来表示场景。然而，密集的场景图表示会给多模态大语言模型带来大量推理和上下文开销，而图像—文本记录无法直接转换为可执行的几何路线。为解决这些局限，我们提出 SuperNav-1.5，这是一种具备由智能体构建的结构化空间记忆的智能体导航系统。该记忆由区域分割的占据地图组成，并标注有由智能体维护、基于地图的记忆节点。该地图引导智能体前往未访问区域，并提供到已知位置的可执行路线。针对多会话导航，我们引入智能体引导的重定位，其中智能体根据当前观测和存储的记忆记录推断区域先验，以约束几何匹配并在存储地图中定位机器人。这些设计共同实现了跨会话和连续物体目标的高效导航。实验表明，我们的方法在单目标、多目标和需求驱动导航基准上优于基线，尤其在路径效率方面提升显著。多会话评估表明所构建的记忆可被重用，而在真实四足机器人上的部署进一步显示了系统的适用性。

## Abstract
This paper addresses the challenge of scene-level memory design for efficient navigation across sessions and successive object goals. Recent methods commonly represent a scene using scene graphs or image--text records. However, dense scene-graph representations impose substantial reasoning and context overhead on multimodal large language models, while image--text records cannot be directly converted into executable geometric routes. To address these limitations, we propose SuperNav-1.5, an agentic navigation system equipped with a structured spatial memory constructed by the agent. The memory consists of an area-segmented occupancy map annotated with agent-maintained, map-grounded memory nodes. This map guides the agent toward unvisited areas and provides executable routes to known locations. For multi-session navigation, we introduce agent-guided relocalization, whereby the agent infers an area prior from current observations and stored memory records to constrain geometric matching and localize the robot within the stored map. Together, these designs enable efficient navigation across session and successive object goals. Experiments show that our method outperforms baselines on single-object, multi-object, and demand-driven navigation benchmarks, with particularly strong gains in path efficiency. Multi-session evaluation demonstrates that the constructed memory can be reused, while deployment on a real quadruped robot further shows the system's applicability.
