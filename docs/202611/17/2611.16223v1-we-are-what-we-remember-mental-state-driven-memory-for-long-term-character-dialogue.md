## 摘要
人类对话中的共同历史不仅仅是事实的存储库，更是关系演进与相互理解的基础。然而，主流对话记忆系统依赖对外部事实库的被动语义相似度匹配，常常检索到主题相似的记录，却遗漏对关系至关重要的经历。受认知心理学自我记忆系统（Self-Memory System, SMS）启发，我们提出 MindMem，一种心理状态驱动的记忆框架，它异步地将共同经历整合为角色、用户及其关系的、与来源关联的心理状态。在每一轮对话中，专门的心理状态推理器（Mind）将这些持续状态置于语境中，以预判用户潜在需求、形成主动意图，并找回表层匹配所忽略的支撑性情景证据。为评估超越事实回忆的对历史敏感的适应能力，我们提出 MemReal-Bench，一个基于长达一个月的真实用户交互、涵盖双人和群体场景的纵向基准。它将直接问答（DQA）与情境化记忆实现（SMR）配对，测试智能体能否弥合“知道过去事实”与“自然运用共同历史、世界规则和关系轨迹”之间的差距。在 MemReal-Bench 上，MindMem 达到 59.03% 的 SMR 和 82.58% 的 DQA，分别比最强的记忆基线高出 24.19 和 9.19 个百分点，并在 SMR 上优于 oracle 目标记忆注入。代码和数据集见 https://github.com/jiazhicheng7-ctrl/MindMem。

## Abstract
Shared history in human dialogue is not merely a repository of facts, but the foundation of evolving relationships and mutual understanding. However, mainstream conversational memory systems rely on passive semantic similarity over external fact stores, frequently retrieving topically similar records while missing relationally pivotal experiences. Inspired by cognitive psychology's Self-Memory System (SMS), we propose MindMem, a mental-state-driven memory framework that asynchronously consolidates shared experiences into source-linked mental states of the character, the user, and their relationship. At each turn, a specialized mental-state reasoner (Mind) contextualizes these persistent states to anticipate latent user needs, form proactive intentions, and recover supporting episodic evidence that surface-level matching overlooks. To evaluate history-sensitive adaptation beyond factual recall, we introduce MemReal-Bench, a longitudinal benchmark grounded in month-long real-user interactions across dyadic and group scenes. By pairing Direct Question Answering (DQA) with Situated Memory Realization (SMR), it tests whether agents bridge the gap between knowing past facts and naturally using shared history, world rules, and relational trajectories. On MemReal-Bench, MindMem reaches 59.03% SMR and 82.58% DQA, exceeding the strongest memory baseline by 24.19 and 9.19 percentage points, respectively, and outperforming oracle target-memory injection on SMR. Code and dataset are available at https://github.com/jiazhicheng7-ctrl/MindMem.

## 2. 方法论

- **核心思想**：将“背景状态整合”与“在线心理状态推理”解耦。
  - 异步整合器 \(C\) 从已完成交互中修订心理状态 \(M_t\)，并保留指向原始对话片段 \(E_t\) 的来源链接。
  - 在线推理读取最新已提交状态快照和近期对话；当前轮的需求与回应意图只用于推理，不写回为历史证据。
- **状态模式**：\(M_t\) 包含 **40 个维度、7 个语义族**：
  - 参与者状态：用户 12 维、化身 3 维、角色 10 维；
  - 关系动态：关系 10 维；
  - 共享语境：情绪事件 1 维、集体关系 1 维、故事世界 3 维。
  - 支持叙事文本槽和结构化记录槽，并保留归因、时间范围、来源指针。
- **在线推理流程**：
  - 输入当前话语 \(u_t\)、局部场景 \(c_t\)、角色设定 \(p\)、可访问状态 \(M_t\)、向量检索候选 \(C_t\)。
  - 专门推理器 **Mind**（参数 \(\pi_\theta\)）输出决策元组 \(z_t=(\tau_t,S_t,V_t)\)：
    - \(\tau_t\)：Thinking trace，解释当前需求、角色约束、关系语境，形成试探性回应意图；
    - \(S_t\)：选中的状态条目；
    - \(V_t\)：选中的情景候选；
    - 两者均可为空。
- **来源链接召回**：
  - 对选中的状态条目解析来源链接：\(L_t=\text{LinkedEvidence}(S_t;E_t)\)；
  - 与向量候选合并、去重、排序：\(D_t=\text{Assemble}(V_t\cup L_t)\)；
  - 解析时执行时间截止、角色可见性等约束。
  - 这样可召回与当前话语词汇相似度低、但关系上关键的早期经历。
- **生成**：冻结的生成器 \(G_\phi\) 基于 \((u_t,c_t,p,\tau_t,S_t,D_t)\) 生成回复，并被要求核对试探性意图与证据、用户显式请求是否一致。
- **训练**：
  - 只训练紧凑的 Mind，冻结整合、稠密检索和生成器。
  - 先做 **SFT**：最小化参考决策 \(z^*=(\tau^*,S^*,V^*)\) 的负对数似然。
  - 再用 **GRPO** 对齐下游记忆使用：对每个输入采样 \(G\) 个决策，组装证据并由冻结生成器生成回复。
  - 复合奖励：  
    \(r(x,z,y)=g(z)[\lambda_{fmt}+\lambda_{acc}a(x,z)+\lambda_{qual}q(x,y)]\)；
    - \(g(z)\in\{0,1\}\)：格式与 ID 合法性门控；
    - \(a(x,z)\)：状态选择与候选选择相对参考目标的集合级 F1 平均；
    - \(q(x,y)\)：LLM judge 对历史 grounding、角色连续性、关系一致性、不确定性校准的 0–4 分归一化质量；
    - 权重为 \(\lambda_{fmt}=0.10,\lambda_{acc}=0.30,\lambda_{qual}=0.60\)。
  - GRPO 使用组归一化优势、裁剪策略比率和相对 SFT 参考的 KL 惩罚。

## 3. 实验设计

- **自建基准 MemReal-Bench**：
  - 种子来自一个月的真实用户–角色交互，经隐私处理；原始聊天日志不进入生成器或基准历史。
  - 三阶段构建：蒸馏用户画像/互动模式/关系轨迹；合成多 session 双人与群体对话；从转写中抽取原子记忆记录，构建自然触发、目标记忆 rubric 和 DQA 题。
  - 规模：**4,617 个对话轮**、约 **443,994 tokens**、**310 个 SMR probes**、**511 道计分 DQA 题**；历史覆盖约 43 个 session。
  - **DQA**：二值评分的事实问答，拒答/不知道计错。
  - **SMR**：判断回复是否通过历史特定细节、行动或约束自然实现目标记忆，而非仅复述过去或泛化共情；含五维：
    - Factual Realization（FR）
    - World Consistency（WC）
    - Relational Realization（RR）
    - Role Realization（RoR）
    - Personalization（PI）
  - 评测执行时间有效性、群体/双人场景可见性边界、真实用户与虚构化身分离，自然触发不泄露目标。
- **对比方法**：
  - **NoMem**：无长期记忆、无近期 10 轮上下文；
  - **GroundTruth**：直接注入 gold target memories 的 oracle 参考；
  - **Mem0、A-Mem、SimpleMem**：主流记忆系统基线；
  - **MindMem**：主结果使用 SFT+GRPO-2B checkpoint。
- **标准基准**：
  - **LoCoMo**：1,540 道非对抗问题；
  - **LongMemEval-S**：500 题；
  - 遵循 Mem0 开源 memory-benchmarks 协议，时间顺序写入与检索，固定 embedding、answerer 和 judge。
- **控制设置**：
  - 所有 MemReal-Bench 条件共享评测实例、历史截止、prompt 模板、解码设置、固定商业生成器和独立 LLM judge；
  - 基线与 MindMem 均向生成器提供 **16 条召回证据记录**；MindMem 的 16 条由向量选择和槽位链接证据合并去重而成，另额外提供选中状态槽和 Thinking 指导。
- **消融与诊断**：
  - 消融：w/o GRPO、w/o specialized Mind（通用 LLM 替代）、w/o active recall（仅 16 条向量记录，去除 \(\tau_t,S_t,L_t\)）。
  - 诊断：DQA–SMR 的 Knowing–Using Gap、共享正确目标子集、不同历史阶段桶、100 例失败审计。
- **人类评估**：90 条回复，10 名盲评标注者，比较 LLM judge 与多数投票参考。
