Abstract
Large language model (LLM) agents increasingly operate over long
Web interaction histories, making memory management critical for
reliable and efficient decision making. Existing methods primarily
optimize storage, retrieval, or compression, but the memories most
semantically relevant to the current state are not necessarily those
that most improve the agent’s action. We introduce MemCredit, a
decision-centric memory framework that shifts memory selection
from semantic relevance to decision utility. MemCredit estimates
the state-, reference-context-, and policy-conditional marginal con-
tribution of individual memories through controlled counterfactual
interventions, and distills these intervention-derived credits into a
lightweight utility estimator. At inference time, semantic relevance
is used only for high-recall candidate generation, while predicted
utility arbitrates which memories are retained under a fixed token
budget, without modifying the underlying agent policy or requiring
additional environment interaction. We evaluate MemCredit on
ALFWorld and WebShop against representative memory baselines.
On ALFWorld, MemCredit achieves 86.57% SR@50 under a 500-
token historical-memory budget, compared with 65.67% for BM25
retrieval. Counterfactual analysis further shows that memory utility
is sparse, strongly state dependent, and poorly captured by seman-
tic relevance. These results suggest that decision utility provides
a more effective principle than relevance alone for long-horizon
agent memory management.

Existing memory systems address this challenge through recency-
based retention, semantic retrieval, trajectory compression, struc-
tured memory banks, and learned memory policies [1, 11, 21, 27].
Despite these differences, memory selection is still commonly driven
by recency, semantic similarity, salience, or learned retrieval scores.
Such signals identify information that is related to the current state,
but relatedness does not necessarily imply value for sequential
decision making.
As illustrated in Figure 1, a recently observed item may be highly
similar to the current observation yet contribute little to the next
action. Conversely, an earlier constraint, failed attempt, or less
similar piece of evidence may be critical for avoiding an incor-
rect decision. This reveals a fundamental mismatch between in-
formation retrieval and agent memory management: semantic
relevance measures whether a memory matches the current
state, whereas decision utility measures whether it improves
the agent’s decision.
We therefore ask: would the agent make a worse decision if a
particular memory were unavailable? For a decision state 𝑠𝑡, refer-
ence memory context 𝑆, and candidate memory 𝑚𝑖, we define its
policy-conditional marginal decision utility as
𝑈𝜋(𝑚𝑖;𝑠𝑡,𝑆) = E [𝑄| 𝑠𝑡,𝑆∪{𝑚𝑖}, 𝜋𝜃]
−E [𝑄| 𝑠𝑡,𝑆, 𝜋𝜃] ,
(1)
where 𝑄measures environment-grounded decision quality. This
formulation treats memory value as state-, reference-context-, and
policy-dependent, and casts memory management as a fine-grained
credit-assignment problem rather than relevance ranking. It is re-
lated to recent experience- and skill-based agents that evaluate
reusable knowledge through downstream outcomes [18, 20], but
operates at the granularity of individual memories.
Controlled intervention experiments support this distinction
(Sec. 4.3; Table 3 and Figure 5). Across 1,041 context-conditional
interventions from 45 ALFWorld tasks, 86.9% produce no measur-
able behavioral change, indicating that memory utility is highly
sparse. Average utility rises to 0.176 in failure contexts but is only
0.029 outside failure states, while semantic relevance has almost no
overall correlation with counterfactual utility (𝜌= −0.011). These
results suggest that semantic similarity is an unreliable proxy for
whether a memory is consequential to the current decision.
Motivated by these findings, we introduce MemCredit, a frame-
work for decision-time memory arbitration in long-horizon agents.
MemCredit decomposes interaction histories into atomic memories
and uses controlled counterfactual interventions to estimate their
marginal decision contributions. The resulting credits supervise a
lightweight utility estimator, amortizing the cost of counterfactual
evaluation. At inference time, MemCredit separates candidate re-
call from memory arbitration: semantic relevance retrieves a broad
candidate pool, while predicted utility determines which memo-
ries are retained under a fixed token budget. The underlying agent
policy remains unchanged and requires no additional environment
interaction at deployment.
We evaluate MemCredit on ALFWorld [16] and WebShop [23].
On ALFWorld, MemCredit achieves 86.57% SR@50 under a 500-
token historical-memory budget, outperforming BM25 retrieval
by 20.90 percentage points. With a 750-token budget, it reaches
90.30% SR@50, compared with 81.34% for BM25, showing larger
gains under tighter context constraints.
On WebShop, MemCredit achieves the highest task score of
0.612 while using only 152.1 memory tokens per decision. Com-
pared with MemArbiter, the strongest non-MemCredit baseline,
it improves the score from 0.586 to 0.612 while using about 2.8×
fewer memory tokens; relative to BM25, memory usage is reduced
by approximately 3.9×. As shown in Figure 2, MemCredit yields a
clear performance–memory Pareto improvement and also reduces
repeated searches, invalid actions, and trajectory length.
Our contributions are threefold:
• We formulate decision-time memory credit assignment,
distinguishing semantic relevance from the state- and policy-
conditional marginal contribution of an individual memory,
and show that such utility is sparse, state dependent, and
poorly captured by relevance.
• We propose MemCredit, which estimates fine-grained mem-
ory credit through controlled counterfactual intervention
and distills it into an amortized utility estimator for budget-
aware memory arbitration.
• We demonstrate on ALFWorld and WebShop that separating
relevance-based candidate recall from utility-based arbitra-
tion improves both task performance and context efficiency,
especially under tight historical-memory budgets.

Related Work
2.1
Agent Memory Management
Agent memory supports long-horizon interaction through expe-
rience retrieval [13], long-term storage [26], tiered context man-
agement [12], and evolving memory structures [21]. Recent meth-
ods further compress trajectories into structured states [27], learn
bounded memory updates [11], or select compressed blocks using
the query and working memory [1].
MemArbiter [2] addresses the Memory–Action Gap: retrievable
information may still fail to guide actions. It organizes history
into functional banks and controls memory presentation through
demand, relevance, and temporal signals. Its arbitration uses prede-
fined signals rather than intervention-derived memory credits.
Closer approaches explicitly evaluate memory utility. CMI [17]
scores memories through controlled interventions in conversational
tasks. CICL [6] estimates decision-oriented utility and assembles
selected evidence into budgeted memory cards. MeClear [22] com-
bines leave-one-out screening with sampled Shapley attribution to
capture interactions and suppress harmful memories.
MemCredit focuses on state-conditioned, item-level credit as-
signment for sequential decisions. It collects credits through paired
replay from matched environment states under a fixed action pol-
icy, then trains a lightweight estimator for token-budgeted selec-
tion without additional runtime environment interaction. Single-
removal attribution can mask redundancy among interacting mem-
ories; Sec. 3.4 discusses how conditional reference contexts mitigate
this.
2.2
Memory Utilization and Credit Assignment
Effective memory use requires historical experience to improve
downstream behavior. Reflexion [15] stores feedback-derived reflec-
tions in episodic memory, ExpeL [25] extracts transferable insights
from agent trajectories, and SkillRL [20] distills trajectories into
reusable skills. More explicitly, D2Skill [18] evaluates skills through
paired rollouts under the same policy, while memory-augmented
RL optimizes memory updates using trajectory-level rewards [11].
These approaches connect experience reuse with behavioral im-
provement, but their credit signals mainly target reusable skills or
memory-update trajectories rather than individual memories at a
specific decision state.
MemCredit instead performs decision-time credit assignment for
individual memory items. For memory 𝑚𝑖at state 𝑠𝑡, it estimates
marginal decision utility by comparing decision quality with and
without that memory under the same policy, environment state, and
reference context. The resulting counterfactual credits supervise a
lightweight utility estimator for budget-aware arbitration, while
leaving the agent policy unchanged. Semantic relevance is used for
candidate recall, whereas predicted utility determines final memory
priority.
3
Methodology
MemCredit learns which historical memories improve a frozen
agent’s current decision under a limited context budget. As illus-
trated in Figure 3, the framework contains four components: atomic
memory construction, counterfactual credit collection, utility es-
timation, and budget-aware arbitration. The central idea is to es-
timate a memory’s contribution conditional on the other memories
available at the decision. Offline interventions provide these credits;
a lightweight estimator then approximates them during context
construction without further environment interaction.

4
Experiments
4.1
Experimental Setup
Benchmarks. We evaluate MemCredit on ALFWorld and Web-
Shop. For ALFWorld, following the evaluation protocol of MemAr-
biter [2], we use all 134 tasks from the out-of-distribution evaluation
split, with a maximum of 50 interaction steps per episode. Its de-
terministic dynamics allow factual and counterfactual decisions
to be replayed from the same reconstructed environment state.
WebShop evaluates long-horizon Web interaction, where agents
must preserve user constraints, product attributes, and previous
search outcomes. We use a 50-task development set and report final
evaluation on 200 tasks over a 10K-product catalog.
Models and Agent Protocol. All main experiments use Qwen3.6-
27B-FP8 with deterministic decoding. The primary Qwen policy
is served with vLLM [8]. At each step, every method receives the
same task goal, current observation, previous interaction outcome,
and method-specific memory context. The current observation is
excluded from the memory budget, which constrains historical in-
formation only. For ALFWorld, admissible actions are provided to
all methods, and we evaluate historical-memory budgets of 500 and
750 tokens. The agent policy, action parser, environment interface,
and interaction limits are kept fixed across methods.
For cross-model evaluation, we replace only the action-generation
model with Qwen2.5-7B-Instruct, DeepSeek-V3, or GPT-5.4,
while retaining the same memory construction, state parsing, prompts,
and 500-token memory budget. Additional implementation and
prompting details are provided in the Appendix.
Compared Methods. We compare MemCredit with Flat Re-
cency [2], which retains recent history; BM25 Retrieval [14],
which ranks memories by lexical relevance; Dense Retrieval [7],
which uses semantic similarity; Failure-Aware Retrieval, a heuris-
tic that prioritizes recent failure-related memories, inspired by
failure-aware experience reuse [9, 15]; and State-Aware Retrieval,
a heuristic that selects memories aligned with the current interac-
tion state [19]. We also evaluate MemArbiter [2], which controls
memory presentation through functional banks, dynamic signals,
and a temporal gate. Utility-only and relevance–utility hybrid vari-
ants of MemCredit are evaluated in the ablation study.
Counterfactual Credit Collection. For ALFWorld, we collect
1,041 valid context-conditional interventions from 45 tasks,
following the protocol of the Methodology section: reference con-
texts are sampled at occupancy levels 𝛼∈{0, 1
4, 1
2, 3
4, 1} under the
500-token budget, and both branches are replayed from the same
reconstructed environment state with a fixed continuation protocol;
every retained sample passes the reconstruction check. Supervision
comes from task-disjoint training and development splits, and test-
task outcomes are excluded from estimator fitting and threshold
selection, as required by the collection protocol. For WebShop, we
apply the same protocol to a disjoint training set of trajectories. The
resulting memory–state–utility triples train the utility estimator,
which is frozen before evaluation on the 200-task test set. Further
details are provided in the Appendix.

5-fold GroupKFold using Spearman correlation, AUPRC, and AU-
ROC. Confidence intervals are obtained by task- or episode-level
bootstrap where appropriate. Additional details are provided in the
Appendix.
4.2
Overall Performance
ALFWorld. Table 1 compares memory-management strategies
under the same Qwen3.6-27B-FP8 policy on 134 unseen ALFWorld
tasks. Under the tighter 500-token budget, MemCredit achieves
86.57% SR@50, outperforming BM25, State-Aware Retrieval, and
MemArbiter. This corresponds to a 20.90-point gain over BM25.
The improvement spans all six task categories and is particularly
pronounced on Heat, Cool, and Pick Two, where MemCredit im-
proves over BM25 by 30.43, 28.57, and 35.30 points, respectively,
indicating the benefit of utility-aware arbitration for tasks with
stronger historical dependencies.
The advantage persists as the memory budget increases. At
750 tokens, MemCredit reaches 90.30% SR@50, compared with
81.34% for BM25, 85.07% for State-Aware Retrieval, and 85.82% for
MemArbiter. The margin over BM25 decreases from 20.90 points
at 500 tokens to 8.96 points at 750 tokens, suggesting that explicit
memory arbitration is particularly valuable under tighter context
constraints. Behavioral metrics show the same pattern: at 500 to-
kens, MemCredit achieves the highest recovery rate and the low-
est failed-action repetition rate. Overall, these results show that
MemCredit improves both task success and post-failure behavior
through decision-aware memory selection.
WebShop. Table 2 evaluates task performance and interaction
efficiency on 200 WebShop tasks over a 10K-product catalog. Mem-
Credit achieves the highest task score of 0.612, outperforming
BM25, Dense Retrieval, State-Aware Retrieval, and the strongest
structured-memory baseline, MemArbiter. At the same time, Mem-
Credit uses only 152.1 historical memory tokens per decision, com-
pared with 427.6 for MemArbiter and 597.0 for BM25, corresponding
to reductions of 64.4% and 74.5%, respectively.
MemCredit also yields more efficient interaction behavior. Com-
pared with MemArbiter, repeated searches decrease from 0.227 to
0.213, invalid actions from 0.324 to 0.316, and average trajectory
length from 12.3 to 12.0 steps. Similar improvements are observed
over relevance-based retrieval methods. As visualized in Figure 2,
MemCredit therefore shifts the agent toward a more favorable
performance–memory frontier, improving task quality while sub-
stantially reducing the historical context required at each decision
step.

Credit depends on the underlying action-generation model. We
replace only the action model while keeping memory construction,
state parsing, prompts, interaction limits, and the 500-token mem-
ory budget fixed. As shown in Figure 4, MemCredit outperforms
Flat Recency, BM25, and MemArbiter in almost all model and step-
limit settings across Qwen2.5-7B-Instruct, Qwen3.6-27B-FP8,

4.3
Understanding Decision Utility
We next examine what counterfactual interventions reveal about
the value of individual memories at decision time. Our causal set
contains 1,041 valid context-conditional interventions from 45 ALF-
World tasks, all passing deterministic state reconstruction. For each
memory 𝑚𝑖at state 𝑠𝑡with reference context 𝑆, the observed credit
is
𝑈(𝑚𝑖;𝑠𝑡,𝑆) = 𝑉(𝑠𝑡,𝑆∪{𝑚𝑖}) −𝑉(𝑠𝑡,𝑆),
where positive credit indicates that exposing the memory improves
the decision; the removal-based statistics reported below are the
single-removal special case 𝑆= 𝐶𝑡\ {𝑚𝑖}. Table 3 summarizes the
main statistics, and Figure 5 visualizes the corresponding trends.
Relevance is not a stable proxy for decision utility. Across
the combined intervention set, semantic relevance has essentially
no overall association with marginal utility. Moreover, the relation-
ship changes with task coverage: the dense subset yields 𝜌= −0.191,
whereas the broader 44-task subset yields 𝜌= +0.135. Thus, se-
mantic similarity is not a stable estimate of a memory’s marginal
decision value.
Decision utility is sparse but consequential. Mean credit is
0.054, yet 86.9% of interventions produce no measurable change.
Most memories therefore have little effect at a given step, while a
small subset accounts for most of the observed impact.
Utility is strongly state dependent. Failure-context interven-
tions have a mean utility of 0.176, compared with 0.029 outside
failure states. As shown in Figure 5(b–c), failure contexts exhibit
the strongest effects, while several other state categories are sub-
stantially weaker.
Overall, decision utility is sparse, state dependent, and poorly
captured by semantic relevance, motivating MemCredit to esti-
mate memory value explicitly.

Decision utility is the main source of improvement. Replac-

Relevance is more useful for recall than arbitration. Directly
combining relevance and predicted utility (𝜆= 0.5) achieves 78.36%,
5.97 points below utility-only ranking. This supports our design
choice of using relevance for candidate recall while relying on

The gain is not a failure shortcut. Removing explicit fail-

with the weaker Failure-Aware baseline, this suggests that Mem-

relying on explicit failure cues.

context-conditional credit-per-token selection of Sec. 3.4—as the
main source of improvement, while direct relevance interpolation
and failure-specific heuristics provide weaker alternatives. Addi-
tional budget analyses are reported in the Appendix.
5
Conclusion
We introduced MemCredit, a decision-utility-based memory frame-
work for long-horizon agents. Rather than treating semantic rele-
vance as the primary criterion for memory selection, MemCredit
estimates the context-conditional marginal contribution of indi-
vidual memories through counterfactual credit assignment, while
keeping the action policy frozen and avoiding additional environ-
ment interaction at deployment. Experiments on ALFWorld and
WebShop show that this principle improves memory arbitration
under limited context budgets. Our analysis further reveals that
decision utility is sparse, strongly state dependent, and only weakly
captured by semantic relevance. These findings suggest that future
agent memory systems should optimize not only what information
is retrieved, but which memories are most consequential for the
decisions that follow.

Hardware and inference. All same-model ALFWorld evaluations
use Qwen3.6-27B-FP8 served with vLLM [8] on A800-80GB GPUs,
with a 4096-token context window, temperature 0, and seed 42.
All compared methods use the same action protocol, parser, envi-
ronment, and admissible-command hints. The current observation
is included in the base prompt and excluded from the historical-
memory budget.
Pipeline validation. The sharded evaluation pipeline was vali-
dated by rerunning BM25@500, which reproduces the frozen result
(65.67% SR@50) up to the execution-order variance documented
below: across repeated executions, task-level outcomes agree on at
least 94% of the 134 tasks, and single-run aggregate SR varies by up
to ±3 pp. The agent uses no Python-side randomness; the residual
flips trace to GPU-side logit nondeterminism on near-ties under
temperature-0 decoding. Memory budgets of 500 and 750 tokens
apply only to historical memory.
Utility label generation. Intervention labels follow Eq. 9: the
observed one-step credit is the difference between the two branches’
environment rewards, 𝑟+𝑖−𝑟−𝑖, where each branch is executed
by the same frozen policy from the same reconstructed state and
differs only in the rendered inclusion of the target memory. For
ALFWorld, the step reward 𝑟is instantiated with an environment-
grounded outcome score taking values in {+1, 0, −1}: +1 if the
episode is won at this step; −1 if the chosen action is not in the
admissible set or repeats a previously failed action; and 0 for a valid
but neutral action. Reference contexts are sampled at occupancy

WebShop catalog audit. The 10K-product catalog is a uniform
subsample of the standard WebShop catalog. For all 200 evalu-
ated instructions, the target product and its required options are
present in the catalog, and the target is retrievable within the top-
10 search results under the BM25 index used by the environment
(Recall@10/20/50 = 100%), so the evaluation is not confounded
by missing catalog entries. The reward semantics are identical to
standard WebShop; because the catalog is a 10K subset of the full
catalog, scores are not directly comparable to full-catalog literature
values.

A.5
Additional Ablations
The hybrid ablation variant uses a fixed interpolation coefficient
𝜆= 0.5, selected before final evaluation. The Failure-Aware baseline
adds a fixed bonus to failure-related memories while preserving
the same retrieval and memory budget. No post-hoc tuning is per-
formed on the final 134-task evaluation set.
A larger 750-token budget raises utility-only ALFWorld SR from
84.33% to 88.81%, and the primary MemCredit configuration from
86.57% to 90.30%. Additional failure-density analyses stratify tasks
using bins fixed from baseline trajectories before comparing meth-
ods.
A.6
Performance across Failure Density
We further examine whether the benefit of MemCredit is restricted
to failure-intensive trajectories. Using the frozen BM25 trajectories,
we compute the failure density of each ALFWorld task and par-
tition the 134 tasks into low-, medium-, and high-failure-density
terciles. The resulting partition is fixed and applied to both BM25
and MemCredit, avoiding method-dependent grouping.
As shown in Figure 6, MemCredit consistently outperforms
BM25 across all three groups. The SR@50 improvements are +20.0,
+15.9, and +20.0 percentage points for the low-, medium-, and high-
failure groups, respectively. The paired task-bootstrap 95% confi-
dence intervals remain above zero in all three terciles: [+6.7, +33.3],
[+4.5, +29.5], and [+8.9, +33.3].
This result complements the intervention analysis in Sec. 4.3.
Although individual memories exhibit substantially larger marginal
utility in failure contexts, the end-to-end advantage of utility-aware
arbitration is not confined to failure-heavy tasks. Failure context
therefore represents an important source of memory utility, but
not the only setting in which decision-aware memory selection is
useful.
