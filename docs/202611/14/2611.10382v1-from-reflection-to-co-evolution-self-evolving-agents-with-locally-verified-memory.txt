Abstract
LLM agents have made impressive progress
in coding and mathematical reasoning, moti-
vating growing interest in learning from long-
horizon interaction. Memory supports this pro-
cess, but plausible lessons can be redundant or
reinforce inappropriate actions. Can a mem-
ory’s source decision provide a practical test
for whether to retain it? We localize consequen-
tial trajectory steps, extract candidate memo-
ries, and replay each source decision with and
without its candidate under the same context.
This reveals two properties: most candidates
barely shift the probed distribution, and both
successful and failed source actions can be re-
inforced or suppressed. These observations mo-
tivate Anchor, which tests shift magnitude and
source-role alignment before retention. Admit-
ted memories guide later trajectories, enabling
experience-driven improvement under a frozen
policy. On held-out ALFWorld and WebShop
tasks, Anchor improves success rate and mean
score by up to 19.9% and 17.2%, respectively,
relative to the strongest baseline for each back-
bone. With Qwen3.5-27B, it retains 41% fewer
ALFWorld cards than unfiltered retention and
outperforms all four WebShop cost-comparison
baselines while using fewer tokens.

Introduction
Large language model (LLM) applications span
coding (Shi et al., 2026b; Yang et al., 2024),
mathematical and logical reasoning (Ren et al.,
2025; Zhang et al., 2026g,i), scientific investiga-
tion (Zhang et al., 2026a; Cui et al., 2026), and
interactive cognitive training (Shi et al., 2026a).
Beyond individual tasks, recent work asks how
agents can improve through long-horizon interac-
tion and reuse experience (Wang et al., 2023; Shinn
et al., 2023). Memory provides a direct mecha-
nism: Reflexion, ExpeL, and ReasoningBank ex-
tract reusable lessons from trajectories without up-
dating model parameters (Shinn et al., 2023; Zhao
et al., 2024; Ouyang et al., 2026).
Choosing which lessons to retain raises two con-
nected problems. First, textual plausibility and
successful retrieval do not establish a memory’s
decision value: a lesson may repeat what the pol-
icy already knows or reinforce an inappropriate
action. Aggregate task success also leaves the con-
tribution of an individual memory unresolved (Tan
et al., 2025a). Second, continual writing increases
storage, context, and maintenance costs, so retain-
ing ineffective lessons makes future reuse more
expensive (Fang et al., 2026a). Recent methods use
action changes and trajectory feedback to guide
selection (Zhang et al., 2026h; Wang et al., 2026a).
We seek a candidate-level test that connects reten-
tion to behavioral evidence before a memory enters
the bank:
 Can a memory’s source decision provide a
practical test for whether to retain it?
We let the agent localize consequential decisions
in completed trajectories and extract a memory
from each. Replaying each source decision with
and without its candidate under the same context
reveals how that memory changes the policy (Sec-
tion 3).
This replay exposes two properties of self-
extracted memory. Memory influence is concen-
trated: most candidates barely shift the probed
distribution, while a smaller subset produces sub-
stantial changes (Figure 2). Memory influence is
directional: both successful and failed source ac-
tions can be reinforced or suppressed after mem-
ory injection (Figure 3). A large shift alone there-
fore does not identify whether the effect agrees

Our approach. We introduce Anchor, which tests
candidates before retention. Localizer extracts
lessons from source decisions; Amplituder mea-
sures JS shift; Aspecter checks source-role align-
ment; and BankMaster stores, retrieves, and main-
tains admitted cards. Selected memories guide later
trajectories, whose feedback supplies new candi-
dates. This feedback loop between behavior and
memory is the co-evolution studied here; model
parameters remain frozen. Our analysis connects
shift magnitude and direction to local action value
under explicit conditions.
Empirical findings. On ALFWorld (Shridhar
et al., 2021) and WebShop (Yao et al., 2023),
Anchor ranks first across two frozen backbones.
With Qwen3.5-27B, it reaches 96.27% ALFWorld
success and 73.50 WebShop score, versus 92.54%
and 62.74 for the strongest respective baselines.
Source-role filtering improves ALFWorld success
by 28.6% relative to magnitude-only admission,
with 41% fewer ALFWorld cards than unfiltered
retention. On WebShop with Qwen3.5-27B, to-
ken use is below all four cost-comparison base-
lines: slightly below MEM1 and approximately
34%, 59%, and 98.5% below ReasoningBank, Re-
flexion, and AdaMEM, respectively.

Related Work
Learning from interaction.
Reflexion and Ex-
peL extract verbal lessons, Voyager accumulates
skills, and CLIN maintains causal abstractions
without parameter updates (Shinn et al., 2023;
Zhao et al., 2024; Wang et al., 2023; Majumder
et al., 2023). ReasoningBank distills strategies,
while Evo-Memory and MemEvolve study learning
across task streams (Ouyang et al., 2026; Wei et al.,
2026; Zhang et al., 2025). AdaMEM uses trajec-
tory success and action changes to select strategy-
training samples; MemRL learns memory utilities
from feedback (Zhang et al., 2026h,e). Anchor
instead tests individual candidates at their source
decisions before storage.
Memory
organization
and
admission.
MemGPT, Mem0, A-MEM, and SimpleMem
manage, consolidate, link, or compress persistent
information (Packer et al., 2024; Chhikara et al.,
2025; Xu et al., 2025; Liu et al., 2026). LightMem
targets consolidation cost (Fang et al., 2026a).
For selective writes, A-MAC scores candidate
attributes, ConsistencyGate checks source support,
and Janus compares memories on an evaluation
set (Zhang et al., 2026c; Zhang and Li, 2026; Chen
et al., 2026b). MemGuard uses trajectory-verifier
metadata for admission and maintenance (Wang
et al., 2026a). Anchor adds a paired behavioral
test of shift magnitude and source-role alignment.
Decision-aware memory.
EPR uses model like-
lihoods to supervise demonstration retrieval, and
CICL selects and compresses context using action-
choice effects (Rubin et al., 2022; Guan et al.,

2026). Counterfactual auditing of robot memory
distinguishes behavioral influence from appropriate
guidance (Zhang et al., 2026d). Memento-II for-

Anchor: Write, Test, and Reuse

admitted cards (Figure 4). Let Bi precede construc-

Localizer reflects on the completed trajectory and

K = 5:

5
Experiments
Our experiments address four research questions:
RQ1: Memory utility.
Can the extracted mem-
ories improve held-out task performance across
environments and backbones while retaining fewer
memories than storing every candidate?
RQ2: Admission design.
How do shift magni-
tude and source-role direction contribute to mem-
ory quality, and what is gained by combining suc-
cess memories with failure corrections?
RQ3: Resource efficiency.
How does Anchor
balance task performance, persistent memory size,
and total token use across memory construction
and evaluation?
RQ4: Self-evolution.
As experience accumu-
lates along a task stream, does selective memory
reuse improve the frozen agent’s performance be-
yond simply expanding its memory bank?

5.3
Contributions of Magnitude and Direction
Table 2 uses Qwen3.5-27B on the same ALFWorld
split. Anchor w/o Amplituder & Aspecter writes
every candidate; Anchor w/o Aspecter uses mag-
nitude alone. Role ablations keep one role with its
tests intact. Appendix Table 3 gives family-level
results.
Answer 2. Direction improves magnitude-only
admission; retaining both roles performs best.
Removing both tests yields 73.38%; magnitude
filtering alone reaches 74.88%, a 1.49-point differ-
ence. Adding direction raises success to 96.27%,
a further 21.39 points (28.6% relative). The larger
gain comes from distinguishing source-role effects
among candidates that pass magnitude screening.
Keeping both roles adds 9.45 points over success
memories alone and 12.44 over failure corrections
alone. Thus, the strongest tested variant combines
behavioral screening with both reinforcement and
correction memories.
5.4
Resource Use
Answer 3. Selective retention improves the
performance–resource trade-off.
In Figure 5,
Anchor stores 41% fewer ALFWorld memories
while achieving higher success. On WebShop with
Qwen3.5-27B, it leads the five plotted methods in
score, mean steps, and token use (approximately
86.9M). Token use is slightly below MEM1 and ap-
proximately 34%, 59%, and 98.5% below Reason-
ingBank, Reflexion, and AdaMEM, respectively.
These comparisons measure bank size, token con-
sumption, and interaction steps. Token totals cover

5.5
Self-Evolution Along the Task Stream
Answer 4. Selective accumulation improves
construction-stream performance and held-out
reuse. Figure 5 tracks cumulative success over 200
randomly sampled ALFWorld construction tasks.
Anchor and Anchor w/o Amplituder & Aspecter
share a frozen backbone but differ in admission.
After early fluctuations, Anchor maintains higher
cumulative success, finishing approximately 20%
higher relatively despite slower bank growth. This
curve compares behavior during memory construc-
tion; Table 2 tests the resulting banks on held-out
tasks. Together, they connect selective experience
accumulation to stronger subsequent reuse without
parameter updates.
6
Conclusion
We introduced Anchor, which tests memories at
their source decisions before retention.
Paired
replay measures shift magnitude and source-role
alignment under a frozen policy. Across ALFWorld
and WebShop, Anchor improves held-out perfor-
mance; resource comparisons show smaller banks
and lower token use. These results highlight mem-
ory curation as a practical link between reflection
and behavioral improvement. By letting experi-
ence shape memory and selected memory guide
subsequent behavior, Anchor offers a path toward
experience-driven agent co-evolution.
Limitations
The scope of Anchor depends on the resolution of
its behavioral probe and access to model probabili-
ties.
Action-space requirements.
Our long-horizon
benchmarks provide explicit candidate actions. Pre-
fix scoring cannot distinguish actions sharing the
scored tokens, including some object-level errors.
Open-ended settings require other consistent mea-
sures of memory-induced change, such as plan or
response differences.
Access to model probabilities.
Token log proba-
bilities are required but unavailable through some
closed-source interfaces. Model-generated scores,
rankings, or repeated-output preferences offer alter-
natives. Future work can calibrate these measures
and extend replay to broader tasks and interfaces.

Extended Related Work
Learning from interaction.
LATS combines tree search, value estimation, and reflection for plan-
ning (Zhou et al., 2024). Reflexion stores verbal feedback, ExpeL extracts lessons, and Synapse reuses
trajectories (Shinn et al., 2023; Zhao et al., 2024; Zheng et al., 2024); Voyager accumulates executable
skills (Wang et al., 2023). CLIN updates persistent causal abstractions across trials without parameter
updates (Majumder et al., 2023). ReasoningBank distills strategies, Evo-Memory evaluates learning
across task streams, and MemEvolve adapts experiential knowledge and its management (Ouyang et al.,
2026; Wei et al., 2026; Zhang et al., 2025). AdaMEM combines long-term trajectories with within-
episode strategies; its Step-MFT selects strategy-training samples using trajectory success and action
changes (Zhang et al., 2026h). MemRL learns memory utilities from execution feedback, while MACE
co-evolves agents and memory graphs in multi-agent systems (Zhang et al., 2026e; Yang et al., 2026a).
Anchor uses source decisions and feedback roles to select candidates before storage.
Mem2Evolve couples experience distillation with the creation of tools and expert agents (Cheng et al.,
2026); SkillRL co-evolves a hierarchical skill bank and the policy through reinforcement learning (Xia
et al., 2026). Anchor selects external lessons for retention under a fixed policy and action interface.
Memory organization and efficient reuse.
Surveys characterize agent memory by its functions,
representations, and evaluation (Zhang et al., 2024); CoALA connects modular memory with structured
actions and decision-making (Sumers et al., 2024). Liu et al. (2023) show that information position
affects performance, motivating careful selection and organization of retrieved experience. MemGPT
manages information beyond the context window, Generative Agents combines retrieval with reflection,
and MemoryBank adds summarization and forgetting to conversational memory (Packer et al., 2024;
Park et al., 2023; Zhong et al., 2023). Mem0 consolidates facts, A-MEM links notes, and SimpleMem
compresses memories (Chhikara et al., 2025; Xu et al., 2025; Liu et al., 2026). LightMem addresses
consolidation cost, while MemHarness reconstructs experience for the current state (Fang et al., 2026a;
Wu et al., 2026). MemBench, LongMemEval, and MemoryAgentBench test the effectiveness of sustained
memory use (Tan et al., 2025a; Wu et al., 2025; Hu et al., 2026). Anchor adds behavioral admission to
this memory-management pipeline.
Reflective Memory Management combines multi-granularity construction and feedback-driven retrieval
for dialogue (Tan et al., 2025b). Anchor places a paired source-decision test between extraction and
storage, evaluating both construction-stream learning and read-only transfer.
Selective and reliable memory updates.
Self-Refine iteratively revises outputs using model-generated
feedback (Madaan et al., 2023), while CRITIC uses external tools for validation (Gou et al., 2024). For
persistent memory, A-MAC scores candidate attributes, AdaMem learns preference-conditioned writes,
and D-MEM routes selected inputs into a slower evolution path (Zhang et al., 2026c; Chen et al., 2026a;
Song and Xin, 2026). ConsistencyGate checks source support, TRUSTMEM checks update properties,
and Janus compares memories on a compact evaluation set (Zhang and Li, 2026; Yang et al., 2026b;
Chen et al., 2026b). MemGuard stores trajectory-verifier signals as metadata for admission and later
maintenance (Wang et al., 2026a). Memory poisoning, state contamination, and persistent injection
expose risks of unverified writes (Chen et al., 2024; Wang et al., 2026b; Yang et al., 2026c). Anchor
directly measures local action-distribution changes and source-role alignment, extending admission
beyond content- and outcome-based criteria.

Repeated updates can degrade useful memories (Zhang et al., 2026b), motivating a distinction between
initial admission and later maintenance. Anchor addresses admission through source-decision evidence.
Decision-aware memory.
In online content evaluation, Zhang et al. (2026f) identify a gap between AI
preference and real user engagement. For memory admission, we likewise prioritize behavioral evidence:
paired replay measures how a candidate changes the agent’s decision distribution. Liu et al. (2021) retrieve
semantically similar examples to improve in-context learning. EPR uses model likelihoods to supervise
demonstration retrieval, addressing context selection rather than persistent writes (Rubin et al., 2022).
CICL selects and compresses context using its effects on action choices at retrieval time (Guan et al.,
2026). Counterfactual memory auditing of robot policies separates a memory’s behavioral influence from
whether it guides actions appropriately (Zhang et al., 2026d). Anchor uses paired probes at the source
decision and success or failure roles to guide persistent memory admission.

BankMaster Details
BankMaster stores each admitted mt verbatim in the card’s memory_guidance field and adds role,
applicability conditions, retrieval keys, and source metadata. A success hint specifies an action to reinforce
under matching conditions; a failure hint records a pattern to avoid and its immediate correction. Card
construction enriches metadata without rewriting, summarizing, or otherwise changing the tested guidance.

The retrieval score in Eq. 20 combines task-family and state similarity with action compatibility. Up to

Each card stores confidence, support count, source metadata, and reuse statistics. After an episode,

Measurement interface.
The two adapters share a token-budget parameter L, counting action-content
tokens immediately after <action>. The opening tag is context, not part of the scored span. ALFWorld
scores the action head (L = 1); WebShop scores up to five action tokens (L = 5). Appendix E provides
one replay template per environment: the complete saved decision context, with its history, task guidance,
and retrieved memory. Only the injected condition adds mt. The scoring specification below applies to
the paired measurements, including the case studies in Appendix F.
Candidate actions.
At each source decision, store a finite ordered list Ct of legal candidate action
strings, including the recorded source action. ALFWorld obtains this list from the TextWorld environ-
ment’s admissible_commands. WebShop obtains clickable products, option values, and navigation

click[...] command. Thus product selection and option selection are distinct candidates, not a single
click category. The environment interfaces are documented in the ALFWorld and WebShop releases.

and page before the paired test. The adapter serializes these as search[query] actions and stores the list
with the source snapshot. Replay reuses this list and never generates new candidates from the injected
hint or subsequent feedback. Remove duplicate complete strings while preserving their first occurrence.

Source roles.
The Localizer receives the goal, the recorded trajectory, and episode feedback, and
autonomously assigns each selected source step a hindsight credit ct ∈[−1, 1]. Positive credit identifies a
decision to reinforce, negative credit identifies a decision to correct, and zero credit denotes an uncertain
role. For nonzero credit, the step role is yt = sign(ct). A success-maintain memory identifies a
local decision to reinforce; a failure correction identifies a local decision to avoid or correct. The role
describes the step, not the outcome of the whole episode. The categorical mapping is yt = +1 for
success_maintain and yt = −1 for failure_correction; uncertain candidates are excluded
from admission. The gate uses this sign, not the magnitude of ct. The prompt’s importance_score
ranks candidates and is separate from signed hindsight credit. Task-specific guidance supplied to the
Localizer is reproduced in Appendix E.
Evaluation signals.
Paired replay measures a fixed hint’s effect on the normalized candidate-prefix
distribution. Local verification refers to passing the magnitude and role-specific preference predicates
on this distribution. The theoretical bounds instead concern complete-action distributions and condition
on Q-value gaps and residual mass transfer. These conditions are analytical assumptions, not quantities
measured by the gate. In particular, the failure ranking branch can admit an alternative top category even
when the source probability increases; it tests a different preference criterion from positive signed-margin
alignment. Held-out task results assess the constructed bank’s utility under the deployed decoding rule.

Algorithm 2: Branch-specific gate.
Information flow.
The Localizer uses the trajectory and episode feedback to assign hindsight roles.
The hint writer describes a local action under the source decision’s conditions, without presenting future
observations as already available or supplying a complete solution. Candidate text remains fixed during
replay. After admission, the card builder copies it verbatim into memory_guidance and adds only
retrieval and source metadata.
Paired context.
Before executing an action, save the rendered messages: system instructions, history
selected by F, task guidance, observation, ordered admissible actions, and retrieved cards. Replay clones
this snapshot twice and adds CANDIDATE GUIDANCE immediately after the memory-evidence block
in the injected copy. Both calls retain the original card text and order, history clipping, model, tokenizer,
candidate actions, output contract, and L; inserting the hint must not truncate another field. The baseline
omits only the candidate paragraph. Existing memory evidence is absent from both calls only when
absent from the source prompt. The source action and hindsight role remain checker metadata; subsequent
feedback is supplied only to the Localizer and hint writer. A missing snapshot or required score invalidates
the pair.
E.1
ALFWorld Prompts
Action and replay.
Panels (a) and (d) use the same action-only output contract and saved goal, family
recipe, phase guidance, observation, admissible actions, history, and cards. Both request a complete
admissible action; replay scores its first content token after <action> (L = 1).
Extraction and storage.
The Localizer selects at most five consequential decisions, including successful
actions and correctable mistakes (b). Long trajectories are compacted to at most 20 selected steps, with
observations clipped before serialization. Panel (c) shows the failure-correction hint; the success branch
instead reinforces the observed action without adding future steps. The builder stores the admitted hint
unchanged, maps its source role to a memory type, and adds retrieval metadata (e).
E.2
WebShop Prompts
Action and replay.
The policy receives the instruction, task family, page phase, history, current page,
available actions, and cards (f). History and page fields are clipped to 1,800 and 5,000 characters when
the source prompt is built. Replay reuses those rendered fields and requests the same complete action in
both conditions (i). It scores up to L = 5 action-content tokens on fixed candidates, excluding the opening
<action> tag.
Extraction and storage.
The Localizer selects up to five consequential shopping decisions, including
product, option, and checkout errors (g). Each serialized step contains the action, observation, and next
observation; the last two fields are clipped to 400 and 300 characters. The writer supplies a local correction
or reinforcement, not a full shopping solution (h). The builder preserves the admitted hint verbatim and
adds page phase, attribute constraints, retrieval keys, and source metadata in separate fields (j).
