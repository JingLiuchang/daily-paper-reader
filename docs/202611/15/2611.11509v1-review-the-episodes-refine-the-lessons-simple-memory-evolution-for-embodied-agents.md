## 摘要
近期基于前沿多模态大语言模型（MLLMs）的具身智能体研究，围绕 MLLM 发展出 harness 工程，例如带有后训练策略的 harness 以及递归自我改进循环。然而，这些附加组件是否超越 MLLM 的原生能力仍未被探索。我们提出 SimplEvo，用于探索当 MLLM 以自写文本记忆保留其执行经验时，在直接控制下能够提升到何种程度。它不需要权重更新、后训练策略或特权信息。MLLM 仅从单次演示中一次性写入无坐标任务记忆。在严格的训练-测试协议下，它随后仅在训练回合上创建有界工作记忆，并在每个回合后利用关于流程、完成和恢复的经验对其进行精炼。两种记忆在测试时均保持固定。在 EBench 上，SimplEvo 将 GPT-6-Astra 在直接控制下的成功率（SR）从 46.7% 提升至 81.7%，并以 69.63% 的 SR 和 75.32 的得分位居 RoboDojo 排行榜榜首。与同样存储过去视觉帧的记忆相比，SimplEvo 仅用文本记忆即可达到相近的 SR，同时使用更少 token。在其记忆固定的情况下，SimplEvo 还能泛化到未见布局和随机化场景配置。此外，工作记忆可跨模型迁移：由 GPT-6-Astra 编写的工作记忆可被较弱 MLLM 原样复用，并在其自身无需任何适配的情况下提升性能。

## Abstract
Recent studies of embodied agents based on frontier multimodal large language models (MLLMs) develop harness engineering around the MLLM, such as harnesses with post-trained policies and recursive self-improvement loops. Yet whether these additions exceed the native capability of the MLLM remains unexplored. We introduce SimplEvo to explore how far an MLLM can improve under direct control when it retains its execution experience in self-written text memories. It requires no weight updates, post-trained policies, or privileged information. The MLLM writes a coordinate-free task memory once from a single demonstration. Under a strict train-test protocol, it then creates a bounded working memory on training episodes only and refines it after each episode with lessons on procedure, completion, and recovery. Both memories stay fixed at test time. On EBench, SimplEvo lifts the success rate (SR) of GPT-6-Astra under direct control from 46.7% to 81.7%, and tops the RoboDojo leaderboard with 69.63% SR and a score of 75.32. Compared with memories that also store past visual frames, SimplEvo reaches a similar SR with text memory alone while using fewer tokens. With its memories fixed, SimplEvo also generalizes to unseen layouts and randomized scene configurations. Moreover, the working memory transfers across models: written by GPT-6-Astra, it can be reused as is by weaker MLLMs and improve their performance without any adaptation of their own.

## 1. 核心问题与研究动机

- **背景**：以 GPT-6-Astra 为代表的前沿多模态大模型（MLLM）已能在不更新参数的情况下直接控制机器人（读 RGB 与本体感知、输出末端位姿），但现有具身智能体研究普遍在其外围加装“harness 工程”：
  - **代码即策略（code-as-policies）**：让 LLM 写机器人程序，如 Code as Policies、COAP、RAX；多数依赖深度图、相机参数、物体尺寸等特权信息。
  - **带策略的 harness**：把后训练 VLA/WAM 当作可调用工具（如 π0.5、InternW0-Δ），但策略的底层动作不进入 MLLM 上下文。
  - **递归自我改进（RSI）循环**：围绕智能体改写上下文、工具或控制逻辑；部分工作在**测试场景本身**上自适应，导致测试信息泄漏、增益无法证明可泛化。
- **核心问题**：这些附加机制是否真的超越了 MLLM 的原生能力？在“直接控制”（direct control，MLLM 自己下发每一条末端执行器指令，闭环反馈显式可见）下，一个前沿 MLLM 究竟能走多远？
- **关键观察**：直接控制中，每次抓取失败后的诊断与修正确实存在，但**回合结束即消失**，每个 episode 从零开始。
- **论文主张**：只要把跨回合的执行经验以**自写文本记忆**的形式保留并演化，无需权重更新、后训练策略或特权信息，前沿 MLLM 的直接控制能力就能被大幅释放。

## 2. 方法论

### 2.1 核心思想

保持原生直接控制回路不变，仅引入**两份由 MLLM 自己书写的紧凑文本记忆**：

- **任务记忆 M_task**：从**单次示范**一次性提炼，提供阶段顺序与终止状态（解决“不知道先做什么、何时算完成”）。
- **工作记忆 M_work**：在训练回合中逐回合反思重写，保留会被回合边界抹掉的修正（解决“经验不跨回合”）。

### 2.2 直接控制设定与信息协议

- 决策式：$a_t = F(\ell_\tau,\ M_{task},\ M_{work}^{k-1},\ o_{\le t},\ a_{<t})$，其中 $o_t=(I_t,q_t)$ 为 RGB（俯视 + 双腕相机，可按需选视角）与机器人本体感知。
- 每个动作 $a_t$ 是 1–6 个**绝对末端位姿路点**（双臂位姿 + 夹爪目标，EBench 上还有移动底盘位姿），由逆运动学转成关节指令。
- **严格信息协议**：不使用深度、相机内参、物体真值位姿，不使用后训练策略，不使用中间进度信号，遵守 benchmark 原生步数上限。

### 2.3 任务记忆（一次性、无坐标）

- 由同一 MLLM 的“标注者实例”审阅一段训练示范的动作与关键帧后写入一次。
- 内容：按顺序列出各阶段的操作、执行手臂、接触关系，以及**完成时的可见终态**；**不含任何坐标**，以便迁移到其他布局。
- 因终态被显式写出，形成**终止状态锚定（terminal-state anchoring）**，使智能体在尚无执行经验时就有停止判据。
- RoboDojo 的 8 个 Open 任务无示范，则不使用 M_task。

### 2.4 工作记忆（逐回合反思、有界全量重写）

- 更新式：$M_{work}^{k} = F(M_{work}^{k-1},\ \xi_k,\ r_k)$，$|M_{work}^k| \le B = 32\text{KB}$，$r_k$ 为评测器返回的成功/分数（回合级奖励）。
- 每回合后仅一个“反思回合”（不允许机器人动作），MLLM 可**整篇重写**记忆，自行决定保留/丢弃内容，因此记忆长度远短于累积对话历史。
- 蒸馏三类经验：**流程（procedure）、完成判据（completion）、错误恢复（recovery）**，并附代表性指令与结果作为证据。
- 工具描述明确要求：把实测坐标当作“场景特定证据”而非可复放的命令，以抑制对自身探索轨迹的路径依赖。

### 2.5 训练–测试协议与部署

- 在线自适应：每个任务沿一条**自适应链**顺序执行最多 15 个训练回合（EBench 连续 3 次成功后提前停止），链末的 $M_{work}^K$ 固定。
- 部署：测试回合只读固定记忆，**不再反思、不再更新**，因此测试场景信息无法泄漏进记忆。
- 附带能力：GPT-6-Astra 写出的工作记忆可被其他 MLLM **原样读取复用**。
