## 摘要
语言模型不断演进，但通过用户交互积累的观察、修订和上下文应保持可用。每个新模型都必须能够检索过去的证据、跟踪修订并添加新的观察。我们提出 MIGRO，一种解耦的长期记忆系统，它将经验视为在相继语言模型之间共享的持久状态。MIGRO 遵循一个简单原则：精确保存历史证据，近似地组织它，并且仅在问题已知时才决定检索什么。我们称之为具有延迟选择性的非对称保真。共享语义索引支持检索，而精确记录保留观察及其历史关系。由于模型在词表和分词方面存在差异，宿主特定接口会将选定的证据转换为接收模型可使用的输入。可逆编码减少了归档存储，同时支持精确恢复。共享状态及其访问接口使相继宿主能够读取并扩展累积的经验。在匹配的 LoCoMo 状态上，MIGRO 的得分比最强质量基线高 7.3%，且使用的私有内存少 99.3%。在交接之后，持续写入通过扩展继承状态，保留了完整历史重建质量的 99.9%。在百万 token 的 BEAM 历史上，MIGRO 平均比最紧凑的基线少使用 57.5% 的私有存储。MIGRO 兼具高回答质量、跨宿主持续记忆增长和低存储成本。代码可在 https://github.com/zOUMINGXI/MIGRO 获取。

## Abstract
Language models evolve, but the observations, revisions, and context accumulated through user interactions should remain usable. Each new model must be able to retrieve past evidence, track revisions, and add new observations. We present MIGRO, a decoupled long-term memory system that treats experience as a persistent state shared across successive language models.   MIGRO follows a simple principle: preserve historical evidence exactly, organize it approximately, and decide what to retrieve only when the question is known. We call this asymmetric fidelity with deferred selectivity. A shared semantic index supports retrieval, while exact records retain observations and their historical relationships. Because models differ in vocabulary and tokenization, host-specific interfaces convert selected evidence into inputs the receiving model can use. Reversible encoding reduces archival storage while enabling exact recovery. The shared state and its access interfaces let successive hosts read and extend the accumulated experience.   On matched LoCoMo states, MIGRO scores 7.3% higher and uses 99.3% less private memory than the strongest quality baseline. After handoff, continued writing retains 99.9% of full-history rebuilding quality by extending the inherited state. On million-token BEAM histories, MIGRO uses 57.5% less private storage on average than the most compact baseline. MIGRO combines high answer quality, continued memory growth across hosts, and low storage cost.   Code is available at https://github.com/zOUMINGXI/MIGRO.

# MIGRO 论文中文总结

## 1. 核心问题与研究动机

- **核心命题：“记忆应当比模型活得更久”（Memory Should Outlive the Model）。** 长期交互中积累的观察、修订、偏好与上下文，在服务模型被升级或替换后仍应可被检索、修订与继续扩展。
- **现有范式的问题：模型绑定的记忆（model-bound memory）。** 每次更换模型都需重训、适配、重放历史（“Replay. Retrain. Repeat.”），成本高且历史易丢失。
- **两条既有研究路线的不足：**
  - 神经/潜变量记忆（Memorizing Transformer、MemoryLLM、LSTMem、TransMem、Metis、MemT-1.0、δ-mem 等）把记忆并入模型计算状态，难以跨模型迁移；
  - 检索增强与 Agent 记忆（RAG、MemGPT、Mem0、A-MEM、PlugMem、TiMem、Zep、MemoryLACE 等）虽已外置存储，但**“保存历史”与“让新宿主可用”是两个不同需求**：摘要会丢失早期版本证据，而幸存证据又可能因词表/分词差异难以被新模型解释。
- **关键洞察：** 写入时不知道未来会问什么问题，读取时问题已知——因此记忆必须在写入阶段保留一切可能区分的差异，在读取阶段才做选择。

## 2. 方法论

### 2.1 核心思想：非对称保真 + 延迟选择（Asymmetric Fidelity with Deferred Selectivity）

- **精确保留证据**（canonical evidence：源 token ID、来源、时间、会话、版本关系）；
- **近似组织访问结构**（量化语义锚点 + 残差）；
- **只在问题已知时决定检索什么**（query-conditioned evidence packet）。

### 2.2 持久状态定义

- 状态 $M_n = (A_n, D_n, X_n, P_n, G_n, V_n)$：锚点、地址残差（innovation）、精确内容、来源元数据、引用关系、历史版本。
- 四个操作：**Write / Read / Persist / Handoff**（Algorithm 1 给出完整生命周期：写入 → 查询 → 快照 → 交接，写入使缓存快照失效，交接不重放全历史）。

### 2.3 写入：共享地址 + 独立证据

- 冻结语义编码器产生公共地址 $k_t=\mathcal{E}(o_t)$，共享中心 $\mu$、基 $U$ 得到坐标 $u_i=U^\top(k_i-\mu)$。
- **锚点捕获共性，残差捕获个体差异**：残差 $e_{ij}=\|(I-W_\delta W_\delta^\top)(u_i-A_j)\|_2$；若低于复用阈值（0.48）则复用锚点并量化保存局部位置，否则新建量化根。
- 地址重建：$\hat k_i=\text{norm}(U(A_{a_i}+W_\delta\hat\delta_i)+\mu)$。
- **上下文链接**：当前宿主在有限同会话窗口（≤4 条前序记录，取第 $\max(0,\lfloor 2L/3\rfloor-1)$ 层表示）内池化隐向量，按余弦相似度推断前驱 $\rho_i$；仅保存引用，隐表示不持久化。

### 2.4 读取：预算化检索 + 宿主适配

- 候选生成：重建地址相似度 + 词法匹配（≤64 候选）→ 冻结 MiniLM 交叉编码器重排 → **MMR 式相关性/多样性贪心选择**（冗余系数 0.35）→ $K=16$ 个相关性种子 + 时间序保留 + 局部/引用支撑；
- 交付受源 token 预算约束：$\sum_{e\in E_q}|v_e|+\nu_{sep}(E_q)\le T$（$T=2000$）；
- **词法/子词传输**：源 ID → 公共嵌入 → 加权词法假设 → 跨子词边界组合 → 目标分词器与嵌入表（8 个假设、softmax 尺度 100、word beam 4、位置质量阈值 0.5）；可选 rank-16 残差校准（冻结主干）。

### 2.5 持久化：可逆因果编码

- 冻结因果预测器（Qwen3-4B，1024-token 分页，24-bit 整数 CDF）+ 算术编码；内容长度 $\ell_{content}\approx-\sum_p\sum_{t\in T_p}\log_2 e^\phi_p(y_{p,t}|c_{p,t})+\ell_{framing}+\ell_{exceptions}$；
- **双层例外**：surface exceptions（分词器敏感表层）+ source-ID exceptions（重分词会改变规范 ID 时保留）；
- 每个新候选必须**独立解码并与保存状态逐字段比对**后才被接受；在“完整编码字节 + 新增共享依赖字节”上取最小。

### 2.6 理论刻画

- **命题 1（查询可区分信息丢失的不可逆性）**：若与查询无关的编码 $F(R_1)=F(R_2)$ 但 $R_1\not\sim_Q R_2$，则任何仅用 $q$ 与 $F(R)$ 的读出都无法保证两个历史都答对。

## 6. 主要发现与结果解读

- **同宿主全面领先：** 在 Qwen3-4B 下五项基准均列第一，相对次优（多为 Mem0）的增益在 LoCoMo（+2.01）、LongMemEval-S（+11.60）、MemOps（+14.17）、MemoryAgentBench（+2.34）、BEAM-1M（+3.40）上不等，**结构化生命周期任务（MemOps）与长程记忆（LongMemEval-S）增益最大**，说明“精确保留证据 + 延迟选择”对需要版本追溯与多跳整合的题型收益更显著。
- **状态迁移优于全历史重建：** 在三条迁移链上，MIGRO 的 State Transfer 模式随宿主升级保持稳定甚至小幅上升，而 Full-History Rebuilding 类方法在跨族迁移（尤其换分词器）时出现明显回落，**直接验证了“记忆应与模型解耦”的核心命题**。
- **存储摊销成立：** 随独立记忆数 $N$ 增大，$C_{memory}(N)=B_{shared}/N+B_{user}$ 趋近单用户边际成本，共享锚点/基/预测器的固定开销被有效摊薄，支持“多用户共享基础设施”的部署叙事。
- **消融指向关键组件：** 去掉地址残差（Anchor-only）或去掉边界组合/持久化编码后性能下降，表明**残差承载个体差异、可逆编码承载精确证据**两者缺一不可；状态复用控制（BM25、近期窗口、无记忆、目标重建）均显著劣于完整方法，排除了“仅靠检索基线即可复现”的解释。
- **续写实验：** 跨边界问题（旧历史与新历史交界）是难度最高的一类，MIGRO 在该类上的相对优势最大，呼应其“版本关系 $V_n$ 与引用 $G_n$ 显式建模”的设计。

## 7. 局限性与开放问题

- **理论保证的边界：** 命题 1 是**不可能性结论**（说明无损读出不可行），命题 2 是**局部稳定性结论**（依赖边界间隔 $\gamma_q>2\varepsilon$），二者均未给出端到端质量的可证下界，实际性能仍依赖经验调参。
- **传输保真度：** 词法/子词传输在分词器差异极大（如字节级 vs 词级）时，位置质量阈值 0.5 与 8 个假设的覆盖可能不足，论文未系统刻画最坏情况的语义漂移。
- **算力与可复现性：** 如第 4 节所述，缺少 GPU 型号/数量/时长与总训练成本，第三方难以精确复算资源账本。
- **超参与规模：** 复用阈值、冗余系数、候选上限（≤64）、$K=16$ 等均为固定值，缺少随数据规模/领域变化的自适应策略；100K 以上规模的稳定性仅有趋势性证据。
- **评测生态：** 依赖自动评判器与既有基准，缺少人类偏好或真实生产流量的验证；基线的“原生预算”差异也使绝对排名需谨慎解读。

## 8. 结论与启示

- **一句话贡献：** MIGRO 把“记忆”从模型的内部状态重构为**可持久、可迁移、可精确追溯的外部状态**，用“写入保真、读取选择”的非对称设计，调和了“保存历史”与“让新宿主可用”这对长期被混淆的需求。
- **方法论启示：** “写入时不知道问题、读取时问题已知”的信息论洞察，为记忆系统设计提供了清晰的原则——**在写入端最大化可区分信息，在读取端最小化交付成本**；这一原则可迁移到 RAG、Agent 记忆、持续学习等更广场景。
- **工程启示：** 冻结主干 + 轻量校准（rank-16 残差）+ 可逆因果编码的组合，给出了一条**低训练成本、支持模型热升级**的可行路径，对需要长期服务、频繁换模的产品形态具有直接参考价值。
- **待补方向：** 补齐算力口径与完整对照矩阵、给出端到端质量的理论下界、发展自适应超参与更强分词器无关的传输机制，是该工作走向更严格可复现与更广落地的主要缺口。
