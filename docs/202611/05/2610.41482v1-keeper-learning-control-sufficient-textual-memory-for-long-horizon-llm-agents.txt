# KEEPER: Learning Control-Sufficient Textual Memory for Long-Horizon LLM Agents

Abstract 

Recursive textual memory can carry earlier er-rors into later updates, yet task performance alone does not establish memory reliability. We define self-consistency bias as the persis-tence of incorrect claims already present in the incoming memory. We present KEEPER, a comparative analysis of four auxiliary ob-jectives along information-content and update-sensitivity axes within a shared recursive in-terface, examining how supervision targets re-late to agent performance. Among evaluated conditions, reward-related prediction achieves the highest task performance before and after offline reinforcement learning, outperforming joint supervision. A claim-level analysis of one baseline trajectory documents error persistence despite corrective observations. Together, these analyses motivate evaluating error persistence and valid-information retention alongside task outcomes. 

1 Introduction 

Long-horizon language agents need information from earlier interactions to guide later decisions. We use textual memory to mean a natural-language summary of past observations, actions, and task progress that an agent uses for subsequent deci-sions. In recursive memory systems, a generator up-dates this summary using the previous memory and the latest interaction (Zhou et al., 2026; Yu et al., 2026a; Zhen et al., 2026). We use self-consistency 

to describe agreement between successive memo-ries on historical claims that new evidence has not revised. Preserving valid historical claims matters when the current observation leaves earlier events unspecified, including whether a prerequisite action has already been completed. Agreement between successive memories does not establish the factual correctness of the informa-tion they share. Language models can repeat the

same incorrect answer across independent samples from a fixed input, and existing detection methods struggle to identify such errors (Tan et al., 2025). Recursive memory adds a further route to agree-ment: each update conditions on the previous mem-ory, so a claim can recur through reuse rather than independent regeneration. If a memory incorrectly records a prerequisite as completed, later updates may repeat that statement while new observations leave the issue unresolved. This concern is related to intrinsic self-correction: in reasoning tasks, re-vising an answer without external feedback does not reliably improve performance (Huang et al., 2024). We refer to the persistence of incorrect claims already present in the incoming memory across successive updates as self-consistency bias . The focus is on the continuation of an existing error; the generation of a new error is a separate event. In agents that retrieve stored experiences, inaccuracies in past experiences propagate to later tasks (Xiong et al., 2026); there, stored records are reused as retrieved, whereas recursive memory is rewritten at every update. Whether self-consistency bias occurs in recursively rewritten memory, and under which update conditions, requires direct evaluation in the memory system. If an intervention reduces self-consistency bias, that reduction alone is insufficient to establish an improvement in memory quality. An update that discards historical information can remove errors while also losing correct facts needed for later de-cisions. Improving recursive memory therefore requires reducing self-consistency bias while pre-serving historical information that remains correct and relevant to the task. Existing approaches (Zhou et al., 2026; Li et al., 2026a; Wang et al., 2026) train memory using task feedback, memory-specific credit assignment, and learned summarization decisions. These training signals can encourage the retention of useful in-arXiv:2610.41482v1 [cs.CL] 30 Oct 2026 formation. However, improved task scores alone leave unclear how the properties encouraged by training affect self-consistency bias and the reten-tion of valid historical information. We therefore compare auxiliary objectives that target different properties of recursive memory updates. We organize the analysis along two axes. The first concerns information content , specifically which information the memory generator’s internal representation retains. Approximate information-state theory motivates reward-related and predic-tive information as complementary criteria under explicit assumptions (Subramanian et al., 2022; Ni et al., 2024). Semantic agreement with reference memories provides a comparison for these task-related signals. The second concerns update sen-sitivity , specifically how changes in the incoming memory affect the subsequent update. Recursive reuse motivates examining this sensitivity, because errors in one memory become part of the input to the next update. We introduce KEEPER to analyze how aux-iliary supervision affects task outcomes within a fixed recursive memory interface. We evaluate four auxiliary objectives, individually and jointly, and compare task outcomes before and after offline re-inforcement learning. For each objective, we spec-ify a hypothesis linking its supervision mechanism to recursive memory quality. A complementary claim-level analysis examines how incorrect claims persist across updates in one baseline trajectory. We compare three objectives for information content . (1) Reward Preservation (Sec. 3.2.1) requires reward-related prediction, which we hy-pothesize encourages representations to retain dis-tinctions relevant to task progress. (2) Predictive Preservation (Sec. 3.2.2) requires successor pre-diction, motivating the retention of future-relevant information beyond immediate reward. (3) Seman-tic Anchoring (Sec. 3.2.3) aligns a learned projec-tion with the semantic representation of a reference memory. We hypothesize that this alignment en-courages the generator to preserve valid historical information in its output. 

(4) Update Stability (Sec. 3.3.1) constrains sen-sitivity to incoming-memory perturbations, moti-vating a reduction in their influence on subsequent updates. We also evaluate all four objectives jointly. The task results show that the benefits of individual ob-jectives do not necessarily accumulate under joint supervision. Together with the error persistence ob-served in a baseline trajectory, these findings moti-vate evaluating recursive memory through both task outcomes and direct assessment of self-consistency bias and valid-information retention. Our contributions are as follows: • We compare four auxiliary objectives within a shared recursive memory interface, separating information content from update sensitivity. • On ScienceWorld (Wang et al., 2022) and ALFWorld (Shridhar et al., 2021), Reward Preservation ranks highest among evaluated conditions before and after offline reinforce-ment learning, exceeding joint supervision. • We document self-consistency bias despite corrective observations in one baseline tra-jectory, distinguishing persistence, recurrence after correction, and omission without explicit correction. 

2 Related Work 

2.1 Learning to Manage and Revisit Memory 

Memory-R1 learns memory operations through re-inforcement learning (Yan et al., 2026), and Age-Mem unifies long-term and short-term memory management within the agent’s policy (Yu et al., 2026b). Self-Sum learns summarization timing and content (Wang et al., 2026), while MemPO assigns credit based on memory effectiveness (Li et al., 2026a). A-Mem links and updates memory records (Xu et al., 2025); ReMemR1 retrieves his-torical memories during updates for long-context question answering (Shi et al., 2026), and ARC uses reflection to revise context during information seeking (Yao et al., 2026). Using STEP-HRL’s recursive progress-memory interface (Zhen et al., 2026), we compare supervision targets within a shared update structure.

2.3 Information Content and Update Sensitivity 

Information-state theory and self-predictive RL motivate reward and successor prediction as cri-teria for decision-relevant representations under explicit assumptions (Subramanian et al., 2022; Ni et al., 2024). The usefulness of self-predictive objectives also depends on their relation to task val-ues (Khetarpal et al., 2025). Future-summary pre-diction (Mahajan et al., 2026) and Semformer (Yin et al., 2024) use future-text and response-semantic representations as auxiliary targets, respectively. These precedents motivate our comparison of reward-related prediction, successor prediction, and reference-memory alignment. Recurrent stability theory characterizes con-tractive updates (Miller and Hardt, 2019), while JacHess regularizes representation derivatives with respect to input embeddings (Juki´ c and Šna-jder, 2025). We therefore compare information-content supervision with penalties on sensitivity to incoming-memory perturbations, asking whether their effects extend to generated memories and re-duce self-consistency bias while preserving valid historical information. 

3 Methodology 

Within KEEPER , we compare auxiliary objectives for recursive textual memory and formulate hy-potheses linking their supervision mechanisms to self-consistency bias and valid-information reten-tion. Fig. 1 summarizes the auxiliary supervision during training and the shared recursive inference procedure. Our analysis separates information con-tent , which concerns the distinctions encouraged in a representation, from update sensitivity , which concerns the response to changes in the incoming memory. Reward Preservation (RP) and Predic-tive Preservation (PP) target information relevant to task outcomes and future contexts. Semantic Anchoring (SA) provides a comparison based on reference-memory content, while Update Stability (US) constrains sensitivity to incoming-memory perturbations. We distinguish three levels of evidence: the rep-resentational property encouraged by supervision, its expression in generated memory, and its conse-quences for subsequent decisions. Improvement at one level provides a hypothesis to test at the next level rather than establishing that effect. 3.2 Information-Content Supervision 

Information-content supervision specifies which historical distinctions the memory representation should retain. The following three objectives super-vise these distinctions through prediction of reward-related auxiliary labels, prediction of successor contexts, and alignment with reference-memory content. 

3.2.1 Reward Preservation (RP) 

Reward Preservation (RP) supervises informa-tion that distinguishes reward-related outcomes. Approximate information-state theory motivates expected-reward prediction as a criterion for re-taining decision-relevant information (Subrama-nian et al., 2022), and latent-state modeling uses reward prediction to constrain state representa-tions (Gelada et al., 2019). The relevant mecha-nism is the pressure to distinguish examples with different targets: if their representations are in-distinguishable, a predictor receiving those rep-resentations cannot account for the target differ-ence. When the difference depends on historical task progress, preserving that information helps reduce prediction error. Reward supervision there-fore adds an explicit prediction requirement beyond reference-token likelihood. Support would consist of improved reward-related predic-tion accompanied by these claim-level changes. The behavioral question concerns decisions that depend on the recorded progress, such as whether a prerequisite remains to be completed. 

3.2.2 Predictive Preservation (PP) 

Predictive Preservation supervises information that explains subsequent contexts. Two histories can have the same reward-related target while leading to different continuations. Reward prediction alone supplies no target difference that requires those histories to remain distinguishable. Approximate information-state theory therefore motivates suc-cessor prediction alongside reward prediction (Sub-ramanian et al., 2022; Ni et al., 2024). Self-predictive representation learning also provides em-pirical evidence for learning useful features through future prediction (Schwarzer et al., 2020; Mahajan et al., 2026). When successor targets differ, infor-mation that explains the difference helps reduce the predictive loss, providing additional supervision for distinctions that reward targets leave unresolved. Let c⋆t+1 denote the recorded successor context, and let ϕ be a fixed text encoder that produces unit-normalized semantic embeddings. A predictor F maps ht to a prediction of the successor embedding. The corresponding behavioral ques-tion is whether these future-relevant distinctions help the policy select actions whose consequences depend on them (Khetarpal et al., 2025). 

3.2.3 Semantic Anchoring (SA) 

Semantic Anchoring supervises correspondence with reference-memory content. Reward and pre-dictive objectives select information according to its usefulness for particular prediction targets. Semantic alignment instead uses the reference memory itself to define the representational tar-get. Matching distinct reference embeddings favors projected representations that vary with reference content: a constant projection cannot exactly match different embedding directions. We therefore ex-pect alignment to encourage content-dependent rep-resentations to the extent that the fixed encoder dis-tinguishes the reference memories. This condition provides a comparison between task-related predic-tion and reference-based content supervision. 3.3 Update-Sensitivity Supervision 

Update-sensitivity supervision concerns how a rep-resentation changes when the incoming memory changes. Holding the remaining update inputs fixed makes this response the focus of the comparison. US penalizes excessive sensitivity to sampled mem-ory perturbations. 

3.3.1 Update Stability (US) 

Update Stability constrains the influence of incoming-memory perturbations on the next rep-resentation. An erroneous claim in one memory becomes part of the input to the next update, pro-viding a route for its influence to persist. Recurrent stability theory relates sensitivity to the propagation of state differences: under a uniformly contractive update and identical external inputs, differences caused by an initial state decay over successive updates (Miller and Hardt, 2019). This principle motivates penalizing sensitivity to perturbed incom-ing memories (Juki´ c and Šnajder, 2025). The ex-pected effect is a smaller influence of the sampled perturbations on the subsequent representation. We replace the reference incoming memory p⋆t−1

Near-constant projections can also produce small sensitivity ratios, so a lower penalty alone does not establish a more reliable memory update.

4 Experiments 

We examine how auxiliary supervision of recur-sive memory affects whole-agent task scores on ScienceWorld and ALFWorld. We compare each objective individually and all four jointly, before and after offline reinforcement learning (RL). A qualitative analysis of a recorded memory trajec-tory then examines how incorrect claims persist, recur, and disappear across updates. 

4.1 Experimental Setup Benchmarks and metrics. We use Science-World (Wang et al., 2022) and ALFWorld (Shridhar et al., 2021). ScienceWorld evaluates multi-step sci-entific reasoning in an interactive text environment, while ALFWorld evaluates language-conditioned household task execution. We follow the data splits and evaluation protocol of STEP-HRL (Zhen et al., 2026). The ScienceWorld split includes 1,483 train-ing task instances, 194 seen evaluation instances, and 211 unseen evaluation instances. The ALF-World split includes 3,211 training task instances, 140 seen evaluation instances, and 134 unseen eval-uation instances. We report average task scores on ScienceWorld and task success rates on ALFWorld, separately for seen and unseen instances. Higher values indicate better task completion. 

Implementation details. We use Llama-3.2-3B-Instruct and follow the official STEP-HRL imple-mentation (Zhen et al., 2026) for the hierarchical agent architecture, demonstration data, training and evaluation settings, and offline RL data construc-tion. Supervised initialization uses low-rank adap-tation with AdamW, a learning rate of 10 −4, a total batch size of 128, and five training epochs. Each evaluation episode allows at most 50 environment steps. Appendix A.1 summarizes the inherited pro-tocol, and Appendix A.2 specifies the auxiliary representations, targets, coefficients, and gradient routing. The auxiliary objectives apply only dur-ing supervised initialization; we retain the origi-nal offline RL procedure for the primed conditions (Appendix A.1.2). The auxiliary encoder and pre-diction and projection functions are absent during execution. 4.2 Main Results 

Tab. 1 compares the supervision conditions before and after offline RL. 

Individual objectives. After supervised initial-ization, RP and US yield higher task scores than BC on both seen and unseen splits of both bench-marks, whereas PP and SA yield lower scores. RP ranks highest across these comparisons. The ob-served benefit therefore depends on the supervision signal. 

Joint supervision. Applying all four objectives together yields lower task scores than RP and US individually after supervised initialization. The joint condition exceeds BC only on unseen Sci-enceWorld tasks. Thus, the gains observed with individual objectives do not accumulate under joint supervision in this setting. 

Subsequent offline RL. RP remains the highest-scoring condition after offline RL, but its Science-World scores increase while its ALFWorld success rates decrease relative to supervised initialization. The joint condition improves across both splits of both benchmarks, whereas BC scores decrease on ScienceWorld. Offline RL therefore has differ-ent outcomes across initialization conditions and benchmarks. 

Scope of the comparison. These results com-pare complete agents: the memory generator and controller share trainable parameters. Higher task scores alone do not establish reduced self-consistency bias or improved retention of valid his-torical information. The following qualitative anal-ysis examines observed memory errors, without attributing their frequency to auxiliary supervision.

5 Conclusion 

Our KEEPER has provided a comparative analysis of how four auxiliary supervision objectives affect task outcomes within a shared recursive memory in-terface, distinguishing information content from up-date sensitivity. On ScienceWorld and ALFWorld, Reward Preservation and Update Stability have im-proved over behavioral cloning after supervised initialization, whereas Predictive Preservation and Semantic Anchoring have yielded lower task scores and success rates. Reward Preservation has ranked highest both before and after offline reinforcement learning, exceeding joint supervision. The effects of subsequent offline reinforcement learning have varied across benchmarks and initialization con-ditions. A complementary baseline analysis has documented error persistence despite corrective ob-servations. Together, these findings have shown that the task-level benefits of auxiliary memory supervision vary with the supervision target and training condition, and that the benefits of individ-ual objectives do not necessarily accumulate under joint supervision. Limitations 

Our evaluation covers two language-model back-bones within one agent architecture, with the sec-ond backbone evaluated only on ALFWorld. Shared trainable parameters prevent attributing task-score differences solely to memory generation. Teacher-forced representation supervision does not establish generated-memory correctness. The sen-sitivity penalty evaluates projected representations under sampled text perturbations and does not guar-antee global contraction. Our qualitative evidence comes from one base-line trajectory selected post hoc. It does not es-tablish error prevalence or the effects of auxil-iary supervision on error persistence and valid-information retention.

A.2.2 Reward Preservation 

RP uses the stored reward field of each memory-update example as its target yt. This field follows STEP-HRL’s converted training labels rather than a newly annotated measure of memory quality. In the upstream conversion, a subtask-final action re-ceives +1 , other actions receive 0, and the desig-nated invalid-action response receives −1; the con-verter’s terminal handling is retained. The memory-update example inherits the corresponding action label. These auxiliary labels are distinct from the benchmark’s episode-level evaluation score. The reward predictor uses smooth-L1 loss with its default transition parameter of one. With the default warm-up of 500 training minibatches, the progress-side reward loss initially updates the pre-dictor using detached features. After this warm-up, the loss also propagates through ht to the shared trainable backbone parameters. The warm-up counter advances once per minibatch, before accounting for gradient accumulation. When RP is active and low-level reward labels are available, the same reward predictor also re-ceives supervision at the end of the reference ac-tion output. The low-level features are detached by default, so this additional term trains the shared pre-dictor without sending a direct gradient through the low-level representation. Both reward terms use the RP coefficient. The auxiliary reward supervision therefore includes a predictor-training component as well as the progress-side representation loss de-scribed in the main text. 

A.2.3 Predictive Preservation 

PP uses a recorded successor target constructed from adjacent rows of each stored memory-update dataset. A row is linked to the next row when its reference output appears exactly as the next row’s previous-memory field. For a linked pair, the primary successor target c⋆t+1 concatenates the next row’s resulting observation and reference output memory, using observation and local-progress field labels. The target contains these two fields; it does not append the subtask or a future action. Rows without a matched successor receive an empty target and are excluded from the PP average. The implementation prefers the next_state col-umn. For legacy files without that column, it can use the next_progress column, which contains only the next memory. These target definitions are different and must be kept consistent across compared PP conditions. The predictor minimizes cosine distance to the frozen embedding of each nonempty target. If a minibatch contains no eligi-ble targets, it contributes no PP loss. 

A.2.4 Semantic Anchoring 

SA projects ht into the fixed encoder space and normalizes the result to obtain qt. It minimizes cosine distance between qt and ϕ(p⋆t ), where p⋆t is the reference output memory. The encoder target receives no gradient. The projection also supplies the representation used by US when that objective is active. An improvement in this teacher-forced alignment objective concerns the supplied refer-ence representation; generated-memory factuality is a separate property. 

A.2.5 Update Stability 

US replaces only the previous-memory field of the update input. The subtask, action, resulting obser-vation, and teacher-forced reference output remain fixed. The implementation shuffles the configured perturbation operators and accepts the first operator that changes the text. The default operators are: • Deletion: remove one sentence or tagged memory unit when at least two units are avail-able. • Substitution: replace one object or location mention with a different vocabulary entry of the same type. • Injection: insert a template-generated state-ment about an object, location, or completed action. The perturbation sampler uses a local random gen-erator initialized with the training seed plus 1,234. A comma-separated clause deletion serves as a fall-back when the configured operators fail. Empty previous memories and examples for which no op-erator changes the text are excluded from the US average. Substitution and injection require a vocab-ulary with both object and location entries. Without that vocabulary, only applicable deletion operations remain. The perturbations are text edits, without an external factuality judge; an injected statement is therefore not guaranteed to contradict the envi-ronment. The denominator uses the Euclidean distance be-tween the frozen, normalized embeddings of the clean and perturbed previous memories, with sta-bilizer δ = 10 −4. The numerator uses the dis-tance between the corresponding normalized pro-jections of the teacher-forced hidden states. The penalty is the mean squared hinge above a ratio of one. By default, the clean projection is detached, and gradients from US flow through the perturbed branch. This routing preserves the numerical form of the sensitivity ratio while making its optimiza-tion asymmetric. The ratio measures sensitivity of the learned pro-jection on sampled pairs, rather than a global Lip-schitz constant of decoded memory. In the US-only condition, SA is inactive, so reference-content alignment does not constrain this projection. Anearly constant projection can produce a small penalty; the penalty alone therefore does not estab-lish factual correction or retention of useful history.

A.3 Reading the Qualitative Memory Case 

The two memory-analysis figures in the main text describe one recorded trajectory labeled BC base-line. The update-level view aligns the previous memory, the resulting observation, and the updated memory. The trajectory-level view follows the same two claims about pot contents and agent lo-cation over subsequent recorded steps. Their ref-erence is the environment observation, rather than agreement between successive generated memo-ries. A claim is contradicted when its stated content conflicts with the recorded environment state, and 

consistent when it agrees with that state. An omit-ted claim is absent from the memory text. An 

ambiguous claim lacks enough detail for either cor-rectness judgment. These categories describe the displayed case; they do not constitute an aggregate automatic metric. Persistence denotes an incorrect claim continuing across successive updates. Recur-rence denotes an incorrect claim appearing again after a correct statement. Omission alone provides no evidence that the generator has replaced an in-correct claim with the correct one.
