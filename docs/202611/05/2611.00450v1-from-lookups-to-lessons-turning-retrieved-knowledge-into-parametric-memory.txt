## ABSTRACT 

Retrieval-augmented generation (RAG) helps large language models (LLMs) an-swer factual questions beyond their training data, but it adds storage and inference costs. Distilling previously retrieved information into parametric memories en-ables reuse without online retrieval. However, training the memory to mimic a retriever rewards accurate independent predictions, which do not necessarily im-prove the final output quality when combined with the LLM’s existing predictions. To address this, we introduce ResMem , in which the LLM reads retrieved text offline to generate teacher targets. This design avoids storing massive token rep-resentations, unlike existing parametric memory approaches such as MLP Mem-ory, which relies on k-nearest neighbor (kNN) datastores. Furthermore, by using the LLM as an offline teacher that reads privileged retrieved evidence alongside the input, we train a parametric memory to learn an additive logit residual. This residual aligns the predictions of a student sharing the same backbone with the teacher distribution, while self-distillation updates remain confined to the para-metric memory. On a Wikipedia subset, ResMem reduces the storage retained for teacher construction by 94.7% compared with the evaluated kNN pipeline. Across five question answering datasets, ResMem raises mean token F1 from 32.83% for the frozen LLM to 34.48%. It also breaks 21% fewer of the LLM’s correct answers than a kNN-trained memory. These findings validate our motivation of treating re-trieval as a learning resource, with parametric memory shaped by how retrieved knowledge is used to inform the model’s future predictions. Code and model weights are available at https://github.com/SSRand/From-Lookups-to-Lessons and https://huggingface.co/RandHan/ResMem-Mistral-7B-v0.3. 

## 1 INTRODUCTION 

Nowadays, many LLM applications need information beyond the current prompt, such as knowledge from external corpora and facts introduced in earlier interactions (Park et al., 2023; Zhang et al., 2025). One option is to keep such information in the model’s active context. However, longer context windows do not ensure reliable use of information at every position (Liu et al., 2024b), and growing histories still require managing a finite active context (Packer et al., 2023). Retrieval-augmented generation (RAG) is a widely used way to recover relevant evidence from external storage (Lewis et al., 2020). This access requires maintaining a corpus and its index, while retrieving and reading the evidence adds inference latency. At corpus scale, these costs motivate storing knowledge for use without online retrieval. Retriever-pretrained parametric memories offer such retrieval-free storage: they learn what a re-triever would return and keep it in network weights, so inference needs no index or search. Building on kNN language models (Khandelwal et al., 2020), MLP Memory and Memory Decoder train a memory to reproduce a retriever’s next-token distribution, then interpolate its prediction with a frozen base model (Wei et al., 2025; Cao et al., 2025). MLP Memory reports storage compression and faster inference, while Memory Decoder enables reuse across compatible base models. Both memories, however, learn to match the retriever alone and meet the base model only at inference. Their training loss never sees the base prediction (Figure 1a). A memory that reproduces the re-

The frozen base model serves as its own teacher by reading the query together with retrieved evidence, while the student sees only the query. The memory adds a logit residual to the student’s logits, and the distillation and next-token losses are computed on this sum. Because the loss is computed on the base prediction plus the residual, positions where the base already matches the training target give little gradient. The memory thus learns a correction to the base, not a second copy of the retriever. This builds on context distillation and retrieval-free dialogue distillation (Snell et al., 2022; Zhu et al., 2024). Inference then needs only the frozen base and the trained memory, with a coefficient γ setting how strongly the residual adjusts the base (Eq. 3). Because retriever-pretrained memories draw their supervision from a kNN datastore of corpus rep-resentations, they also pay a construction cost. Memory Decoder names the neighbor search over this datastore as a training bottleneck (Cao et al., 2025, Sec. 9), and later work scales the search with compression and sharding (Wei et al., 2026). An evidence-reading teacher needs no such datastore. ResMem retrieves passages with BM25 and caches only the teacher’s top-64 targets, which cuts retained construction storage from 602.0 to 32.0 GiB on a subset of English Wikipedia, a 94.7% (18 .8×) reduction (Section 5.2). On five knowledge-QA datasets, ResMem improves exact match (EM) and token F1 over the base model on every dataset and raises mean F1 from 32.83 to 34.48. Compared with MLP Memory, it corrects 11% more base errors and breaks 21% fewer correct base answers, so most of its advantage comes from avoided harms. Under a shared teacher, the residual objective mainly preserves correct answers, and its extra repairs come with the evidence-reading teacher. Memory Decoder falls below both memories under the same teacher. Our main contributions are: (i) We introduce residual self-distillation, which trains an additive logit residual through the joint base-plus-memory prediction and keeps it at inference. (ii) We replace the kNN datastore with text retrieval and an evidence-reading teacher. This cuts retained construction storage by 94.7% ( 18 .8×). The teacher’s targets also keep the shape of the base prediction. The kNN targets are much sharper. (iii) We evaluate the recipe and its parts on knowledge QA, answer-level corrections and harms, and shared-teacher ablations. 2Preprint 

## 2 RELATED WORK 

Retrieval and parametric memory. Retrieval keeps information outside model parameters. RAG, RETRO, and Atlas condition generation on retrieved text (Lewis et al., 2020; Borgeaud et al., 2022; Izacard et al., 2023), and xRAG compresses each retrieved document into a one-token representation (Cheng et al., 2024). kNN-LM instead forms a next-token distribution from neighboring contexts (Khandelwal et al., 2020). Memorizing Transformers and LongMem attend to stored representations of earlier tokens (Wu et al., 2022; Wang et al., 2023). Product quantization, GPU similarity search, and efficient kNN-LMs reduce the cost of such stores (J´ egou et al., 2011; Johnson et al., 2021; He et al., 2021). All of these methods query a store during inference. Parametric memories instead learn to reproduce a store, building on the view of feed-forward layers as key–value memories (Geva et al., 2021). kNN knowledge distillation moves retrieval into preprocessing for translation (Yang et al., 2022). MLP Memory and Memory Decoder train separate parametric memories to imitate retriever distributions (Wei et al., 2025; Cao et al., 2025). Memory Decoder at Scale extends this route to larger memories and corpora with compressed, sharded search (Wei et al., 2026). MemSFT adds learned token-level routing between a retrieval-supervised memory and the frozen backbone (Wang et al., 2026a). We instead train the memory’s contribution through the joint prediction. Parametric RAG still retrieves documents, each encoded as LoRA parameters (Su et al., 2025). Test-time train-ing layers, Titans, and δ-mem update memory states online while processing a stream (Sun et al., 2025; Behrouz et al., 2025; Lei et al., 2026b). ResMem instead trains its memory offline. 

Distillation and output composition. Knowledge distillation transfers a teacher’s predictions to a student (Hinton et al., 2015), and the teacher may use privileged information that is absent at de-ployment (Lopez-Paz et al., 2016). Context distillation internalizes the benefit of extra instructions, examples, or reasoning in language models (Snell et al., 2022). Cartridges uses it to learn compact KV caches offline (Eyuboglu et al., 2025). TTCD updates a short-context student’s fast weights on-line from long-context supervision (Wang et al., 2026b). Born-Again Networks show that the teacher need not be larger than the student (Furlanello et al., 2018). In ResMem, teacher and student share the frozen backbone, and only the parametric memory is trained. Retrieval-conditioned distillation carries the benefits of retrieval into retrieval-free students, as in QUILL, RA2FD, and InstructRetro (Srinivasan et al., 2022; Zhu et al., 2024; Wang et al., 2024). TS-Memory distills kNN-induced cor-rections into a time-series adapter (Lyu et al., 2026). TransMem is the closest work. It also trains a memory by evidence-conditioned self-distillation with a shared frozen backbone (Lei et al., 2026a). However, its student reads the full long context and outputs gated hidden-state shifts. Our student lacks the evidence and outputs a logit residual. DExperts, contrastive decoding, proxy-tuning, and context-aware decoding combine or contrast model predictions at decoding time (Liu et al., 2021; Li et al., 2023b; Liu et al., 2024a; Shi et al., 2024). ResMem instead learns its residual through a loss on the combined prediction and needs evidence only offline. ResMem also trains on fixed teacher-forced continuations. On-policy distillation, OPSD, and OPSDL use student-generated trajectories instead (Agarwal et al., 2024; Zhao et al., 2026; Zhang et al., 2026). 

## 3 METHODOLOGY 

ResMem writes external knowledge into a parametric memory while keeping the language model frozen. The memory architecture follows MLP Memory. ResMem changes the teacher and the objective (Section 3.2), and the teacher’s cached targets replace the kNN datastore (Section 3.4). 3.1 MEMORY INPUT AND ARCHITECTURE 

For a token sequence x, causal position t predicts the next token yt = xt+1 . The frozen base produces logits zB,t ∈ R|V | over vocabulary V . At the same position, we extract ht ∈ Rd at the input to the final Transformer block’s feed-forward sublayer (Appendix A). The memory maps this contextual vector to vocabulary logits, sθ,t = mθ (ht) ∈ R|V |. Following MLP Memory (Wei et al., 2025), it consists of a stack of feed-forward blocks with RMS normal-ization and residual connections, followed by a final normalization and its own trainable vocabulary projection. Each gated block acts on one position; the base representation already carries the pre-ceding context, so the memory needs no attention over tokens. Only memory parameters, including its output projection, are trained. 3Preprint 3.2 RESIDUAL SELF -DISTILLATION 

Distilling the privileged gain into memory. On-policy self-distillation (OPSD) (Zhao et al., 2026) turns privileged input into supervision: the same model, given information the student lacks, pro-duces a dense token-level output distribution. Teacher and student share one backbone, so this dis-tribution lives in the base model’s own output space. It differs from the base prediction only through what the privileged input adds. A residual on the base must learn exactly this part (Eq. 2). ResMem uses retrieved evidence as the privileged input, as in context distillation (Lopez-Paz et al., 2016; Snell et al., 2022), and distills this gain into the parametric memory. The teacher πT (· | c, x ≤t) is the frozen model reading passages c retrieved by BM25 (Robertson & Zaragoza, 2009) before the span x. The student πS (· | x≤t) = softmax( zB,t + sθ,t ) is the same model reading only x, plus the memory’s residual. ## 4 EXPERIMENTAL SETUP 

Models. We use Mistral-7B-v0.3 (Jiang et al., 2023) as the base model. ResMem and MLP Mem-ory each attach an eight-layer memory with hidden size 4096, intermediate size 14336, and approx-imately 1.54B parameters. Additional baselines are BM25-RAG (Robertson & Zaragoza, 2009; Lewis et al., 2020), LoRA (Hu et al., 2022), and Memory Decoder (Cao et al., 2025). On the Wikipedia subset, we train two memories with this architecture on a kNN teacher built from the subset. Both start from the same initialization, follow the same example order, and train for three epochs (220.8M tokens). One uses the standalone objective, and the other uses the residual objective (Section 5.3; Appendix A). For knowledge QA, the correction analysis, HaluEval, and the precision study, ResMem, MLP Memory, and Memory Decoder are each trained for one epoch on full En-glish Wikipedia. MLP Memory and Memory Decoder follow their official pipelines, including the kNN teacher. The shared-teacher ablation trains eight new paired seeds for each objective and for Memory Decoder, all with equal exposure (Section 5.4). 

Datasets. Following MLP Memory, we use the December 2021 English Wikipedia dump as the corpus for memory training. The Wikipedia subset, used for the storage comparison and these two memories, contains 74 of its 4,716 source shards, about 1/64 of the corpus. Knowledge QA contains 38,627 questions from Natural Questions (NQ) (Kwiatkowski et al., 2019), WebQuestions (Berant et al., 2013), TriviaQA (Joshi et al., 2017), PopQA (Mallen et al., 2023), and HotpotQA (Yang et al., 2018). We also use HaluEval’s Dialogue, QA, and Summarization splits (Li et al., 2023a). Hardware, training schedules, and evaluation configurations are given in Appendix A. 

## 5 RESULTS 

5.1 KNOWLEDGE QA T ASK PERFORMANCE 

The QA checkpoints are each trained for one epoch on full Wikipedia (Section 4). We report EM, token F1, and reference-answer PPL on 38,627 questions, averaging the five datasets equally. For each memory and dataset, we select λ or γ to maximize EM on the validation set. We then use that coefficient to compute EM, F1, and PPL on the evaluation set (Appendix A). A QA-supervised tokenwise gate changes mean EM by only +0 .07 points and mean F1 by −0.02 points, so ResMem is reported without it (Table 6 in Appendix E). ResMem has the highest EM and F1 and the lowest PPL in all three task families (Table 1). Over Base, it raises mean EM from 25.91 to 26.74 and mean F1 from 32.83 to 34.48. Both metrics improve on every dataset (Appendix B). Its F1 margin over MLP Memory grows from 0.32 points on open-domain QA to 1.08 on long-tail and 1.77 on multi-hop QA. On HaluEval hallucination detection, the same checkpoints raise mean accuracy from 54.83 to 63.09, against 60.34 for MLP Memory (Appendix C). Answer likelihood alone does not explain these results. BM25-RAG lowers open-domain answer PPL below Base (10.02 versus 11.11), yet it loses 5.42 EM points. Generation must choose its own words and decide when to stop. 5.2 CONSTRUCTION STORAGE

A change in mean EM is the net of two opposing effects: the memory fixes some questions the base model answers wrongly and breaks some it an-swers correctly. We pair the answers to all 38,627 questions with the frozen Base answers and count corrections C (Base wrong, memory right) and harms H (Base right, memory wrong) under normalized EM. The net EM gain is (C − H)/Q over the Q questions. Each method uses one global coefficient chosen on 4,091 NQ/TriviaQA develop-ment questions disjoint from the test sets: λ∗ = 0 .3 for MLP Memory, γ∗ = 0 .3 for ResMem, and λ∗ = 0 .2 for Memory Decoder. Figure 3a traces correction against harm rate as the coefficient varies. Net EM rises while a curve is steeper than the ∆EM = 0 line. Figure 3b splits the net gain into corrections and harms at the selected coefficients. ResMem corrects 704 answers and harms 381, against 633 and 482 for MLP Memory. Its net EM gain is 0.84 points, against 0.39 (paired difference 0.45, 95% interval [0.25, 0.64]). Most of this difference comes from the 101 avoided harms. Memory Decoder nets −0.04 points, with 124 corrections and 138 harms. One source of the harm gap is the shape of the kNN target (Figure 4a). Over all 74.6M cached positions, a single token carries at least 95% of its mass at 87% of positions. Its median entropy is 0, and its mean top-1 probability is 0.95. The evidence-reading teacher is shaped like the base instead. It does so at 24% of 1.05M positions, and the base at 22%. Their mean top-1 probabilities are 0.60 and 0.59. This sharpness is a known property of kNN-LM. The kNN distribution comes from 

k ≪ | V | neighbors through a softmax over negative distances, so it is sharper than a model’s output (Xu et al., 2023). A higher temperature spreads the mass (Khandelwal et al., 2021). The original kNN-LM therefore mixes this distribution at a small weight, λ = 0 .25 on WikiText-103 (Khandelwal et al., 2020). Our kNN teacher follows the MLP Memory pipeline at T = 16 . The comparisons above differ in teacher, objective and readout, and memory architecture at once. Holding the teacher fixed, we first vary the objective and readout, and then the architecture. 

Objective and readout. Both memories use the same BM25-RAG teacher, cached inputs, eight-layer architecture, paired initialization, and example order. Eight paired seeds each receive 8,388,608 supervised-position exposures over eight epochs. Each configuration selects one coef-ficient on 1,024 development questions disjoint from the test sets. Pairing the seeds lets each com-parison share its initialization and data order. We call the standalone objective with mixture readout and the residual objective with additive read-out the native configurations. Both improve mean F1 over Base (Table 2). The residual configu-ration leads by 0.117 points, with a 95% question-cluster bootstrap interval of [−0.020 , 0.258] , or 

[−0.180 , 0.477] when seeds are also resampled. In the four-cell diagnostic on 4,096 shared questions, both crossed configurations select coefficient zero and recover Base. Residual scores read as a standalone distribution yield an F1 of 0.06, so they are useful only when added to the base logits. Pooled over the eight runs at native operating points, the residual configuration preserves 96.11% of Base-correct answers, against 94.05%. It repairs 1.51% of Base errors, against 2.25% (point estimates). With the teacher fixed, it thus trades some repair for preservation. 

Architecture. Memory Decoder replaces the hidden-state memory with a separate 0.47B-parameter decoder that reads the token sequence (Appendix A). With the same supervision, exposure, and optimizer schedule and a mixture readout, it reaches F1 32.87. This is 0.26 and 0.37 points below the standalone and residual configurations ( [−0.42 , −0.09] and [−0.49 , −0.25] ). Development selection sets its coefficient to zero for six of the eight seeds (Table 2). Under this training budget and at these sizes, the hidden-state memory is the stronger design. Unlike the shared-teacher runs, full-recipe ResMem both corrects more and harms less than MLP Memory (Section 5.3). The objective and readout thus contribute to the better preservation. The ex-tra repairs come with the evidence-reading teacher, in line with the sharper kNN targets in Figure 4a. 

## 6 CONCLUSION 

ResMem distills a retrieval-augmented teacher into an additive logit residual on a frozen base model. On a Wikipedia subset, it cuts retained construction storage by 94.7% ( 18 .8×). On five knowledge-QA datasets, it raises mean F1 from 32.83 to 34.48. It also corrects more base errors and harms fewer correct answers than MLP Memory. With a shared teacher, the residual objective mainly preserves correct answers, and the extra repairs come with the evidence-reading teacher. The storage saving and the extra repairs thus share one source, the teacher that reads retrieved text. With only the parametric memory trained, the base model stays unchanged. A limitation of this design is that the memory reads one hidden state and writes only to the output logits. ## A IMPLEMENTATION DETAILS 

Memory input. In the Mistral backbone, ht is the state after the attention residual connection and its following RMS normalization (Zhang & Sennrich, 2019). Base logits are computed separately through the remaining feed-forward computation, final normalization, and frozen vocabulary head. 

Subset kNN teacher and Memory Decoder. The kNN teacher for the Wikipedia subset is built with the original teacher’s builder. It reproduces the original position count and 26.967 GiB target cache. Memory Decoder uses a Qwen3-0.6B-Base body with the Mistral vocabulary (0.47B parameters). 

Knowledge-QA configuration. For each dataset, we select λ for MLP Memory and Memory De-coder and γ for ResMem by the highest EM on the validation set. Each memory then uses its selected coefficient for all three metrics on the evaluation set: EM, F1, and PPL, with EM and F1 computed from the same generated answers. LoRA uses strength 0.25, chosen on development data. BM25-RAG retrieves five Wikipedia passages with a 4096-token input and up to 64 output tokens; the other methods use 384 input tokens and at most 12 output tokens. PPL scores answer tokens and excludes the prompt and EOS. On a separate Wikipedia sample, with coefficients selected on 128 calibration sequences and scored on 256 others, the QA checkpoints reach perplexity 7.441 (MLP Memory), 8.660 (ResMem), and 9.959 (Base). MLP Memory fits held-out text more closely, yet ResMem answers more questions correctly (Table 1). A closer fit to the corpus thus does not by itself give better final answers. 

Hardware. The two memories trained on the subset’s kNN teacher use A100-SXM4-80GB GPUs. Knowledge-QA memory sweeps use NVIDIA A100-SXM4-40GB GPUs. QA inference uses BF16 base computation, eager attention, batch size 16, and greedy decoding. The shared-teacher ablation and precision measurements use two eight-GPU A100-SXM4-80GB hosts, with one model worker per GPU. The precision study uses BF16 Base with FP32 or BF16 memory and SDPA/KV caching. Deployment timing uses one GPU. Detailed schedules, checkpoint sources, and scoring configura-tions are recorded in the repository’s experimental-protocol note.

The gate decides when the memory should act on the base output. The residual matters only at decoding steps where it changes the base’s top token. At such a step, it either repairs a base error or overrides a correct base token. The gate aims to keep the repairs and block the overrides, using only signals available during decoding. At step t, we compute the base logits zB,t and the fused logits zB,t + γs θ,t . From both, we form 22 features. They describe each distribution (entropy, top-token probability, and top-two margin) and how the two top tokens compare, such as the residual’s advantage for the fused token. They also cover the step index, the generated prefix, and whether either top token would end the answer. A logistic classifier maps the features to a score gt. The step uses the fused logits if gt ≥ 0.5 and the base logits otherwise, so the residual scale is γt ∈ { 0, γ }. The gate uses no labels or future tokens. On the test questions, the fused top token differs from the base top token at 19,254 of 463,520 decoding steps (4.2%). The gate accepts 10,614 of these changes and blocks 8,640. Of the accepted changes, 7,493 occur at the first answer token. The gate is fitted on 264 NQ/TriviaQA training questions and selected on a disjoint 4,091-question development split, so it adds QA supervision beyond memory training. On all 38,627 questions, relative to fixed-strength ResMem, the gate changes mean EM by +0 .07 points (95% question-cluster bootstrap interval [−0.06 , 0.19] ) and mean F1 by −0.02 points.
