## 摘要
面向多跳推理的检索增强生成（RAG）要求检索能够随着中间证据揭示新的信息需求而自适应调整。现有方法通过显式图结构或迭代式查询重写来支持这种检索，但会引入图构建或查询时开销。我们提出证据引导的自适应图检索（EAGR），该框架中累积证据动态决定下一步探索哪些语义方向，且无需专用图数据库，也无需显式图物化。EAGR 在一个隐式语义图上运行，该图由预先摄入标准 VectorDB 的紧凑段落元数据诱导而成。从稠密检索得到的种子段落出发，LLM 迭代评估累积证据、识别有前景的语义方向、通过基于元数据的邻域查找扩展检索前沿，并在收集到足够证据后终止。通过预计算语义元数据，EAGR 能够进行以证据为条件的图探索，而无需物化显式图、维护专用 GraphDB 或迭代重写查询。在三个广泛使用的多跳问答基准上，EAGR 在所评估方法中取得最高的基于 LLM 的答案准确率；在 HotPotQA、2WikiMultiHopQA 和 MuSiQue 三个常用基准上平均而言，其性能比原始 RAG 高出 17%，比最强的图感知基线高出 4 个百分点。

## Abstract
Retrieval-Augmented Generation (RAG) for multi-hop reasoning requires retrieval to adapt as intermediate evidence reveals new information needs. Existing approaches support such retrieval through explicit graph structures or iterative query reformulation, introducing graph-construction or query-time overhead. We present Evidence-Guided Adaptive Graph Retrieval (EAGR), a framework in which accumulated evidence dynamically determines which semantic directions to explore next, and which requires no dedicated graph database and no explicit graph materialization. EAGR operates over an implicit semantic graph induced by compact passage metadata pre-ingested into a standard VectorDB. Starting from dense-retrieval seed passages, an LLM iteratively assesses accumulated evidence, identifies promising semantic directions, expands the retrieval frontier through metadata-based neighborhood lookup, and terminates once sufficient evidence has been collected. By precomputing semantic metadata, EAGR enables evidence-conditioned graph exploration without materializing an explicit graph, maintaining a dedicated GraphDB, or iteratively rewriting the query. Across three widely used multi-hop QA benchmarks, EAGR achieves the highest LLM-based answer accuracy among evaluated methods, outperforming the vanilla RAG by 17\% and strongest graph-aware baseline by 4\% percentage points averaged across three popular benchmarks HotPotQA, 2WikiMultiHopQA, and MuSiQue.
