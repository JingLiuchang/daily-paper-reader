## 摘要
检索增强的语言模型系统通常依据以查询为条件的相关性来选择上下文。我们认为，长期存续的 AI 系统需要第二种算子：以激活为条件的记忆可用性。我们指定了一种架构：请求与目标线索为授权记忆图提供种子，激活与扇出衰减分配有界遍历前沿，检索到的实体递归地发出线索，并在生成前重构类型化证据图。该规范产生了关于候选选择、遍历控制、图正则化、证据重构和强化的五项架构性推论。我们推导了实现层面的成本估计，并定义了消融、失败条件和可复现的评估协议。若更简单的图重排序器在同等预算下在因果与时间恢复上匹配完整遍历，则核心主张被收窄或被证伪。这篇架构与分析预印本不报告基准测量。若该主张成立，检索返回的是使记忆可用的证据路径，而不仅仅是一个排序列表。

## Abstract
Retrieval-augmented language model systems generally select context by query-conditioned relevance. We argue that long-lived AI systems require a second operator: activation-conditioned memory availability. We specify an architecture in which request and goal cues seed an authorized memory graph, activation and fan attenuation allocate a bounded traversal frontier, retrieved entities recursively emit cues, and a typed evidence graph is reconstructed before generation. The specification yields five architectural consequences about candidate selection, traversal control, graph regularization, evidence reconstruction, and reinforcement. We derive implementation-level cost estimates and define ablations, failure conditions, and a reproducible evaluation protocol. The central claim is narrowed or falsified if a simpler graph reranker matches full traversal on causal and temporal recovery under equal budgets. This architecture-and-analysis preprint reports no benchmark measurements. If the claim holds, retrieval returns the evidence path that makes a memory available, not only a ranked list.

## 二、方法论：激活引导图检索（AGGR）

- **核心思想**：在候选生成与图遍历之上增加一个有状态的控制层。请求、目标和智能体状态生成线索，线索在授权记忆图中播种；激活分数与扇出衰减共同分配有界遍历前沿；检索到的实体可递归发出新线索；最终在生成前重构类型化证据图。
- **记忆图结构**：图 \(G=(V,E)\) 可包含目标、领域、情节、事件、事实、文本块、实体、程序、决策、来源和智能体动作；边可表示时间顺序、因果、包含、矛盾、更新、来源、推导、相似性、指派或依赖等类型。
- **运行时流程**：
  1. 从请求、目标、工作流和智能体状态派生线索；
  2. 解析授权种子节点并生成外部搜索候选；
  3. 计算候选记忆实体的激活；
  4. 用激活与扇出衰减分配有界遍历前沿；
  5. 扩展图路径，允许已检索实体发出新线索；
  6. 按预算、边际证据、矛盾或覆盖标准停止；
  7. 重构带来源与未解决缺口的类型化证据图；
  8. 将证据图交给生成，并记录合格结果用于后续强化。
- **授权前置**：授权在内容承载的激活评分和扩展之前执行。不可访问节点不能通过激活行为泄露内容、身份、度数或分数；度数、衰减和共现统计仅在请求者授权子图上计算。遍历记录已访问节点，避免重复评分或重复扩展。
- **激活模型**：
  - 基础项近似 ACT-R 激活：
    \[
    B_i(t)=\log(n_i+1)-d_i\log(\Delta t_i+1)+\beta\kappa_i
    \]
    其中 \(n_i\) 为合格成功使用次数，\(d_i\) 为记忆特定衰减率，\(\Delta t_i\) 为距合格事件的时间，\(\kappa_i\) 为显著性，\(\beta\) 为显著性权重。
  - 运行时综合分数：
    \[
    A_i=\eta s_q(m_i)+B_i(t)+\sum_j W_jS_{ji}+U_i+Q_i-C_i+\epsilon
    \]
    包括查询相关性、基础激活、线索扩散激活、任务效用、来源/验证权威、矛盾/陈旧/冗余/政策风险惩罚及噪声项。作者强调这是可审计的排序代理，不是校准概率。
- **扇出感知遍历**：对高度数线索进行衰减：
  \[
  \phi(\deg(j))=\frac{1}{1+\alpha(\deg(j)-1)^2}
  \]
  从线索 \(j\) 到记忆 \(i\) 的移动分数：
  \[
  F_{ij}=W_jS_{ji}\phi(\deg(j))\psi(A_i)
  \]
  路径分数综合移动分数、成本和冗余惩罚：
  \[
  Score(p)=\sum_{(j,i)\in p}F_{ij}-\lambda Cost(p)-\gamma Redundancy(p)
  \]
- **递归线索与证据重构**：已检索实体可引入原请求中没有的线索，例如“账户损失→预测修订→预算削减→取消”。递归扩展在预期边际证据超过阈值且满足成本与授权边界时继续。最终输出不是无序列表，而是证据图 \(G_e=(V_e,E_e)\)，保留节点、类型化关系、来源、检索路径、激活贡献、置信度、矛盾分支和未解决缺口。
- **成本估计**：
  - 遍历：\(T_{traverse}=O(hLb\log L)\)，前沿内存约 \(O(Lb)\)；
  - 上下文：\(T_{context}\approx |V_e|(u+\rho)+|E_e|\ell\)，不保证小于平坦检索的 \(kc\)；
  - 图存储：\(O(|V|+|E|)\)，激活元数据另加 \(O(|V|)\)；
  - 强化更新：对 \(|V_e|\) 个实体约 \(O(|V_e|)\) 次写入，计算成本小，但统计风险大。
