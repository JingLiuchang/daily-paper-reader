I. INTRODUCTION
Driven by the rapid advancement of deep learning, mas-
sive volumes of unstructured data, such as text, images, and
videos, are routinely transformed into high-dimensional vector
embeddings to capture their underlying semantic relationships.
To efficiently manage and query these immense datasets,
specialized vector databases (e.g., Milvus [1], Qdrant [2], and
Weaviate [3]) have emerged and are now widely deployed.
Serving as the core retrieval engine for these systems, ANN
search has established itself as a fundamental primitive in
the era of artificial intelligence. Leveraging this capability,
vector databases empower a wide range of data-intensive ap-
plications, including retrieval-augmented generation [4], rec-
ommendation systems [5], and semantic search [6]. To support
ANN search on a massive scale, modern vector databases rely
on advanced indexing structures, such as hashing [7], inverted
files [8], and proximity graphs [9], [10]. In this paper, we focus
on proximity-graph-based (or simply graph-based) indexing
methods, as they achieve the best trade-off between search
efficiency and recall [11].
With the exponential growth in dataset sizes and the con-
tinuous increase in vector dimensionality, maintaining massive
vector databases locally has become prohibitively expensive
for many data owners. Consequently, there is a growing trend
to outsource vector data management to third-party cloud
platforms, leveraging their scalable storage and computational
capabilities to support ANN queries [12]–[14]. Despite the
benefits of outsourcing, this paradigm introduces critical trust
concerns regarding the execution integrity of the search ser-
vice. For instance, a rational but dishonest platform might
terminate the query process early and return suboptimal results
to reduce computational overhead, thereby compromising the
accuracy of the results. While authenticated query processing
over outsourced data has been extensively investigated for
traditional relational databases [15]–[17], it remains largely
under-explored for high-dimensional vector databases.
To ensure the integrity of ANN search in outsourced vector
databases, a common approach is to employ traditional au-
thenticated data structures (ADS), such as the Merkle Hash
Tree (MHT), to build an authenticated graph index [18], [19].
Under this approach, upon executing an ANN query, the
cloud service provider constructs and returns a verification
object (VO) that contains the graph traversal path and all
the raw high-dimensional vectors evaluated during the search.
The client can then verify the integrity of the query results
by locally replaying the search process and recomputing the
distances. However, existing methods [18], [19] necessitate
the transmission of large volumes of raw high-dimensional
vectors in the VO for local distance recomputation. Further-
more, their MHTs are constructed without considering the
underlying topology of the graph index, resulting in inefficient
authentication paths. Consequently, these limitations lead to an
excessively large VO size, incurring high bandwidth costs and
resulting in prohibitive communication overhead.
To overcome this challenge, we propose VIDA, a novel and
efficient scheme for authenticated graph-based ANN search
that effectively addresses the critical bandwidth bottleneck.
Unlike traditional baselines that require the transmission of
raw high-dimensional vectors, VIDA integrates established
vector commitments and Inner Product Argument (IPA) into
a novel authentication scheme tailored to graph-based ANN
search, enabling compact distance verification without trans-
mitting raw vectors. Furthermore, to address the challenge of
verifying a massive number of distance computations during
graph traversal, we propose a proof aggregation mechanism
that compresses the verification tasks for multiple visited

side computational overhead.
Beyond optimizing data-level transmission, we further pro-
pose MeST, a topology-aware ADS that minimizes the struc-

minimum spanning tree to align authentication paths with
graph traversal, thereby reducing the size of Merkle proofs
required for verification. Even after these optimizations, the
residual verification cost still scales with the number of

support lower-bound-based quantization-aware graph search,
in which pruned candidates are justified by compact au-
thenticated quantization payloads, while only the surviving
candidates require exact-distance authentication via the aggre-
gated IPA proof. Extensive experiments demonstrate that our
methods outperform baseline methods, achieving a substantial
speedup in end-to-end latency and reducing data transfer by
orders of magnitude in high-recall scenarios.
Our main contributions are summarized as follows:
• We propose VIDA, a novel verifiable graph-based ANN
search scheme that integrates vector commitments and
IPA to authenticate distances without transmitting raw
high-dimensional vectors.
• We design a proof aggregation mechanism that com-
presses multiple inner-product verifications into a single
compact proof, greatly reducing client-side computational
overhead.
• We introduce MeST, a topology-aware ADS built via
a distance-aware minimum spanning tree, which aligns
verification paths with graph traversal to minimize Merkle
proof size.
• We adapt VIDA to quantization-aware graph search,
reducing the number of exact distances that require
cryptographic authentication.
• We provide a formal security analysis and conduct ex-
tensive experiments on both real-world and synthetic
datasets. The results show that our methods achieve up
to a 6.6× speedup in end-to-end latency and a 99.2%
reduction in data transfer time compared with state-of-
the-art methods.

System Model. Our system, as illustrated in Figure 1, com-

publishes the signature to the client.
• SP: Equipped with abundant computational resources, the

of the DO. Upon receiving a query Q from the client,
the SP executes the designated ANN algorithm over I to
compute the result R and constructs a verification object

• Query Client: The client is an end-user who issues
search queries to the SP. Upon receiving the result R
and its corresponding VO, the client verifies the integrity
and correctness of R by validating the VO.
Threat Model. The main security threat arises because the SP
is an untrusted third party that may deviate arbitrarily from
the protocol. For example, it may return incorrect results to
save computation by skipping neighbors or tampering with the
index or vector values. In contrast, we assume that both the
DO and the query client are honest and follow the protocol.
To counter this threat, the SP must return a VO along with the
query result R to prove execution integrity. At the same time,
because exact kNN search is prohibitively expensive in high
dimensions, we do not require the SP to return the exact result.

III. PRELIMINARIES
In this section, we introduce background on graph-based
ANN algorithms and a strawman approach for authenticated
ANN query processing. The frequently used notations through-
out this paper are summarized in Table I.
A. Graph-based ANN Algorithms
Graph-based algorithms have been recognized as the most
effective category for high-dimensional ANN search. Repre-
sentative index structures, such as HNSW [9] and NSG [10],
have demonstrated superior efficiency and accuracy. Conse-
quently, they have been widely adopted in large-scale vector
database systems [1]–[3]. In general, these algorithms operate
in two primary phases: offline index construction and online
query processing.
During the index construction phase, given a database D, the
construction algorithm builds a proximity graph I. Each node
vi in the graph corresponds to a data object oi ∈D, while
the edges capture the neighborhood proximity between data
points. The index is usually built incrementally by inserting
points sequentially, and each new point is connected to a set
of selected neighbors subject to an out-degree limit. During
the query processing phase, given an ANN query Q = (k, xq),
the search algorithm initiates a greedy traversal over the graph
I, starting from a designated entry node vep. Throughout the
traversal, a priority queue of candidate nodes is maintained,
typically ordered by their distance to the query vector xq. The
algorithm iteratively expands the search frontier by extracting
the most promising candidates and evaluating their unvisited
neighbors. After the traversal terminates according to the spe-
cific stopping condition, the top-k closest nodes encountered
during the search are returned as the ANN query result R.
B. Strawman Solution
A strawman solution to enable authenticated graph-based
ANN search is to build an MHT [20] as the underlying
ADS over all graph nodes in I. During the query phase, in
addition to executing the prescribed ANN search algorithm,
the SP is required to generate the corresponding Merkle proofs
for all visited graph nodes. These visited nodes, along with
their cryptographic proofs, constitute the verification object
(VO). Upon receiving the VO, the client first verifies the
data integrity of the visited nodes using their Merkle proofs.
Subsequently, a subgraph is constructed from these verified
nodes, allowing the client to locally replay the ANN search
on this subgraph to verify the returned results.
1) ADS Construction: The ADS of the strawman solution
is a binary MHT built on top of the graph nodes. Specifically,
each graph node vi is represented as a leaf node. The leaf node
hash is computed as Hi = H(IDi | Adji | xi), where IDi and
xi are the identifier and raw vector of the corresponding data
object, Adji is the adjacency list consisting of the identifiers of
its neighbors on the index graph, H(·) denotes a cryptographic
hash function, and | represents the concatenation operation. By
contrast, the non-leaf node hash is computed as H(Hl | Hr),
where Hl and Hr are the hashes of the left and right child
nodes. Finally, the DO signs the root hash of the MHT and
the identifier of the entry point (i.e., (Hroot, IDep)) using its
private key to generate a digital signature σ as the trusted root.
Example. Consider a proximity graph as shown in Fig-
ure 2a. The strawman approach constructs a corresponding
MHT, illustrated in Figure 3; e.g., the hash of leaf node v1 is
computed as H1 = H(ID1 | Adj1 | x1), whereas the hash of
the non-leaf node v13 is computed as H13 = H(H1 |H2). The
DO signs (Hroot, IDep = 1) to generate σ.
2) Verifiable Search: Given a query Q, the SP executes
the designated graph-based ANN search and records the set of
visited candidate nodes Vgraph (i.e., all nodes whose distances
to the query vector are evaluated during the traversal, including
the entry point vep). It then constructs a VO consisting of: (1)
the identifier IDi, raw vector xi, and graph adjacency list
Adji for all vi ∈Vgraph; (2) the corresponding Merkle proof
for these nodes; and (3) the DO’s signature σ. The SP returns
the result set R along with the VO.
To verify the query result, the client first uses the Merkle
proof in the VO to recompute the root hash from the received

IV. VIDA SCHEME
In this section, we address the first challenge, namely
the prohibitive communication overhead. To solve this issue,
we propose VIDA, a Verifiable Inner-product-based Distance
Authentication scheme that allows the client to authenticate
distance computations without receiving the raw vectors.
A. Inner-product-based Distance Authentication
Preliminary evaluations in Figure 4 indicate that the primary
bottleneck of the strawman solution is the requirement for
the client to receive the complete raw vector xi for every
visited node vi ∈Vgraph to replay the search process locally.
This overhead is particularly expensive for modern machine
learning workloads, where the dimensionality of embeddings
often reaches thousands and continues to grow. Ideally, it
would be much preferable if the client could attest to the
distance between xq and xi without receiving xi itself. To
achieve this, we analyze the algebraic structure of common
distance metrics used in vector databases:
• Euclidean distance:

A crucial observation is that these metrics depend on three
components: the norm of the query vector ∥xq∥, the norm of
the data vector ∥xi∥, and the inner product IPi = ⟨xi, xq⟩.


Since the client provides the query vector xq, its norm ∥xq∥
can be computed locally. Meanwhile, the DO can precompute
the norm of each data vector ∥xi∥for every object oi ∈D
as part of the ADS. Consequently, the remaining problem
reduces to proving the correctness of the inner product IPi. To
this end, we propose to leverage the Inner Product Argument
(IPA) [22], [23], a cryptographic protocol that allows a prover
to convince a verifier of the inner product of two vectors
represented by constant-size commitments. The IPA protocol
consists of the following PPT algorithms:
• KeyGen(1λ) →pp: Given a security parameter 1λ, it
generates a public key pp.
• Com(xi, pp) →Ci: Given a vector xi and the public key
pp, it generates a constant-size, computationally binding
Pedersen vector commitment [24].
• ProveIPA(x1, x2, pp) →(IP, ρ): Given vectors x1, x2
and the public key pp, it computes the inner product
IP = ⟨x1, x2⟩and the corresponding IPA proof ρ.
• VerifyIPA(C1, C2, IP, ρ, pp) →{0, 1}: Given the
commitments C1, C2, the claimed inner product IP, a
proof ρ, and the public key pp, it outputs 1 if and only
if ⟨x1, x2⟩= IP ∧Com(x1) = C1 ∧Com(x2) = C2.
Because the size of a Pedersen commitment is independent of
the vector dimensionality d, replacing raw vectors with com-
mitments immediately removes the dominant communication
overhead associated with transmitting xi. Furthermore, as we
will see later, the IPA enables efficient verification of the inner
product computations required for ANN queries and can be
extended to support the aggregation of multiple proofs.
B. VIDA Design
We now describe how VIDA leverages inner-product-based
distance authentication to support authenticated ANN search.
1) ADS Construction: The ADS in VIDA is structured simi-
larly to the strawman solution, employing a binary MHT where
each leaf node corresponds to a graph node vi. However, the
leaf node hash is computed as Hi = H(IDi | Adji | Ci | ∥xi∥),
where Ci and ∥xi∥are the Pedersen commitment and the norm
of xi, respectively. Note that including the raw vector xi in the
digest is unnecessary, as the commitment Ci itself serves as
a cryptographic binding to the data object. The remainder of
the ADS structure and its construction algorithm are identical
to those described in Section III-B.
2) Verifiable Search: Given a query Q, the SP executes
the designated graph-based ANN search over the index and
records the visited node set Vgraph. Unlike the strawman
solution, for each visited node vi ∈Vgraph, the VO includes
the commitment Ci and norm ∥xi∥instead of the raw vector
xi, while retaining the identifier IDi and adjacency list
Adji. Meanwhile, the SP generates an IPA proof ρi using
ProveIPA(xi, xq, pp) for each visited node vi to attest to
the inner product IPi = ⟨xi, xq⟩. These authenticated inner
products, combined with the commitments and norms, replace
raw-vector transmission and enable the client to recompute
distances without accessing xi, reducing communication over-
head. Finally, the SP generates the Merkle proof for Vgraph and
returns the result set R along with the VO. In summary, the
VO in VIDA comprises:
• the identifier IDi, the adjacency list Adji, the commit-
ment Ci, and the norm ∥xi∥for every vi ∈Vgraph;
• the claimed inner product IPi = ⟨xi, xq⟩and correspond-
ing IPA proof ρi for every vi ∈Vgraph;
• the corresponding Merkle proof for Vgraph;
• the DO’s signature σ.
Upon receiving (R, V O), the client first reconstructs the
root hash and verifies the DO’s signature σ. This step authen-
ticates the search subgraph, including IDi, Adji, Ci, and ∥xi∥
for each visited node vi ∈Vgraph. Subsequently, the client
verifies each raw vector xR in R against its corresponding
commitment CR. For each visited node vi ∈Vgraph, the client
validates the IPA proof ρi for the claimed inner product IPi
by invoking VerifyIPA(Ci, Cq, IPi, ρi, pp). A valid IPA
proof certifies that IPi = ⟨xi, xq⟩matches the commitment
Ci. Using the authenticated IPi, the validated norm ∥xi∥,
and the locally computed ∥xq∥, the client computes the
distance δ(xi, xq) for each node vi. It then constructs a local
search subgraph I′ = {(IDi, Adji, δi)}vi∈Vgraph and replays
the graph-based ANN search algorithm over I′. Unlike the
strawman solution, which recomputes distances from high-
dimensional raw vectors, VIDA replays the search using these
authenticated distances. Verification succeeds if the replay
yields the same result set R = R′ without attempting to access
any node outside the authenticated set Vgraph.
Example. The search in Figure 2b visits Vgraph = {v1, v3,
v5, v6, v9, v11, v12} and returns R = {x9}. The SP includes
(IDi, Adji, Ci, ∥xi∥) for every vi ∈Vgraph in the VO and
provides the Merkle proof as in Section III-B2. For distance
authentication, the SP computes IP1 = ⟨x1, xq⟩for v1,
generates the IPA proof ρ1, and adds both to the VO instead
of the raw vector x1. The client reconstructs the root from
the node data and Merkle proof, verifies its signature, and
checks each result vector in R against its commitment (e.g.,
Com(x9) = C9). For every node in Vgraph, it then verifies
the IPA proof and recovers the distance. For v1, it checks ρ1
using C1, IP1, and the local query vector xq, then computes
the Euclidean distance δ1 = (∥x1∥2 + ∥xq∥2 −2IP1)1/2.
C. Proof Aggregation
Although the IPA-based approach significantly reduces the
VO size, it requires a distinct proof for every visited node
vi ∈Vgraph. This imposes substantial computational overhead
on the SP for proof generation and on the client for veri-
fication. Furthermore, high-recall ANN searches in machine
learning workloads typically traverse thousands of nodes. The
cumulative size and verification time of these individual proofs
become a severe bottleneck. To address this, we propose an
IPA aggregation protocol that compresses multiple proofs into
a single proof. Specifically, it extends the original IPA with
the following two PPT algorithms:

Our solution exploits the fact that all n inner products share
the same query vector xq as a common input. Thus, we apply
random linear combination [25] to batch these n inner product
arguments into one aggregated proof. Specifically, the prover

We now describe the integration of the aggregation protocol

V. TOPOLOGY-AWARE VIDA
This section proposes a novel ADS called the Merkle
Spanning Tree (MeST) for proximity graphs, which overcomes
the topology-agnostic limitation mentioned in Section III-B3
and seamlessly integrates with VIDA.
A. Topology-aware ADS Construction
Recall that the strawman solution constructs the MHT based
on node identifiers, ignoring the topological structure of the
proximity graph. Consequently, it fails to exploit the search
index’s topological semantics, leading to redundant and inef-
ficient Merkle proofs in the VO. To address this, we propose
building the MHT directly over the proximity graph to align
the ADS with the search access patterns. However, optimizing
VO size for ANN search poses two primary challenges:
• Graph-to-tree mapping and path compression: Unlike the
hierarchical structure of an MHT, proximity graphs are
undirected and often cyclic. The challenge lies in finding
an optimal graph-to-tree mapping such that nodes fre-
quently co-visited during search share a common Merkle
path with high probability. This alignment is critical for
maximizing proof compression by deduplicating shared
internal hash nodes.
• Node content and minimal disclosure: Since ANN search
involves the iterative exploration of a node’s neighbor-
hood, the ADS must be carefully designed. We must
determine the optimal granularity of information (e.g.,
adjacency lists and commitments) stored in each MHT
node to ensure the client receives all necessary data for
verification while minimizing the number of revealed
Merkle nodes to reduce VO size.
We observe that graph-based ANN search typically employs
greedy traversal guided by a priority queue, where exploring
a node frequently leads to the subsequent exploration of
its immediate neighbors. To capture this spatial-topological
correlation, we construct the MHT based on a spanning tree
rooted at the graph’s global entry point. While a standard
unweighted minimum spanning tree can minimize hop dis-
tance by placing nodes reachable in d hops at depth d of
the Merkle tree, it treats all neighbors equally and ignores
the distance-driven nature of greedy search. Conversely, a
traditional distance-weighted minimum spanning tree mini-
mizes global edge weights without regard to tree depth, which
may produce excessively deep paths and degrade Merkle
proof efficiency. To balance these requirements, we propose
a Distance-aware Minimum Spanning Tree (Algorithm 1).

C. MeST for Multi-layered Graphs
Many graph-based ANN indexes, such as HNSW [9], use
multi-layered graphs. MeST supports them by building the
Merkle spanning tree over the union of all layer-wise edges
and organizing each node’s graph ADS into layer-specific
neighbor payloads whose digests are combined into the node
hash. During verifiable search, the SP reveals only accessed-
layer payloads and provides digests for the others. The client
replays the original top-down search and rejects if any required
payload is missing. Full details are in Appendix A.
VI. QUANTIZATION-AWARE VIDA
VIDA and MeST reduce authentication overhead through
IPA aggregation and a topology-aware ADS, respectively.
Nevertheless, each evaluated candidate introduces an exact-
distance authentication instance for verifier-side replay, so the
remaining cost scales with the candidate count. Large-scale
and high-recall graph-based ANN searches may evaluate many
candidates, shifting the dominant authentication cost from per-
candidate overhead to the number of such instances.
Modern ANN systems address an analogous query-time
bottleneck through vector quantization, which encodes vectors
into compact representations and evaluates candidates without
accessing their full-precision vectors. Classical methods like
PQ [8] and SQ [27] approximate distances from compressed
codes and often rerank a shortlist using exact distances to
preserve search accuracy. In contrast, methods such as Ra-
BitQ [28] compute one-sided lower bounds that enable pruning
when they exceed the current search threshold. Such pruning
is more compatible with authenticated search, because the
verifier can recompute the bound and validate the pruning
decision without checking the exact distance.
Motivated by this observation, we extend VIDA to authen-
ticate quantization-aware graph search. Exact distances are
authenticated only for candidates that require exact evalua-
tion, whereas candidates eliminated by quantization can be
justified using compact authenticated quantization payloads.
Quantization thus reduces both ANN query-time computation
and the number of exact distance computations that must enter
the aggregated IPA proof. We next present the corresponding
ADS construction and verifiable search protocol.
ADS Construction. To support quantization-aware authen-
tication, we extend the Graph Node ADS defined in Sec-
tion V-A. Besides the exact-distance payload used for IPA-
based authentication, each neighbor entry must also bind
the quantization payload used to compute the lower bound.
Accordingly, each neighbor vj contributes two payloads to
the quantization-aware Graph Node ADS: the exact-distance
payload (Cj, ∥xj∥) and the quantization payload ηj. All other
components of the ADS and its construction are unchanged
from Section V-A.

VII. SECURITY ANALYSIS
We first establish the computational knowledge soundness
of IPA aggregation using the underlying IPA extractor [29],
then use authenticated distances and deterministic replay to
prove the execution integrity of VIDA and its variants. Com-
plete proofs are provided in Appendices B and C.
Theorem 7.1 (Soundness of IPA Aggregation). Let Adv be a
PPT adversary that produces a valid aggregated IPA proof for
the relation ⟨xagg, xq⟩= IPagg with non-negligible probabil-
ity. There exists a PPT extractor E that extracts the witnesses
{xi}n
i=1 such that ⟨xi, xq⟩= IPi for all i ∈{1, . . . , n}.
Proof Sketch. By rewinding the prover at the Fiat–Shamir
challenge [30], E obtains accepting transcripts for n distinct
nonzero challenges. The IPA extractor yields an aggregated
witness per transcript. Solving the resulting invertible Vander-
monde system recovers the individual witnesses. Commitment
homomorphism and binding tie each xi to Ci, while inner-
product linearity gives ⟨xi, xq⟩= IPi.
We next consider execution integrity under Definition 2.1,
including the topology-aware and quantization-aware variants.
Theorem 7.2. VIDA and its variants are secure with respect to
Definition 2.1, assuming the underlying cryptographic primi-
tives, including IPA aggregation, are secure.
Proof Sketch. An accepted forgery must either alter the au-
thenticated data or deviate from the designated search. Al-
tering graph structure or metadata requires a hash collision
or signature forgery; changing a committed vector violates
binding; and falsifying an authenticated distance contradicts
Theorem 7.1. Otherwise, replay uses genuine graph data and
distances: omitting a required node causes rejection, while
deterministic replay yields the honest result. MeST preserves
this argument through authentication against the signed root.
For the quantization-aware variant, pruning is checked using
authenticated lower-bound payloads at the same replay thresh-
old. Under the quantization guarantee, a valid pruning step, or
its replacement by an exact evaluation, preserves the effective
search state. Thus, an incorrect result can be accepted only
with negligible probability.

VIII. EVALUATION
A. Experiment Settings
Datasets and Query Workload. We conduct extensive
experiments on six datasets with diverse sizes, dimensions,
and data types, as summarized in Table II. The synthetic
Cluster dataset is generated following [31]. Regarding query
workloads, we use the official query sets when available. For
datasets without a predefined query set, we randomly sample
1,000 vectors from the base data to serve as queries. Unless
otherwise specified, all experiments use Euclidean distance as
the similarity metric and set the result size to k = 100. The
target recall for each dataset follows the varying-k experiment.
Metrics. In our experiments, we primarily focus on end-to-
end latency, defined as the total time elapsed from the client
sending a query until completion of the verification process.
We report recall to evaluate search accuracy. Furthermore, to
assess index construction overhead and storage efficiency, we
measure the construction time and the size of the ADS.
Main Algorithms for Evaluation. We evaluate three base
methods and their quantization-aware variants. Strawman em-
ploys a standard MHT over the graph and transmits raw vec-
tors for distance verification. ANNProof [18] improves Straw-
man with a sharded MHT, while retaining raw-vector-based
verification. VIDA* is the full topology-aware instantiation
of VIDA described in Section V, combining aggregated IPA
with MeST. Their quantization-aware variants, Strawman-
Q, ANNProof-Q, and VIDA*-Q, apply the quantization-
aware search in Section VI, using authenticated quantization
payloads for pruned candidates and their respective original
mechanisms for exact-distance verification.
We use HNSW [9] as the underlying ANN search index,
unless otherwise specified. For the HNSW index configuration,
we set the construction parameter efconstruction to 500 across all
datasets. The maximum number of links per node, M, is set
to 32. During the query phase, we vary efsearch to achieve
different trade-offs between recall and latency. For IPA, we
instantiate the protocol using the lightweight Bulletproofs [22]
(a variation) together with the Springproofs [23] framework.
For quantization-aware variants, we use RaBitQ [28] on top
of the corresponding graph index.
Environment. We implement the proposed schemes and base-
lines in the Rust programming language. The source codes
are available at https://github.com/hkbudb/auth-ann. For the
cryptographic primitives, the IPA is implemented via Bullet-
proofs [36] using the Ristretto255 curve for group operations.
All experiments were conducted on a server equipped with
Dual 28-core Intel Xeon Gold 6330 @ 2.0GHz CPUs and
2TB RAM. To simulate real-world outsourced database sce-
narios, we limit the network bandwidth using the toxiproxy
utility [37]. The default network bandwidth is set to 300 Mbps.
B. Search Performance
1) Latency under Varying Recall Targets: We first evaluate
the trade-off between end-to-end query latency and recall.
Figure 7 compares the methods across recall targets on six
datasets. For Msmarco, we use NSG [10] as the underlying
ANN algorithm to evaluate our approach’s generality beyond
HNSW. We also include Strawman and its quantization-
aware variant Strawman-Q as reference baselines. As shown
in Figure 7, Strawman(-Q) and ANNProof(-Q) show very
similar latency trends. We therefore omit Strawman and use
ANNProof as the baseline in subsequent experiments.
Overall, VIDA* consistently outperforms Strawman and
ANNProof across all datasets, and the advantage becomes
more pronounced in high-recall settings. This trend is es-
pecially evident on high-dimensional OpenAI3072. At the
highest recall target, VIDA* achieves a 6.6× speedup over
ANNProof, while VIDA*-Q achieves a 3.0× speedup over
ANNProof-Q. These results are consistent with our analysis.
Achieving higher recall requires increasing the search param-
eter, e.g., efsearch for HNSW, which increases the number
of nodes visited during graph traversal. For raw-vector-based
baselines, the transmission cost grows with the number of vis-
ited nodes and becomes the dominant contributor to end-to-end
latency. In contrast, VIDA* replaces raw-vector transmission
with compact commitments and aggregated IPA proofs, and
further uses MeST to place neighboring graph nodes close
together in the authentication tree. This reduces both distance-
authentication cost and structural proof size. For instance,
on OpenAI3072, VIDA* reduces the transfer cost by 99.2%
compared with ANNProof at the highest recall target, while
VIDA*-Q reduces it by 82.5% compared with ANNProof-Q.
Quantization-aware variants further reduce latency by reducing

IX. RELATED WORK
ANN Search. ANN search algorithms are broadly cat-
egorized into hash-based [7], inverted-file-based [8], and
graph-based methods [39]. Currently, graph-based methods are
widely recognized for achieving the best trade-off between
search efficiency and recall [11]. These methods operate as
a greedy best-first search on a proximity graph. Based on
graph topology and edge pruning strategies, graph-based ANN
methods are categorized into hierarchical (e.g., HNSW [9],
HVS [40]) and flat structures (e.g., NSG [10], DPG [41]).
Recent research has expanded graph indexes to diverse envi-
ronments, including disk-resident designs for massive datasets
(e.g., DiskANN [42]), hardware-aware layouts for GPUs (e.g.,
CAGRA [43]), and metadata-filtered searches [44]. Despite
these optimizations, their core search paradigm remains reliant
on sequential graph traversals.
Verifiable Query Processing. Verifiable query processing over
structured databases has been widely studied using authenti-
cated data structures (ADS) [15] or zero-knowledge proofs
[16], [17] to ensure query integrity across various query
types [45]–[48]. When extending verifiable queries to vector
data, existing works mainly target exact kNN search. These
works generally leverage spatial partitioning ADS (e.g., MR-
trees [49], Voronoi diagrams [50]) to ensure result integrity by
rigorously proving that the unsearched space cannot contain
better candidates. Regarding ANN search, however, this exact
verification paradigm is fundamentally incompatible: high
dimensionality renders spatial geometric proofs prohibitively
expensive, while enforcing exactness contradicts the efficiency
goal of approximate search. Consequently, verifiable ANN
should shift its focus from strictly verifying the final exact
result to guaranteeing execution integrity, ensuring that the
search algorithm is executed correctly and faithfully.
For graph-based ANN, ANNProof [18] and Wang et al.
[19] use MHTs and raw-vector replay to verify HNSW and
HCNNG searches, respectively. Wang et al. further reduce the
number of probed nodes through HCNNG-specific optimiza-
tions. V3DB [51] and zkRAG [52] verify IVF-PQ and HNSW
retrieval, respectively, using succinct zero-knowledge proofs
that hide private database and index information. However,
generating such proofs incurs substantial computational over-
head. For example, zkRAG reports a proof generation time of
approximately 26 seconds per query on SIFT1M. In contrast,
VIDA targets general graph-based ANN methods. It integrates
vector commitments and aggregated IPA to authenticate dis-
tances without transmitting raw vectors, and uses topology-
aware MeST to reduce structural proof overhead. Separately,
privacy-preserving ANN methods protect vector values and
access patterns from service providers [53]–[57].
X. CONCLUSION
In this paper, we presented VIDA for efficient verifiable
graph-based ANN search in outsourced vector databases.
VIDA combines vector commitments with aggregated IPA
proofs to authenticate distances without transmitting raw vec-
tors. Furthermore, we developed MeST, a topology-aware
Merkle spanning tree index that aligns structural verification
paths with graph traversal sequences to minimize required
Merkle proofs. We also adapted VIDA to quantization-aware
graph search to avoid unnecessary exact-distance proofs.
Our formal security analysis and experimental evaluations
demonstrated that the proposed approach is secure and highly
scalable. It delivers up to a 6.6× speedup in end-to-end latency
while reducing data transfer time by 99.2% compared with
state-of-the-art methods.

MEST FOR MULTI-LAYERED GRAPHS
In graph-based ANN search, a prominent class of algorithms
employs multi-layered graph structures [9], which effectively
function as skip lists to accelerate query processing. These
indexes organize the graph into a hierarchy, enabling the query
to navigate from sparser upper layers all the way down to the
dense base layer. To further exploit this hierarchical topology,
we extend MeST with a layer-aware design that aligns the
Merkle spanning tree with the existing graph layers.
ADS Construction. To construct a unified spanning tree

flattening step ensures that the spanning tree captures the skip-

the ANN search may traverse neighbors within a specific layer

verification, the client replays the designated ANN algorithm

replay attempts to access the neighborhood information of a
node vi on a layer whose payload is not disclosed in the VO,
the verification fails immediately. In this way, MeST avoids
transmitting unused layer-specific graph information.

property guarantees that a prover cannot produce a valid proof

⟨xi, xq⟩= IPi.

APPENDIX C
SECURITY OF VIDA
Theorem 7.2. VIDA and its variants are secure with respect to
Definition 2.1, assuming the underlying cryptographic primi-
tives, including IPA aggregation, are secure.
Proof. Let Adv be a PPT adversary that wins the ex-
periment in Definition 2.1 with non-negligible probability.
Namely, given a database D and a query Q, Adv outputs
a query result RReal and a verification object VO such that
Verify(Q, RReal, VO) = accept, yet RReal̸ = RIdeal,


where RIdeal is the output of the designated deterministic
ANN algorithm faithfully executed on the authentic index
generated from D. For the quantization-aware instantiation, the
designated algorithm is the deterministic quantization-aware
graph search designated by the DO.
We show that such an adversary must break at least one of
the underlying cryptographic assumptions with non-negligible
probability.
Integrity of the Local Subindex. During verification, the
client reconstructs a local subgraph I′ from the data carried
in the VO. Let I denote the authentic ANN index generated
during the setup phase. We analyze the integrity of I′ from
the following three aspects.
• Structural Integrity. If the structural information of any
node in I′ (e.g., node identifier or adjacency list) differs
from that in I, yet still passes Merkle-root verification
against the signed root digest, then Adv must either forge
a signature or find a collision in H in order to produce a
valid proof for altered data.
• Data Integrity. If the commitment Ci or the authenticated
norm ∥xi∥associated with a node vi in I′ differs from
the corresponding value in I, while the verification still
accepts, then again Adv must either forge a signature
or find a hash collision. Moreover, if Adv claims that
a commitment Ci opens to some vector x′
i̸ = xi, then
this violates the computational binding property of the
Pedersen commitment.
• Distance Integrity. If the recovered distance between a
node vector and the query vector differs from the true
distance induced by the vector committed in Ci, then
Adv must have produced a valid aggregated IPA proof
for an invalid inner-product relation. This contradicts the
computational knowledge soundness of the underlying
IPA protocol.
Therefore, except with negligible probability, the verifier
reconstructs a faithful local subgraph I′ of I: for every node
included in I′, its authenticated structural information and its
recovered distance to the query are identical to those in the
authentic index.
Integrity of the Replay Process. Let f denote the des-
ignated deterministic ANN algorithm. In the Ideal Game, the
trusted party outputs RIdeal = f(Q, I). In the Real Game, once
the structural proof and the aggregated IPA proof are accepted,
the verifier replays the same deterministic algorithm on the
reconstructed subgraph I′ and obtains a local replay result
R′ = f(Q, I′). The verification procedure accepts only if the
replay does not require any missing node and R′ = RReal.
We now analyze the ways in which Adv may try to make
the Real Game output a result different from the Ideal Game.
Case 1: Adv provides an incomplete subgraph. Suppose
Adv omits some node that is required by the honest execution
of f on the authentic index. Because the ANN search proceeds
by graph traversal, every such node is reached through the
authenticated adjacency list of some previously revealed node.
Hence, during replay on I′, the verifier will eventually attempt
to access a missing node. According to the verification proce-
dure, this causes rejection, and thus GameReal = ⊥. Therefore,
an incomplete subgraph cannot lead to a successful forgery.
Case 2: Adv provides a complete and faithful subgraph
but deviates from the search protocol. Assume now that
I′ contains all nodes required by the honest search and is
faithful to I on those nodes. Since the verifier replays the same
deterministic ANN algorithm f on the same authenticated
structure and distances, the replay necessarily follows the
honest behavior on the revealed subgraph. Consequently, the
replay result coincides with the honest result: R′ = RIdeal.
If Adv outputs any forged result RReal̸ = RIdeal, then
necessarily RReal̸ = R′, so the final equality check fails and
the verifier rejects. Hence, in this case as well, Adv cannot
make the Real Game output a value different from the Ideal
Game while still being accepted.
Security

Security of Quantization-aware Instantiation. For the
quantization-aware instantiation, the replay process further
contains two types of branches. For nodes represented by
the exact-distance branch (i.e., nodes in Vexa), the verifier
follows the same exact-distance authentication procedure as in
VIDA: the commitments, norms, and claimed inner products
are authenticated by the ADS and the aggregated IPA proof,
and hence the recovered exact distances are faithful to the
committed vectors. Such authenticated exact distances are
sufficient for replay even if a node could have been pruned
by quantization. Specifically, if δj ≤δth, then, under the
stated guarantee of the quantization method, the pruning
condition cannot hold for vj, so the node cannot be validly
pruned. Otherwise, if δj > δth, the designated ANN update
discards the node without changing the effective search state.
Therefore, an unnecessary exact evaluation may change the
verification branch, but it leaves the replay state and result
unchanged.
For nodes pruned by quantization (i.e., nodes in Vqua), the

commitment scheme, or computational knowledge soundness
of the IPA protocol. All of these events occur only with
negligible probability. Therefore, the success probability of
Adv is negligible, which proves the theorem.
