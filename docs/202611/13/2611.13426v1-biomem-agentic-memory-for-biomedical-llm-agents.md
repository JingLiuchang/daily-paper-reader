## 摘要
大语言模型（LLMs）在生物医学应用中展现出巨大潜力，而智能体记忆系统已成为跨任务和交互保存与利用信息的一种有前景的方法。然而，一个根本问题仍然存在：这些系统在保留、检索、更新和利用生物医学信息方面的有效性和可靠性如何？本研究系统考察生物医学领域的智能体记忆，重点关注任务有效性、检索质量、信息保真度和长期鲁棒性。我们在三种代表性场景中评估了四种LLM上的五种记忆方法：生物医学知识推理、临床预测和长期对话记忆。我们的分析揭示了记忆构建、证据相关性和对话历史如何塑造下游生物医学性能，并突出了在检索相关信息、保持其保真度以及有效利用其进行推理方面的独特挑战。基于这些发现，我们提出混合记忆检索与利用（HMRU），一个无需训练的框架，联合增强证据可及性和任务感知利用，以改进生物医学推理和长期对话记忆。HMRU在生物医学问答和对话记忆基准上平均取得8.6%的相对提升，并在部分临床预测任务中带来额外增益。它进一步将对话答案错误率降低24.9%，并弥合了与全上下文推理之间48.0%的性能差距。我们的发现系统刻画了生物医学智能体记忆，并为开发更有效、更可靠的记忆增强LLM系统提供了实践见解。

## Abstract
Large language models (LLMs) have demonstrated considerable potential in biomedical applications, while agentic memory systems have emerged as a promising approach to preserving and utilizing information across tasks and interactions. However, a fundamental question remains: how effectively and reliably do these systems retain, retrieve, update, and utilize biomedical information? In this study, we systematically investigate agentic memory in the biomedical domain, focusing on task effectiveness, retrieval quality, information fidelity, and long-term robustness. We evaluate five memory approaches across four LLMs in three representative settings: biomedical knowledge reasoning, clinical prediction, and long-term conversational memory. Our analyses reveal how memory construction, evidence relevance, and conversational history shape downstream biomedical performance, highlighting the distinct challenges of retrieving relevant information, preserving its fidelity, and effectively utilizing it for reasoning. Building on these findings, we introduce Hybrid Memory Retrieval and Utilization (HMRU), a training-free framework that jointly enhances evidence accessibility and task-aware utilization to improve biomedical reasoning and long-term conversational memory. HMRU achieves an average relative improvement of 8.6% across biomedical question-answering and conversational memory benchmarks, with additional gains in selected clinical prediction tasks. It further reduces conversational answer errors by 24.9% and closes 48.0% of the performance gap to full-context inference. Our findings provide a systematic characterization of biomedical agentic memory and practical insights into developing more effective and reliable memory-augmented LLM systems.

## 2. 方法论：核心思想与关键技术

### 2.1 评估框架（分析层面）
论文首先构建了一个**三层分析框架**来刻画记忆系统的行为：
- **Layer 1 — 答案暴露与标签一致性**：将检索到的记忆回溯到原始训练记录，判断是否包含与测试答案匹配的来源（答案匹配源暴露 \(A_i\)）。
- **Layer 2 — 信息保留**：在答案匹配源被检索到的条件下，检查参考答是否仍以完整词形式显式保留在记忆文本中（针对 RiTeK 任务）。
- **Layer 3 — 证据相关性**：用独立 LLM 评估器（Qwen3-30B，temperature=0）将测试问题—来源对分类为 **same fact / related / unrelated**，并用 BGE-M3 计算语义相似度；临床任务则用诊断码 Jaccard 相似度。

### 2.2 HMRU：混合记忆检索与利用框架（免训练）
HMRU 是一个**不更新模型参数**的推理期框架，核心思想是**同时增强证据可访问性与任务感知利用**。

**关键技术组件**：
- **混合检索**：稠密检索（dense）∪ BM25 词法检索，互补语义与词面证据。
- **交叉编码器重排序**：对候选记忆按 query–memory 相关性精排。
- **任务感知上下文构造**：将任务描述、重排后的记忆、当前问题、任务特定利用指令拼接为提示。

**核心公式（文字说明）**：
- 检索公式：\(\mathcal{M}^*(q) = \text{TopK}_{m \in \mathcal{R}_{dense}(q) \cup \mathcal{R}_{BM25}(q)} \; s_{cross}(q, m)\)，即对稠密与 BM25 检索并集按交叉编码器得分取 Top-K。
- 上下文构造：\(C_t(q) = [D_t; R(\mathcal{M}^*(q)); q; I_t]\)，其中 \(D_t\) 为任务描述，\(I_t\) 为证据利用指令，\(R\) 为记忆表示方式；最终预测 \(\hat{y} = f_\theta(C_t(q))\)。
- 紧凑记忆表示（HMRU-C）：\(R_{compact}(m_i) = [\text{Input}(m_i); \text{Answer}(m_i); \text{Context}(m_i)]\)。

**四种配置**：
- **HMRU-R**：混合检索 + 交叉编码器重排序（仅增强证据选择）。
- **HMRU-I**：在 R 基础上加入**任务感知利用指令**（如生物医学 QA 强调实体—关系一致性、保留实体拼写；临床预测强调风险因素与结局患病率）。
- **HMRU-C**：在 I 基础上采用**紧凑记忆表示**（去除关键词、标签、时间戳等辅助元数据）。
- **HMRU-T**：面向长期对话，将检索记忆按**会话时间顺序重组**并引入结构化状态跟踪（THREAD / PROFILE / UPDATES）。

## 6. 主要结论与发现

### 6.1 四项核心发现
1. **检索到证据 ≠ 正确利用**：答案匹配源可用时准确率 77–88%，缺失时仅 12–16%；但即使检索到答案源，错误仍持续存在，且错误预测常与检索记忆中的答案**完全匹配**（RiTeK-ADInt 约 16–21%，PharmKG 约 24–29%），提示**竞争性证据干扰**。
2. **语义相似 ≠ 结局相似**：TCGA-Reports 上同类别检索富集 lift > 15，但 MIMIC-III 死亡/再入院预测的标签富集弱且不一致——语义近邻检索适合事实/诊断类别识别，但**不足以支撑前瞻性风险预测**。
3. **迭代记忆演化可能偏离来源**：A-MEM 中来源不支持上下文的比例在 MIMIC-IV OOD 从 12% 升至 44%，RiTeK-PharmKG 从 16% 升至 35%；重写 ≥5 次的记忆不支持率高达 80%，而 MIMIC-III 两任务始终 < 2%。
4. **长期对话记忆不只取决于历史长度**：自然历史长度与 A-MEM（OR=0.42）、MemZero（OR=0.68）的准确率负相关，但**受控长度实验**（23k–48k tokens）未观察到一致退化；**证据检索完整性**才是更强关联因素（A-MEM 完整检索 QA 89.7 vs 不完整 43.2）。

### 6.2 方法性能结论
- **无单一记忆方法全面占优**：A-MEM/NaiveRAG 在知识推理较强，LightMem 在 TCGA 较强，MemZero 在死亡率（Meditron3）较强，NaiveRAG 在阿片过量（HuatuoGPT）显著领先。
- **FullContext 在长期对话中全面领先**：配对比较中 FullContext 比 A-MEM 多答对 55 题（A-MEM 独有 22 题），差距 10 个百分点（McNemar P<0.001）。
- **HMRU 效果**：
  - 生物医学 QA：HMRU-I 将 RiTeK-PharmKG F1 从 39.27 → 43.48，ADInt 从 52.94 → 57.64。
  - 临床预测：HMRU-C 死亡率 AUPRC 9.81 → 10.03；HMRU-I 再入院 AUPRC 61.91 → 62.17；但**阿片过量未改善**（基线 4.94 仍最高）。
  - 长期对话：HMRU-R 将 RealMem 完美答题率从 80.3% → 85.2%，与 FullContext（90.5%）差距从 10.2 → 5.2 个百分点（**缩小 48%**），26 题修正 / 10 题新增错误（McNemar P=0.011）。
  - 总体：平均相对提升 **8.6%**，对话答案错误减少 **24.9%**。

## 7. 优点

- **问题定义清晰且具有现实意义**：首次系统性地将“代理记忆”置于生物医学场景下，从有效性、检索质量、保真度、鲁棒性四个维度联合评估，填补了评估空白。
- **多层次分析框架**：三层分析（答案暴露 → 信息保留 → 证据相关性）将“检索失败”与“利用失败”解耦，机制解释力强。
- **受控实验设计精巧**：通过**会话级删除/重排**分别操纵历史长度与证据距离，在保持证据完整的前提下分离变量，方法学上较严谨。
- **信息保真度分析新颖**：追踪 A-MEM 迭代重写与来源

与来源记录的一致性，揭示迭代压缩/改写带来的信息漂移风险，这是以往记忆系统评估中较少被量化的维度。

- **训练无关、即插即用**：HMRU 不修改模型参数，仅通过检索增强与提示构造即可叠加到现有记忆系统之上，工程落地成本低，便于在不同机构、不同模型间迁移。
- **结论具有反直觉价值**：明确指出“更大记忆库/更长上下文/更高语义相似度”并不自动带来更好结果，纠正了记忆系统设计中若干默认假设，对后续研究具有指导意义。

### 8.5 方法层面

## 9. 启示与实践建议

### 9.1 对记忆系统设计者
- **优先优化检索召回与重排，而非单纯扩大记忆容量**：检索完整性是与正确率关联最强的因素之一。
- **显式给出证据使用指令**：任务感知的利用提示（HMRU-I）能以极低代价带来稳定提升，说明“如何用记忆”与“能否取到记忆”同等重要。
- **谨慎对待迭代重写/压缩**：重写次数越多，来源不支持率越高；建议保留原始证据锚点、限制重写层数、引入来源回溯校验。
- **长期对话中避免过度摘要化**：FullContext 在长期对话中领先，提示“原始证据保留 + 精准检索”可能优于“激进压缩 + 结构化笔记”。

### 9.2 对评估方法学
- 建议采用**三层解耦评估**（答案暴露 → 信息保留 → 证据相关性），以区分检索失败与利用失败。
- 建议引入**受控扰动实验**（会话级删除/重排）分离“历史长度”与“证据距离”等混淆变量。
- 建议报告 LLM 评判器与人工标注的一致性指标，并对关键结论做人工抽样复核。

### 9.3 对临床落地
- 语义相似检索适合**事实性问答与诊断类别识别**，但不宜直接作为**前瞻性风险预测**的唯一证据来源；风险预测需结合结构化特征、时间序列与人群先验。
- 需建立记忆内容审计机制，防止演化过程中出现与原始病历不一致的“记忆幻觉”。

---

## 10. 总体评价

BioMem 的核心贡献不在于提出一个更强的记忆架构，而在于**建立了一套面向生物医学智能体的记忆系统评估范式**，并通过大规模、多模型、多任务的实证揭示了三类关键失配：**检索到 ≠ 用得上**、**语义近 ≠ 结局近**、**记得久 ≠ 记得准**。其 HMRU 框架作为免训练的推理期增强方案，验证了“检索质量 + 利用指令 + 紧凑表示”组合的有效性与边界（平均相对提升 8.6%，长期对话差距缩小约 48%，但临床风险预测与极稀缺正例场景收益有限）。

论文的不足主要集中在因果推断、统计效力、评判器效度与基线覆盖四个方面，但这些不足更多是**评估型研究的共性挑战**，而非致命缺陷。整体而言，该工作为生物医学 LLM 智能体的记忆系统研究提供了可复用的分析框架、可复现的实验设置与具有实践指导价值的负面发现，是该方向上一项定位清晰、方法扎实的基础性工作。
