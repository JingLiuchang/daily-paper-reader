## 摘要
在日益复杂的现实应用驱动下，检索增强生成（RAG）已从文本流水线演进到多模态场景，涵盖两个互补维度：知识组织与检索增强。然而，现有方法仍面临构建成本高、上下文窗口受限，以及离线与在线知识源之间缺乏统一训练等挑战。为解决这些挑战，我们提出 MMGraph-Agent，一个基于缓存启发式多模态知识超图的统一多模态 RAG 框架。MMGraph-Agent 能够以零 API 成本实现极其轻量的超图构建，并支持基于动态记忆的检索，从而缓解长上下文问题。在离线、在线及联合检索设置下的实验表明，其在性能、效率和架构统一性方面均取得一致提升。我们的软件和数据公开于 https://github.com/LHRLAB/MMGraph-Agent。

## Abstract
Driven by increasingly complex real-world applications, Retrieval-Augmented Generation (RAG) has evolved from textual pipelines to multimodal settings, comprising two complementary dimensions: knowledge organization and retrieval enhancement. However, existing methods still face challenges of high construction cost, context window limitations, and the lack of unified training across offline and online knowledge sources. To address these challenges, we propose MMGraph-Agent, a unified multimodal RAG framework based on cache-inspired multimodal knowledge hypergraphs. MMGraph-Agent enables extremely lightweight hypergraph construction with zero API cost and dynamic memory-based retrieval that alleviates long-context issues. Experiments across offline, online, and joint retrieval settings demonstrate consistent improvements in performance, efficiency, and architectural unification. Our software and data are publicly available at https://github.com/LHRLAB/MMGraph-Agent.
