## 摘要
向量数据库依赖分层可导航小世界（HNSW）索引进行相似性搜索，但仅由数据构建的图可能与偏斜或变化的查询工作负载匹配不佳。我们提出 REWEAVE（Reward-Guided Rewiring of Vector Graphs，奖励引导的向量图重连），一种在线索引维护方法，它从查询反馈中学习边的效用，并在原始每节点度数上限内定期重连底层。该方法支持稀疏的精确近邻反馈与自标签相结合，并且在禁用自适应后，可进行标准 HNSW 服务而无需学习开销。在明确假设下，我们证明了价值估计和图稳定化保证。在平稳偏斜下，REWEAVE 相比 HNSW 将留出召回率最多提高 23.3 个百分点。在与查询感知基线在多达 1 亿个向量上的比较中，它在 recall@100 为 0.80 时达到 NGFix 查询吞吐量的最高 3.3 倍。在存在查询漂移的 Amazon-ESCI 上，它将流式 recall@100 从 0.745 提高到 0.979，同时搜索距离计算次数比冻结的 HNSW 少 34%。这些结果展示了在现有图度数预算内提高检索质量并减少搜索工作量的潜力，同时在自适应期间会产生额外工作。

## Abstract
Vector databases rely on Hierarchical Navigable Small World (HNSW) indexes for similarity search, but a graph built from data alone can be poorly matched to a skewed or changing query workload. We present REWEAVE (Reward-Guided Rewiring of Vector Graphs), an online index-maintenance method that learns edge utility from query feedback and periodically rewires the bottom layer within the original per-node degree cap. The method supports sparse exact-neighbor feedback combined with self-labels, and standard HNSW serving without learning overhead once adaptation is disabled.   Under explicit assumptions we prove value-estimation and graph-stabilization guarantees. Under stationary skew, REWEAVE improves held-out recall by up to 23.3 percentage points over HNSW. In comparisons with query-aware baselines on up to 100M vectors, it achieves up to 3.3x NGFix's query throughput at recall@100 of 0.80. On Amazon-ESCI with query drift, it increases stream recall@100 from 0.745 to 0.979 with 34% fewer search distance computations than frozen HNSW. These results illustrate the potential to improve retrieval quality and reduce search effort within an existing graph-degree budget, while incurring additional work during adaptation.

## 1. 核心问题与研究背景

- **核心问题**：HNSW 等图索引通常只依据向量数据构建，但真正决定“哪些边有用”的是查询工作负载。当查询分布偏斜（集中在少数主题/区域）或随时间漂移时，语料构建的图会把有限的每节点出度预算浪费在很少被遍历的边上，导致召回下降或搜索距离计算增多。
- **研究动机**：向量数据库、RAG、推荐、相似连接等场景广泛依赖 ANN 图索引；查询负载与索引数据往往不匹配。已有工作或只调整入口点、或离线构建查询感知图、或只在现有边中选择、或增量修复图，但**没有在固定度数预算内在线变更图拓扑，并给出相对显式预算内基准的 regret 保证**。
- **整体含义**：论文提出 REWEAVE，把“图导航”建模为在线学习问题，用查询反馈学习边效用，在原始度数上限内周期性重连第 0 层，使图逐步匹配查询工作负载；适配结束后可退回标准 HNSW 服务，不再有学习开销。

## 2. 方法论

### 2.1 核心思想
- 每条出边 `(u,v)` 视为一个可选择的“搜索动作”，其奖励反映该边在当前查询上的有用性。
- 学习器在服务查询的同时：选择搜索路径 → 根据反馈给边打分 → 更新边价值估计 → 收集候选边 → 周期性重连。
- 仅适配第 0 层；上层仍按距离路由，并为训练游走提供入口。

### 2.2 五步在线循环
1. **导航（Step 1）**：从上层下降得到入口，沿第 0 层选择“严格更接近查询”的出边，最多接受 `H` 条边。
   - 支持 `ε-greedy`：以概率 `ε_t = min{1, c_ε/√t}` 随机排序，否则按分数排序。
   - 支持 UCB：按 `Q̂_{t-1}(e) + sqrt(2 log(t∨2)/N_{t-1}(e))` 排序，未观测边指数为 `+∞`。
   - 可选 beam 导航（宽度 `W`、分支因子 `b`），同时探索多条路径以收集更多反馈。
2. **奖励分配（Step 2）**：
   - **Endpoint 奖励**：边目的地属于真实 top-k 则为 1，否则为 0。
   - **Recall 奖励**：将本次搜索的 recall@k 赋给所有被遍历边，可奖励中间步骤。
   - **MC(γ)/TD(γ) 信用**：用折扣回报把后续成功回传给上游边；TD 使用 bootstrap 目标。
3. **价值估计（Step 3）**：
   - Running mean：`Q̂_t(e) = Q̂_{t-1}(e) + (Y_t(e) - Q̂_{t-1}(e))/(N_{t-1}(e)+1)`。
   - 漂移场景使用时间折扣：维护折扣奖励和 `S^λ` 与折扣计数 `N^λ`，`Q̂^λ = S^λ/N^λ`，遗忘时间尺度约 `O(1/(1-λ))`。
4. **候选生成（Step 4）**：
   - **邻居缓冲 `B_nn`**：LRU 保存访问节点上反馈邻居集 `L(q)` 中的候选。
   - **漏检邻居缓冲 `B_miss`**：精确反馈下，把真实 top-k 中未被搜索检查到的最近邻作为候选注入。
   - 候选池 `P_t(u) = N_out,t(u) ∪ B_nn,t(u) ∪ B_miss,t(u)`，容量 `C ≥ M`，包含现有出边。
5. **预算保持重连（Step 5）**：
   - 每 `B` 个查询，对每个节点合并当前出边与两个候选缓冲，按边分数排序，保留 top-`M` 作为新出边；平局按到节点距离、再按 ID 打破。
   - 出度上限始终为 `M`，不增加存储或度数预算。

### 2.3 反馈模式
- **精确反馈**：`L(q) = N_k(q)`，可提供真实 top-k 和漏检候选。
- **自反馈**：`L(q) = A(q)`，复用搜索自身返回结果作为标签，降低成本但有偏。
- **两率混合**：每个查询以概率 `p` 使用精确反馈，否则使用自反馈；精确标签还可填充 `B_miss`。

### 2.4 理论保证
- **假设 1**：每条被评估边的条件均值围绕固定参考值 `θ_r(e)` 的波动不超过 `κ`。
- **假设 2**：选择边际 `Δ_set > 2κ`、导航边际 `Δ_nav > 2κ`，保证参考排序可被有限样本区分。
- **假设 3**：比较宇宙中每条边被无限次评估、统计量跨重连/驱逐保留、参考边最终可用。
- **Theorem 1（UCB 导航）**：`|Reg(T)| ≤ H·D_T + O(K log(T∨2)/g²_nav)`，其中 `D_T` 是图失配查询数；路由学习成本为对数级。
- **图稳定化**：在假设 1–3 下，批量 top-M 重连几乎必然最终稳定到 value-greedy 参考图 `G†`。
- **混合反馈恢复精确参考图**：若 `2[κ_p + (1-p)b_label] < Δ_ex,set`，则稀疏精确反馈可让图稳定到精确参考图。
- **漂移扩展**：折扣 UCB 在变化预算 `Υ_T` 下给出 `Õ(√((Υ_T+1)T))` 的动态 regret 路由项。
