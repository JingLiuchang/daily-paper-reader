## 摘要
长期航天器自主性要求具身智能体在通信延迟、时间关键操作、环境不确定性、复杂物理交互、功率与计算约束以及安全性和可靠性要求下利用运行历史。我们提出 AstroMemBench 以及一种场景—挑战—能力（Scenario-Challenge-Capability）设计方法，将上述需求映射为可执行的记忆测试。该基准涵盖行星表面作业、在轨服务和深空探索中的九项任务，通过 140 个模板和 2240 个实例覆盖 16 个记忆子挑战。确定性环境根据任务完成、状态变化、安全性和资源使用对动作进行评分。九种条件下的消融实验表明，该基准对智能体恢复和使用历史信息的准确程度以及记忆系统设计差异具有敏感性。主实验比较了六种配置。Mem0、Chain-of-Memory、LightMem 和检索增强生成（RAG）相比原生 Pi Agent 提升了同会话平均得分，但三种记忆系统相对于 RAG 没有明显优势。在会话重启后，Mem0 比 RAG 高 12.25 分。收益更多体现在指令保持和结果复用上，而非持续状态跟踪和能量预留。AstroMemBench 支持具身航天器智能体记忆系统的设计、开发和选择。AstroMemBench 1.0 及其评估代码已公开：https://github.com/flyingView/AstroMemBench-v1。

## Abstract
Long-term spacecraft autonomy requires embodied agents to use operational history under communication delays, time-critical operations, environmental uncertainty, complex physical interactions, power and computational constraints, and safety and reliability requirements. We introduce AstroMemBench and a Scenario-Challenge-Capability design method that maps these requirements to executable memory tests. The benchmark covers 16 memory subchallenges through 140 templates and 2240 instances across nine tasks in planetary surface operations, on-orbit servicing, and deep-space exploration. A deterministic environment scores actions for task completion, state changes, safety, and resource use. Ablations under nine conditions show that the benchmark is sensitive to how accurately agents recover and use historical information and to differences in memory-system design. Main experiments compare six configurations. Mem0, Chain-of-Memory, LightMem, and retrieval-augmented generation (RAG) improve same-session mean scores over native Pi Agent, with no clear advantage of the three memory systems over RAG. After a session restart, Mem0 outperforms RAG by 12.25 points. Benefits favor instruction retention and result reuse over ongoing state tracking and energy reservation. AstroMemBench supports the design, development, and selection of memory systems for embodied spacecraft agents. AstroMemBench 1.0 and its evaluation code are publicly available: https://github.com/flyingView/AstroMemBench-v1.

## 3. 实验设计与评测框架

- **评测对象**：论文将 AstroMemBench 定位为记忆系统的领域专用测试平台，评测对象包括原生智能体配置与多种代表性记忆增强方案（如检索增强、长期记忆管理、分层记忆/压缩记忆等）。其目的不是比较单一模型能力，而是在相同环境、相同历史与相同动作空间下，隔离“记忆机制”对具身航天任务表现的影响。
- **评测流程**：智能体读取只读历史、当前公开观察与动作菜单，通过工具提交动作；环境依据模板中的状态转移规则执行动作，返回观察与反馈，并在终止时按任务完成、状态变化、安全条件与资源后果给出分数。该流程强调依赖历史的决策，而非一次性问答。
- **核心指标**：
  - **平均得分与满分率**：平均得分反映整体任务表现，满分率反映严格完成全部评分条件的能力。
  - **头部归一化增益 \(G\)**：衡量记忆增强配置相对原生配置在接近满分区间内的有效提升，避免高分区间饱和导致差异被低估。
  - **分数效率 \(E\)**：以每十亿 token 得分衡量记忆方案的成本效益，揭示“更长上下文/更多检索”是否真正带来有效收益。
  - **分挑战与分任务分析**：按 16 个记忆子挑战和 9 项任务拆分，识别记忆机制在指令保持、状态维护、经验复用、能量预留、安全与故障恢复等维度的短板。
- **配对实例的用途**：配对实例通过仅改变关键历史事件来构造“当前请求相同、正确动作不同”的对照，用于检验智能体是否真正依赖关键历史，而非仅依据当前观察或表面模式作答；这使评测更具诊断性。

## 4. 主要发现与结果分析

- **记忆增强并非普遍有效**：整体上，记忆增强方案可能改善部分需要历史保持与经验复用的任务，但提升幅度受任务类型与记忆机制影响显著；单纯增加上下文长度或检索量并不必然转化为更高任务得分。
- **挑战维度差异明显**：相对直接的指令保持、单操作状态跟踪等挑战较易受益于显式历史注入；而故障恢复、能力更新、能量预留、跨阶段多操作状态维护等挑战更依赖对历史因果关系的正确理解与状态一致性维护，现有通用记忆方案仍存在明显不足。
- **效率—性能权衡突出**：长历史与约 70K token 级输入使 token 成本成为不可忽视的评测维度；部分方案虽获得一定分数提升，但分数效率下降，说明面向航天器的记忆系统需在有限计算、功率与通信约束下进行压缩、检索与优先级管理。
- **配对实例揭示“伪记忆”风险**：在仅关键历史不同的配对实例上，若智能体不能区分历史事件是否发生，容易出现动作选择错误；这表明仅靠语义相似检索或摘要可能丢失对任务安全至关重要的细粒度状态信息。
- **领域专用评测的必要性**：通用对话记忆基准难以覆盖航天操作中的安全前提、资源预留、下行确认、延迟任务与故障恢复等要求；AstroMemBench 的分挑战诊断能力有助于定位记忆系统在具体运行约束下的失效模式。

## 5. 贡献与创新点

- **基准贡献**：提出面向具身航天器操作的记忆评测基准 AstroMemBench，将场景、运行挑战与基础能力组织为可执行、依赖历史的任务模板。
- **方法论贡献**：提出场景—挑战—能力（SCC）三维设计法，将 ESA Technology 2040 的运行挑战细化为可测试的记忆子挑战，并建立模板—能力关联，使评测兼具领域覆盖与能力诊断性。
- **环境贡献**：构建确定性状态转移与多维评分环境，综合任务完成、状态变化、安全与资源后果，支持可复现的端到端具身评测。
- **诊断贡献**：通过配对实例、分挑战指标、归一化增益与分数效率，区分“记忆是否被使用”“记忆是否被正确使用”以及“记忆使用的成本效益”。

## 6. 局限与未来方向

- **模拟环境与真实航天差距**：基准以确定性规则模拟航天操作，虽利于可复现评测，但仍难以完全覆盖真实航天器中的传感器噪声、执行器故障、通信中断与复杂物理交互。
- **任务与挑战覆盖仍需扩展**：当前覆盖 3 类场景、9 项任务与 16 个记忆子挑战，未来可加入多智能体协同、长期在轨维护、极端故障链、动态任务重规划等更复杂情形。
- **记忆机制评测范围**：论文主要评估代表性记忆增强方案，尚未穷尽所有记忆架构；后续可引入更细粒度的消融，如历史压缩策略、检索粒度、状态摘要方式与安全约束注入机制。
- **成本与部署约束**：约 70K token 级历史输入对星载计算、存储与能耗提出挑战，未来需研究面向航天器的轻量化记忆、分层存储、事件驱动检索与可信状态校验。
- **评价函数可扩展性**：当前评分综合任务完成、状态、安全与资源后果，未来可引入不确定性下的风险度量、失败恢复时间与长期任务收益等指标。

## 7. 总体评价

AstroMemBench 的核心价值在于把“航天器记忆”从泛化的对话回忆问题转化为依赖历史、受安全与资源约束的具身决策问题，并通过场景—挑战—能力三维设计、确定性环境和配对实例提供可诊断的评测基础。其实验分析表明，通用记忆增强方案在航天操作场景中并非天然有效，关键历史事件的细粒度保持、跨阶段状态一致性与成本效率仍是主要瓶颈。该工作为航天器记忆系统的设计、选型与后续研究提供了较系统的评测框架，但其模拟环境与任务覆盖仍需在更真实、更复杂的航天运行条件下继续验证和扩展。
