Abstract
Long-video question answering requires retrieving and in-
tegrating relevant evidence from videos spanning hours or
even days. Recent agentic approaches organize video in-
formation into external memories and iteratively retrieve
evidence to answer questions. However, effective retrieval
and reasoning remain challenging, as agents must determine
what information to search for, which memory sources to ac-
cess, and how to connect evidence across distant temporal in-
tervals. To address these challenges, we propose Video Mem-
ory Skill Agent (VMSA), a framework that jointly designs
structured video memories and memory skills for long-video
understanding. VMSA constructs three complementary mem-
ory components. Segment Caption Memory and Entity Event
Memory serve as searchable evidence sources, while Entity-
Aware Episode Memory provides broad yet detailed video
context to guide evidence retrieval and reasoning. To further
support effective memory utilization, VMSA induces mem-
ory skills from successful agent trajectories, incrementally
refining or extending a compact skill library to guide itera-
tive evidence retrieval, reasoning, and verification. Across
seven long-video question-answering benchmarks, VMSA
achieves the highest accuracy on all three week-long ego-
centric benchmarks, outperforming the strongest baseline
by up to 9.4% on Ego-R1 Bench, and the best or competi-
tive performance on four additional benchmarks. Ablation
studies further demonstrate the contributions of all three
memory components and memory skills, with memory skills
also improving temporal evidence localization.
1. Introduction
Recent advances in multimodal large language models
(MLLMs) have achieved remarkable performance across
a wide range of vision-language tasks [2, 10, 29, 37]. How-
ever, understanding long videos remains challenging, par-
ticularly when videos span hours or even days [43, 53, 58].
Processing such videos directly with MLLMs incurs sub-
stantial computational overhead due to the large number of
visual tokens, which may also exceed the models’ available
context windows [14, 41]. Moreover, long videos contain
extensive information that may be irrelevant to a given ques-
tion, making it difficult for MLLMs to identify fine-grained
visual details and evidence dispersed across distant temporal
intervals that are essential for answering the question.
To address these challenges, retrieval-augmented ap-
proaches organize information extracted from videos into
searchable memories, allowing models to retrieve query-
relevant evidence without processing the entire video for
each question [22, 24, 39, 58, 63]. These approaches use var-
ious representations, such as segment captions, hierarchical
summaries, and graph-based structures, to organize video
information for retrieval. More recently, agentic approaches
have further developed various video memory structures
and incorporated iterative reasoning and tool use to sup-
port long video question answering [18, 21, 23, 38, 54, 59–
61, 68]. These agents iteratively retrieve relevant evidence
from video memories and use the retrieved information to
guide subsequent searches and reasoning.
However, providing agents with access to extensive video
memories does not necessarily ensure that they can effec-
tively retrieve and reason over relevant evidence [62]. In
long video question answering, relevant evidence may be
scattered across distant temporal intervals and multiple mem-
ory sources, making it difficult for agents to determine what
information to search for, which memory sources to access,
and how to connect retrieved evidence [25, 53]. These de-
cisions depend not only on the question but also on the evi-
dence gathered and reasoning performed in previous steps,
further complicating iterative retrieval and reasoning [17, 40].
Addressing these challenges requires more than organizing
video information into searchable memories. Agents also
need broad yet detailed video-wide context to help them de-
cide what information to search for, along with strategies to

for retrieving and reasoning over evidence. Guided by both,
the agent iteratively searches Segment Caption Memory and
Entity Event Memory and, when necessary, directly inspects
relevant segments of the source video to gather and verify
evidence before generating an answer.

video question-answering benchmarks, including three

2. Related Work
2.1. Long-Video Understanding
Recent advances in MLLMs have enabled video understand-
ing through sampled video frames [10, 29, 37]. To improve
long-video understanding, specialized models have been de-
veloped to process extended video sequences and enhance
temporal reasoning. Some approaches employ efficient vi-
sual token processing and compression [20], while others
use post-training techniques, including reinforcement learn-
ing, to improve multi-step reasoning and temporal ground-
ing [3, 8, 35, 45, 46, 50, 51, 66]. However, processing long
videos directly remains challenging due to the large number
of visual tokens and the difficulty of capturing fine-grained
evidence across distant temporal intervals.
Retrieval-augmented methods address these challenges by
organizing video information into searchable representations,
such as captions, hierarchical summaries, and knowledge
graphs [22, 24, 39, 58, 63]. These methods allow models to
retrieve relevant evidence without repeatedly processing en-
tire videos. More recently, agentic frameworks have incorpo-
rated iterative reasoning and tool use to progressively gather
and examine video evidence [18, 21, 23, 38, 54, 59–61, 68].
These approaches enable agents to adapt their searches based
on intermediate observations and reasoning, rather than rely-
ing solely on fixed retrieval procedures.
2.2. Agentic Video Frameworks
Agentic approaches to long-video understanding iteratively
gather evidence and use intermediate reasoning to guide sub-
sequent searches. Early methods employ LLMs to select
query-relevant frames or retrieve information from tempo-
ral and object memories [6, 48]. Hierarchical approaches,
such as VideoTree and VideoLucy, explore relevant video
segments through tree expansion or memory-based back-
tracking [52, 69]. More recent frameworks, including Active
Video Perception (AVP), LensWalk, VideoSeek, and Deep
Video Discovery (DVD), dynamically adjust search loca-
tions, observation scope, or temporal resolution based on
intermediate reasoning [18, 21, 54, 68].
Recent studies have also developed structured video mem-
ories to facilitate agentic retrieval and reasoning. M3-Agent
employs entity-centric memory [23], WorldMM uses multi-
scale episodic, semantic, and visual memories [59], and
EGAgent constructs entity graphs to connect evidence across
temporal intervals [38]. VideoARM and HAVEN further
integrate hierarchical memories with audio transcripts for
iterative retrieval [60, 61]. However, organizing video in-
formation into structured memories alone does not ensure
effective agentic retrieval and reasoning, as agents must de-
termine what information to search for and how to connect
evidence across multiple memory sources. Motivated by
this challenge, VMSA jointly designs complementary video
memories and a memory-skill construction framework to
guide evidence retrieval, reasoning, and verification.
3. Method
Our method, VMSA, is a long-video question-answering
agent that combines structured video memory with memory
tools and reusable skills to effectively gather evidence from
videos spanning hours to days. We first describe the construc-
tion of structured video memory in Section 3.1, followed by
the memory tools and agentic search process in Section 3.2.
We then describe the skill induction process, which extracts
reusable procedural knowledge from successful trajectories,
in Section 3.3. Finally, we explain how VMSA iteratively
gathers evidence and generates answers at inference time in
Section 3.4. Figure 1 provides an overview of our method.
3.1. Structured Video Memory
Our structured video memory consists of three levels: Seg-
ment Caption Memory, Entity Event Memory, and Entity-
Aware Episode Memory. In this section, we describe each
memory component and its construction process, with fur-
ther implementation details provided in Appendix B.1.
3.1.1. Segment Caption Memory
Segment Caption Memory consists of detailed captions of
video segments and their corresponding temporal ranges.
To construct this memory, we first divide a long video into
short temporal segments. For each segment si, we uniformly
sample frames and provide them to a memory-construction
vision-language model (VLM) to generate a caption Ci.
Each caption describes the visual content of the segment, in-
cluding participants, objects, actions, interactions, and state
changes. The resulting memory is defined as

3.1.2. Entity Event Memory
Entity Event Memory consists of entities and their associ-
ated events, each describing an activity, interaction, or state

change involving an entity. To construct this memory, we
progressively merge entity profiles within and across sliding
temporal windows, then consolidate their associated events.
Specifically, for each video segment si, the memory-
construction VLM extracts local entity profiles from uni-
formly sampled frames, where each profile records observ-
able attributes, actions, relations, and state changes. Within
each sliding temporal window, we construct a mutual-kNN
graph [44] over profile embeddings to identify candidate
groups of profiles referring to the same entity. The VLM ver-
ifies these groups and merges profiles referring to the same
entity by aggregating their attributes. This merging process
is periodically repeated across profiles accumulated from
previous windows, followed by a final video-level merging
pass, yielding Ne entities.
For each resulting entity Ek, we consolidate descriptions
of the same continuing event by removing duplicates and
extending its temporal range to cover all supporting observa-

3.1.3. Entity-Aware Episode Memory
Entity-Aware Episode Memory consists of a global video
summary and entity-aware episodes that connect related ob-
servations of the same entity across temporally dispersed in-

adjacent Segment Captions describing the same ongoing
activity or interaction into local episodes. The memory-
construction VLM then uses Entity Events to identify lo-
cal episodes involving the same entity and merges seman-
tically related episodes across different temporal intervals
into entity-aware episodes. Finally, the VLM generates a
global video summary using all the entity-aware episodes.

3.2. Search and Verification Tools
Our video agent iteratively gathers and examines evidence
using tools that operate over structured video memory and
the source video. While Entity-Aware Episode Memory is in-
cluded in the agent’s initial context, Segment Caption Mem-
ory and Entity Event Memory are accessed through search
tools, and the source video is directly inspected through
a verification tool when further verification is needed. In
this section, we describe these three tools, with retrieval
equations and additional details provided in Appendix B.3.
Caption Search. Caption Search retrieves segment captions
and their temporal ranges from Segment Caption Memory.
The agent formulates a search query based on the question
and accumulated evidence. Using embedding-based retrieval,
the tool identifies query-relevant segment captions and re-
turns them with their corresponding temporal ranges. The
retrieved captions provide fine-grained visual descriptions,
while their temporal ranges indicate candidate intervals for
further inspection.
Entity Event Search. Entity Event Search retrieves entity-
related evidence from Entity Event Memory. The agent
formulates a query specifying a target entity and relevant
event information. Using embedding-based retrieval, the
tool identifies relevant events and returns their descriptions,
supporting temporal ranges, and associated entity profiles.
This allows the agent to retrieve observations of the same
entity across temporally distant intervals.
Segment Inspection. Segment Inspection examines visual
details directly from the source video when evidence re-
trieved from structured video memory is insufficient. The
agent formulates a verification query specifying the informa-
tion to examine and selects relevant temporal intervals for
inspection. The tool inspects video frames within these inter-
vals and returns observations that help resolve uncertainties
or verify candidate interpretations.
3.3. Memory Skills
We induce memory skills from successful agent trajectories
to guide the agent’s iterative reasoning and tool use across
multiple memory sources and the source video. Each skill
provides structured guidance on when to apply it, how to
retrieve and verify evidence, what information to retain, how
to reason over accumulated evidence, when to terminate the
search, and what common mistakes to avoid. To construct a
skill library, an induction LLM sequentially processes suc-
cessful trajectories, assessing whether the procedural knowl-
edge from each trajectory is already covered by existing
skills and refining existing skills or adding new ones as
needed. The memory-skill template and an example of an
4


induced skill are provided in Figure 4 of Appendix B.4, with
further details provided in Appendix B.4.
Collecting Successful Trajectories. To encourage general-
ization, we collect successful trajectories from source video
benchmarks separate from those used for evaluation. We
run the agent on these benchmarks using structured video
memories and the search and verification tools, retaining
trajectories whose final predictions are correct. For each
successful trajectory, we preserve the agent’s reasoning and
tool calls while omitting raw tool results to reduce context
length.
Incremental Skill Library Update. Starting from an empty
skill library P0 = ∅, we process successful trajectories
sequentially. At step i, the induction LLM receives the i-th
successful trajectory ξi and the current library Pi−1, and
updates the library as follows:
Pi = Induce (ξi, Pi−1) ,

where Induce(·) denotes the library-update operation per-
formed by the induction LLM. The LLM assesses whether
existing skills cover the retrieval, reasoning, and verification
procedures demonstrated in the trajectory. If they do, the
library remains unchanged. Otherwise, the LLM refines an
existing skill or adds a new one, depending on whether the
missing procedural knowledge can be incorporated into an
existing skill. Throughout this process, trajectory-specific
information is abstracted away to extract transferable proce-
dures that generalize across queries and videos.
Periodic Skill Library Consolidation. After every 100 pro-
cessed trajectories, the induction LLM is prompted to reduce
redundancy in the library by merging skills that capture the
same underlying procedure. The resulting skill library P is
used during evaluation on the target benchmarks.
3.4. Skill-Guided Agentic Search
At inference time, the agent retrieves the top-Ks query-
relevant memory skills from the induced skill library P
using embedding-based similarity. The agent receives the tar-
get question, retrieved memory skills, and the entire Entity-
Aware Episode Memory as its initial context. Guided by this
context, the agent iteratively reasons about the question and
invokes Caption Search, Entity Event Search, or Segment
Inspection as needed to gather evidence and verify candidate
claims. At each iteration, the agent incorporates the tool
observations into its accumulated context and determines
whether further evidence is needed. This process continues
until the agent decides that sufficient evidence has been col-
lected to generate a final answer or reaches the maximum
number of iterations. Figure 6 in the Appendix provides a
qualitative example of VMSA’s inference process, includ-
ing query-relevant memory skill retrieval, iterative evidence
gathering and reasoning through search and verification tools,
and final answer generation.
4. Experiments
4.1. Experimental Setup
Benchmarks. We evaluate VMSA on seven multiple-choice
long-video question-answering benchmarks covering di-
verse video domains, durations, and question types. The
three week-long egocentric benchmarks are EgoLifeQA [58],
Ego-R1 Bench [43], and EgoMemReason [53], which con-
tain egocentric videos recorded over seven days, with an
average of 44.3 hours of footage per participant.
The
other four benchmarks are Video-MME (long split) [9],
LongVideoBench (long split) [56], LVBench [47], and Hip-
poVlog [22], with average video durations ranging from
approximately 24 to 67 minutes. Together, these bench-
marks assess VMSA’s ability to identify fine-grained visual
details, locate relevant events, and retrieve and integrate evi-
dence across different temporal intervals to answer questions.
The week-long egocentric benchmarks provide a particularly
challenging setting due to their substantially longer videos.
Benchmark statistics, including the number of source videos
or participant streams, the number of questions, and average
video durations, are provided in Appendix A.

Implementation Details.
For structured video memory
construction, we use Qwen3.5-9B [36] as the memory-
construction VLM, dividing videos into 60-second seg-
ments for the three week-long egocentric benchmarks and
16-second segments for the remaining four benchmarks.
To reduce computational cost for the week-long egocen-
tric benchmarks, we reuse the segment captions released
5


by WorldMM [59] instead of generating new ones. For
memory skill induction, we use GPT-5.6 [32] as the induc-
tion LLM and collect successful agent trajectories without
memory-skill guidance. To evaluate the transferability of
the induced skills across benchmarks, we construct sepa-
rate skill libraries using trajectories from benchmarks out-
side each target evaluation group. Specifically, the library
for the week-long egocentric benchmarks is constructed
from ScaleLong [25], VideoOdyssey-V [15], Video-MME,
LongVideoBench, LVBench, and EgoSchema [26], while
the library for the remaining four benchmarks is constructed
from ScaleLong and VideoOdyssey-V. For skill-guided agen-
tic search, we use Qwen3.6-27B [37] as the agent model,
retrieve the top-Ks = 3 query-relevant memory skills, and al-
low up to 10 iterations per question. To reduce inference cost,
we disable Segment Inspection for the week-long egocentric
benchmarks. Further details are provided in Appendix B.

the three memory components serve complementary roles

5.2. Effect of Memory Skills
We evaluate the effect of memory skills on temporal evidence
localization and answer accuracy by comparing VMSA with
and without memory skills.
For benchmarks providing
ground-truth evidence intervals, we compute temporal In-
tersection over Ground Truth (tIoG) and Intersection over
Union (tIoU) between the temporal intervals observed by the
agent at each iteration and the annotated evidence intervals.
We calculate average best-turn tIoG and tIoU by selecting
the highest value across iterations for each question and then
averaging across questions.
As shown in Table 5, memory skills consistently improve
tIoG across all four benchmarks, while also improving tIoU
to a lesser extent. These results suggest that memory skills
help the agent cover a greater proportion of ground-truth evi-
dence without merely expanding the observed temporal in-
tervals to include irrelevant content. These improvements in
temporal evidence localization may help explain the higher
answer accuracy achieved with memory skills across all four
benchmarks. Additional answer accuracy results for bench-
marks without ground-truth evidence intervals are provided
in Table 15 of the Appendix.

5.4. Analysis of Search-Turn Budget
We examine how the maximum search-turn budget affects
VMSA’s answer accuracy. Table 26 shows that increasing
the budget from 3 to 7 turns improves accuracy on all three
benchmarks. The gains saturate at 7 turns on LVBench and
Video-MME (L). On LongVideoBench (L), accuracy im-
proves at every budget increase, rising from 62.8% at 3 turns
to 71.1% at 7 turns and 74.1% at 10 turns. VMSA uses an av-
erage of 4.60 turns per question on LongVideoBench (L), the
highest among the seven benchmarks, suggesting that some
questions benefit from additional turns to gather sufficient
evidence.
5.5. Effect of Agent Models
We evaluate the effect of replacing VMSA’s default agent
model with alternative models while keeping all other com-
ponents unchanged. As shown in Table 8, GPT-5 achieves
the highest accuracy across all four benchmarks. Notably,
replacing the default Qwen3.6-27B with GPT-5 improves
accuracy on Video-MME (L) from 76.1% to 77.4%, sur-
passing all baselines in Table 3. These results suggest that
VMSA can benefit from using stronger agent models while
remaining effective across different models.

ScaleLong.
ScaleLong [25] evaluates long video under-
standing at four nested temporal granularities: clip, shot,
event, and story. Questions at all four scales are constructed

questions over 263 valid videos. We report overall accuracy
and the per-granularity breakdown in Table 21.

VideoOdyssey [15] evaluates ultra-long

B. Implementation Details
B.1. Structured Video Memory Construction
We use Qwen3.5-9B as the memory-construction VLM for
segment captioning, local entity profile extraction and merg-
ing, Entity Event consolidation, and Entity-Aware Episode
construction. Segment captions, entity profiles, events, and
episodes retain their supporting temporal ranges.
Dense segment captioning.
For the week-long egocen-
tric benchmarks, we use 60-second segments and populate
Segment Caption Memory with the captions released with
WorldMM [59]. For all other benchmarks, we divide each
video into 16-second segments with a 12-second stride, yield-
ing a 4-second overlap between consecutive segments. The
memory-construction VLM generates a caption for each
segment from uniformly sampled frames using a four-shot
prompt. We preserve the aspect ratio of each frame and limit
its area to 524,288 pixels (0.52 MP), corresponding to an
upper bound of approximately 256 visual tokens per frame.
Local entity profile extraction.
For each segment, the
memory-construction VLM extracts local entity profiles
from uniformly sampled frames. Each profile follows a fixed
schema that records observable attributes, actions, relations,
and state changes together with their supporting temporal
range. For the week-long egocentric benchmarks, the VLM
also receives the corresponding segment caption as input.
Entity profile merging.
We progressively merge profiles
that refer to the same entity within and across sliding tem-
poral windows. Each window contains up to 32 consecutive
segments. Within a window, we construct a mutual-kNN
matching over profile embeddings with k = 6 to identify can-
didate groups. We directly merge high-confidence matches
with cosine similarity above 0.85. For the remaining groups,
the memory-construction VLM verifies which profiles refer
to the same entity and merges them by aggregating their
attributes. We repeat this process on the accumulated pro-
files after every four windows. After processing the sliding
windows, we perform three final video-level merging passes.
Entity Event consolidation.
For each resulting entity
Ek, we order its segment-level descriptions by time. The
memory-construction VLM consolidates repeated descrip-
tions of the same ongoing event and extends its temporal
range to cover the supporting observations. It starts a new
event when the observations indicate a substantive change in
the action, participants, relation, scene, or entity state. Each
Entity Event ek,j consists of an event description and its
supporting temporal range.
Entity-Aware Episode construction.
Within each 1,200-
second sliding window, we group adjacent segment cap-
tions that describe the same ongoing activity or interaction
into non-overlapping local episodes. For each entity Ek,
we select candidate local episodes whose temporal ranges
overlap at least one of its Entity Events. When the candi-
dates span disjoint intervals, the memory-construction VLM
checks each episode for observations of the entity’s activ-
ities, states, or interactions. It orders the verified episodes
chronologically and merges those that describe semantically
related observations of the entity. Each resulting entity-
aware episode preserves the relevant participants and inter-
actions and records disjoint supporting intervals separately.
We retain unmerged local episodes as standalone episodes.
Finally, the VLM generates a global video summary from
the entity-aware episodes.
Post-hoc correction of entity profiles.
After profile merg-
ing, Qwen3.6-27B reviews the resulting profiles for over-
merging and under-merging. It corrects over-merging by
separating local profiles that refer to different entities and
corrects under-merging by combining profiles that refer to
the same entity. Section B.2 reports a model-based assess-
ment of profile merging on ScaleLong and VideoOdyssey-V.

C. Evidence Retrieval and Temporal Ground-
ing
We evaluate the temporal grounding of VMSA’s search using
temporal Intersection-over-Ground Truth (tIoG) and tempo-
ral Intersection-over-Union (tIoU). For each tool turn, we
compare the union of retrieved temporal ranges with the
union of ground-truth intervals. tIoG divides the duration
of their intersection by the total ground-truth duration and
measures evidence coverage. tIoU divides the same inter-
section duration by the duration of their union, measuring
overlap between the retrieved and ground-truth intervals.
We use these metrics to examine whether better-grounded
trajectories are associated with more accurate answers.
C.1. Temporal Grounding and Answer Accuracy
We examine the association between evidence coverage
and answer accuracy by grouping trajectories according to
whether their best-turn tIoG exceeds 0.5 (Table 12). The
group with tIoG greater than 0.5 achieves answer accuracy
that is 3.6%, 9.1%, and 13.1% higher on LVBench, Scale-
Long, and VideoOdyssey-V, respectively.

Memory-skill template. Each retrieved memory skill contains a procedure name, trigger, ordered steps, an evidence memory checklist,
a reasoning template, a stop rule, and an avoid list. A representative memory skill is shown below.
TopicIntervalLocalization (temporal localization)
Trigger. Use when asked for the start and end time of a topic, event, or
discussion whose core material must be localized within a segmented
long video.
Steps.
1. Expand the target into exact terms, abbreviations, synonyms, precursor
events, characteristic imagery, and closing events.
2. Search from specific phrases to broader associated cues until at least
one high-confidence core segment is found.
3. Use Segment Inspection to move backward from the hit to the first
segment substantially about the target and forward to the last contigu-
ous core segment before the topic changes.
4. Classify boundary evidence as introduction, core discussion, continu-
ation, incidental mention, or transition so peripheral references do not
widen the interval.
5. Bracket both sides with neighboring non-target content and preserve
uncertainty when the topic begins or ends within a segment.
6. Convert segment bounds to clock time using the actual segment du-
ration, indexing origin, and end-bound convention, and check the
arithmetic.
7. Compare candidate ranges by overlap with the verified core span and
reject ranges centered on precursor or adjacent topics.
Stop rule. Stop when both topic boundaries are bracketed by neighbor-
ing non-target content, the segment-to-time mapping and arithmetic are
checked, boundary uncertainty is recorded, and only one candidate range
adequately covers the contiguous core interval.
Evidence memory.
• Search vocabulary grouped as exact term, abbreviation, synonym, pre-
cursor, characteristic visual cue, and closing cue.
• Verified first core segment, last core segment, and neighboring non-target
segments that bracket the interval.
• Classification of each inspected segment as introduction, core discussion,
continuation, incidental mention, or transition.
• Segment duration, indexing origin, start-bound formula, end-bound
formula, and partial-segment uncertainty.
• Overlap of each candidate range with the verified core interval.
Reasoning template.
1. Searches locate the target’s core material near <candidate
region>; backward and forward Segment Inspection calls establish
contiguous bounds <first> through <last>.
2. Neighboring segments contain <non-target content>, so pre-
cursor and retrospective mentions are excluded from the core interval.
3. Using
segment
duration
<duration>
and
indexing
origin
<origin>, convert the verified bounds with <formulas>; select
the range that covers the core span and excludes adjacent topics.
Avoid. Do not stop after one failed exact-phrase search; equate a precursor,
incidental mention, or retrospective reference with the contiguous core
interval; mix one-based labels with zero-based time calculations; report
precise clock bounds without checking duration, indexing origin, end-
bound convention, and partial-segment uncertainty; or choose a range
merely because it touches the topic while being centered on adjacent
content.

Input. The current skill library and successful source trajectories.
Assess each trajectory against the current library. Consider it covered only if existing
skills specify its information-need decomposition, memory and tool selection, evidence
retention, reasoning or verification, and stopping decisions.
For covered trajectories, identify the skills that provide coverage. For an uncovered
trajectory, explain the missing procedural knowledge and propose either a revision of a
compatible skill or a new skill for a distinct procedure. Use the shared skill template for
both operations.
Abstract reusable procedures. Exclude video-specific facts, entities, answers, answer
choices, and trajectory identifiers from skill descriptions.
Output. A coverage assessment for each trajectory and proposed library changes. Each
proposal identifies the supporting trajectories and provides either a complete revision of
an existing skill or a complete new skill record.
Library Consolidation
Input. The current skill library after incremental
induction.
Merge skills only when their trigger conditions,
retrieval and verification steps, evidence-retention

underlying procedure.
Preserve their reusable procedural knowledge when
merging, and retain skills that represent distinct
procedures.
Output. A consolidated skill library with redundant
skills merged while preserving their reusable
procedural knowledge.

F.3. Effect of Search-Turn Budget
We examine how the maximum search-turn budget affects
VMSA’s answer accuracy. Table 26 shows that increasing
the budget from 3 to 7 turns improves accuracy on all three
benchmarks. The gains saturate at 7 turns on LVBench
and Video-MME (L). On LongVideoBench (L), accuracy
improves at every budget increase, rising from 62.8% at 3
turns to 71.1% at 7 turns and 74.1% at 10 turns. VMSA also
uses more turns on average on LongVideoBench (L) than on
any other benchmark, which suggests that some questions
benefit from a larger budget to gather sufficient evidence.
