## 摘要
基于图的索引通过链接相似对象，能够在大规模数据上实现高效的近似最近邻搜索。在产品检索和租赁房源搜索等应用中，相似性取决于多个组件，而这些组件的相对重要性会随查询而变化。挑战在于：索引必须在构建阶段选择邻居，但决定哪些对象最近的查询权重尚不可知。一种直接的方法是对每个组件分别建立索引。然而，合并这些搜索的结果可能会遗漏加权距离下的最近邻。联合图允许搜索沿着跨组件的链接进行，从而有助于避免此类遗漏，但在每个组件内分别选择邻居会留下冗余边，并且保持组件层次结构同步会限制并行构建。为解决这些局限，我们提出 Skyline 联合图（SJG）。尽管查询权重会改变候选邻居的排序，但候选邻居之间的支配关系与这些权重无关。SJG 利用这一性质，跨组件汇集候选，并为每个节点保留 Skyline，从而能够在不同查询权重下实现高效的近似最近邻搜索，同时支持图的并行构建。在六个真实世界数据集上的大量实验表明，在 90% Recall@10 时，SJG 的查询吞吐量最高可达基线方法的 27.9 倍，同时将单线程索引构建速度最高提升 201 倍。其索引所需空间比最小的基线索引至少少 36%。

## Abstract
Graph-based indexes enable efficient approximate nearest neighbor search at scale by linking similar objects. In applications such as product retrieval and rental listing search, similarity depends on several components whose relative importance varies across queries. The challenge is that the index must select neighbors during construction, but the query weights that determine which objects are closest are not yet known. A straightforward approach is to index each component separately. However, merging the results of these searches can miss the nearest neighbor under the weighted distance. A joint graph allows a search to follow links across components, helping to avoid such misses, but selecting neighbors separately within each component can leave redundant edges, and keeping component hierarchies synchronized limits parallel construction. To address these limitations, we propose the Skyline Joint Graph (SJG). Although query weights can change the ranking of candidate neighbors, the dominance relation among them is independent of those weights. SJG exploits this property by pooling candidates across components and retaining the Skyline for each node, thereby enabling efficient approximate nearest neighbor search under different query weights while supporting parallel graph construction. Extensive experiments on six real-world datasets demonstrate that SJG achieves up to $27.9\times$ the query throughput of baseline methods at 90% Recall@10, while accelerating single-threaded index construction by up to $201\times$. Its index requires at least 36% less space than the smallest baseline index.

## 1. 核心问题与研究背景

- **应用背景**：产品检索、租赁房源搜索、推荐系统等场景中，对象不再是单一向量，而是由多个异构组件构成（如房源含位置、名称、价格、可住人数、设施集合；商品含图像、描述、价格），每个组件有自己的距离函数（L1/L2、编辑距离、词余弦距离、Jaccard 等）。
- **核心矛盾**：不同查询对各组件赋予不同权重（如有人重位置、有人重设施），同一数据集在不同权重下返回不同最近邻。但**图索引必须在构建阶段就选定邻居，而查询权重此时未知**。
- **现有方案的两类缺陷**：
  - **复合式（composite）方法**（Milvus 式多字段检索、Uemura 等的跨图引导）：每个组件单独建图，查询时合并结果。问题在于——某对象可能在所有单组件排序中都不靠前，却在加权距离下成为最近邻（论文图 2 中对象 C 即为例），**合并+重排无法找回这类对象**；加长候选列表又会推高遍历与重排成本。
  - **联合图 HJG**：为每个组件建层次图并**同步对应节点的层级**。问题有二：(a) 各组件内独立选边导致联合图中**冗余边**多，索引更大、搜索更贵；(b) 层级同步带来**级联更新依赖**（某节点被提升层级会触发跨图更新与邻居再提升），**难以并行构建**。
- **两大挑战**：① 在权重未知时如何选出有效邻居（不依赖固定权重、又不保留全部候选）；② 如何实现无层级同步依赖的**并行**联合图构建。
- **整体含义**：论文主张用"**支配关系与权重无关**"这一数学性质替代"固定距离函数选边"，从而一次性构建出对任意非负权重都有效的单层联合图。

## 2. 方法论

### 2.1 问题形式化
- 对象 $o=(o^{(1)},\dots,o^{(m)})$，各组件距离 $d_i$ 经**最大距离归一化**。
- 加权距离 $D_w(q,o)=\sum_{i\in I_w} w_i d_i(q^{(i)},o^{(i)})$，$w_i\ge 0$，$\sum w_i = 1$，零权重表示该组件不参与。
- 目标：返回加权距离最小的 $k$ 个对象，质量用 Recall@k 衡量。

### 2.2 核心思想
- 关键观察：权重会改变候选的**排序**，但**逐组件的支配关系不随权重改变**。若 $u$ 在每个组件上都不比 $u'$ 远，则对任意非负权重 $D_w(v,u)\le D_w(v,u')$。
- 因此可在权重未知时安全删除被支配候选，只保留 **Skyline（非支配集）**，从而兼顾"紧凑"与"对任意权重的有效性"。

### 2.3 关键技术细节

**阶段一：候选获取（Candidate Acquisition）**
- 对每个组件用 **NN-Descent** 构建近似 K-NN 图，得到邻居表 $L_i(v)$（$K$ 为组件邻居表大小，区别于查询结果数 $k$）。
- 因 K-NN 关系**不对称**，组件候选集取前向+反向邻居：$A_i(v)=L_i(v)\cup\{u: v\in L_i(u)\}$。
- 跨组件并集去重：$C(v)=\bigcup_{i=1}^{m} A_i(v)$。各组件图**完全独立构建**。

**阶段二：Skyline 联合邻居选择**
- **支配定义**：$u\prec_v u'$ 当且仅当对所有 $i$ 有 $d_i(v,u)\le d_i(v,u')$，且至少一个组件严格更近。
- **Skyline**：$S(v)=\{u\in C(v): \nexists u'\in C(v),\ u'\prec_v u\}$，作为初始邻居集。
- **命题 1（加权最小值保持）**：对任意非负权重 $w$，$\min_{u\in S(v)}D_w(v,u)=\min_{u\in C(v)}D_w(v,u)$。证明思路：任一被支配候选沿支配链必追溯到某 Skyline 候选，由传递性与权重非负性，加权距离不增。
- **最小出度补充**：若 $|S(v)|<\min(\tau,|C(v)|)$（$\tau$ 为最小出度），按**组件内排名和** $B_v(u)=\sum_i \rho_i(u)$ 升序从 $C(v)\setminus S(v)$ 补充至该阈值。
- 最终性质：$S(v)\subseteq N(v)\subseteq C(v)$，$|N(v)|=\max(|S(v)|,\min(\tau,|C(v)|))$，出度由 Skyline 规模决定而非固定上限。
- **尺度不变性**：候选获取、支配判定、排名补充只依赖各组件内的距离**序**，故组件距离的严格单调变换不改变构建结果（但查询期固定权重下的排序仍可能变）。

**算法流程（Algorithm 1）**
1. 对每个组件：NN-Descent 建 K-NN 图，填充前向/反向关系 $A_i$。
2. **并行**对每个节点 $v$：去重得 $C(v)$ → 计算并缓存各组件距离 → 求 $S(v)$ → 若不足则按 $B_v(u)$ 补充 → 写入 $G[v]$（只写自己的邻接，不读改他人邻接）。
3. 固定入口节点 $v_0=o_1$。

**查询（Algorithm 2）**：best-first 搜索，最小堆 $H$ 管理待扩展候选，最大堆 $W$ 保留至多 $ef$ 个结果并作为准入阈值，访问集 $V$ 去重；当 $H$ 空或最近待扩展候选远于满 $W$ 的最远者时终止，返回 $W$ 中最近 $k$ 个。仅对 $w_i>0$ 的组件计算距离。

**复杂度**
- 时间：$O\big(\sum_{i} T_i(n,K) + nmK + m\sum_v c_v^2\big)$（去重 $O(nmK)$，Skyline 两两比较 $O(mc_v^2)$ 标量比较、不额外算距离；总候选数 $\sum_v c_v\le 2nmK$）。
- 空间：最终图 $O(n\bar r)$，候选辅助空间 $O(nmK)$，单节点临时 $O(mc_v)$。

## 7. 局限性与可讨论之处

- **理论保证的边界**：命题 1 只保证"在候选集 $C(v)$ 内，Skyline 不丢失任意非负权重下的加权最近邻"，但 $C(v)$ 本身来自近似 K-NN 图，**近邻召回损失无法由该命题覆盖**；论文对候选获取阶段的误差传播缺少理论刻画。
- **单层图 vs 层次图**：SJG 放弃了层次结构，靠固定入口 + best-first 搜索。在低召回、小 $ef$ 的极端设置下，缺少长程跳跃边可能影响收敛；论文未专门分析入口选择（固定 $v_0=o_1$）对性能的影响。
- **权重假设**：方法要求权重非负且归一化。对负权重、或组件间存在相关性/冗余（如两个高度相关的文本特征）的情形不适用；组件高度冗余时 Skyline 会退化（几乎所有候选都非支配），剪枝收益下降，论文未讨论这种"高维 Skyline 膨胀"的退化场景。
- **距离函数假设**：尺度不变性依赖"只用序关系"，但若某组件的距离不是度量（如某些学习到的相似度），支配关系的传递性论证需重新审视。

- **图表设计**：用一张反例图直观说明复合式方法的根本缺陷，是全文最有说服力的表达；消融用"距离计算次数"作为代理指标虽不够全面，但概念上直接对应"剪枝是否有效"。
- **可改进**：部分关键结论（如 36/42、21.4×）集中在正文叙述而图上看不到逐组数据；命题 1 的证明较简略（依赖传递性一句话带过），可补充形式化细节；对"为何不需要层次结构"这一设计选择的论证偏经验性。

## 9. 总体评价

- **贡献定位**：论文的核心贡献是把"多组件 ANN 中权重未知"这一实际痛点，转化为"支配关系与权重无关"这一数学性质，并据此设计出**单层、可并行、权重无关**的联合图。这一视角转换是清晰且有价值的，区别于复合式的"建多个图再合并"和 HJG 的"同步层次建一个图"两条既有路线。
- **技术成色**：方法本身不复杂（NN-Descent + Skyline + 最小出度补充），但**简洁正是优点**——它把复杂性转移到了一个有理论支撑的剪枝准则上，且天然并行。复杂度分析与尺度不变性讨论显示作者对方法边界有清醒认识。
- **实证强度**：6 个真实数据集、42 组权重设置、4 类基线、消融与参数敏感性、千万级可扩展性实验，覆盖面在同类工作中属上游；构建时间上 1–2 个数量级的差距尤其有说服力。
- **主要短板**：理论保证只覆盖"候选集内不丢失"，不覆盖候选获取的近似误差；实验呈现的完整度（逐组数据、对称的线程配置、QPS 维度的消融）仍有提升空间；与更多融合检索方法的对比缺失。
- **适用性判断**：对"多字段/多模态对象检索、查询权重因用户而异、需要一次建索引长期复用"的工业场景（电商、房源、推荐召回），SJG 的思路具有很强的可落地性；对组件数很多且高度冗余的场景，需先评估 Skyline 规模是否可控。
