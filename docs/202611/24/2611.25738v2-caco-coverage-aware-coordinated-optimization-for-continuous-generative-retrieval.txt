Abstract
Continuous generative retrievers powered by flow matching and
diffusion sample multiple queries in item embedding space for
approximate nearest-neighbor (ANN) search under fixed budgets.
However, existing generative retrievers can suffer from retrieval
overlap under uncoordinated sampling, whereas explicit diversity
guidance to broaden the candidate set may induce relevance drift
as it lacks direct feedback on the value of additional items. We
introduce CACO (Coverage-Aware Coordinated Optimization), a
self-supervised post-training framework coordinating queries from
frozen flow-matching and diffusion retrievers toward complemen-
tary item coverage with negligible latency overhead. Using empiri-
cal retrieval frequencies across sampled reference queries as a rele-
vance proxy, CACO formulates a label-free coverage objective that
improves recall across all 30 backbone–dataset settings in offline ex-
periments. To avoid the overhead of sampling reference queries at
inference, CACO employs a coordinated query adjustment net-
work combining inter-query bidirectional attention with gated
relative directions, updating queries via bounded tangent-space
projection and spherical retraction. During training, CACO applies
tangential antithetic perturbations and counterfactual single-query
replacement to measure each query’s marginal gain, yielding an
unbiased gradient estimator of smoothed set coverage across non-
differentiable ANN search. On eight public benchmarks and an
in-house 24-partition streaming industrial dataset, CACO improves
Recall@100 and Recall@400 by up to 23.7% and 23.9% over the
strongest baseline, cuts inter-query overlap by 53.3%–64.9%, and
adds only 0.5%–3.0% inference latency.

Introduction
Large-scale recommender systems in e-commerce, short-video
feeds, and online news have to retrieve a limited set of rele-
vant candidates from massive corpora under strict latency bud-
gets [6, 11, 15, 24, 52]. Recent continuous generative retrievers
powered by diffusion [26, 55] and flow matching [10, 22, 31, 44, 56]
model user-conditioned query distributions in item embedding
space and retrieve candidates via approximate nearest-neighbor
(ANN) search [34]. This generative process allows the system to
sample multiple queries under the same user context and merge
their retrieval results into a final candidate set, thereby better
capturing diverse user interests [5, 26].
However, generating multiple queries alone does not automati-
cally guarantee capturing diverse interests: maximizing recall re-
quires set-level complementarity, where a query adds value only

when it retrieves relevant items missed by the others [2]. Stan-
dard generative retrievers enrich the query distribution across
user preferences, yet still sample queries independently at infer-
ence [26, 28, 31, 32, 37, 55]. Because independent samples remain
blind to one another’s results, even a diverse distribution can map
onto overlapping top-𝐾ANN neighborhoods, causing retrieval over-
lap that wastes limited slots on duplicates. To break this overlap,
recent methods go further by applying explicit diversity guidance—
steering queries apart via interest priors, semantic anchors, or re-
pulsive signals [5, 36, 44]. Although such guidance broadens the
candidate set, it lacks direct feedback from retrieval results on the
value of newly added items, risking relevance drift that trades du-
plicate items for off-topic candidates.
Figure 1 illustrates both failure modes for a user interested in
guitar practice under a budget of 𝐿= 3 queries and 𝐾= 2 videos
per query. Uncoordinated queries in Panel I cluster around chords
and repeatedly retrieve the same two videos, returning only two
distinct items across six slots. In contrast, in Panel II, explicit guid-
ance pushes the third query beyond chords and strumming toward
generic practice routines. Without direct feedback on the value of
new results, it picks off-topic fitness videos over guitar tuning, leav-
ing only four of the six videos relevant. Rather than steering queries
directly, an alternative workaround for overlap is to increase the
retrieval depth 𝐾and deduplicate the results. Nevertheless, such a
compensatory strategy trades extra retrieval overhead for broader
coverage, leaving query generation unchanged without optimizing
each query’s contribution to the merged candidate set. Achieving
the complementary, fully relevant set in Panel III motivates our
central question: under a fixed retrieval budget, how can we coor-
dinate queries so that each retrieves relevant items missed by the
others?
In practice, learning to coordinate queries toward this goal
presents two challenges. First, user interaction data provide only
partial supervision: indiscriminately expanding coverage may
introduce irrelevant items, while fitting a single observed target
cannot capture the full range of interests that the query set should
cover. We therefore need a coverage objective that approximates
item relevance beyond the single observed target and rewards
queries for covering complementary candidates. Second, even
with a suitable coverage objective that can identify high-quality
query sets, using it to train query generation remains challenging.
On the one hand, coverage depends on the discrete candidate
sets returned by approximate nearest-neighbor search, which
prevents direct optimization of query generation through standard
backpropagation [41, 53]. On the other hand, direct distillation
of these high-quality query sets does not necessarily preserve
their broader coverage of relevant items, because matching query
representations and optimizing set-level retrieval coverage are
different objectives. Preserving this coverage advantage during
learning therefore requires training signals derived from actual
retrieval results.
To address these challenges, we propose CACO (Coverage-
Aware Coordinated Optimization), a lightweight self-supervised
post-training framework that coordinates queries from frozen flow-
matching and diffusion retrievers. CACO constructs a label-free,
frequency-weighted coverage objective using item retrieval counts
across reference queries sampled from the frozen base model as
a relevance proxy. Each covered item contributes its weight only
once, so retrieving duplicates yields zero additional gain. Applying
offline greedy selection over a large reference pool confirms that
this objective consistently guides query selection toward higher
recall without ground-truth target labels. To avoid generating a
large query pool at inference, CACO employs a coordinated query
adjustment network that integrates context cross-attention, inter-
query bidirectional attention, and gated relative directions, updat-
ing queries by bounded tangent-space projection and spherical
retraction. During training, CACO applies tangential antithetic
perturbations and holds the other queries fixed via counterfactual
single-query replacement to measure each query’s marginal cover-
age gain. This formulation yields an unbiased gradient estimator
of Gaussian-smoothed set coverage across non-differentiable ANN
search, improving complementary coverage while keeping the base
generator, query count, and retrieval depth unchanged.
Our main contributions are as follows:
• Label-Free Coverage Objective. We formulate a frequen-
cy-weighted set-coverage objective that uses empirical re-
trieval counts across sampled reference queries as a rele-
vance proxy, and verify via offline greedy selection that it
improves recall across all 30 backbone–dataset settings.
• Self-Supervised Post-Training Coordination. We pro-
pose CACO, a lightweight self-supervised post-training
framework that coordinates queries sampled from a frozen
base generator under a fixed retrieval budget, deriving an
unbiased smoothed-coverage gradient estimator from tan-
gential antithetic perturbations and counterfactual single-
query replacement.
• Public and Industrial Validation. Across eight public
benchmarks, an in-house 24-partition streaming industrial
dataset, and six frozen flow-matching and diffusion back-
bones, CACO improves Recall@100 and Recall@400 by up
to 23.7% and 23.9%, cuts query overlap by 53.3%–64.9%, and
adds only 0.5%–3.0% inference latency.

Related Work
2.1
Generative Retrieval
Generative retrieval in recommender systems follows discrete or
continuous paradigms. Discrete methods generate semantic item
IDs [17] constructed through vector quantization [18, 42] or hierar-
chical clustering [46]. Later work incorporates collaborative signals
into tokenization and generation [30, 51, 58] or aligns recommen-
dations with user preferences [12]. Alternative generation schemes
include parallel decoding [21], latent-token-conditioned multi-tree
decoding in LATTE [19], and masked diffusion in LLaDARec [45].
Continuous methods generate query embeddings conditioned
on user context for nearest-neighbor search. Diffusion-based meth-
ods model target representations via iterative denoising [28, 55]
or incorporate multi-interest and quantized guidance for diver-
sity [5, 26, 36]. ADRec [9] combines autoregressive modeling with
item-level diffusion and multi-stage alignment, while PreferDiff [32]
formulates Bayesian personalized ranking using generation prob-
abilities. For efficient generation, TA-Rec [37] uses consistency
regularization for single-step generation, FMRec [31] adopts
straight-path flow matching—further extended with contrastive

alignment [22] and popularity debiasing [56]—and X-Rec [44]
combines anchor conditioning with Riemannian flow matching [10]
on the unit sphere. Order-agnostic continuous item identifiers also
enable parallel generation [29]. Building on continuous generative
retrieval, CACO introduces a self-supervised post-training layer
that coordinates queries from frozen flow-matching and diffusion
backbones for complementary set-level coverage.
2.2
Multi-Interest Retrieval
Multi-interest retrieval represents each user with multiple vectors
to capture diverse preference facets for parallel nearest-neighbor
search. Early approaches extract interests from behavior sequences
through dynamic capsule routing [24] or self-attentive aggrega-
tion [6]. SINE [47] infers a sparse set of active concepts, while
behavior clustering provides another way to construct multiple
user representations [40]. Subsequent work enriches interest mod-
eling with temporal patterns and user profiles [7, 8].
Beyond interest extraction, disagreement and backward-flow
regularization promote more informative and diverse representa-
tions [25, 57], while graph-based item partitioning supports interest
disentanglement [14]. REMI [54] further improves interest learning
through interest-aware hard negative mining and routing regular-
ization. At the supervision level, TiMiRec [50] introduces target-
interest distillation to guide multi-interest learning. Moving beyond
single-positive supervision, MIMA [38] groups concurrent posi-
tives within a request, models interest dependencies via a causally
masked decoder, and applies Hungarian matching to exclusively
assign distinct positive items to different interests.
Similarly, continuous generative retrievers capture diverse
preferences through multi-query sampling and explicit diversity
guidance [5, 26, 36, 44]. However, differentiating representations
or guiding queries in isolation from merged retrieval results leaves
a coverage gap: independent queries can still retrieve overlapping
nearest-neighbor sets, whereas ungrounded query separation risks
relevance drift toward off-topic items. Instead of relying solely on
query- or target-level differentiation, CACO coordinates queries
directly through marginal gains in frequency-weighted candidate
coverage.

framework for multi-query coordination. We first formulate the
label-free coverage objective and verify it via offline greedy selec-

Baselines. We compare CACO against three categories of repre-
sentative retrieval methods: (1) Multi-interest retrieval meth-
ods, which learn multiple user interest vectors for parallel nearest-
neighbor search, including ComiRec [6], REMI [54], and MIMA [38];
(2) Discrete generative retrieval methods, which tokenize items
into semantic IDs and generate target identifiers via sequence de-
coding or discrete diffusion, including TIGER [42], LATTE [19],
and LLaDARec [45]; and (3) Continuous generative retrieval
methods, which generate query embeddings in the continuous
item space via diffusion or flow matching for nearest-neighbor re-
trieval, including DreamRec [55], DimeRec [26], PreferDiff [32], TA-
Rec [37], ADRec [9], and X-Rec [44]. In addition, we include Base,
our backbone continuous generator that adopts the sequence archi-
tecture of X-Rec [44] without anchor conditioning and learns query
embeddings via Riemannian flow matching on the unit sphere [10].
As shown in Figure 3(a), Base constructs each historical interaction
token representation by summing its item embedding and action
embedding. Applying CACO on top of the frozen Base model pro-
vides a direct comparison to isolate the gain of coordinated query
adjustment.
Training. Across all compared methods, we use a shared set of
fixed, unit-normalized 128-dimensional item embeddings on each
dataset. For public datasets, the item embeddings are pretrained
on training sequences using a 2-layer causal Transformer with a
next-item prediction objective; for the industrial dataset, each item
is represented by a 128-dimensional unit-normalized multimodal
embedding. The public Base generator uses 8 Transformer layers
with hidden dimension 256 (∼8M parameters), 30 Euler integration
steps, and a classifier-free guidance scale of 3.0, while the adjust-
ment network of CACO sets the number of layers 𝑁= 2, hidden
dimension 128, and the number of attention heads 𝐴= 4 (∼0.6M
parameters); overall, CACO and all baselines maintain a compa-
rable parameter scale. On public datasets, all retrieval models are
trained for two epochs using AdamW (learning rate 10−4, batch
size 512). For CACO, we train the adjustment network for the first
epoch using the reference query set and item weights from Base,
and refresh them using queries adjusted by the first-epoch network
before training for the second epoch. We set 𝑀= 200, 𝛼= 0.5, step
bound 𝜌= tan 32◦, and perturbation scale 𝜎= tan 8◦/

Coverage Objective Analysis
Table 3 evaluates offline greedy selection under 𝐹ℎ(𝑄) across five
retrieval backbones and six datasets, comparing random selection
against unweighted (𝛼= 0), sublinear (𝛼= 0.5), and linear (𝛼=
1) frequency-weighted coverage. At 𝛼= 0.5 and 𝛼= 1, greedy
selection improves Recall @400 over random sampling in all 30
backbone–dataset settings while substantially lowering MPJ (e.g.,
𝛼= 0.5 boosts Base by 3.25–14.25 pp on public benchmarks and
from 0.181 to 0.222 on the industrial dataset, with MPJ dropping
from 0.1250 to 0.0392); intermediate exponents 𝛼∈{0.25, 0.75}
likewise achieve 30-out-of-30 recall gains (Appendix D.2).

Comparing 𝛼∈{0, 0.5, 1} directly confirms the risk of relevance
drift when broadening coverage without feedback on the value
of additional items. For instance, unweighted selection (𝛼= 0)
drives X-Rec’s MPJ on KuaiRec to 0.0000 yet lowers recall from
0.472 to 0.369 (and drops LATTE on Industrial from 0.098 to 0.091),
whereas 𝛼= 0.5 and 𝛼= 1 raise X-Rec’s recall to 0.570 and 0.595.
Optimal exponents track intrinsic query redundancy: highly over-
lapping DimeRec (random MPJ of 0.622–0.668 on Amazon) peaks at
𝛼∈[0, 0.5] where dispersing collapsed neighborhoods dominates,
whereas low-overlap LATTE (MPJ of 0.012–0.069) and X-Rec favor
𝛼= 1 to prioritize high-confidence items. Moderately redundant
Base and CACO peak at 𝛼= 0.5, supporting our default setting.
Finally, varying the training reference-pool size 𝑀∈[20, 800] on
Beauty, Sports, and Toys shows rapid saturation, with 𝑀= 20
already retaining 89%–91% of the Recall @400 gain achieved at
𝑀= 800.
6
Conclusion
We proposed CACO, a lightweight self-supervised post-training
framework that coordinates queries from frozen flow-matching
and diffusion retrievers toward complementary coverage under a
fixed retrieval budget. Using empirical reference-query retrieval
counts as a relevance proxy, CACO learns coordinated query ad-
justment from unbiased marginal-coverage gradients without con-
structing a large query pool at inference. Experiments across eight
public benchmarks, an in-house streaming industrial dataset, and
six generative backbones show that CACO effectively improves re-
call while substantially cutting inter-query overlap with negligible
latency overhead.

A
Iterative Reference-Pool Updates
We examine whether repeated reference-pool updates yield further
gains. Starting from Base’s 𝑀= 200 reference queries per context,
we update the pool using the preceding adjustment network. Each
stage trains a new network for two epochs from the same initial-
ization within each seed, holding its pool fixed. Base and the initial
queries 𝑄(0) remain unchanged; inference uses only the current
adjustment network at 20 × 20.
Figure 8 shows that the first update improves Recall@400 by
0.37, 0.45, and 0.27 percentage points on Sports, Instruments, and
Movies, respectively. Further updates yield diminishing returns:
Sports declines, while Instruments and Movies nearly plateau be-
fore decreasing slightly, despite additional rounds of training and
reference generation.
B
Reference-Query Pool Size
We vary the reference-query pool size 𝑀from 20 to 800 on Sports,
Toys, and Beauty. Each setting uses the same 𝑀in both training
epochs: we train for one epoch, refresh the pool with the resulting
adjustment network, and continue training that network for one
more epoch. All other training settings remain fixed, and inference
uses one adjustment network at 20 × 20.
Figure 9 shows diminishing returns as 𝑀increases. Sports nearly
plateaus beyond 𝑀= 100, while Toys and Beauty continue to
improve modestly. Even 𝑀= 20 retains 89–91% of the Recall@400
gain over Base achieved with 𝑀= 800 across the three datasets.
One possible explanation is that the adjustment network learns
from many user contexts within each dataset, reducing its reliance
on large reference pools for individual contexts.

Coverage–relevance trade-off trajectory. Increasing 𝛼from 0 to
1 monotonically permits higher pairwise overlap (MPJ) in exchange
for stronger concentration on frequently retrieved candidates. Pure
unweighted coverage (𝛼= 0) assigns equal weight to every item
in the reference pool without distinguishing item value, inducing
relevance drift toward peripheral candidates on backbones whose
queries are already dispersed (e.g., reducing LATTE from 0.464
to 0.378 on KuaiRec and X-Rec from 0.504 to 0.398 on ML-25M).
Introducing even mild frequency weighting (𝛼= 0.25) immedi-
ately reverses these drops, raising Recall @400 to 0.516 and 0.561,
respectively.
Link between preferred 𝛼and intrinsic query redundancy.
Comparing optimal exponents across backbones reveals a clear
relationship with initial retrieval overlap. Highly redundant gen-
erators such as DimeRec (random-pool MPJ of 0.6220–0.6675 on
Amazon benchmarks) peak at smaller exponents (𝛼∈[0, 0.5]),
where dispersing collapsed neighborhoods is the primary bottle-
neck. Conversely, backbones whose sampled queries already exhibit
low overlap—such as multi-tree LATTE (MPJ of 0.0115–0.0693) and
anchor-conditioned X-Rec (MPJ of 0.0042–0.1316)—attain peak re-
call at larger exponents (𝛼∈[0.75, 1]), benefiting from stronger
emphasis on high-confidence items. Base and CACO exhibit mod-
erate redundancy and achieve optimal or near-optimal recall at
𝛼= 0.5 across datasets, supporting our default choice.

F
Additional Experiments
F.1
Effect of Reference-Pool Refresh
Refreshing the reference pool updates coverage supervision using
the queries produced by CACO. To separate this benefit from ad-
ditional optimization, we compare three training schedules from
the same frozen Base model: one epoch, two epochs with a fixed
reference pool, and two epochs with a refresh after the first epoch.
All schedules use the same data splits and training seeds (42, 44,
and 45), and inference applies a single adjustment network. We re-
port the mean and sample standard deviation across training seeds,
averaging inference seeds 42 and 43 within each model.
Under the 20×20 retrieval setting used during training, refreshing
the pool improves Recall@400 over the fixed-pool two-epoch con-
trol on all five datasets by 0.121–0.893 percentage points (Table 6).
The gains hold for every training seed on every dataset (Table 7),
showing that the improvement comes from updated supervision
rather than additional training alone.
The benefit is less consistent when transferring directly to 10×10
retrieval. Mean Recall@100 improves on Beauty, Toys, and KuaiRec
but decreases on Sports and ML-25M. Reference refresh therefore
strengthens coverage learning under this retrieval setting, while its
benefit under a different query count and retrieval depth depends
on the dataset.
F.2
Initial Overlap and Failure Cases
We examine how CACO’s gains vary with the overlap among Base
queries. Test examples are assigned to low, middle, and high overlap
groups using tertile boundaries estimated from Base MPJ on the
validation set. The lower and upper boundaries are (0.0806, 0.2642)
for Beauty, (0.1125, 0.2167) for Sports, and (0.0738, 0.2240) for Toys.
Base and CACO are compared on the same examples with paired
inference seeds.
Table 8 shows positive recall gains in every group, with the
largest absolute improvements in the high-overlap group on all
three datasets. This pattern is consistent with query coordination
being most beneficial when the initial retrieval sets are redundant,
although the grouping alone does not establish causality. The gained
targets outnumber the lost targets in every group, explaining the
overall recall improvement.
Broader coverage does not guarantee that every target is retained.
In Table 9, CACO returns more distinct items and lowers MPJ but
loses a target retrieved by Base under both inference seeds. For
each dataset, we select the first such example in test-set order, using
a loss under either seed only if no example fails under both. These
cases complement the successes in Appendix E and illustrate the
distinction between improving aggregate coverage and preserving
each individual prediction.
F.3
Retrieval Efficiency and Budget Allocation
We examine the quality–speed trade-off at the common 𝐿= 𝐾= 20
setting, comparing Recall@400 with end-to-end inference time per
sample.
All methods use a checkpoint trained with seed 42, with Recall
averaged over inference seeds 42 and 43 and time over five full
test-set evaluations. Measurements use H100 GPUs, batch size 32,
four CPU threads per worker, disjoint CPU affinity, and passive
OpenMP waiting. End-to-end time includes host-to-device transfer,
query generation, history-filtered exact cosine retrieval, device-
to-host transfer, and deduplication; loading, warmup, and offline
preparation are excluded. Discrete generators use the same SID-to-
vector retrieval protocol as the other shared-space comparisons.
Figure 15 shows that lightweight methods are faster, while CACO
achieves the highest Recall on all three datasets in this comparison.
