## 摘要
高维向量上的近似最近邻搜索（ANNS）是现代检索系统中的核心原语。在实践中，对象通常还关联有标签（例如属性或关键词），检索需要将向量相似性与显式的基于标签的过滤相结合，从而产生了标签过滤 ANNS。该任务具有挑战性，因为标签过滤与 ANNS 适合的索引结构差异很大，选择性过滤会碎片化可允许的搜索空间，且更新会使索引维护复杂化。为应对这些挑战，我们提出 DYLAN，一种用于标签过滤 ANNS 的动态复合索引，支持包含、重叠及其合取与析取。DYLAN 在按频率排序的 trie 中按共享前缀组织标签集，并在由 trie 诱导的子集之间选择性地共享 HNSW 风格图索引，使每个 trie 区域具有常数因子的覆盖索引，而每个对象仅参与对数数量级的索引。为缓解碎片化，DYLAN 执行跨区域多图搜索，利用祖先级索引作为原本孤立的 trie 区域之间的桥梁。为支持插入，它采用基于阈值的维护方案，仅在必要时重建共享索引，从而实现较低的摊还更新成本。在真实数据上的大量实验表明，DYLAN 在召回率相当的情况下持续提升查询吞吐量，在具有挑战性的标签丰富数据集上最高可达两个数量级，同时保持有竞争力的内存、构建和更新成本。

## Abstract
Approximate nearest neighbor search (ANNS) over high-dimensional vectors is a core primitive in modern retrieval systems. In practice, objects are often also associated with labels (e.g., attributes or keywords), and retrieval must combine vector similarity with explicit label-based filtering, giving rise to label-filtered ANNS. This task is challenging because label filtering and ANNS favor very different index structures, selective filters fragment the admissible search space, and updates complicate index maintenance.   To address these challenges, we propose DYLAN, a dynamic composite index for label-filtered ANNS supporting containment, overlap, and their conjunctions and disjunctions. DYLAN organizes label sets by shared prefixes in a frequency-ordered trie and selectively shares HNSW-style graph indices across trie-induced subsets, so that each trie region has a constant-factor covering index while each object participates in only logarithmically many indices. To mitigate fragmentation, DYLAN performs a cross-region multi-graph search that exploits ancestor-level indices as bridges between otherwise isolated trie regions. To support insertions, it adopts a threshold-based maintenance scheme that rebuilds shared indices only when necessary, yielding low amortized update cost.   Extensive experiments with real data show that DYLAN consistently improves query throughput at comparable recall, by up to two orders of magnitude on challenging label-rich datasets, while retaining competitive memory, construction, and update costs.

- 每个对象的标签按 ID 升序排列、末尾追加 `#`，沿根到叶插入；对象分配到匹配其标签集的叶子。
