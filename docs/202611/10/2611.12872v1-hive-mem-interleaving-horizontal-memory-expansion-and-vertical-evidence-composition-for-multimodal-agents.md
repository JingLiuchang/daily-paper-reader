## 摘要
随着多模态智能体积累越来越长的交互历史，有效检索和利用过去信息对于长期交互变得至关重要。现有记忆系统通常依赖对压缩记忆的语义检索，并暴露预定义表示，这可能遗漏相关记忆，并忽视不同查询对异构证据的需求。我们提出 HiVe-Mem，一个多模态记忆框架，它将横向记忆扩展与纵向证据组合交织在一起。对于横向记忆扩展，HiVe-Mem 利用文本和视觉锚点将记忆片段组织为关系图，通过相关邻居扩展语义检索得到的种子，以恢复互补信息。对于纵向证据组合，每条检索到的记忆保留多种证据形式，包括紧凑摘要、说明文字、具定位信息的视觉视图、原始图像和交互历史。一个轻量级可训练选择器为每条检索到的记忆独立组合一个证据子集，从而实现异构多模态信息的查询自适应利用。这种二维设计共同拓宽了记忆覆盖范围，并自适应调整各条记忆所提供的证据。在三个多模态记忆基准上的实验表明，HiVe-Mem 在不同基座模型上持续提升任务性能，同时与最高效的竞争多模态基线相比，token 消耗降低约 90%。

## Abstract
As multimodal agents accumulate increasingly long interaction histories, effectively retrieving and utilizing past information becomes critical for long-term interaction. Existing memory systems typically rely on semantic retrieval over compressed memories and expose predefined representations, which may miss relevant memories and overlook heterogeneous evidence needs across queries. We introduce \textbf{\hivemem}, a multimodal memory framework that interleaves \textbf{\textsc{H}}or\textbf{\textsc{i}}zontal Memory Expansion with \textbf{\textsc{Ve}}rtical Evidence Composition. For horizontal memory expansion, \hivemem organizes memory episodes into a relational graph using textual and visual anchors, expanding semantically retrieved seeds with related neighbors to recover complementary information. For vertical evidence composition, each retrieved memory retains multiple evidence forms, including compact summaries, captions, grounded visual views, raw images, and interaction history. A lightweight trainable selector independently composes an evidence subset for each retrieved memory, enabling query-adaptive utilization of heterogeneous multimodal information. This two-dimensional design jointly broadens memory coverage and adapts the evidence contributed by individual memories. Experiments across three multimodal memory benchmarks show that \hivemem consistently improves task performance across base models while reducing token consumption by about 90\% compared with the most efficient competing multimodal baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：多模态智能体（如个人助理、具身智能体）在长期交互中会积累同时包含文本与图像的超长交互历史，记忆系统成为保存与复用过去信息的关键基础设施。
- **现有方法的两大局限**：
  - **结构化记忆以抽象实体-关系为中心，而非交互片段本身**。这类结构擅长知识整合，但难以捕捉多模态历史中跨片段的“软关联”（如共享实体、场景、事件，但无显式符号关系），导致语义检索容易漏掉分布在多个片段中的相关信息。
  - **检索到的记忆以预定义表示暴露**。部分记忆只需紧凑摘要，部分则需要细粒度视觉或上下文证据；固定表示要么信息不足，要么冗余，既限制记忆利用又推高 token 消耗。
- **核心挑战**：多模态记忆系统如何在推理时灵活地“识别哪些记忆相关”并“决定每条记忆贡献什么证据”。
- **整体含义**：论文提出一个二维记忆利用框架，同时拓宽召回覆盖面（横向）并自适应组合证据粒度（纵向），在不改变底层记忆库的前提下实现查询自适应的记忆使用。

## 2. 方法论

### 2.1 核心思想
- **横向记忆扩展（Horizontal Memory Expansion）**：用文本/视觉锚点构建片段间亲和图，从语义检索的种子节点扩展到关联邻居，补充语义匹配之外的跨片段上下文线索。
- **纵向证据组合（Vertical Evidence Composition）**：每条记忆保留多种证据形式，用轻量级 RL 训练的选择器为每条记忆独立决定暴露哪些证据，兼顾答案质量与 token 成本。

### 2.2 关键技术细节

**（1）片段中心的多模态记忆构建**
- 将交互历史按约 256 token 的固定跨度切分为连续片段（尊重对话/会话自然边界，不强行截断），每个片段转为记忆对象：
  $$m_i = (r_i, s_i, c_i, o_i, g_i, T_i, V_i)$$
  其中 $r_i$ 原始交互文本、$s_i$ 紧凑摘要、$c_i$ 图像描述、$o_i$ 原始图像、$g_i$ 具定位视觉视图（VLM 预测目标物体坐标后裁剪，可减少 20–40% 视觉 token）、$T_i$ 文本锚点（实体/事件/主题）、$V_i$ 视觉锚点（物体/场景/活动/属性）。
- 每个片段仅由 VLM 处理一次，同时生成摘要与两类锚点。

**（2）跨片段亲和图**
- 构建无向图 $G=(M,E)$，节点为记忆片段，边权基于锚点重叠：
  $$A_{ij} = (T_i \cap T_j) \cup (T_i \cap V_j) \cup (V_i \cap T_j)$$
  后两项构成文本-视觉的跨模态桥接。
- 用 IDF 加权抑制高频通用锚点、突出稀有判别性锚点：
  $$w_{ij} = \sum_{a \in A_{ij}} \text{IDF}(a),\quad \text{IDF}(a)=\log\frac{N+1}{1+df(a)}$$
- 每个节点最多保留 $K_{edge}$ 条边（默认 4），按权重降序贪心选取。

**（3）亲和引导的记忆扩展**
- 先按查询与摘要的语义相似度检索 $K_{ret}=5$ 个种子记忆，取其一度邻居（排除已检索）作为扩展候选。
- 候选 $m_u$ 的扩展分数基于其与种子共享的**唯一锚点** $B_u$：
  $$S_{exp}(m_u|q) = \sum_{a \in B_u} \text{IDF}(a)\cdot \text{sim}(q,a)$$
  即“锚点特异性 × 查询相关性”，取 Top-$K_{exp}=2$，最终最多 $K_{ret}+K_{exp}=7$ 条记忆。

**（4）查询自适应证据组合**
- 每条记忆的候选证据集 $E_i=\{r_i,s_i,c_i,o_i,g_i\}$（可扩展）。
- 选择器为轻量 MLP，输入为查询与摘要的拼接嵌入 $h_i=[E(q);E(s_i)]$，一次前向输出各证据的选择概率：
  $$p_i = f_\theta(h_i) \in [0,1]^{|E_i|}$$
  按 0.5 阈值二值化为 $z_i$，实现不同记忆暴露不同证据子集。

**（5）基于 RL 的选择器训练（PPO）**
- 奖励同时考虑答案质量与证据消耗：
  $$R = R_{ans}(\hat{y},y) - \lambda \tilde{C}(z),\quad C(z)=\sum_i\sum_k z_{i,k}\tau_{i,k}$$
  其中 $R_{ans}$ 用 F1，$C(z)$ 为选中证据的 token 数，$\tilde{C}$ 经滑动窗口分位数裁剪与标准差对齐归一化。
- 采用因子化策略 $\pi_\theta(z_i|h_i)=\prod_k \pi_\theta(z_{i,k}|h_i)$，优化标准 PPO 裁剪目标；$\lambda$ 控制质量-成本权衡。

## 6. 主要结论与发现

- **性能稳定提升**：HIVE-MEM 在两个基座上的平均 F1/LJ 分别为 32.32/57.96（Qwen3-VL-4B）与 35.94/64.69（GPT-5-mini），在多数单基准上取得最优或次优，且 GPT-5-mini 结果来自**选择器零重训迁移**，说明跨模型泛化性。
- **显著的 token 效率**：平均消耗仅 0.658M / 0.748M token，相比最高效多模态基线（7.812M / 7.350M）降低约 **91.6% / 89.8%**。
- **两组件互补且缺一不可**：
  - 去掉横向扩展 LJ 从 57.96 降至 56.51；去视觉锚点降至 57.30；去 IDF 加权降至 56.55（IDF 影响最大）。
  - 去掉纵向组合（仅摘要）LJ 暴跌至 44.47，是最大退化项；去掉原始文本（49.68）与原始图像（51.02）影响次之，说明细粒度多模态证据不可替代。
- **预算自适应**：λ 增大时选择器非均匀压缩——原始历史被大幅削减，原始图像选择率低但 token 占比高（高单价、按需保留），形成可调的“质量-消耗”工作点。
- **查询类型自适应**：文本主导查询几乎不选视觉证据；视觉主导与跨模态查询显著增加视觉证据，但原始图像选择率仍仅约 35.2%/30.2%，说明压缩/定位视图常已足够，体现比“按模态路由”更细粒度的证据调度。
- **低延迟开销**：TTFT 约 1.03 s，显著低于多数多模态基线（如 8.89 s、6.60 s），仅略高于最简单检索式基线。
- **超参鲁棒**：$K_{edge}$ 在较宽范围内稳定；检索分配在 5:2 附近最优，纯语义检索（7:0）次之，过度扩展反而下降。

## 7. 优点

- **问题切分清晰**：将记忆利用解耦为“召回哪些记忆”（横向）与“每条记忆暴露什么”（纵向），两个维度正交且互补，框架具有可解释性。
- **轻量高效的设计**：锚点图仅用 IDF 加权的集合重叠，无需预定义关系类型；证据选择器为 3 层 MLP，单次前向即可完成多证据联合决策，避免逐证据串行判断。
- **RL 目标贴合真实目标**：奖励直接由下游答案质量与 token 成本构成，并做了分位数裁剪与标准差对齐等工程处理，使质量与成本信号可比。
- **保留多粒度证据而非单一抽象**：原始文本、原始图像、定位视图、摘要、描述并存，为异构查询提供弹性空间；grounded view 还兼顾了视觉 token 压缩。
- **迁移性验证**：选择器跨基座模型零重训迁移仍保持收益，增强了方法的实用价值。
- **实验分析细致**：从消融、预算敏感性、图超参、延迟到查询类型分层，形成多维证据；效率收益（~90% token 降低）是极具说服力的卖点。
