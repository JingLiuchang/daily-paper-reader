## 摘要
智能体探索会产生有价值的过程性知识，但其中大量经验仍局限于瞬时的执行轨迹中，未被系统性地复用。我们提出 Evolver，一个经验驱动框架，可在不更新基础模型参数的情况下，将智能体探索转化为持久、可复用的能力。Evolver 以结构化 Gene 资产为核心，整合经验获取、检索与反馈引导的演化，以支持现有智能体执行框架中基于经验的执行。我们使用 Claude Code 和 Codex 两种基础模型配置，以及 Terminal-Bench 2.1、SWE-bench Multilingual、SWE-rebench 和 GAIA 四个基准对 Evolver 进行评估。在选定的 320 次配对执行诊断集上，Evolver 将任务成功率从 83.13% 提升至 87.50%（+4.38 个百分点），同时将记录的任务执行 token 消耗降低 24.24%。此外，在两种条件下均成功的 265 对执行中，token 消耗降低 17.57%，表明即使任务成功保持不变，也能带来效率收益。这些发现表明，持久的过程性经验可以同时提升任务有效性与执行效率，为将智能体探索转化为可进化能力提供了实用基础。

## Abstract
Agent exploration produces valuable procedural knowledge, yet much of this experience remains confined to transient execution traces and is not systematically reused. We introduce Evolver, an experience-driven framework that transforms agent exploration into persistent, reusable capabilities without updating foundation model parameters. Built around structured Gene assets, Evolver integrates experience acquisition, retrieval, and feedback-guided evolution to support experience-conditioned execution across existing agent harnesses. We evaluate Evolver using Claude Code and Codex, two foundation model configurations, and four benchmarks: Terminal-Bench 2.1, SWE-bench Multilingual, SWE-rebench, and GAIA. On a selected diagnostic set of 320 paired executions, Evolver improves task success from 83.13% to 87.50% (+4.38 percentage points) while reducing recorded task-execution token consumption by 24.24%. Furthermore, among 265 pairs successful under both conditions, token consumption decreases by 17.57%, demonstrating efficiency benefits even when task success is preserved. These findings suggest that persistent procedural experience can improve both task effectiveness and execution efficiency, providing a practical foundation for transforming agent exploration into evolving capabilities.
