## 摘要
记忆对于当前推理可能已经过时，但对于重建过去却可能不可或缺。基于相关性的检索忽视了这一张力：语义相关性、有证据支撑的有效性以及查询特定的适用性彼此不同。我们提出 CALM，一个冲突感知的生命周期记忆治理框架，将持久记忆保存与查询时准入解耦。CALM 将异构记录转换为有证据支撑的记忆单元，利用支持、冲突和依赖信号更新有效性与生命周期状态，并通过由时间适用性提供信息的免训练或学习型门控来准入适合查询的证据。在 LongMemEval-S 和 LoCoMo 上，使用 Qwen 与 GPT 主干模型，CALM 优于最先进的基线，取得最佳总体准确率。与简单过滤和重排序相比，查询条件化准入进一步改进了证据选择。冲突阻断与鲁棒性分析表明，CALM 在保留有用证据的同时抑制了错误检索到的记忆。历史重建实验表明，保留被取代的记录有助于准确的早期状态推理，同时不损害当前状态的答案。

## Abstract
A memory can be outdated for present-day reasoning yet indispensable for reconstructing the past. Relevance-based retrieval overlooks this tension: semantic relevance, evidence-grounded validity, and query-specific eligibility are distinct. We propose CALM, a conflict-aware lifecycle memory governance framework that decouples persistent memory preservation from query-time admission. CALM converts heterogeneous records into evidence-grounded memory cells, updates validity and lifecycle states using support, conflict, and dependency signals, and admits query-appropriate evidence through training-free or learned gating informed by temporal applicability. Across LongMemEval-S and LoCoMo with Qwen and GPT backbones, CALM outperforms state-of-the-art baselines, achieving the best overall accuracy. Compared with simple filtering and reranking, query-conditioned admission further improves evidence selection. Conflict-blocking and robustness analyses show CALM suppresses erroneous retrieved memories while retaining useful evidence. Historical-reconstruction experiments demonstrate that preserving superseded records supports accurate earlier-state reasoning without compromising current-state answers.

## 1. 核心问题与整体含义（研究动机与背景）

- **现有方法缺陷**：主流记忆系统（Mem0、MemOS、HippoRAG、Zep 等）侧重存储、组织与语义相关性检索，但**语义相关 ≠ 查询可用**——一条主题相关的记忆可能已被取代、被矛盾或超出查询的时间/范围条件，直接进入上下文会误导推理。
- **概念澄清**：论文区分三种不同属性：
  - **语义相关性**（ζ）：与查询的主题相关程度；
  - **查询无关的有效性**（V）：基于累积证据的持久可靠性；
  - **查询条件化资格**（g）：结合查询的时间目标、适用范围与意图后是否应进入工作上下文。
- **研究定位**：将长时程记忆使用重新表述为"查询条件化资格"问题，主张把**持久生命周期治理**与**查询时准入**解耦，而非仅依赖记忆组织或相关性排序。

## 2. 方法论

### 2.1 核心思想
CALM 是一个两层框架：在记忆后端与工作上下文之间插入"证据锚定的生命周期治理 + 查询条件化门控"，**不修改上游检索器与答案模型**。被拒绝的记忆仍保留在持久存储中，可供历史查询使用。

### 2.2 三阶段流程

**Stage I：证据锚定的记忆适配**
- 将异构后端记录（对话片段、抽取事实、摘要、结构化记录）统一为规范记忆单元：
  - `m_i^t = (c_i, E_i^t, a_i, ρ_i^t, s_i^t)`，其中 `a_i = (κ_i, τ_i, π_i, U_i, Ω_i)` 分别表示语义类型、时间锚点、来源溯源、关联实体、适用范围。
- 保留原始证据溯源；完全重复的记录合并，语义相似但值不同的记录**不合并**，留待生命周期治理判定冲突或时间状态差异。
- 按来源粒度赋固定可靠性权重 ν（如原始对话 0.74、观察 0.95、会话摘要 0.82），聚合可靠性 `ρ_i^t = max_{e∈E_i^t} ν(e)`。
- 新单元初始化为 `CANDIDATE` 状态。

**Stage II：生命周期感知的记忆治理**
- 构建生命周期图 `G^t = (M^t, E_conf^t, E_dep^t)`，冲突与依赖关系由**确定性规则**识别（无外部 LLM 裁判、无学习型关系分类器）。
- 三类信号：
  - **支持度** `S_i = min(1, 0.55·min(1, n_i/3) + 0.45·c̄_i)`，证据数贡献在 3 条后饱和；
  - **冲突风险** `C_i`：取最强冲突置信度，被取代记忆取最大值 1；
  - **无效依赖风险** `D_i`：上游被取代时按依赖强度传播，`D_i^(k+1) = min(1, D_i^(k) + 0.4·d_ji)`，每个源最多贡献一次。
- 生命周期状态：`CANDIDATE → ACTIVE → STABLE`，以及 `STALE`、`SUPERSEDED`、`ARCHIVED`。
  - 直接用户证据或置信度 ≥0.60 → ACTIVE；≥2 条证据或置信度 ≥0.80 → STABLE；
  - 强冲突（`f_conf ≥ 0.75` 且非弱类型）触发取代，旧记录有效性上限压至 0.15，并保留指向替代者的指针；
  - 依赖强度 ≥0.80 的强依赖源被取代时，下游转为 STALE；级联风险 ≥0.70 触发验证标记；
  - **时间流逝本身不触发 STALE**，时间仅用于确定更新顺序与适用区间；归档由可选保留策略控制。

**Stage III：查询条件化记忆门控**
- 对检索候选集 `R_q`（Top-48），先施加**共享硬资格过滤** `h_{q,i}^t`：
  - 当前状态查询通常排除 CANDIDATE/ARCHIVED/STALE/SUPERSEDED；
  - 明确的历史查询可临时准入匹配历史区间的旧记录（不改变持久状态）。
- 构造四维特征：`x_{q,i}^t = [ζ_{q,i}^t, V_i^t, ψ_{q,i}^t, 1 - R_{q,i}^t]`，其中：
  - `ψ` 为查询—记忆兼容性（时间、实体、范围、类型四因子均值）；
  - `R` 为查询条件化风险（冲突、依赖、时间失配、生命周期不兼容四因子的概率式聚合）。
- 两种策略：
  - **CALM-ZS（免训练）**：四特征均匀平均，阈值 0.50；
  - **CALM（学习型）**：单隐层 MLP + GELU + sigmoid，加权二元交叉熵训练，阈值 0.50；监督标签由开发集上"支持 ∧ 兼容 ∧ 非误导"的确定性规则独立构造，含语义相关但过时/冲突的硬负例。
- 最终准入 `g_{q,i}^{b,t} = h_{q,i}^t · I[F_b(x_{q,i}^t) ≥ θ_b]`，准入记忆按策略分数排序并在 token 预算内贪心打包。

## 6. 主要结论与发现

- **总体准确率最佳**：LongMemEval-S 上 CALM 达 79.60%（Qwen3）、83.00%（GPT-4.1-mini）、78.20%（GPT-4o-mini）；LoCoMo 上达 88.70%、93.51%、88.70%，均为最佳或并列最佳。
- **学习型门控优于免训练策略**：CALM 相对 CALM-ZS 在 LongMemEval-S 提升 3.00%，LoCoMo 提升 1.88–3.38 个百分点，说明查询条件化准入带来超越固定过滤的增益。
- **冲突阻断有效**：CALM 阻断 81.30% 错误记忆、保留 72.06% 有用记忆、冲突泄漏降至 20.00%，显著优于无门控（EMB 0%、CL 100%）。
- **历史重建成立**：CALM 在当前状态与历史状态查询上分别领先最强基线 3.71% 和 9.26%，证明"保留被取代记录"与"当前推理正确性"可以兼得。
- **鲁棒性更强**：错误记忆注入从 0% 到 50%，CALM 仅下降 7.0 个百分点，而 Relevance-Only 和 w/o Stage III 分别下降 11.6 和 16.8 个百分点。
- **效率可接受**：CALM 相对 CALM-ZS 准确率 +3.0%，内存用量仅 +3.1%，总时延从 12.00 秒增至 12.84 秒；且在 2048 token 预算下相对 CALM-ZS 增益最大（4.8%）。
- **消融结论**：三个阶段互补；存储有效性对知识更新类问题关键，时间线索对时间推理类问题关键。

## 7. 优点

- **问题刻画清晰**：明确区分"语义相关性 / 查询无关有效性 / 查询条件化资格"三个概念，并用"搬家"例子直观说明，问题定义具有理论价值。
- **架构解耦优雅**：持久保存与查询时准入分离，被拒绝记忆不删除、可服务历史查询，避免了"删除丢历史、全留扰当前"的两难。
- **即插即用**：不修改上游检索器与答案模型，适配异构记忆后端，工程落地友好。
- **双策略设计**：同时提供免训练（CALM-ZS）与轻量学习（MLP）两种门控，兼顾零成本部署与性能上限。
- **实验设计严谨**：严格匹配的准入控制（相同硬过滤、相同特征、相同打包规则）有效隔离了"硬过滤 / 排序 / 阈值准入"各自的贡献；错误记忆注入与历史重建实验针对性强。
- **鲁棒性与效率兼顾**：在噪声增加时优势扩大，且推理开销增长有限。

- **阈值与权重的启发式性**：可靠性权重（0.74/0.95/0.82）、支持度系数（0.55/0.45）、冲突阈值 0.75、依赖传播系数 0.4、级联阈值 0.70、门控阈值 0.50 等均为固定启发式值，敏感性分析仅覆盖来源可靠性权重一项，其余超参的稳健性与跨数据集可迁移性未系统验证。
- **时间建模较简化**：时间仅用于确定更新顺序与适用区间，未处理周期性事件、模糊时间区间、时区与粒度不一致等复杂情形；"时间流逝不触发 STALE"的设计在需要时效衰减的场景（如临时性偏好）中可能过于保守。
- **未与端到端方案对比**：基线均为"检索 + 答案"式记忆系统，未与端到端训练的记忆智能体、或让答案模型自身进行记忆取舍的方案比较，因而难以判断"外置门控"相对"模型内化判断"的净收益。
- **隐私与安全未展开**：刻意保留被取代的敏感信息（旧住址、过期凭据等）在提升历史可回答性的同时扩大了暴露面，论文仅提及"可选保留策略"，未讨论访问控制、遗忘权（right to be forgotten）、敏感信息分级与审计机制。
- **多用户/多任务隔离缺失**：实验均为单用户长会话设定，未讨论多用户共享记忆库时的身份绑定、跨用户泄漏与冲突判定问题。
- **可扩展性未量化**：生命周期图的冲突/依赖边随记忆规模增长的维护复杂度、规则匹配的候选规模控制（如是否做近邻剪枝）未给出复杂度分析或大规模（万级以上记忆单元）实测。

## 9. 总体评价与启示

- **定位**：论文的核心贡献不在于新的记忆表示或检索算法，而在于**重新界定问题**——把"该不该用这条记忆"从语义相关性中剥离出来，形式化为查询条件化资格，并给出"持久治理 + 查询时门控"的解耦式实现。这一视角对现有记忆系统具有普遍适用性，可作为检索器之上的通用中间层。
- **方法论价值**：Stage II 的确定性规则治理与 Stage III 的轻量学习门控形成"可解释下限 + 学习上限"的组合，既保证了无训练数据时的可用性（CALM-ZS），也留出了性能提升空间；严格匹配的对照实验（相同硬过滤、相同特征、相同打包）使各组件贡献可被清晰归因，是本文实验设计中最有说服力的部分。
- **证据强度**：主结果在 2 个数据集 × 3 个答案模型上一致领先，配合冲突阻断指标（EMB 81.30% / UMR 72.06% / CL 20.00%）、错误记忆注入曲线与历史重建实验，构成了"准确率提升有机制解释"的较完整证据链；但统计显著性与跨领域泛化仍是薄弱环节。
- **实践启示**：对工程落地而言，最有价值的结论是"**不要删除被取代的记忆，而是给它加上状态与准入条件**"——这同时解决了当前推理的正确性与历史可追溯性，代价仅是少量存储与约 0.84 秒的额外时延。
- **后续可延伸方向**：(1) 用可学习的冲突/依赖判定替代确定性规则，同时保留可解释性；(2) 将门控与检索联合优化，缓解多跳场景下上游召回不足的瓶颈；(3) 引入隐私分级与保留策略，使"保留历史"与"合规遗忘"共存；(4) 在更大规模、更多领域（代码、文档、多模态）上验证资格判定的迁移性；(5) 补充显著性检验与超参敏感性分析，提升结论的统计可信度。
