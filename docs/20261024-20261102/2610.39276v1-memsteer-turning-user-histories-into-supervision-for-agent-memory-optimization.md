## 摘要
有效的智能体记忆系统应能适应用户历史和任务需求。人工标注的监督可以通过提供反馈来评估和改进记忆设计，从而指导这种适应。然而，对于新的用户历史，合适的标签很少可用，且人工构建问答对及支撑证据成本高昂。我们提出 MemSteer，它将未标注的用户历史转化为带有支撑证据的问答（QA）监督，用于记忆设计优化。MemSteer 构建一个基于证据的答案计划，明确相关记录中的事实如何共同支持一个参考答案。该计划指导问题生成，而基于来源的审计和盲答案恢复则检查生成的标注。为研究这种监督的效用，我们开发了 MemSteer-Opt，它将基于 QA 的设计评估与证据引导的失败诊断相结合，在不更新模型参数的情况下修订记忆存储、检索和上下文构建。在 ATM-Bench 和 RHELM 上的实验表明，这种监督与官方 QA 引导的优化具有竞争力。相对于 Base-BM25，MemSteer-Opt 在无外部数据和有外部数据时，分别将 ATM-Bench Question Score 提高 13.4 分，将 RHELM 准确率提高 4.1 和 6.6 分。该监督还使 ATM-Bench 上的两个现有优化器受益，而新用户实验表明，可以使用目标历史生成的监督持续进行设计优化。

## Abstract
An effective agent memory system should adapt to a user's history and task requirements. Human-annotated supervision can guide this adaptation by providing feedback for evaluating and improving memory designs. Yet suitable labels are rarely available for new user histories, and manually constructing QA pairs and supporting evidence is costly. We introduce MemSteer, which turns unlabeled user histories into question-answer (QA) supervision with supporting evidence for memory-design optimization. MemSteer constructs an evidence-grounded answer plan that specifies how facts across related records jointly support a reference answer. The plan guides question generation, while source-grounded auditing and blind answer recovery check the resulting annotations. To study the utility of this supervision, we develop MemSteer-Opt, which combines QA-based design evaluation with evidence-guided failure diagnosis to revise memory store, retrieval, and context construction without updating model parameters. Experiments on ATM-Bench and RHELM show that this supervision is competitive with official-QA-guided optimization. Relative to Base-BM25, MemSteer-Opt improves ATM-Bench Question Score by 13.4 points and RHELM accuracy by 4.1 and 6.6 points without and with external data, respectively. The supervision also benefits two existing optimizers on ATM-Bench, while new-user experiments demonstrate continued design optimization using supervision generated from the target histories.

- **核心痛点**：现有记忆设计优化方法（如 MemEvolve、ALMA、M⋆）依赖下游任务的成功/失败信号，但个人记录与日常交互往往没有显式反馈信号；人工标注 QA 对及支撑证据成本高昂，且新用户历史几乎不存在现成标签。
- **核心问题**：能否将**无标注的用户历史**转化为可用于**记忆设计优化**的监督信号？论文提出 MemSteer，从历史记录本身构造带来源证据的 QA 监督，并据此优化记忆的存储、检索与上下文构建，且**不更新模型参数**。

## 2. 方法论

### 2.1 核心思想

- 将用户历史组织为图结构，采样相关记录形成“材料包”，再由 LLM 构建**证据化答案计划**（明确哪些事实、如何共同支持参考答案），据此生成问题，并通过**来源审计**与**盲答恢复**双重校验，得到高质量的 QA–证据三元组 `(q, a, E)`。
- 用该监督驱动 **MemSteer-Opt**：以 QA 准确率评估候选记忆设计，并利用证据标注对失败案例做**存储/检索/回答**三阶段归因，指导迭代修订。

### 2.2 MemSteer：QA–证据监督构建流程

- **图引导的材料准备**：将历史记录建图，边连接共享对话、相邻文档章节、显式引用或词汇重叠的记录；从种子节点做路径扩展，采样连通子图，形成受上下文预算约束的材料包 `B`，并保留来源跨度引用。
- **证据化答案规划与问题生成**：
  - LLM 规划器输出答案计划，包含：问题应问什么（主题/属性/约束）、参考答案 `a`、支持事实及来源跨度引用、每条证据记录的贡献、组合事实所需操作。
  - 对答案计划做**程序化结构一致性与来源覆盖检查**，不通过则拒绝，不进入问题生成。
  - 通过检查的计划交给问题生成器，生成独立问题 `q`。
- **来源审计与盲答恢复**：
  - **语义审计**：LLM 审查员对答案支持、问题–计划一致性、每条事实的来源支持、每条证据记录的贡献分别给出结构化判断，全部通过才进入下一步。
  - **盲答恢复**：仅给问题、答案类型和材料包 `B` 中的源记录，由 LLM 盲读者返回答案与引用；要求声明可回答、类型规范化后与参考答案精确匹配、引用覆盖所有选定证据记录。
- **数据划分**：生成的 QA–证据标注划分为不相交的训练集与验证集；训练集用于生成修订提案，验证集用于选择记忆设计。

### 2.3 MemSteer-Opt：证据引导的记忆设计优化

- **设计空间**：记忆设计 `d = (s, r, c)`，分别对应存储（记忆单元组织与索引）、检索策略、上下文构建；回答模型、指令提示和最终上下文预算在各设计间固定。
- **评估**：对每个问题检索并组装上下文，生成预测 `â`，与参考答案比较得到二元正确性 `y`；设计得分为验证集准确率 `A(d)`。
- **证据引导诊断**：对训练集错误回答，检查所需源记录与引用段落是否完整出现在最终上下文中：
  - 若完整出现 → 标记为**回答失败**；
  - 若缺失，且存在不可恢复的记录 → **存储失败**；
  - 若缺失但所有记录均可恢复 → **检索失败**。
- **失败分层采样**：按失败类别分别采样（每类最多 10 例），避免高频失败类型占满提议者的输入预算；每个样本包含问题、参考答案、标注证据、当前响应与诊断结果。
- **反馈引导修订与选择**：LLM 设计提议者根据诊断反馈提出修订设计 `d′` 及理由；重建记忆并在固定验证集上评估，仅当 `A(d′) > A(d_t)` 时接受，否则保留原设计；接受后重新在训练集上运行以刷新诊断与采样。
- **对现有优化器的复用**：生成的 QA（及可选证据）可直接作为任务反馈提供给 M⋆、MemEvolve 等优化器，保留其各自的设计空间与优化流程。

## 6. 主要结论与发现

- **生成监督可有效指导记忆设计优化**：MemSteer-Opt 在 ATM-Bench 上将 QS 从 54.9 提升至 68.3（+13.4），Hard 集从 8.2 提升至 29.1（+20.9），R@10 从 61.7 提升至 84.1；RHELM 上无/有外部数据分别提升 4.1 与 6.6 个准确率点。
- **与人工标注监督竞争力相当**：ATM-Bench 上 MemSteer 略高于 Official-QA（QS +1.1 / Hard +1.3）；RHELM 上仅低 0.1 / 0.8 个点，且未使用官方 QA 做训练或设计选择。

## 7. 局限与不足

- **对强 LLM 的依赖较重**：答案规划、问题生成、语义审计、盲答恢复、设计提议均调用第三方 LLM API，论文未报告 token 消耗、延迟与费用，实际部署成本与可扩展性不明确。
- **基准仍以合成或半合成场景为主**：RHELM 为合成人设，ATM-Bench 虽基于个人记录但经过基准化处理；真实用户历史的噪声、隐私约束与长期漂移是否同样适用，尚缺用户研究验证。
- **QA 监督的覆盖面受生成器能力限制**：证据化规划倾向于可被材料包支撑的事实型问题，对主观偏好、时序推理、跨包长程依赖或需要外部常识的问题覆盖可能不足，进而使优化偏向“可验证型”记忆能力。
- **材料包采样可能引入偏差**：图引导采样受上下文预算与种子节点选择影响，若关键证据未被纳入材料包，则相应能力无法进入监督信号，存在系统性遗漏风险。
- **优化轮数与接受准则较固定**：每组设置固定运行 20 轮，仅以验证集准确率严格提升作为接受条件，未深入分析收敛性、早停策略或对验证集规模的敏感性。
- **基线比较存在一定信息泄露瑕疵**：Official-QA 基线使用部分官方 QA 做训练/验证且这些题仍在评估集中（以 † 标注），虽已说明，但严格公平性仍受影响；MemSteer 侧虽避免使用官方 QA，但训练/验证集来自同一生成流程，分布一致性可能带来乐观偏差。
- **多模态利用有限**：ATM-Bench 含图像、视频记录，但 QA 生成与证据审计主要围绕文本跨度展开，视觉证据的检索与验证机制讨论不足。
- **隐私与安全讨论不足**：从个人邮件、文档生成 QA 并用于设计优化，涉及敏感信息抽取与存储；论文未系统讨论脱敏、访问控制或生成数据泄漏风险。

## 8. 启示与未来方向

- **“无标注历史→证据化 QA→设计优化”形成可复用范式**：该方法把记忆设计优化从依赖下游反馈转为依赖历史自身的可验证结构，为缺少显式反馈的个人化智能体提供了一条自监督路径。
- **证据归因诊断具有跨系统迁移价值**：存储/检索/回答三阶段失败归因不绑定特定记忆架构，可嵌入其他记忆优化器或 Agent 自反思流程，作为“可解释的优化信号”。
- **监督质量优先于监督数量**：消融显示证据化规划与来源审计是质量关键，未来可进一步研究更轻量的校验机制，在成本与质量间取得更好平衡。
- **持续与个性化适配值得深入**：跨用户实验提示“共享设计+目标侧继续优化”是现实部署形态，未来可研究在线增量生成监督、漂移检测与隐私保护下的本地化优化。
- **需要更真实的评估生态**：包括真实用户长期历史、多模态证据、主观与开放问题的标注协议，以及报告算力/费用预算的可复现性规范。
- **可与主动交互结合**：当历史证据不足或存在歧义时，让智能体主动向用户澄清，再把澄清结果纳入监督，可能进一步提升记忆设计的实用性与用户信任。
