## 摘要
数据集搜索仍是数据分析工作流中的瓶颈，因为现有系统主要依赖关键词匹配或浅层检索，难以捕捉用户意图。为促进意图驱动的搜索，我们提出两个检索组件，通过自然语言为多维度数据集搜索界面提供支持。首先，我们提出假设模式嵌入（Hypothetical Schema Embeddings, HySE），其利用语言模型生成与任务对齐的假设性表格模式，并将这些模式用于基于嵌入的检索，从而弥合意图与表格内容之间的差距。我们引入 KaggleDS，这是一个包含 6,503 张表以及源自 Kaggle 的多样化任务查询的语料库，并表明 HySE 在召回率上稳定优于强关键词基线和基于嵌入的基线，也优于在 KaggleDS 上微调的稠密表格检索器。我们还表明，HySE 可泛化到端到端问答，例如在 NQ-Tables 数据集上——该数据集包含 169,898 张维基百科表格及人工编写的查询——HySE 将 Recall@10 相比稠密检索基线提升了 +6.0 个百分点。其次，我们引入 FlexPrune，它将用自然语言表达的数据集约束转换为作用于可定制元数据索引的 SQL 谓词，从而能够跨任意元数据属性进行过滤。与 HySE 结合后，FlexPrune 相比先进行稠密检索再进行基于标签的过滤，将 Recall@10 提升了 +6.0 个百分点。我们的结果表明，支持任务查询和元数据查询的基于自然语言的检索，为数据集搜索中模式级关键词搜索提供了一种可行的替代方案。

## Abstract
Dataset search remains a bottleneck in data analysis workflows, as existing systems largely rely on keyword matching or shallow retrieval that fail to capture user intent. To facilitate intent-driven search, we present two retrieval components to equip multi-faceted dataset search interfaces through natural language. First, we propose Hypothetical Schema Embeddings (HySE) that uses a language model to generate task-aligned hypothetical table schemas which are used for embedding-based retrieval, bridging the gap between intent and table content. We introduce KaggleDS, a corpus comprising 6,503 tables and diverse task-queries derived from Kaggle, and show that HySE consistently improves recall over strong keyword and embedding-based baselines, as well as over a dense table retriever fine-tuned on KaggleDS. We also show that HySE generalizes to end-to-end question answering on, for example, the NQ-Tables dataset, a corpus of 169,898 Wikipedia tables with human-written queries, where HySE improves Recall@10 by +6.0 pp over dense retrieval baselines. Second, we introduce FlexPrune, which translates dataset constraints expressed in natural-language into SQL predicates over a customizable metadata index, enabling filtering across arbitrary metadata attributes. Combined with HySE, FlexPrune increases Recall@10 by +6.0 pp over dense retrieval followed by tag-based filtering. Our results show that natural-language-based retrieval supporting task and metadata queries offers a viable alternative to schema-level keyword search in dataset search.
