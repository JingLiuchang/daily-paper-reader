## 摘要
近似最近邻搜索（ANNS）在高维空间中检索与查询向量最相似的向量。标签过滤近似最近邻搜索（LFANNS）在 ANNS 的基础上引入标签过滤器，要求基向量的标签与查询标签满足某种集合关系（例如相等、包含或重叠）。现有 LFANNS 索引在不同过滤类型下性能不一致，并且在标签规模和分布变化时可扩展性下降。本文定义了标签分层相似图（LSSG），其中边连接标签集位于分层相似度阈值内的邻近向量。为高效实现 LSSG，我们设计了一种增量插入算法，在向量空间和标签空间中剪枝冗余边，并利用 MinHash 结构确保对大规模标签的可扩展性。我们在显式标签模型下分析逐步概率，并解释为何更严格的标签层级能够减少无效的过滤内扩展。基准实验表明，LSSG 对相等查询达到了理想最优性；在精度相同且索引大小为 0.35 倍的情况下，其在包含和重叠查询上的查询速度分别比最佳竞争索引快 1.06 倍至 92.9 倍和 1.08 倍至 84.1 倍。

## Abstract
Approximate nearest neighbor search (ANNS) retrieves the most similar vectors to a query vector in high-dimensional space. Label-filtering ANNS (LFANNS) extends ANNS with a label filter that the labels of base vectors must satisfy a set relation (e.g., equality, containment, or overlap) with the query labels. Existing LFANNS indices suffer from inconsistent performance across different filter types and degraded scalability under varying label scale and distribution. In this paper, we define label-stratified similarity graph (LSSG), where edges connect neighboring vectors whose label sets fall within stratified similarity thresholds. To implement LSSG efficiently, we design an incremental insertion algorithm to prune redundant edges in both vector and label spaces, and leverage a MinHash structure to ensure scalability for large-scale labels. We analyze stepwise probabilities under explicit label models and explain why stricter label tiers reduce ineffective in-filtering expansions. Benchmark experiments show that LSSG achieves ideal optimality for equality queries, and 1.06x-92.9x and 1.08x-84.1x faster than the best competing index for containment and overlap, respectively, in query speed with identical accuracy and 0.35x index size.

# 论文总结：通过渐进式标签集分层实现快速标签过滤近似最近邻搜索

## 1. 核心问题与整体含义

- **研究背景**：近似最近邻搜索（ANNS）是高维向量检索的基础操作，广泛应用于向量数据库、搜索引擎、检索增强生成（RAG）等场景。图基 ANNS 索引因其查询速度快、精度高而成为主流。
- **问题定义**：标签过滤 ANNS（LFANNS）在 ANNS 基础上引入标签过滤器，要求基向量的标签集与查询标签集满足三种集合关系之一：
  - **相等过滤（Equality）**：标签集完全一致；
  - **包含过滤（Containment）**：查询标签集是基向量标签集的子集；
  - **重叠过滤（Overlap）**：查询标签集与基向量标签集至少共享一个标签。
- **现有方案的三类缺陷**：
  - 预过滤（Pre-filtering）：对过滤子集线性扫描，子集大时效率低；
  - 后过滤（Post-filtering）：先检索再过滤，选择性高时返回不足 k 个结果；
  - 过滤内（In-filtering）：图遍历时动态检查过滤条件，但过滤严格时图连通性下降，易陷入局部最优。
- **两大核心挑战**：
  - **挑战 1（语义一致性）**：不同过滤类型的标签集合关系本质不同（精确匹配、超/子集、部分交集），难以用统一索引高效支持。现有索引通常只擅长一种语义，跨语义性能不一致。
  - **挑战 2（标签特征鲁棒性）**：标签空间扩大时不同标签集组合呈指数增长，索引体积或查询延迟急剧恶化；且多数索引假设标签服从幂律分布，分布趋于均匀时标签共享机会减少，索引碎片化严重。
- **整体意义**：本文提出统一的 LFANNS 索引范式，试图在单一索引中同时支持三种过滤语义，并在标签规模、分布、选择性等变化下保持鲁棒性与可扩展性。

## 2. 方法论

### 2.1 核心思想：标签分层相似图（LSSG）

- **距离视角统一语义**：将三种标签集关系解释为标签集距离的不同程度，按标签集相似度将顶点分层，每层施加不同的标签距离上界。
- **分层结构**：图 G 的边集划分为 T 个子集，第 t 层子图 G_t 中边满足：
  - **约束 C1（向量空间 RNG 多样化）**：对任意第三点 v_k，边 v_i→v_j 需满足 δ_v(v_i,v_j) < δ_v(v_i,v_k) 或 δ_v(v_i,v_j) < δ_v(v_j,v_k)，即标准 RNG 式剪枝；
  - **约束 C2（标签分层与多样化）**：δ_L(l(v_i), l(v_j)) ≤ θ_t，且对更近的邻居 v_k 要求 δ_L(l(v_j), l(v_k)) ≥ θ_t。
  - 阈值设定：θ_t = 1 - (t-1)/(T-1)，从底层的 1（标签无关，保证全局导航）逐步收紧到顶层的 0（仅连接标签集完全相同的顶点）。
- **直观解释**：底层保留全局可达性，上层提供标签一致的捷径，使过滤内遍历能从局部最优中逃脱。查询时从随机合法入口出发，低层遍历卡住时向更高层升级，借助更严格的标签一致性边跳出局部极小。

### 2.2 关键技术细节

- **相似标签集选择**（Alg. 1）：避免 O(|L|²) 全对计算，提供两种策略：
  - **渐进式 IVF 扫描**：按标签频率升序合并位图，直到候选预算 φ 用尽，低频率标签优先提高选择性；
  - **渐进式 MinHash 探测**：将标签集签名分 β 个 band，利用 LSH 碰撞概率优先检索高 Jaccard 相似度的标签集。
- **MinHash 碰撞概率定理（Theorem 3.1）**：对 J(L₁,L₂) ≥ 1-θ_t 的标签集，至少在一个 band 碰撞的概率下界为
  - P_collide ≥ 1 - [1 - (1-θ_t)^r]^β，其中 r = τ/β。
- **多层级插入算法**（Alg. 2）：四阶段流程
  1. 标签集注册（IVF 位图 + MinHash 签名）；
  2. 相似标签集选择（Alg. 1）并缓存 δ_L；
  3. 逐层过滤候选（δ_L ∈ (0, θ_t]），必要时 beam search 补充；
  4. 双空间剪枝与边更新：RNGPrune（向量空间去冗余）+ LabelPrune（标签空间多样化）。
- **过滤内遍历与查询**（Alg. 3、Alg. 4）：
  - 根据过滤类型构造标签集作用域 L_q（相等为 {L_q}，包含为位图交集，重叠为位图并集）；
  - 从多个合法标签集区域选取入口，逐层扫描邻居，仅保留标签合规的顶点，每轮限制新访问候选数不超过 m；
  - 用 min-heap 和 max-heap 维护候选与结果，标准 beam search 早停。
- **理论分析**：
  - 定义逐步过滤有效扩展概率 Pr(u' ∈ U)，即从合法顶点出发扩展仍为合法顶点的概率；
  - **相等**：顶层 θ_T = 0 时 P_e = 1（理想保持）；
  - **包含**：在独立 Bernoulli 模型下，P_c ≥ (1-p_max)^((1-ε)|A|)；在 Zipf 偏斜分布下给出更紧的下界（Theorem 4.2），说明高频标签在高 Jaccard 约束下不易出现在差集中；
  - **重叠**：P_o ≥ ε（Theorem 4.3）；
  - **复杂度**：索引空间 O(m|V|T)，索引时间期望 O(|V| log|V|)，查询时间期望 E[C_query] = C_scope + O(α_f⁻¹ η_q log|V_{f,L_q}|)。

## 6. 主要结论与发现

- **相等查询**：LSSG 达到理想最优性（顶层仅连接相同标签集），与 UNG 并列最佳；UNG 在部分数据集精度略高，但归因于静态 Vamana 底层而非标签过滤机制。
- **包含查询**：LSSG 整体最强，LSSG-MinHash 比最强基线 UNG 平均快 2.95x，在 YTB-Audio 上比 ELI 快 92.9x。
- **重叠查询**：LSSG 与 ACORN 整体最强；LSSG-MinHash 在 YTB-Video 上比 ELI 快 84.1x，在 YFCC-1M 上比 UNG 快 99.8x。
- **索引效率**：LSSG 索引大小为 UNG 的 0.82–0.84x，为 ELI 的约 0.35x；LSSG-MinHash 索引时间为 UNG 的 0.78x、ELI 的 0.87x。
- **鲁棒性**：在标签空间扩大（|A| 从 128 到 8,192）、标签分布从 Zipf 到 Uniform/Poisson/Multinomial、插入漂移（未见标签、频率反转）下，LSSG 均保持稳定；UNG 和 ELI 在均匀分布或大规模标签下显著退化。
- **与库/数据库对比**：FAISS/VSAG/Milvus/PGVector 在高召回下 QPS 远低于 LSSG（部分场景仅 16–41 QPS 或无法达到 0.95 召回）。
- **理论验证**：过滤有效扩展比随层严格度上升而提高（
